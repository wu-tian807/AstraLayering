# v2 参考动作与 v1 问题独立分析

结论：**v1 需返修。** 单独证明控件会改变形状，并不足以证明动作符合参考视频。当前最关键的是俯仰和手臂方向错误、普通嘴型过高、近侧手臂被静态服装层吞掉，以及身体动作/发束惯性在画面上表现不足。此报告为分析，不是 v2 成品验收。

本轮没有修改 v1 或 v2 实现，只在本目录写入分析脚本、冻结受审 HTML、参考帧、截图与报告。

## 核心发现与修正建议

### R01 / P1：headY 与 bodyY 的俯仰方向相反

**依据：** 0.50s 与 15.30s 原视频明显低头闭眼，发顶、脸和肩部相对背景下沉；这时红点 `headY` 约 +12、`bodyY` 约 +8。14.9→15.3s 向下点头，15.5→15.7s 抬回。`sequence-nod.jpg` 清楚显示连续过程；对应的 `exact-00.50.jpg`、`exact-15.30.jpg` 包含参数红点。

v1 却在 `headWarp` 使用 `-sin(py)×depth`，在 `bodyWarp` 使用 `y-=bodyY×.9`，正值使头与上半身上移。更关键的是 bodyY 几乎只做平移，缺少胸肩前俯和颈部压缩；即使反号后仍需改体积关系。

**建议：** 统一为视频中的“正值低头/前俯”，或仅在轨迹映射处反号一次。低头应连带眼鼻口在头部体积上的投影、下巴/颈部的缩短、肩胸的前俯；身体与头保留各自轨迹，不全部锁成一个刚性组。

### R02 / P1：手臂转动正负与参考动作相反

**依据：** 1.00s 视频双手向两侧打开，轨迹 `armL=-7.5`、`elbowL=-9.13`、`wristL=-4.02`；v1 同时却把手臂向内收。3.00s 与 6.00s 视频把手放到背后，`elbowL≈+27`、`wristL≈+9`；v1 却明显张开手臂。

证据：`exact-01.00.jpg` / `exact-03.00.jpg` / `exact-06.00.jpg` 与 `v1-at-1.png` / `v1-at-3.png` / `v1-at-6.png`。

**建议：** 轨迹到关节姿态重新标定：参考正值应向内、向后收；负值为外展。背后收手应有真实前后深度，不只是画面内旋转。右臂也不能只是左臂幅度乘 .35–.45 后长期形成不符合视频的左右不对称。

### R03 / P1：服装静态压住整个近侧手臂

**复现：** `MillyRig.set({armL:-30,elbowL:-30,bodyX:10})`，人物左臂（屏幕右侧）从肩以下大段消失在服装后，手却又从另一侧露出；右侧镜像同样发生。`v1-armL-in.png`、`v1-armR-in.png`、`v1-cross-both.png`。

**建议：** 根据手臂动作语义与实际深度排列服装、上臂、前臂和手。普通前伸与近侧手的可见段应绘在服装前，放背后的动作才在躯干后；不能把全体手臂固定在服装下，也不能简单把全体手臂永远搬到最上层。排序阈值保留连续过渡或滞后，避免过中线闪跳。

### R04 / P1：普通讲话张嘴过高，不是开闭方向错误

**依据：** 1.00s/6.00s 源视频为普通开口微笑，嘴张幅适中。1s 源口腔约高 27px、宽 53px，高宽比约 .5（目视测量）；v1 同时的开口接近高宽比 1，并占据明显更多下半脸。`mouth-detail-ref-1.png` 与 `mouth-detail-v1-1.png` 为诊断裁切。

v1 当前 `low=cy+o×25`，而反向归一后 1s、6s 的 `o≈1`，所以轨迹会长时间触发过大的嘴，不是降低默认 mouthOpen 就能解决。

**建议：** 常规 `o=1` 先按 12–14 SVG 单位高度校准（当前宽度约 25–29），再通过专用惊讶预设或非线性上段提供夸张张嘴。同步压低下巴联动，使普通说话不拖长脸。以高宽比和嘴至下巴距离验收，而不只看参数值。

### R05 / P2：躯干的视觉运动少，不能仅靠加快播放修复

**依据：** 2.3–3.2s、4.4–5.0s 原视频都有清晰的肩胸转向与侧倾，头相对肩线继续调整；v1 对应时刻主要表现为整块脸/身体的小平移、对称压宽和画面内转动。原轨迹 bodyX 在 2.3s 约 +5.65，3.2s 约 −5.43，5.0s 约 +9.02，事件其实已在数据中。

v1 记录的 24 路轨迹均有 450 个采样，没有标记缺失；数值变化时间并未大段冻结。轨迹的动作停留与转向快段应保留，例如 1.8–2.1s 是相对停留，2.3–3.1s 是转向，不应强加匀速正弦使整段一直摇摆。

**建议：** 保留源节奏，增强肩胸/腰/髋分段的可读形变：近远肩宽与高度、胸腔中线、领口弧度和躯干侧弯；头脸远近侧应有投影差异，避免整块宽度同时缩放。以 2.3、3.0、4.4、5.0、15.3s 作关键姿态对照。headZ 在 1s 的负值与源画面的负倾斜基本一致，不宜把所有轴一键反号。

### R06 / P2：发束缺少由全身运动驱动的迟滞

**依据：** `sequence-turn-1.jpg` 的 2.7–3.3s、`sequence-turn-2.jpg` 的 4.7–5.4s 中，发根随头转向，侧发卷梢随后继续外摆、回收；呆毛环形既改变位置，也改变曲率。15.2–15.7s 点头抬回时，呆毛与侧发又有明显不同步的回弹。这个迟滞是数帧到数个 0.1s 的量级；没有将其宣称为已拟合的精确物理常数。

v1 的惯性输入只来自 `headX×.45+headZ×.7` 的速度，没有 headY 或身体驱动，且目标偏移仅乘 .035。常见轨迹角速度下偏移很小，所以即使有弹簧变量，视觉上仍近似整块头发一起移动。

**建议：** 从头根/头肩的实际变换速度和加速度驱动发束。固定根部，中段与末端用不同阻尼/刚度与相位；侧卷要有扭转和弧度变化，呆毛使用自己的柔软曲线。静止后允许短暂余振但应收敛，发夹作为刚性附件跟随所夹发束。不靠新增手动摆动方向滑杆来冒充运动产生的物理效果。

## 参数方向核对：应保留的反向项

这份视频的滑杆画面确实存在与常见约定相反的显示方式，不能因为标签写着 0/1 就假定 1 必然张开。

| 项目 | 视频可见依据 | v1 方向结论 |
| --- | --- | --- |
| 眼开闭 | 3s 人物右眼（屏幕左眼）闭合，右眼开闭红点在右端约1；9s 双眼闭合，两个红点均在右端 | 反向归一正确，应保留 |
| 眼微笑 | 9s 双眼闭笑时微笑红点在左端约0；0.5s 普通闭眼时在右端约1 | 反向归一正确，应保留 |
| 嘴开闭 | 12s 嘴关闭，红点在右端约1；1s 普通张嘴，红点在左端约0 | 反向归一正确；应修张幅曲线 |
| 嘴变形 | 12s 愁嘴对应正端；3s 微笑对应负端 | v1 的 mouthForm 反号有依据 |
| headY/bodyY | 0.5s、15.3s 正值对应低头前俯 | v1 几何方向需要改 |
| 手臂关节 | 1s 负值外展，3s/6s 正值收背 | v1 几何方向需要改 |

源轨迹用 15 fps 提取，而视频为 30 fps；提取滤镜选帧可引入约一帧的时间差，快速眨眼应以精确源帧为准。改变映射时还应保留滑杆实际端点校准，避免把取样边框范围当作红点中心范围。

## 播放时钟核对

普通负载实测：1440×1000 headless Chromium 中 7.519 秒墙钟对应轨迹 7.533 秒，约 55–60 fps。**未证实普通负载存在整体慢放。** 但 v1 使用截断到 .04 秒的 dt 同时推进物理与轨迹，低于 25 fps 时会变成慢放；建议墙钟时间推进轨迹，物理独立分步积分。这个隐患不能替代上述姿态方向、体积和惯性问题的修复。

## v2 复验重点

1. 同时对照 1s 外展、3s 收背、15.3s 低头；检查前后关系和头身动作方向。
2. 以普通轨迹而非只用极限滑杆，检查嘴高宽比和下巴变化。
3. 播放 2.6–3.5s 与 4.6–5.6s，确认侧发/呆毛有迟滞和收敛，发根不裂、发夹不漂。
4. 让手臂跨到躯干前、后及左右转身，检查近侧前臂与手不被服装错误遮住。
5. 对比一段等墙钟时长的播放与参考，不用提高全局速度掩盖躯干动作不明显。
