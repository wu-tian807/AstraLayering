# Milly 动画演示 v2

打开本目录的 `index.html`，或访问 <http://127.0.0.1:8765/v2/>。v1 保留在上一级目录，页面右上角可以切回。HTML 内嵌模型、动作轨迹和运行代码，可以直接本地打开；参考视频使用同目录的 `reference.mp4`。

## 这版的调整

- 上臂、前臂和手分别处理。肩部接缝保持在躯干和肩带下；前臂与手在尚处于躯干外侧时进入后方，再向内收背，避免在遮挡重叠处换层或横向截断皮肤。双臂外展时前臂位于服装前；同时纠正视频手臂参数的动作方向。
- 身体加入胸肩、腰髋的不同形变权重与前后深度，衣服后片和侧片随之转动。恢复视频中低头、前俯的正确方向，并保留视频的停留、转向和点头节奏。
- 脸部使用有限幅度的转角和独立五官锚点：远侧适度缩小，近侧保持形状，避免把眼睛与下巴整体扭斜。常规讲话缩小嘴巴张幅，嘴型变化连续过渡。
- 16 片头发加独立呆毛。头顶实际移动的速度与加速度驱动物理，包含头部 XYZ 和身体的转向、俯仰、侧倾；发根固定，中段和末端分别计算惯性、弹性与阻尼。侧发、刘海和呆毛使用不同响应，呆毛更软、摆动更明显，停止动作后回弹并收敛。
- 取消手工指定头发摆向的滑杆。物理面板只保留刚度、阻尼、风力与物理强度；默认风力为 0，正常摆动来自人物姿态。这些设置在播放过程中也可调整。
- 鼠标跟随带动头部、视线与身体，身体稍慢于头部；手动姿态平滑过渡。循环末尾回到开头时保留物理连续性。

## 操作

默认播放 30 秒参考动作。可以暂停、拖动时间轴、改变播放速度，或打开参考视频对照。

姿态滑杆会切换到手动模式并保留当前姿态；「参考动作」恢复播放。「头部 / 物理」中的四项物理设置可边播放边调整。测试惯性时保持风力为 0，拖动角色或开启鼠标跟随，转向后停下观察发梢与呆毛的回摆。

左右以人物自身方向为准。头部 Y、身体 Y 的正值表示低头、前俯。手臂角度正值向内收，肩肘一起收起时手臂移到背后，负值向外展开。

40 个可调参数覆盖视频的 24 路参数，并增加对侧眉臂、眼球、视线及头发物理设置。「拆分检查」可以隐藏部件、单独查看服装背片和侧片。三项裙摆参数控制新增的可选测试裙，调节时自动显示；基础服仍沿用 05-2。

「导出参数 / 载入参数」保存和恢复当前设置。手动模式导出滑杆的目标值，避免平滑过渡尚未完成时保存成中间姿态。

## 文件与验证

- `index.html`：自包含交互演示。
- `milly-animation.svg`：细分、补全后的中性分层 SVG。
- `rig.js`、`template.html`、`build.py`：实现与构建入口。重新生成 HTML 使用 `python3 rigging/milly/v2/build.py`。
- `motion-tracks.json`：从原视频滑杆按 15 fps 提取的 24 路轨迹，播放时连续插值。
- `parameter-map.json`：40 个参数的名称、范围、默认值和分组。
- `rig-manifest.json`：部件清单及 05-2 源文件哈希。
- `v1-preservation.json`：v1 交付文件的保留校验值。
- `evidence/validation.json`：38 项姿态/外力控件的画面变化、参数导入导出、参考视频、时间轴、移动布局及本地打开检查。
- `evidence/physics-controls.json`：另两项刚度/阻尼的动态响应、无风姿态驱动、呆毛根部固定、身体跟随延迟和播放中物理设置检查。
- `evidence/dynamics/`：平滑转向及参考转向、点头的连续帧与物理状态。
- `evidence/reference-review/`：视频逐帧分析与 v1 问题证据。
- `evidence/candidate-review/`：独立视觉复验、修正项及复验截图。

本版是 SVG 程序性动画 demo，复现参考的动作语义、节奏与参数覆盖，并非视频原模型的逐像素复刻，也不是 Cubism 工程。服装补全服务于当前有限转角，不支持 360° 转身。保留 05-2 的颜色材质，没有新增阴影制作或投影剪切系统。

程序调用：`MillyRig.set({headX:20, bodyX:5}, {smooth:true})` 平滑转向；`MillyRig.seek(3)` 定位参考动作并重置物理，适合静态对照。动态惯性请通过播放或平滑转向观察。`MillyRig.parameters` 是手动目标参数，`renderedParameters` 是当前过渡中的姿态，`physics` 提供发束物理状态。
