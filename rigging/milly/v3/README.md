# Milly 动画演示 v3

打开 `index.html`，或访问 <http://127.0.0.1:8765/v3/>。v1 和 v2 原文件均保留；页面右上角可切回 v2。

## 这次为什么会出现纸片感与接缝

v2 的脸底形使用近似平面的深度，眼睛与嘴巴主要移动锚点，局部形状没有完整跟随脸表面的方向；头发又有较大的独立位移。转头时这些部件之间的运动不一致，容易被看成几张平面在滑动。过大的转向和脸宽收缩进一步放大了这种观感。

身体接缝另有明确原因：骨盆底部的闭合线、肩部连接区域的边线本应藏在部件重叠内部，却作为可见墨线画出。v2 将腿部放在躯干下方，还让这些隐藏封口暴露在衣服腿口之外。

## 本次修正

- 保留头部 X 的 −30～30 控件范围，但将实际可见偏转限制在约 ±11.7°，俯仰约 ±11.5°。取消参考轨迹额外的横向转头放大。
- 脸型、五官、鼻子、面颊颜色共用横纵连续的曲面。眼睛、嘴巴和眉毛的局部方向、缩放来自同一个表面的切线，并作保守限幅。发根仍随头部，减少前后发与脸的过量滑移。
- 同样的左右极限测试中，脸宽变化约从 v2 的 7.2% 降至 2.2%；两眼相对于各自正面宽度约保持近侧 +2%、远侧 −3.4%，嘴型随表面小幅调整。
- 填充底形继续完整闭合，但身体墨线只留下颈部到肩接点的可见部分。腿部覆盖骨盆连接区，肩髋接触带共用深度与变形，消除横向封口和肩帽重复线。真实的服装领口、袖口及腿口包边保留。
- 收背时前臂产生适量纵深缩短与抬腕，避免交叉的双手从腿间露出。没有用新的裁切遮盖手部。
- 保留无风姿态物理、独立呆毛、头身跟随延迟和 40 个参数。材质沿用 05-2，没有新增阴影制作。

## 使用

「参考动作」播放原视频提取的约 30 秒轨迹；「手动调节」可以逐项调整。拖动角色或打开「鼠标跟随」，头部、眼神与身体联动。

「头部 / 物理」的刚度、阻尼、风力和强度可以边播放边调。风力默认 0，头发仍会由人物运动带动。时间轴定位会重置惯性；观察滞后与回弹请使用播放或平滑拖动。

支持表情预设、暂停、速度选择、参考视频查看、部件开关、可选裙摆测试、参数导出与载入。HTML 内嵌模型与代码，直接本地打开即可运行；参考视频使用同目录 `reference.mp4`。

## 文件

- `index.html`：交互演示。
- `milly-animation.svg`：修正后的分层 SVG。
- `build.py`、`rig.js`、`template.html`：构建入口与实现。修改后执行 `python3 rigging/milly/v3/build.py`。
- `parameter-map.json`、`motion-tracks.json`、`rig-manifest.json`：参数、参考动作及部件清单。
- `v2-preservation.json`：v2 文件的保留校验值。
- `evidence/comparison-body-neutral.png`、`comparison-body-turn.png`：左 v2、右 v3 的接缝对照。
- `evidence/head-range-v3.png`：左、中、右最大视角对照。
- `evidence/validation.json`、`physics-controls.json`：控件、保存、视频、移动布局及物理检查。
- `evidence/root-cause-review/`：用户四张参考图与独立根因分析。
- `evidence/independent-review/`：独立视觉与连续动作复验。

这是适合有限转角的 SVG 程序性演示，沿用 05-2 角色，不是视频原模型或 Cubism 工程。
