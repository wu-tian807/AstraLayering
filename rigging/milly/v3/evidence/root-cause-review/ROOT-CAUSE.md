# v3 有界根因分析

用户反馈成立。本次只分析四张用户截图和v2结构/变形代码，未改实现，未重复历史测试，也不是v3验收。v2版本哈希见 `v2-versions.json`。

**髋部横线**：`body-core-contour` 从两侧髋部经 `C438 747 474 747 505 746 C537 747 575 747 598 739` 画出整个骨盆底部封口。运行时 legs层20在body层25后，封口从高叉服装腿口外露出，成为横跨大腿根的“零件接缝”。这不是服装包边。证据 `user-v2-seams.png`。

**肩部关节帽**：同一body轮廓从约421,346沿414,376到420,399继续画出肩内侧封闭边；upper-arm固定在body后，原本用于重叠补全的边界露在皮肤上，再与arm-inner-contour及bodysuit-armhole-binding形成两条平行线。应由一个可见外轮廓负责肩部，连接内部不留封口墨线。

**填色接缝风险**：legs使用depth0，body使用clothDepth(...,12)，upper-arm由10向-38变化；连接区的同一个解剖接触点经过不同变形场，层级变化只是把错位显示出来。body填充又压在独立腿部渐变上，可能沿旧底形终点截断渐变。删墨线后仍需统一接触带的运动和底色延续。

建议保留闭合填充底形，把可见墨线拆开：body-core仅保留颈到肩接点的真正外缘（左约443,338，右约569,338）；删除内部肩封口和骨盆封口；髋外缘由leg-contour负责，保留衣服腿口包边。肩髋接触带共用变形/深度并保持填充重叠，衔接已有渐变，无需新增阴影蒙版。

**头部贴片感**：face深度18+12仅随y变化，横向颊面基本还是平面；features固定38、nose57、hair最高约60，使脸、五官和头发在转动时以不同幅度滑动。featureWarp只投影锚点，本地sy在最大pitch仍约0.975，脸廓却进行完整pitch投影，视觉上像五官贴在移动的平板上。headX最大实际约21.5°，近/远眼sx约1.01/0.88；用户两张Live2D截图显示的是轻微左右偏转和温和的近远大小差，并非这种幅度。证据 `user-live2d-a.png`、`user-live2d-b.png`、`user-v2-flat-face.png`。

建议先收小普通动作映射：有效yaw约8–12°作为起点，再独立目视，近远眼宽差先控制约3–6%；这些是待调起点，不是从参考测得的精确值。脸/五官共享随x/y连续的颅面坐标场，鼻只作小凸起；五官局部方向和缩放也来自同表面再限幅。近颊、远颊、下颌采用受控弧线变化，保持脸宽和自然下巴，避免整体cos压缩/平移。头发根跟颅顶，原物理留给发梢。两张参考用于运动幅度和体积关系，保留Milly自身中性脸型，不把另一角色脸型照搬。

上一轮review对层级交接的通过不能覆盖这些漏检的可见结构接缝；v3复验应把用户这两张Milly截图所示位置作为必检项。
