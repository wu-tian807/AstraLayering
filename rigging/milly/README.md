# Milly SVG 动画演示

直接打开 `index.html` 即可。动画、SVG 和动作数据都内嵌在 HTML 中，无需安装软件或联网；同目录的 `reference.mp4` 供「查看参考视频」使用。

## 操作

- 默认播放约 30 秒参考动作。暂停、拖时间轴或改变播放速度可观察细节。
- 拖动任一滑杆或输入数值，立即切换到手动模式，保留当时的姿态。
- 「表情」提供单眼开闭、闭眼笑、视线、眼珠缩放、高光、嘴型和左右眉毛。
- 「头发 / 头部」提供头部 XYZ、刘海、两侧发、后发、呆毛、风力和物理强度。
- 「身体」提供身体 XYZ、呼吸、双臂肩肘腕及手形、三路裙摆物理。
- 拖动角色或开启「鼠标跟随」可以转头；滚轮缩放。半身、面部、全身视图可切换。
- 调节裙摆参数时自动显示新增的裙摆测试件。关闭「裙摆测试层」回到原基础服。
- 「拆分检查」可单独隐藏前发、侧发、后发、五官或服装前片，并检查完整背片和侧片。
- 「导出参数 / 载入参数」保存和恢复当前姿态；「重置姿态」恢复中性参数。
- 左右以人物自身方向为准。X 是左右转动，Y 是俯仰，Z 是画面内侧倾。

## 本轮改动

基于 `outputs/milly_v1/step05-base-character/05-2_局部色彩与材质.svg`，原文件未改动。

- 刘海 7 片、两侧发各 3 片、后发 3 片，加独立呆毛；发根与头顶补入隐藏承接底形。发束保留原矢量细节，以重叠裁切形成独立运动片。
- 左右眼分离眼白、虹膜、瞳孔、高光、上眼睑、下眼睑及睫毛；开闭时改变眼眶遮挡，眼珠本身保持完整。
- 嘴部补齐口腔、上牙、下牙、舌头及上下唇。嘴型、张嘴程度与下巴微调联动。
- 脸型、五官、耳朵及前后发使用不同深度和局部变形，支持头部 XYZ 组合。
- 连体服补充完整后片、后领及两侧回折片。转身时前后表面在侧轮廓处收拢，避免整片平移产生突角。
- 身体和手臂使用连续变形，肩、肘、腕及手形可以独立控制。保留原 SVG 的手部细节，不增加单根手指参数。
- 另绘可切换的裙摆前后片与褶片，承载视频中三路裙子物理参数。
- 沿用 05-2 的颜色和材质，并让渐变跟随各部件变形。没有新增动态投影或阴影剪切系统；眼口与发片分割所需的遮挡仍使用蒙版。

## 视频参数覆盖

视频画面共有 24 项，这些参数全部有实际的形变实现：

| 视频参数 | 范围 | 实现 |
|---|---|---|
| 左眉上下、左右、变形、角度 | −1～1 | 独立眉毛位移、曲率、旋转 |
| 头部 X / Y / Z | −30～30 | 脸型与五官透视、俯仰、侧倾 |
| 左眼开闭、右眼开闭 | 0～1 | 独立眼眶与上下睑变形 |
| 左眼微笑、右眼微笑 | 0～1 | 闭眼弧度与眼睑形态 |
| 呼吸 | 0～1 | 胸肩扩张与轻微升降 |
| 嘴巴开闭、嘴巴变形 | 0～1 / −1～1 | 口腔开口、悲喜嘴型与下巴 |
| 左大臂转、左小臂转 | −30～30 | 肩肘连续变形 |
| 左手转、左手变形 | −10～10 / −1～1 | 腕部旋转与手部弯曲 |
| 身体 X / Y / Z | −10～10 | 前后片转身、俯仰和腰部摆动 |
| 裙子物理 1 / 2 / 3 | −1～1 | 横摆、前后扭转、开合 |

另加右眉四项、右臂四项、视线两项、眼珠缩放、高光、五路头发控制、风力和物理强度，共 **43 个可调参数**。

## 动作来源与边界

`motion-tracks.json` 按 15 fps 读取所给视频中红色滑杆的位置，并对方向、中心点作校准；页面在帧间连续插值。右眉和右臂补了对应联动，发束增加阻尼回弹。

这是基于 SVG 的程序性演示：沿用视频的动作节奏和参数覆盖，并非视频原模型的逐像素复刻，也不是 Cubism 工程或 `.moc3`。基础服继续使用 05-2，没有替换成视频的完整水手服。补全服装用于所提供的有限转身范围，不包含 360° 背面角色。

## 文件

- `index.html`：可直接打开的交互演示。
- `milly-animation.svg`：细分、补全后的中性分层 SVG。
- `rig-manifest.json`：部件和源文件哈希。
- `motion-tracks.json`：视频滑杆采样轨迹。
- `parameter-map.json`：全部参数的名称、范围、默认值与分组。
- `reference.mp4`：用户给定参考视频的本地副本。
- `rig.js`、`template.html`、`build.py`：可继续调整的实现和构建入口。构建需 Python 与 lxml；运行演示本身无依赖。
- `evidence/validation.json`：滑杆画面实效、JSON 往返、时间轴、视频加载和本地打开检查。
- `evidence/independent-review/`：独立视觉检查及修订记录。

后续驱动可调用 `window.MillyRig.set({headX: 15, eyeLOpen: 0.5})`；`window.MillyRig.definitions` 提供参数表。手动模式下设置会保留，重新选择「参考动作」后恢复时间轴驱动。
