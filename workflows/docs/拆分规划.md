# 组、独立部件与内部拆分

本文供流程编辑时核对教程与职责。worker 直接执行各自节点内的提示词，无需读取本文。

第 2 步读取本轮 `base_subject.image`，输出独立部件清单；第 3 步逐件建立完整底形、补全与遮挡；后续按组进入部件内部拆分和线稿精修。人物以简化连体服参考为准，非人物先按实际语义对象识别。

## 三个层次

| 层次 | 含义 | 例子与制作时机 |
| --- | --- | --- |
| 1. 部件内部拆分 | 在一个完整部件内，为具体动作、画法或材质控制进一步拆分 | 左眼内的眼睑、眼白、眼黑；后续眼部专项展开 |
| 2. 独立部件 | 当前需要分别保存完整形体和遮挡关系的语义对象或基础结构 | 左眼、右眼、头脸、躯干、连体服、整副眼镜；前期识别并逐件分层 |
| 3. 组 | 组织相关独立部件的制作工作，使用 `kind` 标记 | 眼部组包含左右眼，头发组包含前后发与主要发束；后续按组精修 |

这些名称区分制作粒度。进入专项后，眼白、眼黑也会成为独立图层，并保留所属眼部的关联。前期先把第 2 层做完整，第 3 层组织后续工作，第 1 层按专项展开。

SVG 的绘制组是另一项实现安排：一个独立部件发生前后穿插时可以有多个绘制组，共享 `data-part`。同一 `kind` 的部件也可能分布在不同绘制顺序中，按类别收集不要求它们在画面上粘连或连续排列。

## 边界依据

- [旧版部件规划](../../.agents/skills/svg-layering/workflows/1.确定基础角色与补全范围/生成提示词.txt)按实际对象、替换、显隐与前后关系识别主要部件。[旧版绘制](../../.agents/skills/svg-layering/workflows/2.建立完整部件与遮挡/生成提示词.txt)已验证逐件底形、衣下身体、跨层分段和独显检查的做法，继续沿用。
- [教程的通用拆分](../../live2d-tutorial-text/2.部件拆分总原则.txt)先完成头脸、身体、肢体和整眼等部件，再进入各部位细节；[眼睛专题](../../live2d-tutorial-text/3.眼睛拆分和制作指南.txt)从整眼继续拆眼睑、眼白和眼内部件。
- [拆分与否](../../live2d-tutorial-text/13.判断拆分与否.txt)结合运动、绘制顺序、显隐、剪贴与项目规格判断精度。本流程将这些判断先应用于独立部件层，细致的内部控制在专项中继续判断。

边界主要看两点：是否需要把不同语义对象或主要身体结构分别保留下来；还是在同一个已识别部件内，为更细致的控制继续划分。衣服与身体、发饰与头发、手持物与手属于前者；眼白与眼黑、手指与指节、配件材质分片通常属于后者。用户明确指定了细粒度目标时，以本轮要求调整。

隐藏补全、真实孔洞和跨部件穿插始终属于当前独立部件的完整性。它们不能因内部细拆后置而省略。部件的可见轮廓精度也不随拆分粒度降低。

## 默认粒度与通用物件

检查范围覆盖上述全部部件专题，但只输出实际存在、被遮挡且基础动作需要补全、或确有疑义的对象。列表是观察范围，不要求为每张图补造全部项目，也不额外设计表情或替换姿势。

| 对象 | 当前独立部件层 | 后续部件内部拆分 |
| --- | --- | --- |
| 眼部 | 左眼、右眼，外形和被头发遮住的延续准确 | 上下眼睑、眼白、眼黑、睫毛及高光等功能层 |
| 嘴部 | 当前姿态下的完整嘴部，闭嘴也保留 | 嘴上、嘴下、口内、牙舌及口型所需补画 |
| 头脸 | 头脸底形、左右眉毛、鼻子、左右普通耳朵等 | 转头与表情所需的内部结构和画法细分 |
| 头发 | 前发、侧发、后发、马尾等，必要的主要发束分别保留 | 更细的发束、发丝及精细物理控制 |
| 身体与服装 | 脖子、躯干、骨盆与整件连体服，身体和衣服分别完整 | 具体形变所需的内部结构与服装细片 |
| 四肢 | 左右大臂、小臂、手、大腿、小腿、脚，关节处有搭接 | 手指、指节及更细的形变结构 |
| 配件 | 整副眼镜、整件耳坠、发饰、手持物等，与承载对象分开 | 镜片与镜框、链条与坠体、材质分片等 |
| 通用物件 | 桌子、路灯、杯子等语义对象分别保留 | 物件内部的具体活动结构、材质与装饰细分 |

通用对象先按语义与独立性保留整件，例如桌子、杯子、路灯各有自己的 part。`generic` 表示采用通用制作方法，各对象的内部拆分与分组在后续专项中确定。

半透明物件先以整件对象独立保存，其内部透明与不透明区域留到材质专项。透过它看到的后方对象仍是后方部件。色块稿的标记色仅用于结构检查，真实透明度在后续恢复。

一个配件或发束穿过其他部件前后时，当前就应分绘制段并补全；各段仍归属同一个 part。真实的环孔、指间空隙和主发束之间的开口也在当前保留。内部拆分后置不要求把这些结构压成整块。

## 清单、分层和后续组的衔接

输出为 `parts.yaml`：`subject` 和 `parts`。每个部件有稳定的 `id`、`name`、`kind`、`visibility` 和 `separate_for`；连接、包围、穿插或隐藏补全需求写入简短原因。

`parts` 列表只记录当前独立部件层，不把组作为部件条目，也不递归展开内部层。先确定 part，再标记 `kind`；身体与服装分别归入 `body`、`clothing`。输出字段沿用现有格式，三层概念不增加额外清单或分类步骤。

色块绘制以 `data-part` 对应清单 id，以 `data-kind` 记录制作组；每个 part 有真实底形，跨层分段共享 part 归属。review 核对独立部件是否齐全、形状是否贴合、底形是否完整和组合遮挡是否成立。无需为了当前验收提前画出眼白眼黑等内部功能层，也不能以后续会精修为由省略独立部件。

后续线稿按组处理相关 part，在组内展开必要的内部拆分、补画和笔触精修。通用物件可按语义对象组织专项。细看后发现分类、部件边界或遮挡错误时可以调整，并记录实际变化，复核受影响的相邻部件与整图；未改变的 part 保留原 id。后续节点的具体派发与输出随节点建立，本文件仅定义制作职责与粒度。

当前 face 先[提取脸部色盘](../templates/部件专项/face/1.脸部色盘/提示词.txt)，再由[脸型校准与绘制](../templates/部件专项/face/2.脸型校准与绘制/提示词.txt)集中处理脸型、脸底肤色和轮廓线；周围头发、眼眉等作为定位与遮挡依据，存在明确偏差时联动校准。脸底色与轮廓线分别保存，便于后续独立控制；粗稿经校形后再精修线宽和轮廓色，使线条与肤色协调。

随后用[关联部件校准](../templates/部件专项/face/3.关联部件校准/提示词.txt)检查头脸的组合关系：保留已完成脸底，对照彩图调整关联 part 的位置、外形和显露范围。关联关系可以跨越 kind，参与校准的眼、嘴、头发、颈部或配件仍留在原组；本次几何调整不代表这些专项已完成，也不重新拆分或改写清单。

[肤色与局部层次](../templates/部件专项/face/4.肤色与局部层次/提示词.txt)只处理脸底自身的肤色及连续冷暖变化。色盘辅助取色，原彩图决定分布；妆容、五官明暗和外来投影分别保留归属。

[脸部部件绘制](../templates/部件专项/face/5.脸部部件绘制/提示词.txt)结合教程的枚举方法完成眉、鼻、耳、红晕。左右眉与红晕分别独立；眉周透明，鼻标记与自身明暗可分开调整，耳根补全且隐藏封口不描线。按画法选择色面、必要结构线和柔边，避免统一粗黑描边，红晕通常以扩散色面表达。

[投影与高光效果](../templates/部件专项/face/6.投影与高光效果/提示词.txt)在部件绘制后统一整理独立效果。投影保留来源与承影对象，高光保留承载对象；静态 SVG 先裁切到目标完整表面，效果路径仍可编辑，后续据此建立动画跟随和剪切关系。每项说明实际效果或无可见依据，已有合格光影继续沿用。眼口内部、头发及配件本体由对应专项继续。

## 清单的图像依据

- **归属明确。** 图中显眼的结构与装饰应能找到所属条目；整件合并记录时说明包含范围，相邻或相似部件用位置区分。仍使用 `name` 与 `separate_for` 表达，保持现有输出结构。
- **拆分用途有依据。** 饰品可以固定，也可以摆动；按图中可见关系记录，活动方式不清楚的留给专项确认。新增替换手势或表情素材由用户本轮需求确定。
- **交付前对图核对一次。** worker 按需放大局部，补漏并澄清范围；已归属大件的内部细节继续留给专项制作。此核对在原识别任务内完成。
