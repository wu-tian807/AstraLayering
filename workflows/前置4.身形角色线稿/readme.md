# 前置4：身形角色线稿

生成一张线稿参考，让后续SVG绘制更容易辨认线的位置、走势、粗细与收笔。单轮生图，不设step子目录。

- 输入：前置2的基础角色彩图。
- 输出：同画幅的白底黑色线稿图片，包含原图可见的轮廓与结构细节。建议保存为案例`references/line-art-reference.png`。
- 生图时只需提供原彩图和[提示词](./提示词.txt)。

生成后，用现有SVG预览器并排或叠加比较彩图与线稿：看形状是否移位、原有结构线是否丢失、阴影边缘是否变成多余线条。先确认形状保持，再判断线条是否更易读。

确认后，将线稿参考提供给[阶段2](../2.建立完整部件与遮挡/readme.md)和[阶段3五个step](../3.建立可用线稿/readme.md)。阶段2重点用它辨认头脸与发束轮廓，仍按彩图直接构建完整部件；阶段3前两步同时提供原彩图与上一轮SVG，校准头型和面部，后三步以同一线稿与上一轮SVG为主。疑点均回到原彩图，分件与遮挡补全由SVG绘制者完成。
