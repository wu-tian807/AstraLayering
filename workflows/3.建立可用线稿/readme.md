# 阶段3：建立可用线稿

本阶段分成三个独立执行的 step，每轮交付可检查的 SVG 后，再发起下一轮。step1 已完成首次实测：可见主轮廓质量可以通过，发现两处隐藏自然轮廓缺少墨线；已补充验证子流程，修订后的提示词尚待复测。step2、step3 尚未实测。

直接修改上一轮 SVG 的副本，沿用完整部件、隐藏补全和遮挡关系；人物彩图负责判断改后的造型是否准确。可以重构路径，不受旧节点、分段和曲线质量限制。

| 步骤与提示词 | 外部输入 | 本轮工作 | 固定输出 |
| --- | --- | --- | --- |
| [step1：主轮廓重构](./step1/生成提示词.txt) | 基础角色彩图＋阶段2 SVG | 校准完整底形，按“软尺”思路精修主轮廓，转为白底轮廓稿 | `03-1_主轮廓.svg`、`03-1_轮廓检查.png` |
| [step2：内部结构线](./step2/生成提示词.txt) | 同一彩图＋通过检查的step1 SVG | 五官、主发束、手足与甲片、服装及配件结构线，保留归属与隐藏延续 | `03-2_内部结构线.svg`、`03-2_结构线检查.png` |
| [step3：线条统一与精修](./step3/生成提示词.txt) | 同一彩图＋step2 SVG | 统一线宽、收尖、接头与断笔，清除重复边，补少量辅助细线 | `03_完整分层线稿.svg`、`03_线稿检查.png` |

三轮默认输出到对应案例目录的`outputs/<case>/step03-base-character`，文件名互不覆盖；首例使用`outputs/case1_miku/step03-base-character`。每轮保留输入文件，下一轮传入上一轮实际生成的SVG；SVG通过外部文件提供，不通过文本变量插入。

先测试 step1：提供 `step1` 文件夹内两个 `.placeholder` 所说明的实际文件，再发送该文件夹的提示词即可。占位文件是输入说明，不能替代图片和 SVG。主流程阶段1规划、部件色块图及研究样本均不是阶段3的必需输入。

**step1 的“去掉填色”只改变默认显示，完整底形继续存在。** 原部件标记色改为不透明白色，底形负责遮挡；深色墨线单独归在所属部件内。每个部件先底形后墨线，部件仍从后到前排列。不能把全部填充设为透明，也不能给所有闭合路径直接加黑边。

底形必须闭合，墨线可以有自然断笔。肩根、腕根等人为封口不描黑；被刘海遮住的完整脸轮廓仍保留，由前方部件遮住。本阶段不设计正式底色、明暗或材质，完成后的同一套底形可供阶段4填色。

step1 在绘制后执行独立的验证子流程，分别判定**底形完整、墨线完整、合成正确**。浅灰底逐件独显用于检查实际路径；同一 `data-part` 的分段既要一起显示，也要核对各段。闭合底形、保留 ID、组合好看，都不能单独证明隐藏墨线完整。自然外轮廓属于 step1，即使被覆盖也应保留；人为封口不描黑，局部有意断笔仍允许。

首次实测曾生成并查看独显图，但后续清线将后脑短梢和右马尾后侧回卷的墨线省略，保留白面后仍判为通过。修订要求最后改动后重新渲染并查看受影响部件，且在原有检查 PNG 中增加关键隐藏轮廓的独显证据。仍只交付 SVG 与一张检查图，不增加规划文件或测试框架；三项有任何一项未验证或失败，就不能宣布整轮通过。

step2 按当前角色取舍内部线，每件先定位，再描线并查看局部。甲片基本形与甲缘在本轮完成；新增五官和甲片归所属部件，需要独立填色的区域补闭合白底，纯线条不强求填色面。验证分别检查造型与线质、归属与补全、主轮廓与遮挡；绘制、验证、修复和复查在同一轮完成。检查图包含手足放大与关键隐藏线独显，仍交付两份文件，提示词尚待实测。

三个检查关口分别是：主轮廓与参考吻合、内部结构能读出表情与手势、整体线条具有主次且局部干净。后一步发现前一步的局部问题，可以在原部件中回改并同步底形；不能把错误轮廓锁死，也不能靠增加细节遮掩问题。

笔触依据来自 [Suzuran 分析](../../analysis/suzuran-analysis/绘画策略分析.md) 和 [physics-band 分析](../../analysis/physics-band-analysis/线稿方法分析.md)。“软尺”落实为关键位置、平顺曲线和连贯线宽，不要求复现未提供的物理求解器；共享端点仅用于同一部件的真实连接。
