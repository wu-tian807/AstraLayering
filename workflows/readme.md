# 面向 Live2D 皮套的 Layering 重构

本目录基于 Live2D 实际皮套制作方法，重构角色 SVG 分层流程。目标是在保持角色设计与人物辨识度的基础上，按需整理参考画法，准备适合表情变化、转头、身体运动和物理摆动的部件，让后续皮套动画更加生动、衔接自然。

这里是新流程的重构工作区，通过本目录的 [live2d-layering Skill](SKILL.md) 调度已建立的节点并试跑。现行 [svg-layering skill](../.agents/skills/svg-layering/SKILL.md) 及其内部 workflows 保留，继续作为已有实现与案例依据。

当前按暂定顺序逐步建立节点；[根目录流程文件](流程.yaml)声明外部输入与选项。已建立角色参考准备、皮套结构识别、[大层分层稿](3.大层分层稿/)和[专项细化](4.专项细化/)。专项细化先生成整图线稿参考，再由总控按 kind 展开对应模板。首个 [face 模板](templates/部件专项/face/)先用 Sol-medium 提取脸部色盘，再交给 Astra-xhigh 分别完成脸型、关联校准、脸底填色、脸部小件绘制及效果分组；各组绘制共用同一个 Astra 会话。

新流程采用 [Workflow 文档 DSL](docs/workflow-dsl.md)：从 `1` 统一编号，通过 `1.1` 等子编号展开步骤，同编号的 `parallel` 节点表示并行批次；节点内的 `流程.yaml` 说明输入来源、可选分支、输出与 review。提示词继续作为各 worker 的独立任务资料。

运行选项由负责判断的 agent 使用[选项工具](tools/readme.md)写入本轮工作根目录的 `options.yaml`；总控读取后调度。当前 `simplify` 决定使用原图，还是使用用户提供或按需改绘的角色参考；结构清楚的插画优先直接使用，存在明确的画法适配需求或结构辨认障碍时才改绘。两条分支均向后续提供 `character_reference.image`。

可换装角色在 1.3 使用内置简化连体服；图中没有适用角色时，角色参考直接交给第 2 步的通用物件拆分逻辑。1.1 由 `reference_prep` worker 判断选项；1.2 与 1.3 若需生图，由总控直接调用 imagegen。第 2 步由 `part_planning` worker 识别独立部件并标记制作组，输出部件清单。[拆分规划](docs/拆分规划.md)说明三个层次的边界、教程依据与通用物件的处理方式。

本流程区分 **部件内部拆分 → 独立部件 → 组**：先将左右整眼、主要发片、身体各段、服装和整件配件分别建立完整图层；kind 将这些部件归入制作组。后续按组精修线稿时，再展开眼白眼黑、细发束、配件材质等内部拆分。通用物件先按桌子、路灯等语义对象独立分层。

## 重构方向

- **先完整分出独立部件，再按组展开内部拆分与线稿精修。** 前期落实每个部件的外形、隐藏底形和遮挡；kind 组织专项工作，内部细分依据教程、画风和实际需求决定。
- **补全服务于预期动作。** 除当前姿态的隐藏底形，还要考虑运动会露出的区域、环绕部件的前后面和关节搭接。
- **分别处理部件归属、绘制顺序和运动关系。** 同一物件可以有多个前后绘制片段；投影需要同时关联投影来源与承影部件。
- **保留必要的体积与材质信息。** 自身明暗、外来投影、需要独立变化的高光和半透明材质，按用途组织。裁切控制显示范围，动画绑定负责运动时的跟随关系。
- **通过基础动作检查素材是否可用。** 关注眨眼、张嘴、适度转头、关节连接和发束摆动时的表现，并区分素材问题与绑定问题。

普通用户以提供一张角色图为起点，流程采用可解释的基础动作规格；具体幅度和细分颗粒度逐步验证。大幅改变手势或姿势所需的新素材，作为后续扩展。

当前服装范围限定为简化连体服，身体与服装独立保存。后续添加新衣服时，可以关闭连体服及其包边、投影等附属效果，再处理新衣服的结构与动画。

## 暂定流程

以下是职责顺序，执行步骤数量与目录编号待逐步确定。

| 顺序 | 工作 | 主要结果 |
| --- | --- | --- |
| 1. 角色参考准备 | 判断画法是否适合分层重绘，按需改绘参考；对可换装角色使用内置连体服 | 保留人物特征、必要色彩与体积材质依据的角色彩图 |
| 2. 皮套结构识别 | 按语义与基础结构列出独立部件，记录补全和穿插，再标记 kind；内部拆分留到专项 | 独立部件层的清单与制作组归属 |
| 3. 大层分层稿 | 生成部件分组参考，按清单逐件建立色块底形、补全与遮挡；独立审查还原与部件完整性 | 独立部件齐全、可分别显隐的色块 SVG 与预览 |
| 4. 按组专项制作与线稿精修 | 先生成整图线稿参考，再逐组展开必要的内部拆分、轮廓精修和局部配色；当前先完成脸型与脸底 | 线稿参考与含专项细化结果的分层稿 |
| 5. 整图线稿复核与统一 | 复核各组之间的连接、遮挡和整体还原，统一线质并处理人工拆分边界 | 完整分层线稿 |
| 6. 基础配色 | 补齐尚未完成的基础色与材质透明度，复核已完成局部及相接部件的颜色连续 | 分层底色稿 |
| 7. 体积、投影与材质 | 绘制必要明暗与高光，建立独立投影及裁切关系 | 完整皮套原画素材 |
| 8. 基础动作试装 | 用代表性的动作检查连接、遮挡、补全和光影关系，定位返修责任 | 可交给后续正式绑定的素材及已知限制 |

参考判断与部件识别使用 GPT-6 Sol-xhigh；参考图生成由总控直接调用 imagegen，一次生成后作为下游参考使用；色块分层绘制及其独立审查使用 GPT-6 Astra-xhigh。脸部色盘由 GPT-6 Sol-medium 提取，各组绘制共用一个 GPT-6 Astra-xhigh 会话；模型标记和 worker 名保存在各模板任务中。

当前完成独立部件层：整眼与完整嘴部保留外形，眼白眼黑和牙舌等内部层后续展开。各部件以可辨标记色建立平顺底形，不描线；手势、足趾外缘、主要发束、孔洞和穿插仍需准确。隐藏部分补全到各自路径中，身体与服装分别归入 body、clothing 并独立保存。标记色的透明度不代表最终材质。

3.2 绘制后由总控派发[独立审查](3.大层分层稿/3.2.建立色块分层/review/提示词.txt)，检查形状还原、遮挡与空隙、底形分层。审查提示词、模型标记与对照工具都在该节点的 `review/` 下。发现问题按 DSL 的既有规则交原 worker 返修，再复验当前候选。

独立部件使用 `data-part` 对应清单 id，`data-kind` 记录制作组。同一部件前后穿插时允许多个绘制组共享 `data-part`。审查对照清单逐件独显，人物隐藏服装、头发和配件检查身体，再单独检查服装；通用物件关闭前景，检查各对象的完整底形。内部拆分可以后置，独立部件、真实孔洞和隐藏补全必须在当前落实。

## 第一步：角色参考与按需改绘

旧前置同时要求精简高清渲染、生成平涂版本和改成平视角；旧换装步骤继续要求平涂风格与少量明暗。它有助于降低重绘难度，也可能丢掉后续体积、投影和材质还原的依据。

需要区分两个用途：

- **准备便于后续重绘的角色参考**：根据原图决定是否整理光影、简化渲染，或转为结构清晰的插画表现。
- **在 SVG 绘制中先建立基础色，再绘制明暗**：属于分层制作方法，可以继续保留；这不要求参考图本身没有阴影。

`simplify` 同时覆盖画法适配与光影整理。原图已是轮廓、部件边界与遮挡关系清楚的插画时，优先设为 `false`。整体依赖 3D、写实渲染或厚涂，转成插画能明显降低保留部件的重绘难度，或确有环境光等妨碍结构辨认时，才设为 `true`，并指出具体障碍。自然渐变、反光与半透明材质本身属于设计，应保留其体积与透出关系。

人物原有服装随后会替换为简化连体服，因此旧衣料、服饰纹样及服装层次的复杂度不单独触发参考改绘。原图继续作为人物特征依据，参考改绘本身也不能保证后续重建完全一致。

| 输入情况 | 待验证的处理方向 |
| --- | --- |
| 角色完整、轮廓与结构清楚，现有插画表现适合重绘 | 直接使用，省去参考改绘 |
| 插画结构清楚，包含半透明衣料、自然渐变或复杂的待替换服装 | 直接使用；保留材质表达，随后完成换装 |
| 强环境光、背景效果或模糊遮蔽了部件边界 | 针对妨碍识别的部分整理参考，同时保留原图的必要结构与材质依据 |
| 偏 3D 或写实渲染，主要靠渐变、反光和材质表现形体 | 按需转为轮廓清楚、色区稳定、明暗简洁的插画立绘 |
| 厚涂、复杂纹理或明显艺术化处理 | 判断笔触与细节是否妨碍结构还原，按需整理画法并保留角色特征 |
| 视角或姿势影响目标动作 | 单独讨论姿态适配，与色彩、明暗简化分别处理 |

Live2D 的素材制作允许部件包含线条、填色、滤镜效果，也允许把阴影独立成层；纯平涂并非其素材前提，见[官方素材说明](https://docs.live2d.com/en/cubism-editor-manual/precautions-for-psd-data/)。艺术化图片的困难，需要结合结构可辨认程度、目标动作和制作成本判断。对本项目而言，复杂画风还会增加自动补全与可编辑 SVG 重建的难度，这需要案例验证。

后续可以用同一张图比较直接重建与先改绘参考的结果，观察人物还原、必要明暗和材质保留、下游分层表现，验证参考适配的适用条件。生成图仍按一次生成的参考使用，效果通过后续制作判断。
