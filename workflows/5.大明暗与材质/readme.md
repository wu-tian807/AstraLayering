# 阶段5：大明暗与材质

在完整分层平涂稿上，参照同一基础彩图重建明暗、局部色彩与材质。彩图决定效果，当前SVG提供形体和部件归属；新增表现需适配当前形体，已知早期造型问题单独记录。

## 两轮分工

| 步骤 | 输入与输出 | 检查方式 |
| --- | --- | --- |
| [step1：大明暗与体积](./step1/生成提示词.txt) | 基础彩图＋阶段4平涂 → `05-1_大明暗与体积.svg`、`05-1_明暗检查.png` | 自查后进行[独立review](./step1/review/提示词.txt)，必要时返修复验 |
| [step2：局部色彩与材质](./step2/生成提示词.txt) | 同一彩图＋step1实际结果 → `05-2_局部色彩与材质.svg`、`05-2_细节与材质检查.png` | worker自查，默认不再调用独立reviewer |

主要亮暗面、体积转折和接触关系在step1成立；红晕、虹膜内部层次、局部高光与材质光泽在step2处理。按视觉作用区分，不按面积或亮度简单分类，不把主要亮面遗漏推给后续高光。

## 执行与返修

step1的绘制与审查提示词分别提供；审查者只读作品，自行渲染和取证，不沿用绘制自评。

每轮审查结论对应明确候选版本，返修后重新确认。无法执行独立审查时保持待审，不能写成通过。证据工具见[step1/review](./step1/review/readme.md)。

step1保留可恢复的平涂底层；自身明暗和外来投影分别组织，既检查单件，也检查不同部件形成的连续视觉表面。step2保留底形及墨线几何，允许有依据的少量原明暗回修与内线颜色／透明度调整，并记录改动；关闭新增效果不一定等于恢复原step1，恢复验证需同时还原许可属性。

创作工具按需选择；可尝试SVG局部滤镜或其他矢量效果，实际检查裁切、显隐和渲染表现。完整底形、可编辑归属、参考还原与原稿保留要求继续执行。正式输出名称不变，审查报告及诊断图写在指定审查目录，不混入作品图层。
