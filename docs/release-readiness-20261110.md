## 便携 ffmpeg 可行性

便携 ffmpeg 可以解压后直接执行，无需安装到系统目录。下列架构均已找到公开预编译产物；本轮已在 Linux x64 校验下载摘要并完成实际视频生成、解码和抽帧，其他架构只核对了发布产物，尚未完成实机运行验收。

| 系统 | 架构 | 已找到的来源 | 本轮验收 |
| --- | --- | --- | --- |
| Windows | x64 | `eugeneware/ffmpeg-static` 的 `ffmpeg-win32-x64.gz` | 已核对资源；待实机抽帧和路径处理验收 |
| Windows | ARM64 | `FFmpeg-Builds/FFmpeg-Builds` 提供原生 `winarm64` ZIP，须单独选定固定版本和完整运行文件 | 已核对资源；待固定资源和实机验收 |
| macOS | Intel x64 | `eugeneware/ffmpeg-static` 的 `ffmpeg-darwin-x64.gz` | 已核对资源；待实机验收 |
| macOS | Apple Silicon ARM64 | 同项目的 `ffmpeg-darwin-arm64.gz` | 已核对资源；待实机验收 |
| Linux | x64 | 同项目的 `ffmpeg-linux-x64.gz` | SHA-256、启动、MP4 解码及 PNG 抽帧通过 |
| Linux | ARM64 | 同项目的 `ffmpeg-linux-arm64.gz` | 已核对资源；待实机验收 |

固定 [ffmpeg-static b6.1.1](https://github.com/eugeneware/ffmpeg-static/releases/tag/b6.1.1) 的上述五种构建都有 SHA-256 摘要及对应 README、LICENSE；压缩文件约 18–28 MiB。本机验证的 Linux x64 产物实际报告版本 `7.0.2-static`，`b6.1.1` 是构建包标签。Windows ARM64 来源见 [FFmpeg-Builds](https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases)，当前枚举到的 `latest` 产物会更新，正式集成前须确定稳定资源与固定摘要。本机 Linux x64 产物没有动态库依赖，其他 Linux 构建及发行版兼容性仍须核对；macOS 须核对最低系统版本及执行条件。

Linux x64 本轮已校验的压缩文件 SHA-256 为 `bfe8a8fc511530457b528c48d77b5737527b504a3797a9bc4866aeca69c2dffa`；未来下载器应为每个获准平台记录固定 URL 与完整摘要。

本次选择使用已安装或手动解压的 FFmpeg，通过网页全局设置或 CLI 明确指定路径。上面的资源仅保留为便携版可行性研究；本版不实现自动下载与用户缓存。

独立 section 启动无状态，软件路径每次传入；仅调用方的网页全局设置和总调度 `run.json` 保存参数。默认执行目录为仓库 `.run/`，`demos/` 用于导出与展示成果；现有服务曾被旧全局设置指向 `demos/`，本轮已将该默认设置改回 `.run/`。
