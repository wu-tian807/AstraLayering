# 工作台进度显示规则

工作台展示执行事实和已保存产物；状态汇总不改变步骤或产物。前一步的完成结果按其完成标记显示，不能因为后续步骤未完成而倒退，也不推测引用产物被篡改或过期。中间步骤重试后的下游处理另行设计。

## 单个步骤或部件

- 完成标记表示该步骤已完成；跳过的步骤显示跳过。已有文件本身不代表完成。
- 本次真正发出的调用仍在执行时显示“进行中”，即使已有中间产物；尚未实际开始的工作不能仅因所属流程运行而显示进行中。
- 临时错误进入重试等待时显示“限流等待”，以紫色闪烁点区分待执行和进行中；等待期间保留该调用的并发位置。等待结束并重试后重新显示进行中。
- 流程仍在运行时，尚未完成且没有当前调用的步骤，有已保存的中间产物时显示“已有产物”，没有则显示“待执行”。失败和中断按实际执行状态显示。
- 一个实际调用覆盖多个部件时，所有被该调用处理的部件均显示其执行状态。例如同层轮廓去重运行时，同层参与的部件显示进行中。

单个叶子节点同时只显示一种状态：运行中和执行失败是互斥的实际状态，二者都优先于已有产物和待执行；限流等待优先于它们。

## 汇总节点

汇总按子项及节点自身的实际状态显示：**限流等待 > 进行中 > 执行失败 > 已中断 > 待续跑**。若以上状态均不存在：全部完成或跳过时显示完成；有已完成项或已有产物时显示已有产物；否则显示待执行。子步骤完成不会替代父步骤自己的完成标记。

因此，一个子项失败、其他八项仍在运行时，汇总显示进行中；其他工作结束后才显示失败。节点自身的进行中或限流等待也不能被子节点的已有产物覆盖。汇总状态不改变各子项各自的状态。

分组树中的折叠行代表该组自身的阶段：子孙正在执行、限流等待或发生异常时，折叠行也显示这一状态；尚未开始的子孙不会使该组自身已完成的阶段倒退。

任务和流程的运行状态、具体步骤的调用状态是不同层级：流程正在运行不等于每个步骤都已经开始。
