# 部件分组参考的主要标记色

以下为生成图中主要可见色区的简要对照，方向均按画面左右；具体独立对象以 `structure/parts.yaml` 为准，最终 SVG 不要求沿用本图颜色。

- 高发髻与顶部弧环：金黄；两侧枝形头饰：画面左红粉、画面右绿色。
- 两侧头顶和前额发面：画面左薄荷绿、画面右粉紫。
- 长后发：画面左蓝色、画面右淡紫；头饰垂带以浅青蓝为主。
- 头脸：浅粉；颈与上胸：浅黄。
- 连体服：浅蓝。
- 手臂：画面左浅绿；画面右上臂浅黄、小臂与手浅紫。
- 大腿：画面左珊瑚粉、画面右杏橙；小腿与脚：画面左粉色、画面右淡黄。
- 宝石、耳坠与足链保留蓝色等识别性细节。

该图是一次生成的辅助参考，部分独立小部件仍可能共色。后续按彩图和清单建立独立底形、补全及分层，不直接把可见色区当成完整部件。
