## 3. 基础部件与补全范围

清单用于结构规划，不是最终层数。仅补当前视角和姿势的连续底形；隐藏边界不等于成图可见线。

| 基础部件 | 分离目的 | 隐藏部分与补全范围 |
| --- | --- | --- |
| 头脸 | 承载五官，受前发遮挡 | 推断补齐刘海及侧发下的头部轮廓，接至下颌与颈部。 |
| 五官 | 位于脸上、前发下 | 保留当前表情为一组；眉眼被发遮住处仅补必要延续，不预设动画细拆。 |
| 后侧头发 | 位于脸后，连接马尾根 | 推断补齐头脸和前发遮住的后脑发形，接两侧发根。 |
| 前发与贴脸短发 | 覆盖额头及脸侧 | 推断补齐头顶发束连接；手指挡住的左侧发边接回可见段。 |
| 左长马尾及主要发束 | 位于抬臂后，末端自相交叠 | 补连手臂挡住的上段及发饰下根部；尾端内外束按交叉分段，连接属推断。 |
| 右长马尾及主要发束 | 位于右臂和局部腿后 | 补连肘部、腿缘遮住的发片至可见段；根部及回绕束连接属推断。 |
| 两侧框形发饰 | 与根部、前发遮挡不同 | 框体被发遮住处推断连续；不因框内颜色另拆。 |
| 耳侧装置及左侧弧形短杆 | 与脸、发、手分别交叠 | 左侧装置可见较多，右侧仅局部露出；发下外形和短杆连接待核对。 |
| 颈部与躯干、骨盆 | 与基础服装分开 | 推断补肩根、衣下胸腰到髋及大腿连接；仅必要形体，不添身体细节。 |
| 左上肢及 V 手 | 整体位于马尾前，手又覆脸侧 | 肩根补接躯干；手内相叠处仅补必要连接，其余无需补全。 |
| 右上肢及扶腰手 | 手压住衣侧，臂位于马尾前 | 肩根补接躯干，手腕连续；指间隐蔽连接属推断。 |
| 双腿与双足 | 从衣下接出，局部遮马尾 | 推断补大腿上端至骨盆；膝踝足保持连续，不按关节预切，裸足无需补全。 |
| 基础连体服装 | 可独立替换，覆盖躯干 | 补右手挡住的腰侧衣片和轮廓；衣缘、接缝不作人体结构线。 |

## 4. 关键遮挡关系

箭头表示下层先画、上层后画：下层 → 上层。

| 下层 → 上层 | 可见依据／推断／待核对 |
| --- | --- |
| 后侧头发 → 头脸与五官 → 前发 | 刘海遮额头和眉眼局部；完整后脑发形及其范围为推断。 |
| 长马尾 → 手臂、局部腿 | 抬臂与右肘截断发轮廓，右膝外侧挡住内侧发片。 |
| 马尾根 → 框形发饰 → 局部前发 | 根部关系为推断；框体下端与前发交界待核对，第2步需局部分段。 |
| 耳侧装置 → 贴脸短发 | 左侧装置上缘没入发下；短杆与发丝交界待核对。 |
| 左侧贴脸发、耳侧装置 → V 手 | 横伸手指遮住脸侧发边及装置邻接处，接触边界需核对。 |
| 躯干与大腿根 → 连体服装 → 扶腰手 | 衣缘盖住身体，右手指落在腰侧衣片上；衣下形体为推断。 |
| 马尾内侧长束 → 末端外侧卷束 | 宽卷束遮住部分内侧发片；回绕处待核对，第2步需局部分段。 |

## 5. 第2步交接

- 结论：通过。
- 判断依据：全身及主要末端均在画面内，外观、姿势和基础服装边界足以进入结构绘制。隐藏连接可据邻接轮廓推断，此结论不代表已完成绘制或补全。
- 优先核对：①左侧 V 手、贴脸发、耳侧短杆的交界；②双马尾根部与发饰，以及末端回绕束的穿插；③扶腰手下的衣侧延续及衣下骨盆与大腿连接。
