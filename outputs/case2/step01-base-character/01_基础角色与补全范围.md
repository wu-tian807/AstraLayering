## 3. 基础部件与补全范围

此表是主要部件清单，不是最终层数。补全仅保证当前视角与姿势下的连续；隐藏底形不等于成图需显示的线条。

| 基础部件 | 分离目的 | 隐藏部分与补全范围 |
| --- | --- | --- |
| 后发及顶部翘发 | 位于头脸和前发之后 | 头脸遮住后发中部；推断接成连续后发底形。翘发根补至顶发遮挡处。 |
| 头脸底形 | 承接五官并受前发遮挡 | 刘海盖额头，侧发盖脸侧；推断补齐头部外形，与可见下颌连续。 |
| 静态五官 | 位于脸底上、前发下 | 眼鼻口可见，无需补全；眉端入刘海处仅作短接推断，不作表情细拆。 |
| 前发及贴脸短发 | 覆盖额头与脸侧 | 发饰下的小段推断连回相邻发片；右侧与长发束的分界待核对。 |
| 右侧胸前长发束 | 跨过肩胸，遮挡不同 | 上端与短卷发相接处部分不清，推断连回右鬓；可见垂端无需补全。 |
| 两侧猫耳状配件 | 独立固定配件，根部入发 | 下缘被顶发遮挡；推断补足根部外形，与两侧可见边缘连续。 |
| 右鬓发饰及垂带 | 饰件覆盖发丝 | 主饰完整，无需补全；垂带边与短发交界待核对，遮住处只短接轮廓。 |
| 颈部、躯干与骨盆 | 与基础服装独立 | 发下颈肩、衣下胸腰及骨盆连接均为推断；只补必要形体，不增身体细节。 |
| 左臂与左手 | 臂根与服装存在遮挡 | 推断将衣口附近臂根接入肩部；腕掌连续，指根互遮处按现有手形短接。 |
| 右上臂 | 与长发、肘部外壳交叠 | 发下补至肩部，机械壳下补至肘部连接段，均为推断。 |
| 右肘与机械前臂 | 与上臂、腕手有套接 | 推断补齐外壳遮住的必要连接轮廓至肘腕；内部构造不明，不扩充。 |
| 右机械手 | 腕部关节与手壳交叠 | 推断补齐腕口至掌根、掌指互遮短段；保持当前弯曲手形。 |
| 双腿与赤足 | 腿根受基础服装遮挡 | 推断将衣下腿根接入骨盆；膝踝至足部外轮廓基本完整，无需补全。 |
| 无袖高叉连体衣 | 基础服装独立替换 | 右肩带、胸侧被长发遮挡，推断连回领口、袖窿和侧腰；衣缘不作人体线。 |

## 4. 关键遮挡关系

箭头表示下层先画、上层后画：下层 → 上层。

| 下层 → 上层 | 可见依据／推断／待核对 |
| --- | --- |
| 后发 → 头脸、颈部 | 可见脸颊、颈侧轮廓截住后发；被遮住的后发连续形为推断。 |
| 猫耳状配件根部 → 顶部前发 | 可见两侧配件下缘被顶发遮住；深处连接为推断。 |
| 头脸与五官 → 前发、贴脸短发 | 可见刘海压额、侧发压脸；眉眼附近的发丝边界需核对。 |
| 右侧发丝 → 鬓侧发饰 | 主饰明确压住浅发；垂带旁细发是否绕到前方待核对，若交叉，第2步需局部分段。 |
| 躯干、腿根 → 基础连体衣 | 领口及高叉衣口界定露出范围；衣下身体连接为推断。 |
| 连体衣、右肩上臂 → 胸前长发束 | 可见长束跨过右肩胸，覆盖衣身与上臂局部，垂至腰侧。 |
| 右上臂末段 → 肘部机械外壳 | 可见机械件沿上臂外侧上延；肘腕处壳片与关节的包覆次序待核对，第2步需局部分段。 |

## 5. 第2步交接

- 结论：通过。
- 判断依据：全身、手足及主要配件均在画幅内，足以进入结构绘制。隐藏连接可据相邻轮廓作有限推断，尚未绘制或验证补全。
