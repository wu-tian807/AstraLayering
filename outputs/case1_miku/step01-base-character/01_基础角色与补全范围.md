## 3. 基础部件与补全范围

限当前视角与姿势。衣下只补轮廓和连接；衣缘、接缝不作人体线，隐藏边界不等于可见线条。

| 基础部件 | 分离目的 | 隐藏部分与补全范围 |
| --- | --- | --- |
| 头脸（含五官） | 与颈、头发遮挡不同 | 额与耳侧被发遮住；推断补颅形与脸缘，不添耳内细节。 |
| 后脑发与耳后短发 | 位于脸后 | 被头脸、前发遮住；推断接发顶、束根及耳后短梢。 |
| 前发与贴脸鬓束 | 覆盖额面并穿插配件 | 左手挡住局部；依可见走向续接，发根推断接发顶。 |
| 左马尾及主要回卷束 | 与抬臂及自身交叠 | 饰件、头发、手臂遮住根部与上中段；推断续接，回卷交叉待核对。 |
| 右马尾及主要回卷束 | 与右臂、腿及自身交叠 | 根部、臂后与膝旁内缘被遮；推断续接，回卷交叉待核对。 |
| 双侧几何发饰 | 压住束根且被发丝覆盖 | 部分内缘藏在前发后；推断延续折角至束根。 |
| 耳侧深色配件 | 与鬓发遮挡不同 | 推断补遮住的外形；与上方发饰连接待核对。 |
| 颈、躯干与骨盆底形 | 独立于基础服装 | 下颌遮颈上端，衣服遮躯干；推断接通肩、腰、骨盆及四肢。 |
| 双臂 | 独立肢体，肩带另覆盖 | 肩根被肩带盖住；推断接肩、腕，肘部连续。 |
| 左手 | 位于头发前方 | 外形可见；折指重叠处推断连续手形，接回手腕。 |
| 右手 | 压在腰侧衣面 | 指掌自遮挡处推断补至腕端，贴腰内缘待核对。 |
| 双腿连足 | 位于衣服下方 | 衣服遮大腿根；推断接至骨盆，膝下至赤足无需补全。 |
| 基础无袖连体衣 | 独立替换基础服装 | 右手遮腰侧与腿口附近；推断续接衣片、边缘。 |

## 4. 关键遮挡关系

箭头表示下层先画、上层后画：下层 → 上层。

| 下层 → 上层 | 可见依据／推断／待核对 |
| --- | --- |
| 后脑发 → 头脸 → 前发 | 脸缘前后均有发梢；隐藏后脑范围为推断。 |
| 马尾束根 → 几何发饰 → 局部前发 | 饰件内缘被发遮住；束根连接为推断，需局部分段。 |
| 耳侧配件 → 局部鬓束 | 深色块被发丝截断；与邻近发片的交叉待核对。 |
| 左马尾 → 左臂；左侧前发 → 左手 | 马尾被抬臂截断，V形手指横过左侧发片。 |
| 右马尾 → 右臂及右腿 | 发片在臂后、膝旁终止；隐藏走向为推断。 |
| 身体底形 → 连体衣 → 右手 | 肩带、腿口覆盖身体，右手压衣面；腰侧接触待核对。 |
| 马尾后侧主束 → 前侧回卷主束 | 轮廓中断处待核对，第2步需局部分段。 |
