## 3. 基础部件与补全范围

| 基础部件 | 分离目的 | 隐藏部分与补全范围 |
|---|---|---|
| 后发整体 | 位于头脸与前发之后 | 推断补齐脸后、侧发下的连续发体，接至头顶；保留颈旁外翻发梢。 |
| 前额刘海 | 独立覆盖额头与后发 | 推断补足刘海发根至头顶连接，保留不等长尖圆发束；不逐缕拆层。 |
| 左右侧发 | 覆盖脸侧，外轮廓需独立 | 补到被刘海遮住的上端；与后发交界推断，局部交叉待核对。 |
| 头顶环状翘发 | 轮廓独立，发根有遮挡 | 推断补至头顶发根；保留左侧环状负空间。 |
| 右侧双横发夹 | 固定配饰覆盖发面 | 两条夹片作为一组；可见形状完整，无需补全。 |
| 头脸 | 承接五官并处于发下 | 推断补齐额头、太阳穴及发下侧缘，形成闭合头形；耳部全被遮挡，不添加外露耳线。 |
| 五官 | 独立定位于头脸表面 | 眼、眉、鼻、笑口保留现状；发下眉端仅补必要连接，不预设眨眼或口型细拆。 |
| 颈部、躯干与骨盆 | 身体与服装独立 | 推断补齐下巴后的颈顶及衣下肩胸、腰胯连续外形；不添加衣下身体细节。 |
| 左右手臂 | 独立于躯干及衣肩带 | 推断补齐腋下和肩根连接；上下臂保持连续，不按肘部分层。 |
| 左右手与手指 | 与手臂可独立连接 | 腕端补入前臂少量重叠；弯指遮住的指段仅按当前姿态推断，不逐指预设层。 |
| 左右腿与足 | 独立承接骨盆 | 推断补齐衣下大腿根至髋部；膝踝至脚趾连续，足部不另拆空层。 |
| 白色连体衣 | 基础服装可独立显示 | 闭合肩带、领口、躯干和裤脚区域；肩带连接为推断。领口滚边、侧缝及裤脚线属于服装。 |

## 4. 关键遮挡关系

箭头表示下层先画、上层后画：下层 → 上层。

| 下层 → 上层 | 可见依据／推断／待核对 |
|---|---|
| 后发 → 头脸 → 刘海、侧发 | 脸露于发框内，刘海盖住额头；后发在脸后连续为推断。 |
| 头脸 → 五官 | 眼鼻口可见于脸面；眉与刘海相接处由刘海覆盖。 |
| 后发 → 侧发、刘海 | 发束边界可见；左右侧发与刘海交接待核对，必要时局部分段。 |
| 翘发根 → 头顶发面 → 双横发夹 | 翘发根收进发顶为推断；发夹明确盖在右侧发面上。 |
| 颈部 → 下巴、颈旁发梢 | 下巴截断颈上端，橙色发梢位于颈侧；隐藏连接推断。 |
| 躯干、肩根、腿根 → 连体衣 | 肩带、领口与裤脚明确限定覆盖；手臂与衣侧没有大面积交叉。 |
| 手掌及后侧指段 → 前侧弯指 | 指线有局部交叠；指间穿插待核对，需局部分段，不强定整手层序。 |

## 5. 规划结论与待核对项

- 结论：通过。仅表示参考足以进入结构绘制。
- 判断依据：全身轮廓、表情和服装边界清晰，缺失主要为发下头形与衣下连接，可在当前视角内合理推断。
