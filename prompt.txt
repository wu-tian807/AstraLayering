请基于我提供的原始图片，生成一个最终可直接打开的 HTML 文件，里面内嵌 SVG 形式的高保真临摹图，并提供图层显隐控制功能。

这次任务必须同时满足两个目标：

1. 高保真保留原图的视觉细节
2. 严格按照 bottom-up 的方式完成真正可检查的分层绘制

请特别注意：
我不要“先把整张图临摹出来，再去拆图层、补被遮挡区域、补层级关系”的做法。
那种做法会导致图层污染、补片痕迹、残片、错误遮挡关系，以及关闭图层后下方内容不完整。
我需要你从一开始就按“先定义层，再逐层完整绘制”的方式工作。

------------------------------
【必须遵守的工作流】
请严格按以下流程执行，不要跳步，也不要替换成别的路线：

1. 先定义完整图层清单（layer manifest）
   - 在开始绘制前，先确定需要拆分的所有语义图层
   - 图层顺序必须从最底层到最上层
   - 图层的划分依据必须是“语义部件”，而不是“最终图像里可见的局部区域”

2. 当前图层单独完整绘制
   - 当前图层必须被当作一个完整独立部件来绘制
   - 不能只画原图中露出来的部分
   - 该图层被上层遮挡的区域也要预先补全
   - 当单独显示该图层时，它本身应当仍然是一个完整合理的部件

3. 只允许本层内部有本层自己的细节
   - 本层内部只能包含本层自己的颜色、明暗、线条、纹理、高光、发丝、褶皱等细节
   - 不允许混入其他图层的边缘、阴影、残片、补片、轮廓或描边
   - 不允许借用其他部件的轮廓来裁切本层内容
   - 不允许使用“先描可见区域，再补遮挡区域”的拼接式做法

4. 保存当前层
   - 当前图层完成后，应将它作为独立 SVG 图层保存
   - 然后才能开始绘制下一层

5. 再画上一层
   - 必须严格按照从底层到顶层的顺序推进
   - 最终整张图应由这些已经独立完成的图层叠加组装而成

------------------------------
【禁止事项】
以下做法明确禁止：

- 禁止先临摹完整图，再事后拆图层
- 禁止先做最终效果，再回头补被遮挡区域
- 禁止把“最后分成多个 <g> 组”当作真正分层
- 禁止把其他层的边缘或残片混入本层
- 禁止让本层依赖前景层的裁切轮廓才能成立
- 禁止出现补绘接缝、图层污染、碎片残留
- 禁止为了结构正确而把原图大幅简化成过于概括化、几何化的矢量重绘

------------------------------
【保真度要求】
在满足严格分层的前提下，尽可能保留原图的高保真细节，包括但不限于：

- 主体轮廓的微妙形状变化
- 局部材质差异
- 明暗和高光关系
- 边缘的轻重变化
- 细线、细丝、细碎装饰
- 五官或结构中的微小层次
- 衣物或表面的褶皱、反光和质感
- 原图的整体气质与观感

换句话说：
我要的是“高保真临摹 + 正确分层”，而不是只保其中一个。

------------------------------
【分层原则】
请按“语义部件”来拆层，而不是按视觉区域硬切。

通用示例（仅作为理解原则的例子）：
- 如果主体有前后关系明显的头发，应区分前发、侧发、后发、较大束、游丝等
- 如果主体有眼部结构，应尽量将眼白、虹膜、瞳孔、高光、眼睑、睫毛等分离
- 如果主体有闭合的嘴部，也应理解为可拆的上下嘴唇和口内结构，而不是只有一条线
- 如果主体穿着衣物，衣物和身体应分层；衣物下方的身体结构应补全
- 如果主体有饰品、耳机、帽子、眼镜、发饰、武器、挂件等，它们应作为独立部件处理
- 如果前景部件挡住背景部件，隐藏前景后，背景部件应完整显现，而不是露出拼接痕迹

------------------------------
【验收标准】
请在内部按以下标准自检，只有满足后再输出最终 HTML：

1. 关闭任意上层图层后，下层应完整自然显现
2. 任意单层独显时，应当是完整合理的部件，不应混入其他层内容
3. 不应出现身体残片、衣物残片、边缘污染、补片痕迹或错误遮挡
4. 所有图层重新叠加后，应尽量接近原图观感
5. 不能因为追求结构正确而显著损失原图细节
6. 图层划分必须能服务于后续动画、形变、检查或隐藏显示，而不是仅供形式展示

------------------------------
【最终输出要求】
最终请输出：

- 一个可直接打开的 HTML 文件
- HTML 内嵌最终 SVG
- 带有图层显隐控制 UI
- 可以动态开关图层
- 关闭上层图层后，下层被遮挡部分应完整显现
- 最好支持：
  - 独显某一层
  - 查看“本层及以下”
  - 导出当前 SVG
  - 导出单层 SVG
  - 显示图层列表及顺序

------------------------------
【重要提醒】
这次你的重点不是先生成一张完整图，再想办法补成分层图。
而是从一开始就严格执行：

先定义层 → 当前层完整绘制 → 只保留本层细节 → 保存当前层 → 再画上一层

如果你发现自己正在走“先整图临摹、后补分层”的路线，请立即停止，并改回上述工作流。
