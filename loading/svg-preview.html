    把细节放大看

    将鼠标放在想看的细节上滚动，缩放会围绕该位置进行。也可以拖出选区，直接放大到那一部分。

    放大 / 缩小滚轮 · + / −平移拖动 · 方向键适应窗口 / 实际大小F 或 0 / 1框选放大 / 取消B / Esc打开图像 ACtrl / ⌘ + O

    触控设备支持双指捏合缩放。点击右下角导航，可快速回到作品的任意位置。缩放框支持直接输入比例，例如 10000 或 1e6。

    两个槽位都支持 SVG 以及浏览器可解码的 PNG、JPEG、WebP、GIF、AVIF、BMP 等位图。两张图会按各自最长边等权归一化，再居中放进同一个对比画布；交换 A / B 不会改变对齐结果。左右、叠加和滑动模式共用缩放与平移。

    图层面板读取当前图像 A 的 SVG 嵌套结构。若 B 也是 SVG，可用“交换 A / B”查看和控制它的原生图层。位图没有原生 SVG 图层。

    不设固定缩放倍率上限。SVG 会随视图重新绘制；位图和 SVG 内嵌位图仍受原始分辨率限制。
