放大 / 缩小滚轮 · + / −平移拖动 · 方向键适应窗口 / 实际大小F 或 0 / 1框选放大 / 取消B / Esc打开 SVGCtrl / ⌘ + O

触控设备支持双指捏合缩放。点击右下角导航，可快速回到作品的任意位置。缩放框支持直接输入比例，例如 10000 或 1e6。

不设固定缩放倍率上限。SVG 会随视图重新绘制；极端倍率受浏览器坐标精度限制。SVG 内嵌的位图仍保留其原有分辨率。
