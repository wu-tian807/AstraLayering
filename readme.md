# AstraLayering

探索利用 AI 将角色参考重绘成可编辑、可分层、能补全遮挡部位的 SVG，用于后续换装与 Live2D / 2D 动画制作。

当前重点是同时验证**外观还原、部件完整性和遮挡关系**。SVG 使用原生 `<g>` 和从后到前的 DOM 顺序组织绘制；完整底形与可见线稿分阶段处理。分组正确不等于美术质量已经过关。

## 当前主流程

```text
确认基础角色与补全范围
  → 建立完整部件与遮挡
  → 建立可用线稿
  → 完整底形与基础填色
  → 大明暗与材质
  → 最终边缘与细节
```

前置步骤先准备平涂角色、基础连体服与经过确认的部件色块图。彩图负责外观与真实遮挡，色块图负责可见部件归属，Astra 再建立隐藏区域完整的 SVG 部件。

目前阶段1已验证，阶段2基本通过，仍有发顶局部搭接待修；阶段3至6尚待制定并实测。阶段2的曲线与局部分段允许后续重做，隐藏补全边和部件拼接边不应直接描成最终线稿。

详细输入、提示词、交付和状态见 [工作流索引](./workflows/readme.md)。

## 查看 SVG 与参考图

用浏览器打开 **[loading/svg-preview.html](./loading/svg-preview.html)**，再选择或拖入 `.svg` 即可离线预览。

预览入口已统一为新版 Preview，替代旧工作台。它直接读取 SVG 自带的 `<g>` 嵌套与绘制顺序，无需额外的 manifest 或固定图层契约，让普通 SVG 也能自然地展示层级、分组和控制显隐。

- 图层树支持展开、搜索、逐项显隐，以及全部显示、全部隐藏和恢复原始状态；列表可切换前景优先或从底到顶查看。
- 勾选“识别独立图块”，可按空间关系估计分块并控制显隐，保留原始 SVG 的叠放顺序。空间分块不等于语义部件识别，重叠部件和复合路径仍需人工判断。
- 打开 SVG 后，点击“导入参考图”或拖入 PNG、JPG / JPEG 参考图，支持**左右对比、透明度叠加、滑动分割轴对比**；也可同时拖入 SVG 和参考图。
- 参考图等比居中适配 SVG 画布，宽高比不同时保留留白，不拉伸。两图始终共用缩放与平移，切换模式保留倍率和中心；百分比与 `1:1` 以 SVG 画布为基准。
- 叠加模式可调参考图不透明度；滑动模式可拖动分割轴，或用滑块 / 方向键微调，`Home` / `End` 查看完整单图。支持更换、移除参考图或暂时切回“仅 SVG”；更换 SVG 时保留参考图并重新适配。
- 滚轮围绕鼠标位置缩放，按住拖动平移；触屏支持双指捏合。
- 点击“框选放大”或按 `B`，拖出选区查看细节。
- 缩放框支持输入百分比或科学计数法，例如 `10000`、`1e6`；不设固定倍率上限，极端倍率受浏览器坐标精度限制。
- 按 `F` / `0` 适应窗口，按 `1` 恢复实际大小；右下角导航可快速定位。
- 可切换棋盘格、浅灰、深色及白色背景，支持全屏查看。

预览器通过原生 SVG 视图重绘矢量内容；SVG 中内嵌的位图仍受原始分辨率限制。文件在本地处理。独立 SVG 内的路径、渐变、滤镜和内嵌资源可直接显示，外部资源及脚本不会加载或执行。

预览器是一个独立 HTML 文件，可直接编辑，无需构建或启动服务。

临摹示例：**[深海少女服装 · Astra 临摹](./demos/wu-tian807/miku深海少女服装_astra临摹.svg)**，1024 × 1536，透明背景，包含头脸精修。以贝塞尔路径、渐变和矢量细节绘制，未进行语义分层，可导入上述预览器查看。
