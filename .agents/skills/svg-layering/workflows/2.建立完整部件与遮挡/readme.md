# 阶段2：完整部件与遮挡

使用[执行提示词](./生成提示词.txt)，输入基础彩图、部件色块图、已有的前置4线稿和阶段1规划，单轮绘制完整分层SVG与结构检查图。

worker负责绘制、自查和返修，总控调用独立[review](./review/提示词.txt)核对造型、完整底形与组合遮挡；返修复用同一个worker，reviewer默认复用。见[总控规则](../orchestrator/readme.md)与[本节点工具](./review/readme.md)。

## 本轮输入与核对重点

| 输入 | 用途 |
| --- | --- |
| 参考图1：基础角色彩图 | 决定画布、实际造型与遮挡，也是叠加对照的基准 |
| 参考图2：部件色块图 | 辅助部件归属与分区 |
| 参考图3：前置4线稿 | 看清头脸与发束轮廓，冲突时回到彩图 |
| 阶段1规划 | 核对定位点、补全范围与待核对关系 |

直接建立完整部件，先校准头脸、刘海与鬓发组合后实际露出的面部范围；原图五官用于定位。

透明叠加使用实际SVG的正常组合渲染，以整张图约50%透明度覆盖彩图；不能分别降低各部件透明度，否则会透出隐藏底形。先对齐整幅画布，再裁同一头部范围放大；不依赖分别框选、包围框适配或局部挪动。图2、图3有画幅差异时仅作旁参。

检查时同时查看原图、未叠加结果及叠加图。框只定位，看脸缘与发束交界的实际错位。头部组合检查后单独放大面部，逐段核对定位点之间的曲线；连续外鼓、内缩或转折错位必须定位到实际底形或遮挡边，局部修正，保留已贴合区域。隐藏补全保持已校准的可见轮廓；不追求逐像素吻合。最后修改后重新渲染，检查PNG的B格保存头部叠加及面部局部放大。

输出为`02_完整部件与遮挡.svg`和`02_结构检查.png`，完整SVG经review通过后交给阶段3。
