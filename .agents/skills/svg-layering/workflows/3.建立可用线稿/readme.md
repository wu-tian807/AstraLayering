# 阶段3：建立可用线稿

现行流程分五个独立执行的step：先校准头型与发型，再完成面部表情，随后处理其余部件与全局线质。每轮交付完整角色SVG和一张检查PNG。step2完成后，由总控发起头型、发型与面部表情的独立[review](./step2/review/提示词.txt)，必要时交原step2 worker返修，通过后再进入step3。step3—5以自查为主，step5负责全局线条精修。

## 中间稿与部件边界

step1负责脸部外缘、整套发型及头部配件，先处理发顶和包脸发束，再处理长发。step2完成五官，可依据参考联动回改脸缘与刘海。step3、step4处理其余部件；已校准的头部在后续每轮与输入对照，若有明确错误仍可按原彩图修正。

前两步只有处理过的部件变为白底深色线稿，其余部件可保留阶段2标记色，以便判断整图比例与遮挡。step3再将剩余底形转为白色；该步起交付全角色白底线稿。正式配色、明暗和材质均留到后续阶段。

完整闭合底形与墨线分别保存，真实孔洞保留。自然轮廓在遮挡下延续，人为封口不描黑；每件先底形后所属墨线，保持身份和跨层关联。已有补全依当前姿态延续，不增加未提出的新动作或表情构件。

## 检查如何落到实际结果

- **造型对照**：参考与渲染使用同一画布坐标、裁切框和倍率。头部前两轮的检查图包含参考并排与透明叠加，保留头部周边关系；不能分别缩放或移动面部来对齐。
- **眼部可见比例**：step2在临时副本区分眼白、虹膜和眼睑的颜色，检查全部遮挡生效后的开口与留白；step5改动眼部线条时重做这项检查。诊断色只出现在检查图中。
- **完整性与遮挡**：重新打开最后保存的SVG，实际查看组合和相关部件在中性底上的独显。底形与必要墨线分别核对，跨层分段既合看也分看；最后删改后复看受影响局部。

绘制中的检查由worker自查；step2后的独立review由总控另起reviewer执行，工具见[review目录](./step2/review/readme.md)。返修复用原step2 worker，reviewer默认复用。step2完成后头脸、发型与五官可以合看，也允许联动校准脸缘和刘海，适合在继续绘制前一起确认。

step3—5若再次改动已审头脸／发型的造型、神态或遮挡，由总控安排原reviewer定向复验，返修回到本轮修改worker；不影响这些关系的笔触清理由worker自查。手足和全局线质不属于这次头部独立审查的通过范围，最终线稿分别记录审查与自查状态。见[总控规则](../../SKILL.md)。

检查结论分别说明造型、部件完整性和组合遮挡；生成检查图、路径闭合或部件齐全都不能单独证明还原准确。尚未到本轮的内容不作为缺失，明确造型错误则不以进入下一步代替修复。

曲线与笔触可参考[绘画研究](../../../../../analysis/physics-band-analysis/线稿方法分析.md)中的关键位置、平顺连接和连贯线宽，具体比例与路径复杂度依据本轮参考。
