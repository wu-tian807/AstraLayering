# 阶段4：完整底形与基础填色

使用[绘制提示词](./生成提示词.txt)，提供同版基础彩图、阶段3最终线稿SVG及可选的前置5色盘。worker建立基础配色、自查并交付`04_完整分层平涂.svg`和`04_填色检查.png`。

总控在候选保存后单独调用[review](./review/提示词.txt)，集中检查底色与色区、归属与隐藏延续，以及填色是否改变原有线稿和遮挡。平涂尚无明暗或材质，不作为本轮缺失。

审查问题由总控交回原worker返修，reviewer默认复用。见[总控规则](../../SKILL.md)与[本节点工具](./review/readme.md)。
