# SVG Layering

负责调度，绘制与视觉审查交给对应模型。先读[流程顺序](references/流程.md)，再定位当前节点的模型标记与提示词文件；提示词正文由执行子agent自行读取。

## 通用读取规则

- 模型由当前节点资料目录的 `*.model` **文件名**指定，文件可为空。
- 语言模型文件名格式为 `<模型ID>-<推理强度>.model`，从最右侧拆出推理强度。例如 `gpt-5.6-sol-xhigh.model` 对应 `model="gpt-5.6-sol"`、`reasoning_effort="xhigh"`；`gpt-6-astra-xhigh.model`同理。
- `image2.5.model`指定生图模型。含生图标记的节点由语言子agent调用对应生图入口，其余节点执行语言任务与程序操作。
- 提示词在当前节点资料目录匹配 `生成提示词.txt`、`提示词.txt`或 `*prompt.txt`，应只匹配一份。`.placeholder`描述所需输入，交接时绑定实际素材；`requirements.txt`列出工具依赖。
- 多step阶段查流程表指定的step目录；review查其review目录。每个节点资料目录应有且只有一个语言模型标记，配置缺失或冲突时先报告并解决。

调度者根据 `.model` 文件名填写调用参数；文件改名后，下次调度按新名字调用。skill根目录的标记建议调度会话使用Sol-xhigh，当前主会话模型由宿主设置决定。

## 工作根目录与最小交接

调度前确定并创建本轮工作根目录，交接时填写绝对路径。同一轮各节点的相对输入输出均以该目录为基准；脚本、readme等资料相对提示词所在目录查找。

交接使用以下短模板，输入只列本节点需要的图号／用途与实际路径：

```text
工作根目录：<绝对路径>
提示词：<绝对路径>
输入：<图号或用途＝实际路径，逐项列出>
读取提示词并完成本节点。相对输入输出以工作根目录为准，执行命令时将工作目录设为此处。
```

工作根目录通过执行约定落实，访问权限沿用当前环境。生图节点另附已确认的生图入口、模型与结果相对路径；review另附候选版本、SHA-256与证据相对目录。有额外范围或输出要求时补充对应字段。

## 调用与推进

1. 按用户目标确定结束位置和工作根目录，核实本轮实际素材。未指定目录时在当前项目下新建 `outputs/run-YYYYMMDD-HHMMSS`，解析为绝对路径，重名时追加序号；续跑沿用已有案例目录作为根目录。默认全流程到阶段5；明确只做平涂或到阶段4，就在阶段4review后结束。已有同版素材直接复用；缺失或版本待确认的输入向用户核实。
2. 起子agent时显式传入从文件名解析的模型和推理强度。当前若使用 `collaboration.spawn_agent`，设置 `model`、`reasoning_effort`、`fork_turns="none"`，再填写任务名和交接消息。使用其他接口时传等价参数。
3. 按最小交接模板派发worker，提示词使用本节点的绘制入口。输入按交接的路径与图号绑定，目录内示例文件只有被明确选用时才作为输入。worker在本次执行内完成绘制、自查、修正和复查。
4. 等当前节点完成再推进，记录实际输出路径、版本和worker会话ID。视觉检查由worker与reviewer按各自职责完成；worker报告无法解决的问题时先处理卡点。
5. 到review节点启动独立上下文的reviewer，按同一模板传review提示词路径、原参考、阶段输入、候选快照及版本、SHA-256、证据目录；工具在该提示词同目录。reviewer依据参考和候选独立渲染并判断。
6. reviewer要求返修时，用 `collaboration.followup_task` 或等价继续会话接口，把具体问题和证据交回**同一个worker**，修好再交原reviewer复验。reviewer可替换，替换时附前轮报告、候选版本和待复验问题；worker在同一返修循环中必须复用。
7. 复验通过且对应当前候选版本，才进入下一节点。参考歧义、必要检查缺失、连续返修无进展或原worker会话不可恢复时，报告卡点并暂停推进。

阶段3 step3—5若回改已审头脸／发型的造型、神态或关键遮挡，按step2的review要求定向复验，候选换成本轮实际稿，并提供原受审基线及改动事实；返修交回本轮修改者，通过后继续原来的下一步。普通笔触清理由当前worker自查。该review的验收范围为头脸与发型。

## 生图与资料

前置0—4直接使用节点生图提示词。执行前按生图标记确认入口的实际模型；能够确认使用指定模型后执行生成，无法确认时报告缺少可用入口，并请求用户提供对应结果或接入支持该模型的入口。前置5由语言模型选择取样区域后运行程序提取色盘。

本skill的[workflows](workflows/)链接到仓库原目录，提示词、素材和review工具只有一份源。独立复制skill时须同时将该目录解引用复制为实体资料；历史案例链接仅用于仓库内追溯。执行时资料包按只读使用，产物写入工作根目录，review证据单独保存。

格式依据：[Codex Skills](https://learn.chatgpt.com/docs/build-skills)；子agent模型设置依据：[Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents)。
