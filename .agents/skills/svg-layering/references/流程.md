# 执行顺序与交接

完整流程串行执行：**前置0 → 1 → 2 → 3 → 4 → 5，随后阶段1 → 2 → 3 → 4 → 5**，在表中的review节点插入独立审查。阶段编号与前置编号是两套编号。只做到阶段4时，在阶段4review通过后结束。

所有输入都取本次运行的实际产物。前置3、4、5均直接使用前置2彩图。语言模型和生图模型始终以节点目录的 `.model` 文件名为准；当前配置是前置语言任务Sol-xhigh，主流程与review为Astra-xhigh，生图为image2.5。

前置参考已齐备时从阶段1开始；用户明确从中间阶段继续时，核对该阶段的实际输入后续跑。输入缺失或版本不符时，说明具体缺项并向用户核实。
