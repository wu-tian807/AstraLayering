# 后发上色补充

本文仅补充「01-分层与补全」中绘制后发时的生图描述，不另设制作流程或交付要求。

## 生图办法

沿用主文档的部件生成方法，用完整后发形状和本角色可见素材作为输入，说明这是从正面观察、移除遮挡物后的后发图层，要能支持前发、侧发移开时的左右转头显露。

原图可见的细尖、小片段和回卷都是完整发束的一部分。沿它们向隐藏区补出发根、宽度、两侧边界、发流、结构线和明暗，让每个细尖都能接回有体积的完整发束。参考里的灰色缺失区和三色图的红黄交界不是发束边界，不沿这些截口画横线或拼接边。

## 基本目标

在整个转头可能露出的发面中延续完整的宽发束：较亮的外侧发面深入内部，与较暗的内侧褶面自然层叠、交错；受光、暗部和细描线顺着各束头发的弯曲与翻面走。用发束本身的宽度、覆盖和明暗起伏表现厚度，细节尺度与原画一致。

保留原有形状、配色、笔触、真实开口和尖端特征，让隐藏中段与可见上下段像同一束头发。避免大面积统一暗面、只在外围留一圈亮发丝，或让亮发束像从暗色底板上孤立冒出；不把遮挡物的轮廓或投影画进后发。
