【脸缘辨认与方向先验】
画面左侧远颊由额角经眼窝外侧、颧骨到下颌内收，真实陡边和立体转折保留，不补成外扩圆弧；被头发盖住的部分顺着这段脸缘延续。近侧和隐藏部分同样按本人的脸型补足，不擅自扩大成后脑。俯仰在侧转基础上改变透视：左上下巴上移、下脸缩短，左下额顶占比增大、下巴向脖子收；保留颊部体量和原画下巴形状，不为贴帧压扁或削尖。

以本角色原 KRA 的固有脸型、五官比例、耳轮结构和接点为依据，用视频判断斜角姿态、透视与显露。允许合理压缩和展开，不能为贴帧拉坏部件。直接引用上游 KRA，不修改画稿。只制作两个左角的脸底、五官和原工程已有的独立耳层，保留其他方向和上游绑定。头发、头饰作为遮挡参照，脖子固定；两个左角的额顶、额角、太阳穴和脸侧补全在本步完成，下颌接触在 step07 收尾。登记 UUID 和静止网格不等于完成姿态，需要随动的部件按实际关系挂入承载；独立投影按实际投射者随动、按动态接收者裁切，不烘入脸底。

【脸部轮廓先验】
以下是辨认真实脸缘与遮挡边的倾向，结合本角色原画、本方向先验和参考中的清楚证据使用。

- 整体：脸底通常从额顶经额角、太阳穴、脸颊和下颌连续接到下巴，形成以外凸为主的闭合轮廓。侧转远颊的真实陡边、眼窝起伏和原画固有转折按实际保留，不统一圆滑化。
- 额顶与额角：头骨通常沿一段饱满弧面展开，额顶高于刘海下沿；额角沿头骨接向太阳穴和脸颊。隐藏部分沿本角色脸型延续，不沿发际线的急转折补形。
- 脸颊：常在颧骨或眼睛下方较宽，再向下颌收束。圆脸的颊部弧线保持体量；原画有明确棱角时保留，不因贴合遮挡边造成台阶、凹口或异常瘦直。
- 下颌与下巴：下颌向下巴汇合，圆颏、尖颏或宽扁底缘以原画为准。下颌与固定脖子接触处的阴影线不直接当作脸缘。
- 对称：正面、纯抬头和纯低头通常近似左右对称。单侧明显变瘦、变直或出现凹口时，先查刘海、鬓发、发影和饰品遮挡，再判断是否是真实轮廓；保留角色原有的不对称特征。
- 遮挡：紧贴发丝、耳朵、饰品或投影且走势突然改变的边，可能是可见皮肤窗口的边界。先确认归属，再推断其后的脸缘，不将所有可见皮肤边都当作脸的外轮廓。
- 边缘：形变后的脸底和五官边缘连续、干净，修掉网格拉扯造成的碎裂、锯齿、毛刺和抖动台阶，同时保留原画笔触和有依据的转折。

【1. 补全本角脸底】
逐段辨认描边中的皮肤边界。真实脸缘保留本方向的走向和转折；头发盖住皮肤的边沿发丝走，它后面仍有脸。只有第二类需要顺着本人的脸型伸入头发下，给发片移开留出皮肤覆盖。归属不清的零散露肤先辨认是脸、耳根还是脖子，不为了够到它扩大脸底。
补全轮廓与可见脸缘连续相接，按本方向先验延续，保留真实直线和转折，接合处不生出尖角、折口或缺口。用 preview_svg 的 edge 叠在当前方向参考帧上，沿外缘逐段放大检查：补全段是否仍是这张脸的自然延续、是否藏在合理发面下、发片移开时是否仍有覆盖。参考中露出的背景、发丝空隙和其他部件不能被补成皮肤。修正后复看，结构与参考冲突的局部先纠正边界归属和目标描线，按本人的合理透视和遮挡处理；没有合理遮挡的位置保住脸型，记录具体参考偏差和原因，不为贴帧过度拉伸或挤压。

【2. 写描线并应用形变】
preview_svg 的 reference 按当前角传对应帧。fit_nine_axis 的 corner 与描线文件相配，left-up 用 left-up-face-trace.json，left-down 用 left-down-face-trace.json。
写描线 JSON，version=1、space=view。completion={part,source,target} 中 source 用 source-face.svg 的完整闭合路径，target 用补全后的闭合轮廓；curves 记录对应小段，真实可见脸缘标 visible，隐藏补全段标 occluded。建脸底 Warp，用 fit_nine_axis 先 inspect 再 fit，方向与描线文件沿用当前任务的配置。先确定脸底、五官和耳朵的整体随动，再处理局部透视与接合；父级已带动的运动不在子层重复施加。
两个角分别 inspect 后再 fit；参考、描线或作者改动后，重新 inspect 当前角，保留另一角与单轴。

【3. 微调本角脸底】
用 view_nine_axis 在本方向角度、only=["face/face_base"] 查看实际变形后的脸底，与补全目标和参考帧对照。未到位的隐藏覆盖、接不顺的轮廓和碎边用 fit 的 features 或 edit_nine_axis 局部修正。验收结构合理的目标轮廓与实际网格结果，不能为了追逐视频中的异常轮廓把脸拉坏。

【4. 调整本角五官】
用 edit_nine_axis 调整眉眼、鼻、嘴和腮红。每个部件的固有形态、内部结构、部件间距离与相对位置保持同一角色的关系，只随该姿态的透视合理变化。逐个对照正面原画和本方向参考，修掉额外放大、缩小、拉扯和错位，连同脸底检查原色与边缘。

【5. 调整本角耳朵】
在正面原画定位每侧耳根与同侧脸缘的接合处。让耳根随脸缘移动，按透视调整耳轮位置、形状和角度；同耳多层共用主要 Warp，再按需微调局部。用 level="face" 检查本方向规定的端点和过渡：耳根接到脸底后方，露出的耳轮连续，无悬空、穿插和分层滑动。远耳可自然进入脸或头发之后，不能为增加露出量把耳轮拉长，也不能靠头发遮住断开的耳根。没有独立耳层时检查合成轮廓。被遮住的耳朵仍保留完整形体和随动，不通过关闭显示、降低透明度或挤薄来冒充遮挡。

【6. 检查与交付】
左上检查从左转、抬头进入本角，左下检查从左转、低头进入本角，脸、五官和耳朵共同检查。做完左下后回看左上、两角之间的连续性和右侧镜像，确认既有单轴与第一角未被带偏。脖子保持固定。交付 "{uri:nine-axis/step06_angle-xy}" 下的 face-xy.json、left-up-face-trace.json、left-down-face-trace.json 和 notes.md，left-up-fit-report.json、left-down-fit-report.json 由工具写出，沿用原选帧和描边。
再看包含头发的合成和镜像姿态，核对端点与连续过渡的接点、遮挡显露和投影。中间组合由模型渲染器插值，只按实际过渡需要增加本步允许的局部辅助修正，不穷举所有 X/Y 组合。补全、五官与耳朵均须完成，工具成功或只绑定部件不代表通过；在本步范围内修正后复查。
