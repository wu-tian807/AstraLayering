## 目标是什么

1. 以原有发型和后脑体积为基础，匹配参考关键帧及动画中的转向、透视、发面、发束走向、耳后轮廓、发尾落点与遮挡变化。后发加入后，整头应像同一个有体积的头部在转动；不能仅让外缘贴合，内部纹理却像不动的平面。参考中的显露量需要破坏发束结构才能达到时，检查转面和遮挡，保住完整形体与挂接。缺少单独 right 参考时，依据正面发型和相反透视制作，保留原有两侧差异。
2. 先辨明后发画层各区域的用途：外露后脑发面、内侧背发暗面、前侧发遮挡形成的投影、以及原先藏在发片下的补全暗底。结合原画层内容、分缝、发丝走向、明暗与遮挡关系判断，不能只按颜色深浅分类，也不能因画层名叫后发底就将整层当作可外露的后脑表面。阴影边界不是实体发缘或发根，暗区有像素也不等于能与前侧发接续。
3. 以同一个头壳的发旋、顶弧、耳后根及发髻接点协调前侧后发，再决定各片的局部透视和显露。后发通常承担较稳定的后脑体积，采用与实际转面相符的位移、转动和局部形变；它不是完全不动，也不必跟前发同幅度扭曲。幅度由本角色的转向、挂接和实际体积决定，不设统一数值。保留发束厚度和内部发流，同束多层共享主要运动，父级已有随动不在子层重复施加。
4. 衔接的是实际外层发面。由前发或侧发延续的发冠，要补足对应发片的真实连接段并留出覆盖；需要新露出的后脑外表面，要有相符的发流、笔色、纹理和体积。不能把前侧发缩在一圈内侧暗底里面，靠后发暗面承托成两层帽壳，也不能将前侧发根对到投影边缘。先定位出问题的姿态、发片和外露区域，在该区域修正形变或笔色。如果只是后发内侧暗底误露，优先保留原头壳和已成立的前侧发遮挡，只补实际需要外露的发面；不因补发冠而重画整片刘海、改眼周遮挡或移动无关发束。只有前侧发本身的接点或覆盖经对照确认有误，才局部调整对应发片；不把全部头发一起外扩，不靠拉长前侧发硬补整块后脑。
5. 先判断当前画稿和拆分能否支持所需外露发面。纯几何问题用合理转面与覆盖修正；画稿缺少外层发面时，在 Krita 补绘、修顺或拆分，再制作形变。新露出区若只有内侧背发暗色或补全暗底，应补成该位置应有的外层发面，或让本应承接它的前侧发完整覆盖；合理的内侧暗面仍保留在其应有位置。已烘在画稿中的遮挡投影只有确认归属后才清理或拆为独立投影，不把固有背光和内侧暗面一律提亮。补绘后核对实际取样范围、UUID 和模型绑定，新增画层或补片显式注册。不能把瑕疵挤小、降透明度或藏到截断边代替修复，也不为追逐视频中的结构异常重画角色。保留正面已成立的造型；持续不可见区只需覆盖，转动会露出的区域才按实际发面完成。结构与发面正确后仍有的局部参考差异才可记录。
6. 补齐与已制作前发、侧发、后发相关的独立投影和接收关系。先完成能独立成立的发面，再接入投影；投影跟随正确的发片，按当前接收部件裁切。检查新露出的后发上侧发投影与发缘的关系，避免旧画稿暗影与独立投影重复压暗。投影不能用来补洞、充当连接发片或伪造发根。

## 要保护什么

1. 可编辑 hair/bangs、hair/front_hair、hair/side_hair、hair/back_hair 及其对应阴影和专用 Warp，归属以工具返回的 partId 和 editable 为准。前发、侧发允许为整体协调作有理由的修改，保留已经建立的角色发型和可见参考关系，不无故推翻已有结果。脸、五官、耳朵、下颌、脖子和未制作的辫子、头饰保持原样。
2. 当前 KRA 与 hair.json 是工作依据。画稿修改在 Krita 保存，已有图层沿用 UUID，新图层显式绑定；不用独立 PNG 替换画稿，不回退到上游工程。投影保留独立图层和 caster/receiver 关系，不烘焙到脸或发片。
3. 不制作上下、四角或非零 Y。继承的脸部 Y/XY 数据原样保留。工作范围限本步工程、模型和检查记录，不修改工作流、工具或校验器源码；程序错误记录并返回 error。

## 自检查什么

1. 先在 Krita 核对当前后发及相关前发、侧发的实际内容、UUID、范围、绘制顺序、蒙版和投影。记下哪些部件需要变形或协调，以及是否需要改画稿、原因是什么。用 edit_nine_axis 显式注册需要的后发与阴影，正确组织 Warp、shadow、clip 和顺序；不假设工具会自动带上关联投影。
2. 对照当前 KRA 原形与关键帧描 source/target，保存在 outline/back/，分别标明实际外层发面、发根与分缝、内侧背发/补全暗底、遮挡及投影边界；记录哪段应延续、哪段应被覆盖，不能将暗色边缘直接标成发根或接合线。已有有效描线可复用，局部返工只重描受影响区域。先看完整后脑体积和同束发流，再判断合理显露、局部形变、拆分或补绘。描线核对后用 edit 制作，本轮不使用 fit。
3. 先临时隐藏独立投影，分别看后发画稿本色与前侧后发原色组合，判断实际发面能否连续接续；隐藏后仍在的暗块属于当前画稿，不能继续按独立投影解释。再恢复投影看完整组合，确认阴影只承担明暗和遮挡信息。后发独显检查完整体积、隐藏覆盖与纹理。参考比较使用同画布坐标、crop 和 scale 的 reference + edge，不重新对齐参考；edge 只验可见轮廓，发流、高光、明暗和空间感必须看原色。未制作的辫子、头饰不混入判断。
4. 用 frames 检查 X=-30、左侧中间值、0、右侧中间值和 X=30，全部 Y=0，并检查连续转头动画或更密的中间角度。重点看头顶连续性、近远侧厚度、耳后及发梢的显露顺序；在正常观看尺寸和局部放大时，可见描边、细尖和高光都应清楚连续，不能挤成亚像素碎边。不能后发僵住像贴板，也不能大幅挤压、剪切、拉伸或丢失后脑体积。端点贴合而中间穿插、露底、露出截断边、裂开、跳变或扁平，仍须修正；无翻折只是基本条件。
5. 改动前保存现有可用组合的原色检查图。若改了 KRA，保存后重新用工具读取，核对新增画稿和取样确已进入累计模型。用相同角度、显示范围和取景与改动前逐帧对照，检查整头、眼角和脸侧的遮挡、两侧长束及前后发体积。补片以外已成立的关系出现退化时，先恢复相应画稿或形变，再复查接缝。
6. 正常观看尺寸和放大检查都须确认：发旋与顶弧属于同一头壳，外露发面的发流与明暗随转面连贯，外露接缝没有用内侧暗底或投影边缘顶替应有的外层发面，阴影开关不改变对实体接续的判断。有覆盖但形成双层帽壳、宽暗带夹缝、错误发面显露、纹理不随转或明显亮暗断层，仍是本轮待修问题，不能写成参考偏差后通过；实际发根可藏入遮挡后，固有分缝和合理内侧暗面不要求抹平。保存 KRA、hair.json，在 notes.md 记录发面/暗区判断、实际修复位置、画稿与取样是否修改、原色和投影开关检查及仍有的限制。完成返回 {"error":null}，不能完成则返回 {"error":"具体原因"}。
