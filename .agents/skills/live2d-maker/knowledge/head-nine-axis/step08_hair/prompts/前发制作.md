## 目标是什么

1. 首要目标是与参考关键帧一致。清楚可见的前发直接按关键帧制作：整体位置、外轮廓、分缝、额角覆盖、主要发束的形状与落点、眼周遮挡都要对应，不能以“更自然”或“更圆润”为由另改大形。
2. 只有被遮挡、看不到的发顶需要合理推断。结合可见弧线和原正面比例，局部适度压低、顺接发根，消除悬高和尖顶；不要向外鼓、扩宽整片或做成圆帽，也不把整片刘海下移、压扁。前发不填补尚未制作的侧发、后发区域。
3. 只做 X 轴左右转动及中间过渡。left 对齐所选关键帧，right 保持同一发型和合理的相反透视；保留近远侧厚度，端点与中间值连续。
4. 前发自带的独立投影一起制作。阴影随发片运动，按当前接收部件裁切，不能静止贴在脸上、脱离发缘或越出脸部。强度和混合方式沿用 KRA，再结合参考检查。

## 要保护什么

1. 正面以原图为造型基准，其他有清晰参考的角度按对应关键帧制作。保留角色的发型辨识特征，不让隐藏发顶的补全带偏可见发面。
2. 只编辑 hair/bangs、hair/front_hair 及其对应阴影、专用子节点和 Warp。新增节点 id 沿用这些前缀，新部件 level=hair。脸部、五官、耳朵、下颌、脖子和其他发片的画稿、形变与层级保持原样。
3. 当前 KRA 与 hair.json 是工作依据。需要补绘时在 Krita 中修改并保存；已有图层沿用 UUID，新图层及时绑定，由工具按需读取，不单独修改 PNG。
4. 阴影保留为独立图层及接收关系，不把投影烘焙进前发或脸部画稿。未制作发片及头饰的投影不提前混入本轮。
5. 本步骤不制作上下、四角或任何非零 Y 的关键形。已完成脸部的上下与四角数据只作继承保留，不在本轮修改或预览。
6. 工作范围限本步工程、模型与检查文件，不修改工作流、工具或校验器源码；遇到程序错误，记录原因并返回 error。

## 自检查什么

1. 先用 Krita 打开本步 KRA，检查实际图层、UUID、范围、绘制顺序和混合方式；结合已有阴影记录，独显确认前发、对应投影及接收部件。不要仅凭名称认定内容。将确认结果记入 notes.md，再用 edit_nine_axis 的 add_part 注册需要的图层（已有节点则保留或 bindings 重绑），明确投影的 shadow、clip 和绘制顺序。画稿只引用 UUID，不另做 PNG 素材。共享大形 Warp 时显式选中发片和投影，不假设工具会自动带上关联层。
2. 对着当前 KRA 原形和 left 关键帧描出 source/target 轮廓，保存到本步 outline/；将外缘、额角、主要发束与发梢拆成对应小段，标清可见段和遮挡推断。先检查描线贴合，再用 edit_nine_axis 建 Warp、调整 Y=0 下的左右网格。本轮不使用 fit，描线作为形变和检查的依据。前发独显及与已完成脸部、对应投影的组合都要看；未制作发片不参与判断。
3. 保存 KRA 后，用同一画布坐标、裁剪和缩放作 reference + edge 比较，不重新对齐参考。叠加比较只用工具的 edge，不自行制作 blend 叠图。先核对可见部分的位置、宽度、分缝、额角弧线、主要发束落点和眼周遮挡；这些与关键帧明显不一致就继续修正。内部发流、高光与投影用原色预览检查。隐藏顶缘再单独判断是否适度压低、顺接，不追贴头饰边线，也不外扩。
4. 用 frames 并排检查 X={left_angle}、中间值、0、另一侧中间值与 X={right_angle}，全部固定 Y=0。确认发顶不随左右转头上漂、变尖，近远侧保留合理厚度，发梢和遮挡连续，无明显纹理拉伸、折叠或跳变。
   同时检查投影是否跟随发片、与发缘关系合理、被动态接收部件正确裁切；需要分辨形状问题时可暂时 hidden 阴影，完成前恢复组合复查。
5. 大形、发束或原色体积仍有明显偏差时，在同一制作回合内继续修改并复查。工具成功、网格合法、顶弧变圆或已经看过 edge，都不能单独作为效果合格的依据。
6. 检查通过后保存 KRA、hair.json，并在 {uri:nine-axis/step08_hair/notes.md} 记录实际修改、比较结果和仍存在的问题。完成返回 {"error":null}；无法达到目标时返回 {"error":"具体原因"}，不要把明显未解决的问题写成已通过。
