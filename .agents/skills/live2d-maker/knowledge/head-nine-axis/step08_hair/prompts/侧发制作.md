## 目标是什么

1. 首先对齐参考中清楚可见的侧发：发根位置、外轮廓、耳旁弧线、脸颊覆盖、主要发束与发梢的形状和落点。保留原发型，不以“更圆润”为由扩宽整个头部或另改大形。
2. 侧发与前发通过分层搭接连成同一头壳。保留原有谁盖住谁的关系，侧发隐藏上段延伸到前发后方并留覆盖余量；前侧发不是沿两条边刚好对接。顶区延续原正面厚度和发流，横转时保持连续顶弧。参考被遮住的部位按这种关系补全，不把前景遮挡边当作侧发的完整边界。
3. 制作 X 轴左右端点及中间过渡。left 按关键帧；right 分别处理交换后的近远关系。近侧展开、远侧收窄，耳旁发面和发尾保留厚度；前侧发共同呈现同一个头部的转向，避免两侧一起挤薄或贴成平斜面。
4. 对应独立投影一起制作，包括实际落在侧发上的前发投影、侧发投向已完成部件的投影。先确认实际图层和关系，再注册；投影跟随正确的发片运动，按当前接收部件裁切，混合方式与强度沿用 KRA。接收部件尚未制作的投影留待对应轮次。

## 要保护什么

1. 已完成前发及其阴影、脸、五官、耳朵、下颌和脖子的画稿、形变与层级保持原样。只编辑 hair/side_hair 下的侧发、对应阴影和专用 Warp；新增节点沿用此前缀，部件 level=hair。后发、辫子和头饰不制作。
2. 正面以原图为基准，保留原有发型辨识特征、两侧差异和发梢设计。参考中可见部分优先对齐，隐藏部分的补全不能带偏可见发面。
3. 沿用当前这份 KRA 和 hair.json，不复制或回退到上游工程。需要补绘时在 Krita 修改并保存，已有图层沿用 UUID，新图层显式绑定，不单独修改 PNG。不把独立投影烘焙进发片或脸部。
4. 本轮只做左右，Y=0；继承的脸部上下与四角数据保留，不修改、不预览。工作范围限本步工程、模型与检查文件，不修改工作流、工具或校验器源码；程序错误记录并返回 error。

## 自检查什么

1. 先在 Krita 打开当前 KRA，独显确认两片侧发、对应投影、接收部件、UUID、范围、顺序和混合方式。结合已有阴影记录判断实际内容，不仅凭名称判断。将确认结果记入 notes.md，再用 edit_nine_axis 显式 add_part 或 bindings，设置 shadow、clip 与绘制顺序。工具不会自动带上关联阴影；需要共同大形运动时明确组织 Warp，前发已有节点不重绑、不重挂。
2. 对照当前 KRA 和 left 关键帧描 source/target，保存到 outline/side/。两片分别标出真实可见外弧、贴脸边、发梢，以及伸到前发后方的隐藏覆盖区；先确认边界归属和搭接，再用 edit_nine_axis 制作左右网格。本轮不使用 fit。
3. 每片侧发分别独显作固定坐标 reference + edge，只比参考中真正可见的段，不追贴被前发遮住的隐藏轮廓。再看脸＋前发＋侧发的组合 edge 和原色：核对顶弧、耳旁厚度、遮挡层次、发流与高光。组合 alpha 连成一片不能证明内部搭接正确，需放大查看前侧发接合处。后发、其余头发和头饰不混入本轮。
4. 用 frames 检查 X={left_angle} 到 X={right_angle} 的 13 个等间隔姿态，全部 Y=0。逐段查看前侧发交界及贴脸边的持续覆盖；保留原有可见分缝，同时没有透底、截根或突然脱开的硬边。近侧展开和远侧收窄连续，顶弧不下塌，发流、高光与发梢没有被填缝拉扯。必要时 hidden 阴影区分形状，完成前恢复投影复查。
5. 搭接不足时先定位缺少哪一片的隐藏延伸；必要时在 Krita 补足该片的完整发面和发流，再用合理形变衔接。保留可见耳旁轮廓、发尾和厚度，不靠把整片拉窄、压低或扭曲高光来填缝。轮廓、体积、搭接和连续运动均通过后保存 KRA、hair.json，并在 notes.md 记录证据及限制。返回 {"error":null}；不能完成则返回 {"error":"具体原因"}。
