【脸部轮廓先验】
以下是辨认真实脸缘与遮挡边的倾向，结合本角色原画、本方向先验和参考中的清楚证据使用。

- 整体：脸底通常从额顶经额角、太阳穴、脸颊和下颌连续接到下巴，形成以外凸为主的闭合轮廓。侧转远颊的真实陡边、眼窝起伏和原画固有转折按实际保留，不统一圆滑化。
- 额顶与额角：头骨通常沿一段饱满弧面展开，额顶高于刘海下沿；额角沿头骨接向太阳穴和脸颊。发际线的急转折不等于真实头骨轮廓；本步将被遮住的部分标为临时闭合，不补形。
- 脸颊：常在颧骨或眼睛下方较宽，再向下颌收束。圆脸的颊部弧线保持体量；原画有明确棱角时保留，不因贴合遮挡边造成台阶、凹口或异常瘦直。
- 下颌与下巴：下颌向下巴汇合，圆颏、尖颏或宽扁底缘以原画为准。下颌与固定脖子接触处的阴影线不直接当作脸缘。
- 对称：正面、纯抬头和纯低头通常近似左右对称。单侧明显变瘦、变直或出现凹口时，先查刘海、鬓发、发影和饰品遮挡，再判断是否是真实轮廓；保留角色原有的不对称特征。
- 遮挡：紧贴发丝、耳朵、饰品或投影且走势突然改变的边，可能是可见皮肤窗口的边界。先确认归属，分别标注真实脸缘与遮挡边，不在本步推断或补画隐藏脸缘。
- 边缘：SVG 描线连续、干净，保留原画和本帧有依据的转折，不把发丝、发影切出的边误标成真实脸缘。

【目标】
- source-face.svg：先用 view_nine_axis 在 0 度独显 face/face_base，按 box 裁出检查图作为 source-face-reference.png，再沿该图层的完整 alpha 描脸底并用 preview_svg 核对。检查图不是形变输入素材。
- target-face.svg：对着目标帧描整张脸，两侧一样认真。视频里看得见的皮肤，它的边就贴着皮肤与背景、头发、阴影的交界走，走向、转折和陡度照视频；被鬓发、发束切开后露出的每一段皮肤边都照视频描；刘海、鬓发之间露出的额头、额角、脸颊皮肤都包进脸内，不漏细尖角和暗处的皮肤。
- 只有真正被头发盖住、视频里看不见的地方才临时闭合，不补形。
- SVG 是纯色闭合 path、透明背景、viewBox="0 0 box.size box.size"。

【要保护的】
看得见和被盖住要分清。描线越过皮肤伸进头发或背景的地方，要能指出那里确实是被头发盖住的脸；指不出就是描错了。
用 preview_svg 的 edge 把 target-face 轮廓叠在目标帧上，沿两侧脸缘、额角和下颌逐段放大 crop（scale 4..8），每段看得见的皮肤边都贴住为止。
