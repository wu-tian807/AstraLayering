# 头部九轴先验

本目录只管理头部九轴，和后续身体九轴分开。文件夹以 `head-nine-axis` 明确归属；流程标识与任务产物仍由 `nine-axis` 管线管理。

- `step*/agent.json`：本步骤的提示词组合、角色与工具列表。
- `prompts/`：头部九轴内部共用的脸缘补全、制作与交付范围；步骤通过 `head-nine-axis/prompts/...` 引用。
- `tools/`：头部九轴专用工具说明，包括形变编辑、拟合、多帧预览和参考视频抽帧；工具说明只写工具契约，任务目标留在各步骤提示词。
- 各步骤的 `prompts/`、`references/`、`tools/`：该步骤的目标、参考材料与专用工具覆盖说明。

工具说明按“步骤 → 头部九轴 → 公共工具”的顺序读取。Krita、位图预览等跨管线工具继续使用 `shared/tools`。自定义知识目录也使用这一结构。
