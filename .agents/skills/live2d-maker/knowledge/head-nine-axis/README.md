# 头部九轴先验

本目录只管理头部九轴，和后续身体九轴分开。文件夹以 `head-nine-axis` 明确归属；流程标识与任务产物仍由 `nine-axis` 管线管理。

- `step*/agent.json`：本步骤的提示词组合、角色与工具列表。
- `prompts/`：头部九轴共用的形变与遮挡原则，以及脸部阶段的轮廓先验、补全和制作验收；步骤通过 `head-nine-axis/prompts/...` 引用。方向先验留在各方向正文，整头步骤按自己的编辑范围检查耳根接合。
- `tools/`：头部九轴专用工具说明，包括形变编辑、拟合、多帧预览和参考视频抽帧；工具说明只写工具契约，任务目标留在各步骤提示词。
- 各步骤的 `prompts/`、`references/`、`tools/`：该步骤的目标、参考材料与专用工具覆盖说明。
- `step10_head-pitch/`：完整左右之后的头部上下，沿用单轴参考，up／down 两个独立上下文并发制作整个头部。
- `step11_head-angle-xy/`：完整单轴之后的整头斜角，一个会话协调四角，保留已有单轴。

固定的任务产物用 `{uri:…}`，先验自带的素材用 `{reference:…}`。方向作为 `{group_id}`，有独立要求时用步骤下的 `prompts/groups/<方向>/` 覆盖对应文件。各步骤在提示词中写明目标角度。模型关键形刻度见 `step02_video/references/angles.json`。引用和变量遵循[共享提示词规则](../../shared/README.md#动态位置)。当前 KRA 由模型的 `source.document` 声明，制作步骤自有的 KRA 可直接引用固定路径。

单轴步骤的 `方向任务.md` 由 left、up、down 各自提供，启动时检查三个方向的正文。

工具说明按“步骤 → 头部九轴 → 公共工具”的顺序读取。Krita、位图预览等跨管线工具继续使用 `shared/tools`。自定义知识目录也使用这一结构。
