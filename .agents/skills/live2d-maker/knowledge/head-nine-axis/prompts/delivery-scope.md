【脸部制作与验收】
直接引用上游 KRA，不修改画稿。只制作本方向的脸底、五官和原工程已有的独立耳层，保留其他方向和上游绑定。头发、头饰作为遮挡参照，脖子固定；本方向的额顶、额角、太阳穴和脸侧补全在本步完成，下颌接触在 step07 收尾。登记 UUID 和静止网格不等于完成姿态，需要随动的部件按实际关系挂入承载；独立投影保留实际归属、随动和裁切，不烘入脸底。

1. 逐段辨认描边中的皮肤边界。真实脸缘保留本方向的走向和转折；头发盖住皮肤的边沿发丝走，它后面仍有脸。只有第二类需要顺着本人的脸型伸入头发下，给发片移开留出皮肤覆盖。归属不清的零散露肤先辨认是脸、耳根还是脖子，不为了够到它扩大脸底。
2. 补全轮廓与可见脸缘连续相接，按本方向先验延续，保留真实直线和转折，接合处不生出尖角、折口或缺口。用 preview_svg 的 edge 叠在当前方向参考帧上，沿外缘逐段放大检查：补全段是否仍是这张脸的自然延续、是否藏在合理发面下、发片移开时是否仍有覆盖。参考中露出的背景、发丝空隙和其他部件不能被补成皮肤。修正后复看，结构与参考冲突的局部先纠正边界归属和目标描线，再按形变与遮挡规则处理。
3. 写描线 JSON，version=1、space=view。completion={part,source,target} 中 source 用 source-face.svg 的完整闭合路径，target 用补全后的闭合轮廓；curves 记录对应小段，真实可见脸缘标 visible，隐藏补全段标 occluded。建脸底 Warp，用 fit_nine_axis 先 inspect 再 fit，方向与描线文件沿用当前任务的配置。
4. 用 view_nine_axis 在本方向角度、only=["face/face_base"] 查看实际变形后的脸底，与补全目标和参考帧对照。未到位的隐藏覆盖、接不顺的轮廓和碎边用 fit 的 features 或 edit_nine_axis 局部修正。验收结构合理的目标轮廓与实际网格结果，不能为了追逐视频中的异常轮廓把脸拉坏。
5. 用 edit_nine_axis 调整眉眼、鼻、嘴和腮红。每个部件的固有形态、内部结构、部件间距离与相对位置保持同一角色的关系，只随该姿态的透视合理变化。逐个对照正面原画和本方向参考，修掉额外放大、缩小、拉扯和错位，连同脸底检查原色与边缘。
6. 在正面原画定位每侧耳根与同侧脸缘的接合处。让耳根随脸缘移动，按透视调整耳轮位置、形状和角度；同耳多层共用主要 Warp，再按需微调局部。用 level="face" 检查本方向规定的端点和过渡：耳根接到脸底后方，露出的耳轮连续，无悬空、穿插和分层滑动。远耳可自然进入脸或头发之后，不能为增加露出量把耳轮拉长，也不能靠头发遮住断开的耳根。没有独立耳层时检查合成轮廓。
7. 再看包含头发的合成和镜像姿态，核对端点与连续过渡的接点、遮挡显露和投影。中间组合由模型渲染器插值，只按实际过渡需要增加本步允许的局部辅助修正，不穷举所有 X/Y 组合。补全、五官与耳朵均须完成，工具成功或只绑定部件不代表通过；在本步范围内修正后复查。
