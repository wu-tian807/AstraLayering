【1. 辨认脸缘并补全】
逐段辨认描边中的皮肤边界。真实脸缘保留本方向的走向和转折；头发盖住皮肤的边沿发丝走，它后面仍有脸。只有第二类需要顺着本人的脸型伸入头发下，给发片移开留出皮肤覆盖。归属不清的零散露肤先辨认是脸、耳根还是脖子，不为了够到它扩大脸底。

【脸部轮廓先验】
以下是辨认真实脸缘与遮挡边的倾向，结合本角色原画、本方向先验和参考中的清楚证据使用。

- 整体：脸底通常从额顶经额角、太阳穴、脸颊和下颌连续接到下巴，形成以外凸为主的闭合轮廓。侧转远颊的真实陡边、眼窝起伏和原画固有转折按实际保留，不统一圆滑化。
- 额顶与额角：头骨通常沿一段饱满弧面展开，额顶高于刘海下沿；额角沿头骨接向太阳穴和脸颊。隐藏部分沿本角色脸型延续，不沿发际线的急转折补形。
- 脸颊：常在颧骨或眼睛下方较宽，再向下颌收束。圆脸的颊部弧线保持体量；原画有明确棱角时保留，不因贴合遮挡边造成台阶、凹口或异常瘦直。
- 下颌与下巴：下颌向下巴汇合，圆颏、尖颏或宽扁底缘以原画为准。下颌与固定脖子接触处的阴影线不直接当作脸缘。
- 对称：正面、纯抬头和纯低头通常近似左右对称。单侧明显变瘦、变直或出现凹口时，先查刘海、鬓发、发影和饰品遮挡，再判断是否是真实轮廓；保留角色原有的不对称特征。
- 遮挡：紧贴发丝、耳朵、饰品或投影且走势突然改变的边，可能是可见皮肤窗口的边界。先确认归属，再推断其后的脸缘，不将所有可见皮肤边都当作脸的外轮廓。
- 边缘：形变后的脸底和五官边缘连续、干净，修掉网格拉扯造成的碎裂、锯齿、毛刺和抖动台阶，同时保留原画笔触和有依据的转折。

补全轮廓与可见脸缘连续相接，按本方向先验延续，保留真实直线和转折，接合处不生出尖角、折口或缺口。用 preview_svg 的 edge 叠在当前方向参考帧上，沿外缘逐段放大检查：补全段是否仍是这张脸的自然延续、是否藏在合理发面下、发片移开时是否仍有覆盖。参考中露出的背景、发丝空隙和其他部件不能被补成皮肤。修正后复看，结构与参考冲突的局部先纠正边界归属和目标描线，按本人的合理透视和遮挡处理；没有合理遮挡的位置保住脸型，记录具体参考偏差和原因，不为贴帧过度拉伸或挤压。

【2. 应用脸部形变】
写描线 JSON，version=1、space=view。completion={part,source,target} 中 source 用 source-face.svg 的完整闭合路径，target 用补全后的闭合轮廓；curves 记录对应小段，真实可见脸缘标 visible，隐藏补全段标 occluded。建脸底 Warp，用 fit_nine_axis 先 inspect 再 fit，方向与描线文件使用本方向的 face-trace.json。先确定脸底、五官和耳朵的整体随动，再处理局部透视与接合；父级已带动的运动不在子层重复施加。

【3. 微调脸部形变】
用 view_nine_axis 在本方向角度、only=["face/face_base"] 查看实际变形后的脸底，与补全目标和参考帧对照。未到位的隐藏覆盖、接不顺的轮廓和碎边用 fit 的 features 或 edit_nine_axis 局部修正。验收结构合理的目标轮廓与实际网格结果，不能为了追逐视频中的异常轮廓把脸拉坏。

【4. 调整五官】
用 edit_nine_axis 调整眉眼、鼻、嘴和腮红。九轴只表达头部姿态与立体透视。以正面原画守住各眼的开合和虹膜占比、口型开合与笑意、眉形情绪。视频用来判断五官的位置、朝向和透视幅度，出现瞪眼露白、眯眼、圆口或闭嘴时沿用原画表情，只按姿态缩窄、位移或微斜。各眼虹膜和高光随所在眼的整体透视，按需轻微居中，避免把眼白纵拉或把虹膜单独描窄。逐个对照正面及方向参考，连同脸底核对原色与边缘。

【5. 调整耳朵】
在正面原画定位每侧耳根与同侧脸缘的接合处。让耳根随脸缘移动，按透视调整耳轮位置、形状和角度；同耳多层共用主要 Warp，再按需微调局部。用 level="face" 检查本方向规定的端点和过渡：耳根接到脸底后方，露出的耳轮连续，无悬空、穿插和分层滑动。保留耳朵等小部件的原画形体与自然比例，不为追上视频的露出面积而拉宽或拉长。按正常发片遮挡少露或不露都可以，耳根仍须接到脸缘。没有独立耳层时检查合成轮廓。被遮住的耳朵仍保留完整形体和随动，不通过关闭显示、降低透明度或挤薄来冒充遮挡。

【6. 检查端点与过渡】
X=0 时两侧脸缘通常近似对称；单侧瘦直或有凹口先查遮挡，保留原有不对称。检查正面、半程和抬头端点的五官透视、耳根接合与耳轮显露，耳朵随本方向头部运动，脖子固定。
用 level="face" 检查镜像与连续过渡的接点和投影，发片遮挡以本方向参考帧为依据。中间组合由模型渲染器插值，只按实际过渡需要增加本步允许的局部辅助修正，不穷举所有 X/Y 组合。补全、五官与耳朵均须完成，工具成功或只绑定部件不代表通过；在本步范围内修正后复查。
