【任务】
做脸部＋双耳的上下形变：沿用 step02 的脸部图层与 warp 网格，再拟合两个关键形，ParamAngleY = +30 对齐抬头视角 up.png（约 25°），ParamAngleY = −30 对齐低头视角 down.png（约 20°）。±30 是参数值，不是度数。上下不对称，两个方向分别拟合，不镜像。
只做形变本身：抬头、低头时轮廓线的出现与消失（如下颌线、下巴下缘、被头发遮住或露出的线）本步不处理，留给后续步骤统一调整；不补绘、不改图层像素、不用透明度。

【输入】（只读）
- step02 的变形器："{uri:nine-axis/step02_angle-x/deformers.json}"。每个部件的 bbox、cols、rows、keyforms["0"]（静止网格）与绘制顺序就是本步的网格，不改；贴图在同目录 layers/ 下（按 textureBounds 裁出的透明 PNG）。step02 的拟合脚本在 workspace 里，可以复用。
- 正面头部特写："{uri:nine-axis/step01_views/upper-body.png}"；抬头视角："{uri:nine-axis/step01_views/up.png}"；低头视角："{uri:nine-axis/step01_views/down.png}"。三张都是 box.size 见方，与画布 1:1，像素 (u,v) 对应画布 (box.x+u, box.y+v)；box 见 "{uri:nine-axis/step01_views/crop.json}"。
- up.png、down.png 是生图结果，只作形状目标；画法细节与原图层不同，不拿它们的像素替换图层。

【做法】
沿用 step02 的拟合方法，把转向的轴换成横轴，在 workspace 里自己写脚本完成（Python 的 numpy、scipy、opencv、torch；缺的库用 uv 装在 workspace 内）。蒙版、可见轮廓段、权重、ROI 与耳根点都看本角色的图来定。每一步的中间结果都渲染成图看过再往下走，不合适就调参或改代码，不能跑通即交付。抬头、低头各做一遍：
1. 五官定位：左右眼、左右眉、嘴、鼻各取正面合成上的范围作模板，在目标视角中做多尺度模板匹配（纵向 0.6–1.15、横向 0.95–1.05，TM_CCOEFF_NORMED），得到各五官在目标图中的位置与纵向缩放。分数低或位置明显不对的五官降权或剔除。
2. 父级（整体俯仰与脸型），后向场（目标→原图）= 横轴圆柱俯仰 + 平滑残差：
   - 圆柱：y' = C + ty + R·sin(asin((y−C)/R) − θ)，C 为头部中心所在行。用 least_squares 拟合 R、θ、ty，使五官 y 位置吻合，并约束眉眼、嘴的纵向缩放。横向偏移取五官位移的平均。
   - 残差：脸部框上的 10×10 双三次网格，损失与 step02 相同：目标视角中可见的真实外轮廓（下颌、脸颊）内外侧的脸底 alpha、肤色覆盖（权重 0.3）、网格平滑 5e-3。被头发遮住的轮廓不约束。低头时下巴下缘、抬头时下颌下方新出现或消失的线不当作轮廓目标，按形变本身延续即可。
   - 渲染只用父级变形的脸底与五官，叠在目标视角上看脸型与五官大致位置。
3. 子级（按教程结构）：在父级之上，眉眼（有腮红时并入）6×4、嘴 4×4、鼻 3×3，ROI、损失和参数同 step02。子级只补细节，拟合后对照【教程先验】检查五官间的距离关系，不对就加权或加约束重拟，不手填点。
4. 耳朵：不拟合目标视角中的耳朵像素。双耳都按父级在耳根点（耳朵贴脸一侧与脸底轮廓相接处）的位移整体平移，纵向缩放取父级在该点的纵向缩放，形状不扭曲；耳根始终贴在变形后的脸缘上。上下俯仰时耳朵不转到脑后，绘制顺序沿用 step02。
5. 导出：每个部件在 step02 的 16×16 网格上，用牛顿法反解后向场（父级＋本组子级）求出每个控制点的前向位置，分别作为关键形 "30"（抬头）与 "-30"（低头）。不交付折叠的网格。坐标均为原画布像素。用交付的关键形重新渲染，确认与拟合结果一致。

【教程先验】
Y 轴的重点不在透视，而在距离关系。拟合后逐项对照检查，不合适时调整拟合（加权、ROI、约束），不手填轮廓点或控制点。
- 低头时眉眼距离缩小，抬头时增大。
- 嘴低头变扁，抬头变高。
- 鼻子低头时更靠近嘴，抬头时跟着嘴一起移动。
- 耳朵不做细节调整，贴着脸缘随动、不变形。
- 大造型小细节：父级决定位置和造型，子级只补父级做不到的细节。做一个五官时，注意它与其他五官和脸型的关系。
