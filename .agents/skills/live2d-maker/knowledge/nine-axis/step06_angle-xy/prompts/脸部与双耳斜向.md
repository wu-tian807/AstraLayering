【任务】
做脸部＋双耳的斜向（四角）关键形：左上 (ParamAngleX, ParamAngleY) = ({left_angle}, {up_angle})，即向左约 {left_degrees}° 同时抬头约 {up_degrees}°；左下 ({left_angle}, {down_angle})，即向左同时低头约 {down_degrees}°。单位为度。
程序已经把 step03 的向左与 step05 的抬头、低头线性叠加，写成两个角的起始形；你从这个起始形出发手动斜切，把它调得好看：斜着转头时脸型、五官的透视与位置关系自然，在工作台里从正面拖到四角、在四角之间来回拖时过渡顺滑。右上、右下由程序镜像。
只做形变本身：沿用 step03 的图层、网格和绘制顺序；轮廓线的出现与消失留给后续步骤；不补绘、不改图层像素、不用透明度。

【教程斜切要点】
- 四角从 X 与 Y 的叠加出发，手动斜切，不用一键斜切：手动斜切保留中轴作参考和每个可控的细节。
- 斜切最考验空间感与审美，九轴好不好看多半看斜切；慢慢细调，先拉好大致形状再调细节。
- 时刻保持透视的形状：头往哪边转，透视都以脸部中心为准；网格像贴在球面上，斜着转时横线和竖线一起弯，近侧舒展、远侧收窄。
- 中间的手柄（中轴）留作参考：低头角做完后整体往上移一些，抬头角做完后整体往下移一些，这样从正面拖到斜向时过渡更圆滑。
- 过渡流畅是九轴精度的关键：拖动 X 时变形器沿一条好看的弧线走，X 与 Y 之间的过渡流畅。
- 时刻注意脸部结构：眉毛的位置、眼睛的形状、腮红的形状。
- 眉、眼、腮红作为一组斜切：眉毛与腮红在脸的凸处，眼睛在凹处；眼睛的形状保持完整，瞳孔位置的分割线尽量横平竖直；上半部分透视明显，下半部分几乎没有。抬头时眉眼距离增大，低头时缩小，斜向也保持这个关系。
- 嘴的透视与眉眼相反，下半部分才明显；变形器保持好的形状，嘴的形状就不会差。
- 鼻子转面复杂，四个角各自调成需要的形状，而不是单纯垂直平行地拉；鼻子、嘴和下巴连成一条线比较好看。
- 做一个五官时注意它和其他五官、脸型的关系，看着不好看就一起调；最后对五官和脸型做一次细节微调。
- 大造型小细节：父级（脸底）决定位置、造型和透视，子级（眉眼、嘴、鼻）只补父级做不到的细节。

【做法】
像画师照着教程手动斜切：在 workspace 里自己写脚本改起始形（Python 的 numpy、scipy、opencv、torch；缺的库用 uv 装在 workspace 内），脚本是画笔，好坏靠自己看。每改一次就渲染出图，用 view_bitmap 放大看，看出哪里不好看就改哪里，再渲染再看。
- 先渲染起始形，看清线性叠加的问题出在哪里：哪里透视不对、五官挤或散、脸型走样、上下与左右的变化互相打架。
- 先拉脸底：照参考帧把脸底外轮廓拉成一整条干净的外凸线，近侧舒展、远侧收窄，下巴尖落在参考帧的位置。脸型对了，再逐个调眉眼腮、鼻、嘴，每个部件按自己的形状斜切。脚本按部件、按局部区域拉网格点，像在 Cubism 里拖手柄那样一处一处地调。
- 眉眼一排的走向对照参考帧：斜向时它随转头与俯仰起伏，脸的中线保持竖直，整张脸看上去是在转、在俯仰，而不是在侧歪。
- 需要知道这个角度真实的样子时，从斜向参考视频取帧，与渲染结果叠线稿、半透明叠图对照；被头发挡住的地方照教程纯脸走。
- 每轮都看：四角各自的渲染与参考帧、教程示范并排；从正面经向左、抬头或低头到斜向角的几个中间角度连起来看（按工作台的方式，在 0、{left_angle} 与 {up_angle}、{down_angle} 之间双线性插值），过渡要顺；不叠头发的脸单独放大，被头发遮住的部分像教程纯脸一样干净。
- 不在脚本里写形状的判定或断言，也不以数值达标当作做好了；数值只用来找问题出在哪。

保护：
- 已做好的正面、向左、抬头、低头关键形不变，本步只交付两个斜向角。
- 脸的总体轮廓保持一整条干净顺滑的外凸线，大小与向左、俯仰时一致；正面伸在刘海、侧发下面的脸边，斜向时仍伸在头发下面，脸边与头发之间不露缝。
- 左右与上下各自的特点在斜向上都看得出：转向的近宽远窄、远侧耳朵到脑后由脸遮挡，俯仰的眉眼距离、下巴尖圆。
- 耳朵贴着脸缘随动、不变形；没有耳朵图层时跳过耳朵。
- 有脖子部件（neck）时，它所有关键形都与静止相同：脖子不变形，转头、俯仰时是脸在它上面移动。
