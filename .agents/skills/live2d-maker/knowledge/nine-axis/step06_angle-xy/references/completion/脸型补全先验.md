# 左上／左下完整脸型补全先验

用于 `step06_angle-xy`。**本步由 agent 从左上、左下各自的视频中选择目标帧；选中帧决定可见脸缘、五官、笔锋和位置。** 本页只帮助预测视频看不到的额头、太阳穴、脸颊和下颌。先验与本角色可见证据冲突时，以选中视频帧为准。

已认可的本角色 left、up、down 是角色脸型、体量和过渡的约束，应保住已有轴端点；它们不是替代斜向视频的目标。两个角各自描边、补全和拟合，不把 left 与 up/down 直接相加当作成品，也不把左上倒过来当左下。模型参数 X=-30/Y=±25 仅标记原模型关键形，不是物理测量，不能据此认定本角色视频恰好转了多少度，也不能指定一个通用取帧时间。

## 怎样补全斜向隐藏脸型

先分清真实皮肤外缘、头发遮挡边界、发影与耳轮。源轮廓来自原 KRA 完整脸底；目标轮廓的可见段精确描选中视频帧，隐藏段以原画体量、已认可姿态及接近脸型的结构参考连接。发束围成的皮肤窗口不是完整脸型，发梢凹口不能捏进脸肉。

| 区域 | 左上补全观察 | 左下补全观察 | 共同约束 |
| --- | --- | --- | --- |
| 额头、额顶、太阳穴 | 额部到侧颊怎样在斜向上抬时保持连续体量 | 下俯遮挡增加时，额部怎样仍连到两侧太阳穴 | 不沿刘海闭合，不任意膨胀或压扁隐藏额部 |
| 远侧眼外侧到颊部 | 侧面转折与上抬下颌如何连接 | 侧面转折与下俯渐收段如何连接 | 选中视频可见的切线、竖向段、转折和笔锋优先；不能统一磨成蛋形 |
| 近侧脸颊与下颌 | 饱满颊如何连到投影后的底缘 | 颊部如何渐收至下巴，同时保留原脸型 | 被头发挡住的部分仍有脸肉体量；不把发缘凹口当骨肉外缘 |
| 下巴与固定脖子 | 下颌覆盖脖子顶部的范围 | 下俯脸底遮盖与接触位置 | 脖子固定参与同坐标参考，不挂头部 Warp、不倾斜、不拉长；延长和消线留 `step07_jaw-line` |

五官的目标同样取选中帧。先完成整张脸底的闭合预测，再让自动 Warp 拟合；五官可以按整眼、整嘴等语义组批量形变并局部微调，具体分组和父子关系由 agent 根据本角色需要定义。其它模型的五官位置只帮助理解结构，不能强加“鼻嘴下巴必须共线”“抬头必圆、低头必尖”等规则。

先按原画选择接近的脸型，并说明用于哪个隐藏区域。不同脸型不平均成一种脸；同为圆脸也不共享五官比例。基准 X=0/Y=0 不保证绘画没有倾斜。原模型脸组、纹理或蒙版仍可能留下发影、装饰、小块色带及耳部，这些都不能作为需要复制的脸外缘或笔锋。

来源为本仓库已有 `model-originals/archives/qq-mail-20261009` 官方样例包，复用其恢复后的 runtime-models，原 model3.json、moc3 与贴图只读。直接用已装 live2d-py 的原关键形与蒙版渲染：内存设置移除 motion/physics/pose/expression，关闭自动眨眼、呼吸；身体、视线、嘴开、Z 和整体变换固定为零，其余保持原模型默认值。每张图新建模型，`Update(0)` 后核对 X/Y 实际值及所有固定控制；原文件渲染前后 SHA 相同。

[左上来源与参数记录]({reference:step06_angle-xy/references/completion/left-up/models/sources.json}) 和 [左下来源与参数记录]({reference:step06_angle-xy/references/completion/left-down/models/sources.json}) 保存源文件 SHA、六张图的两个参数检查、联合裁框和交付图片 SHA。每个单模型目录保留 `face_front.png`、`face_left-up.png`／`face_left-down.png`、`features_front.png`、`features_left-up.png`／`features_left-down.png` 原 RGBA。脚本扩展复用 `render_faces.py --axis xy`、`build_reference_board.py --direction left-up|left-down`，原 X/Y 路径保留。原模型参数变化幅度与视觉转角没有统一换算关系，不导入其网格或贴图给本角色。

## 描边、拟合后怎样核对

用现有 `preview_svg` 看选中视频帧的局部叠加，检查远侧眼外侧到颊部的切线和笔锋。将已核对 SVG 形成完整闭合 source/target 及 visible/occluded 分段：可见皮肤外缘不能误归遮挡，头发边界不能误归真实脸缘。先查看无遮挡完整预测，再调用现有 `fit_nine_axis` 自动求 Warp；拟合后用 `view_nine_axis` 单独看真正变形后的完整脸底，并加回五官和固定脖子同坐标对照。

两角分别核对可见轮廓与五官，再回查已认可 left/up/down 和轴到四角的过渡。数值拟合误差只说明约束贴合程度，不能代替脸型、体量和笔锋的视觉检查。结果仍交用户验收，用户明确通过前不得称流程稳定。
