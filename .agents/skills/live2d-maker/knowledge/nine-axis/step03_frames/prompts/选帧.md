【left、up 与 down：选帧】
本步只选帧：为三个单轴方向各选一张参考帧。left 向左转约 {left_degrees}°，up 抬头约 {up_degrees}°，down 低头约 {down_degrees}°。描边、补全和形变交给后面的步骤，它们都照着这里选的帧做。下文的 <view> 指 left、up 或 down。

【输入】
- 原正面 "{uri:nine-axis/step02_video/upper-body.png}"，是三段视频共同的首帧；box 见 "{uri:nine-axis/step02_video/crop.json}"。
- 三段原视频 "{uri:nine-axis/step02_video/left.mp4}"、"{uri:nine-axis/step02_video/up.mp4}"、"{uri:nine-axis/step02_video/down.mp4}"（来源见上游视频目录 videos.json）。视频从正面开始，left 转到接近侧面，up、down 抬头、低头到最大限度；转动的快慢不一定均匀，到达的幅度也不一定相同。

【选帧】
每个方向各自从对应视频选帧。用 extract_video_frame 按实际 frameIndex 或 timeSeconds 从原视频取多帧，用 view_bitmap 看完整运动，在合适处加密比较。按画面判断，不按固定时间或帧号：选一张转动幅度接近目标、五官清楚的帧，拿不准时宁可幅度小一些，不要转过头。up 选看得出抬头、但脖子比首帧多露出得尽可能少的帧：多露出的脖子在后面做九轴时很难处理。视频方向不对、或有滚转、推近、叠影而没有合适帧时返回 error 说明。

【交付，"{uri:nine-axis/step03_frames}"】
- 原帧保存为 frames/<view>.png；由 extract_video_frame 等比规范化到 box.size 见方并保存为 <view>.png，不另裁切、旋转或平移。
- selected-frames.json：version:1，frames 对象有 left、up、down 三个键，每项记录 video、path（指向规范化后的 <view>.png，不是 frames/ 下的原帧）、frameIndex（从0起）和/或 timeSeconds、reason。
完成返回 {"error":null}，做不了时 error 写原因。
