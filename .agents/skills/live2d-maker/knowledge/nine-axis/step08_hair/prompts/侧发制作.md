## 目标是什么

1. 首先对齐参考中清楚可见的侧发：发根位置、外轮廓、耳旁弧线、脸颊覆盖、主要发束与发梢的形状和落点。保留原发型，不以“更圆润”为由扩宽整个头部或另改大形。
2. 被前发或头饰遮挡的上段仍须连成完整头型。结合正面和可见弧线补足发根与头壳的厚度，与现有前发自然衔接；不能把遮挡当作缺失，让一侧发根下塌、顶部尖扁或发面压成平斜面。隐藏部分只作局部合理推断，不追贴遮挡物边线，也不向外鼓成圆帽。
3. 制作 X 轴左右端点及中间过渡。left 按关键帧，right 保持同一发型和相反透视；两侧分别处理近远关系，保留耳旁厚度和发尾体积。前发与侧发组合后应像同一个头部在转动。
4. 对应独立投影一起制作，包括实际落在侧发上的前发投影、侧发投向已完成部件的投影。先确认实际图层和关系，再注册；投影跟随正确的发片运动，按当前接收部件裁切，混合方式与强度沿用 KRA。接收部件尚未制作的投影留待对应轮次。

## 要保护什么

1. 已完成前发及其阴影、脸、五官、耳朵、下颌和脖子的画稿、形变与层级保持原样。只编辑 hair/side_hair 下的侧发、对应阴影和专用 Warp；新增节点沿用此前缀，部件 level=hair。后发、辫子和头饰不制作。
2. 正面以原图为基准，保留原有发型辨识特征、两侧差异和发梢设计。参考中可见部分优先对齐，隐藏部分的补全不能带偏可见发面。
3. 沿用当前这份 KRA 和 hair.json，不复制或回退到上游工程。需要补绘时在 Krita 修改并保存，已有图层沿用 UUID，新图层显式绑定，不单独修改 PNG。不把独立投影烘焙进发片或脸部。
4. 本轮只做左右，Y=0；继承的脸部上下与四角数据保留，不修改、不预览。工作范围限本步工程、模型与检查文件，不修改工作流、工具或校验器源码；程序错误记录并返回 error。

## 自检查什么

1. 先在 Krita 打开当前 KRA，独显确认两片侧发、对应投影、接收部件、UUID、范围、顺序和混合方式。结合已有阴影记录判断实际内容，不仅凭名称判断。将确认结果记入 notes.md，再用 edit_nine_axis 显式 add_part 或 bindings，设置 shadow、clip 与绘制顺序。工具不会自动带上关联阴影；需要共同大形运动时明确组织 Warp，前发已有节点不重绑、不重挂。
2. 对照当前 KRA 原形和 left 关键帧描 source/target，保存到 outline/side/。分开标出发根、耳旁弧线、主要发束和发梢，区分可见段与遮挡推断。描线贴合后，再用 edit_nine_axis 制作左右网格，本轮不使用 fit。
3. 保存后以同画布坐标、裁剪和缩放作 reference + edge 比较，不重新对齐参考。叠加比较只用工具的 edge，不自行制作 blend 叠图。侧发独显看位置与轮廓，再与已完成前发、脸及对应阴影组合检查头顶挂接、耳旁厚度、遮挡与整体头型。原色预览检查发流、高光和投影，后发、辫子与头饰不混入判断。
4. 用 frames 检查 X={left_angle}、两侧中间值、0、X={right_angle}，全部 Y=0。检查两侧根部不随转动上漂或下塌，头顶无尖顶、裂口或重叠硬边；近远侧不突然变薄、压扁，发梢与前发遮挡连续，无明显纹理拉伸、折叠或跳变。必要时 hidden 阴影区分问题，完成前恢复组合检查投影随动和动态裁切。
5. 轮廓、头型、衔接或原色体积仍有明显偏差，就在本轮继续修正。工具成功、网格合法或已经看过 edge 不等于效果通过。完成后保存 KRA、hair.json，并在 notes.md 记录修改、检查结果和仍有的问题。返回 {"error":null}；不能完成则返回 {"error":"具体原因"}。
