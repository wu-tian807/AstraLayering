【任务】
做下颌线与脖子，让第一层「脖子＋脸＋五官」在九个角度上都成立：转头、抬头、低头和斜向时，下巴与脖子之间不露缝、不穿帮，下颌线随角度自然出现、消失。做法照 Cubism 教程的蒙版：
- 下颌线：一条单独的线部件，被一个下颌线蒙版反向裁切（只画在蒙版以外）。蒙版静止时贴在线的下方一点，不挡线；转头、俯仰和斜向时随脸移到线上，把该消失的那段擦掉。哪一段被擦掉按角度和遮挡定：在头发或耳朵一侧的整段可以全擦，也可以只擦靠近脖子的一段。
- 脸色扩展：脸底颜色往外扩大并羽化的一层，被脸部蒙版裁切。转头时脸缘离开原位置，露出的空当由它补上；静止时它不超出脸部蒙版，不溢到脖子上。
- 脸部蒙版：与脸底形状一致、随脸底变形的蒙版部件，只作裁切来源。
- 脖子：放进第一层，排在脸底之下。脖子顶部往上延伸到脸底下面，转头、抬头时下巴移开也不露出脖子顶边；脖子底部（接身体处）不动，顶部随下巴走。
原画本身可能有下颌线，也可能没有。有的话（常见是烘在脸底边缘的一道深色线），把它从脸底分离成线部件，再把脸底在线下面的颜色补齐，免得线被擦掉时留下一道深色残边；没有的话，照角色的线稿风格（颜色、粗细、虚实）补画一条。阴影（如下巴在脖子上的投影）留给后续的阴影步骤，本步不做。
已做好的关键形不重做：沿用 step06 的部件、网格与四角关键形，只新增或替换本步需要的部件。

【教程要点】
- 脸部蒙版是一张与脸底同形、透明度为 0 的图，只作剪贴来源；用它裁切的部件只在脸里显示。
- 脸色扩展比脸底大一圈、边缘羽化，被脸部蒙版裁切：静止时看不出来，转头时补上脸缘移开后的空当。
- 下颌线蒙版有自己的变形器：静止时在下颌线下方一点；转头、俯仰时移到线上，线被反向裁切而消失。擦掉哪一段可以选：头发、耳朵那一侧可以整段擦掉，也可以只擦靠近脖子的一段。
- 脖子分成底色与线；顶部画高一些，插在脸下面。脖子顶部随下巴，底部不动。

【做法】
像画师照教程做：在 workspace 里自己写脚本切图、补画、拉网格（Python 的 numpy、scipy、opencv、torch；缺的库用 uv 装在 workspace 内），脚本是画笔，好坏靠自己看。每改一次就按工作台的方式渲染（双线性网格，裁切按蒙版的透明度相乘，反向裁切乘 1 − 蒙版透明度），用 view_bitmap 放大看，看出哪里不对就改哪里。
- 先放大看原图的下巴与脖子：有没有下颌线、它在脸底里还是单独的图层、脖子顶部是什么形状、哪里被头发挡住。
- 新部件的网格与已有部件同样规则（不透明像素外扩 8px 的 bbox，cols、rows 自定），九个关键形都要给出左侧与静止：下颌线、脸色扩展、脸部蒙版贴着脸底走，可以从脸底的关键形在其网格点上插值得到；下颌线蒙版在脸底的基础上再按角度移动；脖子按上面的要求单独拉。
- 写一份 KRA 作静态真源：在源 KRA 的副本里，把本步的部件按下面的方式放进脸部组。普通裁切：用一个独立（isolated）组装着裁切来源和被裁切的图层，被裁切的图层开 inherit alpha。反向裁切：把蒙版作为擦除（erase）混合模式的图层放在被裁切的图层之上，同装在一个独立组里。只作裁切来源的蒙版另放一份在隐藏的 masks/ 组里。不用 Krita 的透明度蒙版。
- 每轮都看：九个关键形各自的渲染，下巴与脖子处放大；从正面拖到各个角度的几个中间角度连起来看，下颌线的出现和消失要顺；蒙版、被裁切部件单独看，确认裁切的是该裁的地方。
- 不在脚本里写形状的判定或断言，也不以数值达标当作做好了；数值只用来找问题出在哪。

保护：
- step06 的部件、网格和关键形不变；本步替换的部件（如分离出下颌线后的脸底）只改贴图像素，网格与关键形照旧，正面看上去与原图一致。
- 正面静止时整张脸与原图一致：下颌线还在原来的位置、原来的样子，脸色扩展不溢出，脖子顶部被脸挡住。
- 不用不透明度隐藏部件；该消失的用蒙版裁切。
- 脖子底部与身体相接处不动、不变形；脖子不随脸转成别的形状。

【交付】放在本步目录 "{uri:nine-axis/step07_jaw-line}"：
- layers/：新增或重画的贴图，按 textureBounds 裁出的透明 PNG，文件名不与 step06 的贴图重名（如 layers/jaw_line.png）。
- jaw.json，内容如下，parts 从上到下排列（即 KRA 中的顺序），包含 step06 的全部部件：
  {"notes": "简述原图有无下颌线、怎样处理、各蒙版的作用", "parts": [
    {"id": "face/nose"},
    {"id": "face/face_base", "texture": "layers/face_base.png", "textureBounds": [x, y, w, h]},
    {"id": "face/jaw_mask", "role": "mask", "group": "jaw", "texture": "…", "textureBounds": […], "bbox": [x0, y0, x1, y1], "cols": N, "rows": N,
     "keyforms": {"0": [[x, y], …], "{left_angle}": […]}, "keyformsY": {"{up_angle}": […], "{down_angle}": […]}, "keyformsXY": {"{left_up}": […], "{left_down}": […]}},
    {"id": "face/jaw_line", "clip": {"by": ["face/jaw_mask"], "invert": true}, …},
    {"id": "neck", …}]}
  - 只写 id：沿用 step06 的部件。再加 texture、textureBounds：换贴图，网格与关键形不变。带完整网格（bbox、cols、rows 与三组关键形）：替换网格或新建部件；新部件还要有 group、texture、textureBounds。
  - 部件 id 为 face/ 下的路径，脖子为 neck（或 neck/ 下的路径）。role "mask" 的部件不画，只作 clip.by 的来源；clip.by 可列多个部件，取它们的并集；invert 为 true 时只画在蒙版以外。
  - 程序按左右配对镜像出向右与右侧两角，写出本步的 deformers.json；左右成对的部件以 id 中的 left/right 区分。
- character-nine-axis.kra：按上面的方式写好的 KRA。
- jaw-check.png：九个关键形下巴与脖子处的渲染排成 3×3（横向 {left_angle}、0、{right_angle}，纵向 {up_angle}、0、{down_angle}；右侧按镜像渲染）。

完成后返回 {"error":null}；无法完成时，error 写明原因。
