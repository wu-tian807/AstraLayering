【先核对视频方向】
描线前，复用已有 ffmpeg 从本步原视频取开头、四分之一、中间、四分之三、末尾五帧，用 view_bitmap 实际查看。确认是竖直方向的俯仰透视，画面保持正立，没有水平转身、滚转倒立或推近放大。相邻帧只帮助辨认结构，指定目标 PNG 仍是拟合目标。若实际视频是上述错误运动，返回 error 说明问题并停止本步，不把错误视频拟合成俯仰脸型，也不旋转或重新缩放参考来掩盖问题。

【建立本步工程】
先调用 edit_nine_axis {}，自动建立完整 version 2 的 face-up.json。程序继承上游 Warp、局部网格、贴图与绘制顺序。先用 view_nine_axis 在 X=0,Y=0 核对正面，再查看本步端点的初始效果。
Warp 的分组、父子层级与密度由你按实际需要定义；可沿用、增加子 Warp、改挂或独立调整部件。不要预设所有五官都跟脸底变形。既有 X 姿态必须保留；down 步还必须保留已做好的 up。程序会检查这些姿态在画布中的实际位置。
脖子从开始进入参考和完整渲染，始终保持原形、原位置，所有关键形与静止形相同，parent 为空。不倾斜、不拉长、不跟头部 Warp；同时观察下巴覆盖固定脖子的范围。顶部补足和最终消线留 step07_jaw-line，不能为填当前接缝改错目标脸型。

【脸底：辨认 → 描边 → 补全 → 自动拟合】
1. 隐藏五官，单独看原画完整 face_base 与固定脖子，打开上游脸底 PNG。source 是该部件的原画完整 alpha 外缘，不是头发之间露出的皮肤窗口，也不是上游某个转角的轮廓。按 textureBounds 将 PNG 放回画布，再以既定 box 裁出 source-face-reference.png；仅用作检查底图，不改贴图。
2. 先辨认目标帧中的脸、头发、睫毛、脖子和下颌阴影。脸实体外缘实际显露的段标 visible，隐藏段稍后补全并标 occluded。特别辨认颊颌转折、下巴尖端、下颌与脖子的交界；内部阴影/鼻线不是外脸缘，不能把发梢凹口压进脸肉。必要时看相邻视频帧辨认归属，指定 up.png 仍是拟合目标。
3. 复用 Part 的闭合色块描边：source-face.svg 和 target-face.svg 为 box.size 见方、viewBox="0 0 box.size box.size"、纯色闭合 path、stroke="none"、透明背景。先描可靠可见段，隐藏处临时闭合。source 用 preview_svg reference=source-face-reference.png；target 省略 reference，自动叠到本步 up.png。先整图 blend，再用重叠 crop、scale=4..8，反复看 blend/edge 的真实填色外缘。核对两侧颊颌、下巴、可见太阳穴的端点、切线、转折和笔锋；不能只看整图相似或细描线的中心。修改后回看相邻区。
4. 在描准可见段之后，结合原画完整脸型和带图先验补出隐藏的额头、太阳穴、脸颊及下颌体量。俯仰时这些区域的显露比例可能改变，不能把完整脸底简单整体拉高/压扁。具体下巴位置、下颌弧度、头宽、纵深取当前视频；教材的上宽下窄等只帮助理解没有证据的区域。先独显闭合 SVG 看完整素脸，保证连续、合理，随后再叠加复查可见段没有被补全拉走。
5. 用两份已核对 SVG 的同一组路径段生成 face-trace.json：version=1、space=view、completion={part,source,target} 是完整闭合路径；curves 是这两条轮廓上语义对应、方向一致的小段，标 visible/occluded。两侧颊颌、下巴及额顶分别拆段，别用一条跨越多个转折的大曲线猜对应关系；少量 landmarks 可稳定真实对应点。不要让整脸、分段、预览成为三套轮廓。
6. 调用 fit_nine_axis inspect，实际查看 traceCheck 和 completionCheck：原画描线、目标描线、无遮挡完整预测，以及完整 source/target 素脸双图。completionMismatch 必须为空。确认隐藏额顶和脸颊保留体量，可见颊颌/下巴贴住视频，然后保存 trace-check.png、face-completion-check.png。
7. 自己选择合适的脸底 Warp 或部件，用 fit_nine_axis fit 自动求本步 Y 端点参数。工具已经绑定 up 方向，不需要手填角度或大量网格坐标；visible 优先、occluded 弱约束。看每段误差，未贴住时回查对应关系、分段、Warp 范围/密度或局部子级后重新拟合。拟合失败不会保存。
8. 用 view_nine_axis 在 X=0,Y={up_angle} 单独渲染真正形变后的脸底，保存 face-base-up-check.png，与完整预测核对。随后以 reference={path:up.png,bounds:[box.x,box.y,box.size,box.size]} 同坐标叠加，放大两侧颊颌、下巴、额顶/太阳穴可见范围。网格贴描线不等于描线贴视频，必须看实际渲染；不能只交一张好看的预测。

【隐藏额顶与额角：实际补全验收】
本步完成从额顶中心经两侧额角、太阳穴到上颊的完整脸底与有依据的发缘搭接，不能把脸底自身的缺顶、凹坑或露底留给 step07。隐藏部分按原脸体量与带图先验补全，不沿刘海下缘闭合，不按全部头发外轮廓扩大脸底，不规定统一头骨尺寸或固定扩张量。
completionCheck 是 SVG 预测，completionMismatch=[] 只校 SVG 与 trace；fit 残差衡量描线约束，不是实际 alpha 覆盖。读取 occludedWeightScale：为守可见边缘它可能被压得很低甚至归零，此时必须独显真实脸底检查额顶、双侧额角/太阳穴，按先验页的方法对照 completion 和发缘；可见残差小、网格不翻折都不能作为补全完成。
如果预测合理但实际隐藏上沿起伏或覆盖不足，用现有 view_nine_axis 的 only/grid/crop/scale 定位，由你选择脸底部件、现有 Warp 或必要的局部 Warp，复用 edit_nine_axis 局部修正。需要 fit 时用 features 选择相关隐藏段和真实可见连接处；不能把 occluded 改成 visible 绕过保护，没有适用可见段时使用局部编辑。每轮回查全部已对齐的可见脸缘、五官及受保护姿态，不只检查被选 features，也不通过全脸膨胀填顶。
若本次明确为“只修隐藏区”的续修，沿用当前目标帧、可见描边和五官参数，跳过下节五官调整、只作同坐标复查；只修当前获授权方向的隐藏脸底。原 KRA 或视频发缘只作遮挡依据，固定脖子始终不动。没有头发层或未定义发摆范围时，说明静态覆盖与未来动态覆盖的验证边界，不制作额外头发动画。
每个方向保存 forehead-temple-check.png 与 hair-coverage-check.png（xy 使用各 corner 前缀），结合完整实际脸底和 completion 对照说明额顶连贯性、覆盖余量依据及端点/中间值检查。最终局部编辑后更新检查图，notes 记录对应作者 SHA、occludedWeightScale 和剩余差异；不能拿编辑前 fit 报告或旧图验收新工程。


【五官与整体】
重新显示五官，用一次 edit_nine_axis operations 批次完成有把握的眼、眉、鼻、嘴的形状和落点调整，再渲染微调。整眼与口腔各层可共同 Warp，局部不足再独立修正，层级由你决定。
俯仰尤其观察眉眼、眼鼻、鼻嘴、嘴颏的纵向关系，以及眼睑弧度、眼白显露、虹膜/高光配合、嘴的开口高度和鼻的形状。它们按本角色视频拟合；不机械规定抬头一定眉眼拉开/嘴变高、低头一定反过来。保持表情和原画笔触，不只移动瞳孔来制造角度。
最后一起显示脸、五官、固定脖子，检查形状、层次和接触。已有线/脸色层要一起考虑；本步记录应由 step07 处理的脖子顶部覆盖、下颌接触线和阴影，脸底额顶与额角补全在本步完成。不换贴图，不用透明度掩盖错误。原 KRA 没有独立耳朵则说明并跳过。
