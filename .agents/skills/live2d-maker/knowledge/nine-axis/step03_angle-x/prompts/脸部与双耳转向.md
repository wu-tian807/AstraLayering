【任务】
像 Live2D 画师做转头那样，把角色的脸（脸部组下的脸底、五官与双耳图层，不含头发、头饰）做成向左转头的 warp 变形器：关键形 ParamAngleX = {left_angle}（单位为度），转过去的样子对照 step02 从转头视频取出的向左视角 left.png（头部向画面左侧转约 {left_degrees}°）。向右（{right_angle}）由程序镜像，不用做。只做变形，不补绘、不改图层像素。
脖子默认一起带上：KRA 里的脖子图层（通常名为 neck，可能在身体组下）也导出为部件 neck，排在脸底之下；它不变形，各关键形都与静止相同，转头时是脸在它上面移动。没有脖子图层时跳过。

【输入】（只读）
- 源 KRA："{document}"；同画布合成 PNG："{color}"。
- 正面头部特写："{uri:nine-axis/step01_video/upper-body.png}"；向左视角："{uri:nine-axis/step02_views/left.png}"。两张都是 box.size 见方，与画布 1:1，像素 (u,v) 对应画布 (box.x+u, box.y+v)；box 见 "{uri:nine-axis/step01_video/crop.json}"。
- left.png 是转头视频中的一帧，是参考，不是描摹对象：画法细节与原图层不同，不拿它的像素替换图层；脸缘常被头发截断，被挡住的地方照教程纯脸走。
- 教程纯脸模版（Live2D 教程里同一张不带头发的脸，向左转约 {left_degrees}° 前后，带变形网格；不是本角色）：正面 "{reference:step03_angle-x/references/tutorial/front.png}"，转向后的脸底 "{reference:step03_angle-x/references/tutorial/left-face-base.png}"，转向后带五官 "{reference:step03_angle-x/references/tutorial/left-face.png}"；脸底变形器的网格：正面 "{reference:step03_angle-x/references/tutorial/front-grid.png}"，转向后 "{reference:step03_angle-x/references/tutorial/left-grid.png}"。

【怎么做】
- 用 krita 工具从 KRA 导出脸部组下每个图层的可见效果（含所在组的透明度蒙版）为同画布透明 PNG。部件 id 取图层名中的部件路径，如 face/face_base、face/eye_left/iris。
- 直接改变形器：face-left.json 里的控制点就是关键形，像在 Cubism 里拖变形器的手柄一样，看着参考一处一处地挪脸底轮廓、五官和耳朵，先拉大形，再调细节。形状由你亲手定；可以用小脚本帮你成片挪点、让一片点挪得顺滑，但不拿参考图去自动拟合。
- 每改一次就用 view_nine_axis 预览：它按程序的方式组装你的交付并用工作台的渲染画出来，与工作台效果一致。看 {left_angle}，也看 0 到 {left_angle} 之间的几个角度，放大看脸缘、下巴、五官；看出哪里不像 left.png、不像教程那张纯脸，就回去挪那里的手柄，再看。只有在 view_nine_axis 里看起来对了才算做好，自己脚本里的预览不算。
- 和参考对照时，把 view_nine_axis 保存的图与 left.png、教程图并排或半透明叠在一起看。

【转头的样子】（教程纯脸示范的，画的时候眼睛要看的地方）
- 头的大小不变：转过去的头和正面一样高、一样大，头顶的圆顶仍是圆的，不抬高也不压平。
- 远侧（画面左）往上收：下颌和下巴往上、往远侧提，下巴仍是一个尖；远侧从额角经脸颊到下巴是一条顺滑外凸的弧，不推出凹口，也不在眼下鼓出脸颊。
- 近侧（画面右）往左下斜着走：整条弧向内、向下移过去，仍是一条完整顺滑的外凸轮廓，不往外撑大；下巴到近侧的下颌底是一条连续、缓缓上扬的线。不画后脑：近侧轮廓就是头的边。
- 竖着的中线仍大致是竖的，随下巴移向画面左侧；整张脸不能像歪头那样斜过去，也不是整体往左平移、压窄成蛋形。
- 五官随头一起转：远侧眼变窄、近侧眼几乎不窄，五官移向远侧；五官的位置、形状、远侧眼角眉梢到脸缘的距离照 left.png。透视不可无，也绝不能过：眉眼上半部分透视明显、下半部分几乎没有，嘴相反；瞳孔的分割线保持横平竖直；鼻子主要是位置偏移，鼻子、嘴、下巴连成一条线。
- 大造型小细节：脸底决定位置、造型和透视，五官只补脸底做不到的；做一个五官时看它与其他五官和脸型的关系。
- 耳朵（没有耳朵图层时跳过）：不做细节调整，整只刚性随动、不扭曲。近侧耳根始终贴在转过去的脸缘上，不留缝、不插进脸里；远侧耳随头侧转到脑后，排在脸底之下由脸遮住，不用透明度隐藏。

【保护】
- 转过去的脸看起来就是 left.png 里那张脸；被头发挡住的部分像教程纯脸一样干净。
- 从 0 拖到 {left_angle} 的每个中间角度都成立：头不越转越大或越小，轮廓和下巴每一帧都连着，没有折线、缺口、台阶或网格折叠。

- face-left.json：
