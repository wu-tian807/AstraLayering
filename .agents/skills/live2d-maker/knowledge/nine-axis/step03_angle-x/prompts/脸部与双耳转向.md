【任务】
做 left 方向的脸部＋双耳透视形变：把角色的脸（脸部组下的脸底、五官与双耳图层，不含头发、头饰）做成向左转头的 warp 变形器，关键形为 ParamAngleX = {left_angle}（单位为度），形状对齐 step02 从转头视频取出的向左视角 left.png（头部向画面左侧转约 {left_degrees}°）。向右（{right_angle}）由程序镜像得到，不用做。只做变形，不补绘、不改图层像素。
脖子默认一起带上：KRA 里的脖子图层（通常名为 neck，可能在身体组下）也导出为部件 neck，排在脸底之下；它不变形，各关键形都与静止相同，转头时是脸在它上面移动。没有脖子图层时跳过。

【输入】（只读）
- 源 KRA："{document}"；同画布合成 PNG："{color}"。
- 正面头部特写："{uri:nine-axis/step01_video/upper-body.png}"；向左视角："{uri:nine-axis/step02_views/left.png}"。两张都是 box.size 见方，与画布 1:1，像素 (u,v) 对应画布 (box.x+u, box.y+v)；box 见 "{uri:nine-axis/step01_video/crop.json}"。
- left.png 是转头视频中的一帧，只作形状目标；其画法细节与原图层不同，不拿它的像素替换图层。
- 教程纯脸模版（Live2D 教程里同一张不带头发的脸，向左转约 {left_degrees}° 前后，带变形网格；不是本角色）：正面 "{reference:step03_angle-x/references/tutorial/front.png}"，转向后的脸底 "{reference:step03_angle-x/references/tutorial/left-face-base.png}"，转向后带五官 "{reference:step03_angle-x/references/tutorial/left-face.png}"；脸底变形器的网格：正面 "{reference:step03_angle-x/references/tutorial/front-grid.png}"，转向后 "{reference:step03_angle-x/references/tutorial/left-grid.png}"。它示范一张纯脸怎么转：
- 头的大小不变：转过去的头和正面一样高、一样大，头顶的圆顶仍是圆的，不抬高也不压平。
- 远侧（画面左）往上收：下颌和下巴往上、往远侧提，下巴仍是一个尖；远侧从额角经脸颊到下巴是一条顺滑外凸的弧，额角保持圆，不推出凹口，也不在眼下鼓出脸颊。
- 近侧（画面右）往左下斜着走：整条弧向内、向下移过去，仍是一条完整、顺滑外凸的轮廓，不在上面推出起伏，也不往外撑大。
- 下巴到近侧的下颌底是一条连续、缓缓上扬的线。
- 不画后脑：近侧轮廓就是头的边，外面不另长出头的背面。
- 竖着的中线仍大致是竖的，随下巴移向画面左侧；整张脸不能像歪头那样整体斜过去。
把整张脸整体往左平移、压窄成一个蛋形，就不是转头。left.png 里被头发挡住的地方，就照这个模版的样子走。

【做法】
像画师照着模版画转头：在本步 workspace 里自己写脚本做变形（Python 的 numpy、scipy、opencv、torch；缺的库用 uv 装在 workspace 内），脚本是画笔，好坏靠自己看。每改一次就渲染出图，用 view_bitmap 放大看，看出哪里不像 left.png 就改哪里，再渲染再看，直到转过去的脸看起来就是 left.png 那张脸。
- 不在脚本里写形状的判定或断言（宽度、距离、比例是否达标），也不以损失收敛、数值达标当作做好了；数值只用来找问题出在哪。
- 每轮都看这几张：
  - 叠线稿：left.png 的线稿用一种颜色、渲染结果的线稿用另一种颜色叠在一起，重合处一眼可见；
  - 不叠头发的脸单独放大，和 left.png、教程的 left-face.png 并排：它本身要是一张照模版转过去的人脸，被头发遮住的部分要像教程那张纯脸一样干净；
  - 渲染结果半透明叠在 left.png 上；
  - 连续帧：把 0 到 {left_angle} 之间的几帧（关键形线性插值）排成一行，每帧叠上正面脸底的轮廓线：头不能越转越大、越转越小，下巴和轮廓在每一帧都是连着的。

1. 导出图层：用 krita 工具从 KRA 导出脸部组下每个图层的可见效果（含所在组的透明度蒙版）为同画布透明 PNG。部件 id 取图层名中的部件路径，如 face/face_base、face/eye_left/iris。
2. 先看清两张图：放大 upper-body.png 和 left.png，看哪些脸缘真的露出来（紧挨背景、脖子或脸后面的头发），哪些是被刘海、垂在脸前的发束截断的假边。转面一侧从眉骨经眼角、颧骨到下巴的侧脸通常整段都露出来。五官在 left.png 里通常都露在外面，位置和形状可以照它拟合；脸的外轮廓却常有一大段被头发挡住，只能部分照它。所以下面五官和脸底分开做：五官照 left.png 拟合，脸底照轮廓画。
3. 五官（按教程结构）照 left.png 拟合，不用脸底的变形：
   - 定位：左右眼、左右眉、嘴、鼻各取正面合成上的范围作模板，在 left.png 中做多尺度模板匹配（横向 0.6–1.15、纵向 0.95–1.05，TM_CCOEFF_NORMED），得到各五官在目标图中的位置与横向缩放。匹配分数低或位置明显不对的降权或剔除，不硬套。
   - 转向：用一个竖轴圆柱把五官一起转过去，后向场 x' = C + tx + R·sin(asin((x−C)/R) − θ)，C 为脸部中轴列；拟合 R、θ、tx，使五官位置吻合，并加权约束左右眼的横向缩放（cos(φ−θ)/cos φ），纵向偏移取五官位移的平均。远侧眼变窄、近侧眼几乎不窄、五官移向远侧，都由这个转向和 left.png 得到，不另定规则。
   - 细节：在转向之上，眉眼（有腮红时并入）一个 6×4 网格、嘴 4×4、鼻 3×3，各在本组周围（本组范围外扩约 15% 再加 10px，扣除头发）拟合到 left.png 的五官像素：多尺度颜色差加边缘差，网格平滑。睫毛、眼线、上眼睑和眉毛颜色深，别当成头发扣掉；只扣真正压在五官上的发丝。拟合陷在局部最小时（如鼻子没挪到位），先扫一遍整体平移作初值再拟合。
   - 看叠线稿：眼、眉、嘴、鼻的线和 left.png 重合；嘴的倾斜和上下口型的透视、眉的长短和斜度都照 left.png。五官的形状和位置以 left.png 为准，不按脸底轮廓或别的规则另行推移。
4. 画出转过去的整条脸轮廓：在画布上用一条闭合曲线定下 {left_angle} 的脸底外形，按上面教程模版的几条（头的大小不变、远侧往上收、近侧往左下斜着走、下颌底连续、不画后脑）一段段画，露出来的远侧脸缘对到 left.png 的真实脸缘上，被头发挡住的段落照模版定，不用头发截出的假边。轮廓要包住第 3 步的五官，五官与脸缘的关系照 left.png：远侧眼角、眉梢到远侧脸缘的距离，嘴、鼻到下巴的关系都和 left.png 一样。把这条轮廓和第 3 步的五官画在一起，与 left.png、教程 left-face-base.png 并排看，先把轮廓本身改到好看，再做下一步。
5. 用这条轮廓做脸底的整体变形：正面脸底轮廓与目标轮廓在下巴、近侧、头顶、远侧几处对应，之间按弧长一一对应；再在眼、眉、鼻、嘴和额头中部各放一对内部锚点（五官的锚点取第 3 步拟合出的位置），用薄板样条之类的平滑插值求出一个从正面到 {left_angle} 的位移场。场只在脸底不透明区内求，区外取最近的区内位移：原图层的边是硬边，区外再插值会把锯齿拉成毛边。这个变形只用于脸底和耳根，五官不用它。看渲染时常见的问题：
   - 头顶被拉平、额头扁，或头比正面高：头顶几处的目标回到正面的圆顶高度；
   - 下巴断开、成台阶或平台：下巴附近的轮廓对应点不连续，重新排；
   - 远侧往下坠：远侧下半段的目标应在原位置之上；
   - 近侧拉过头、出现直边或折角：近侧目标往左下少移一些，保持一条顺滑的弧。
6. 合起来看：第 3 步的五官叠在第 5 步的脸底上，按每轮要看的几张图检查。五官落在脸里的位置不对（如远侧眉梢、眼角出了脸缘），先回第 4 步看轮廓；轮廓已照 left.png 和模版画对了，就把这一组五官（如一只眼的全部图层）整体平移，不改它的形状。
7. 耳朵：没有耳朵图层（如被头发完全遮住）时跳过本项，照常交付。不拟合 left.png 中的耳朵像素；每只耳朵整体刚性移动，只做平移和横向缩放，形状不扭曲。{left_angle} 时：
   - 近侧耳（画面右侧，朝向观众）：取耳朵贴脸一侧、与脸底轮廓相接处的耳根点，按脸底变形在该点的位移平移，横向缩放取该点的横向缩放。耳根始终贴在变形后的脸缘上，不留缝，也不插进脸里。不要按头侧角度单独转近侧耳：脸缘在正面时并不在头侧 90°，转向时它比头侧移得多，单独转耳朵会让耳朵离开脸。
   - 远侧耳（画面左侧，转离观众）：耳朵长在头侧，随头侧转到脑后，不压扁、不扭曲；在部件顺序中排在脸底之下，由脸遮挡，不用透明度隐藏。露出多少看渲染与 left.png 对照。
   - 渲染耳朵与脸底放大看：近侧耳根与脸缘相接，远侧耳被脸挡住。
8. 导出：每个图层一个 warp，脸底 32×32，其余 16×16（脸底的轮廓弧度大，16×16 的格子在近侧头顶会折出缺口）。
   - 控制网格是该层不透明像素外扩 8px 的范围（bbox）上的规则网格；keyform "0" 即此规则网格。
   - "{left_angle}" 是每个控制点经前向变形后的位置：脸底用第 5 步的变形，五官用第 3 步的转向加本组细节（再加第 6 步的整组平移）；用的是后向场时用牛顿法反解。网格折叠时要查出原因，不交付折叠的网格。
   - 坐标均为原画布像素。
   - 用交付的关键形按格子双线性重新渲染（工作台就是这样画的，不是用拟合时的场），放大看近侧和头顶的边，与拟合时的渲染一致，没有缺口或折线。

【教程先验】
这些是画的时候眼睛要看的地方，不写成脚本里的判定。看出不对时回去改目标轮廓、锚点或变形，不手填控制点。
- 转向后的脸看起来就是 left.png 里那张脸。
- 两侧轮廓都是完整顺滑的外凸弧，见教程模版：远侧不刻意推出凹凸、不鼓出脸颊；近侧不被 {left_degrees}° 转向破坏边界。
- 瞳孔的分割线保持横平竖直。
- 透视不可无，也绝不能过。眉眼的上半部分透视明显，下半部分几乎没有；嘴相反，下半部分透视较明显。
- 鼻子在 X 方向主要是位置偏移；鼻子、嘴、下巴连成一条线。
- 耳朵不做细节调整：近侧耳贴着脸缘随动、不变形，远侧耳转到脑后被脸遮住。
- 脸对头型的影响不能太大：转向时头型大小几乎不变，透视来自远侧往上收、近侧往左下移，以及中线、五官的移动；只把整个头往左平移或压窄、或者把整张脸斜切成歪头，都是做错了。近侧脸颊也不要额外鼓出包。这一阶段不用对脸做过多微调。
- 大造型小细节：五官的位置和透视由转向决定，本组细节只补转向做不到的部分，把五官拉出转向形状太多时加大平滑或缩小范围。做一个五官时，注意它与其他五官和脸型的关系。
