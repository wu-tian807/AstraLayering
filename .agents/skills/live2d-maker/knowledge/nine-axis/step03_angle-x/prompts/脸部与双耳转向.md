复刻本角色视频中的 left 脸型和五官，制作 ParamAngleX = {left_angle}（{left_degrees}°）。向右 {right_angle} 由程序镜像。保留原 KRA 的绘画，用网格形变得到目标，不用视频像素替换贴图。

【参考的职责】
本角色 left 视频帧是可见区域唯一的视觉目标。准确描出看得见的真实脸缘，预测补全被遮挡的整张脸型，单独查看无遮挡脸底后，再用 fit_nine_axis 自动求 Warp；五官继续由你一轮批量液化到参考位置并微调。
教程只帮助补足视频中被头发挡住、看不见的脸部结构。把补全单独标成 occluded，弱约束参与拟合；可见轮廓标 visible。不能为了教程里的通用脸型、三峰三谷或透视比例改变视频里看得见的形状，也不能把发丝轮廓当作脸缘。

变形器分组和父子层级由你按实际部件决定。可以建共同 Warp，也可以给某个部件单独调整、增加子级；不预设所有五官跟脸底共同变形。液化工具 edit_nine_axis 的 transform、drag、points 继续可用。

【导出和初始工程】
从原始 KRA 自行用 krita 导出脸部组的可见图层效果（包含组蒙版）和脖子；按原画布裁切透明 PNG，保存到本步 layers/。脖子通常在身体组，必须一起导入并放在脸下面。没有脖子时说明原因。
用 edit_nine_axis.importParts 首次导入，列表顺序为 KRA 从上到下；给每项 id、group、texture、textureBounds、bbox。工具生成静止网格；原图层、UUID 和原 KRA 保留。不使用已有手调角色的网格或贴图。
先用 view_nine_axis 在 0 度确认导出与原画重合，检查 face_base 和原画脸缘，五官层没有漏掉或错位。脖子保持固定：不挂到头部 Warp，不移动、不拉长、不倾斜；始终作为下巴位置与覆盖的参考。顶部延长和最终接触收尾留 step07，在本步记录需要处理的位置。

【脸底：描真实脸缘 → 预测补全 → 检查素脸 → 自动拟合】
1. 暂时隐藏五官，单独查看原画脸底与固定脖子；打开导出的 face_base PNG。完整 source 轮廓取原画部件，不取头发盖住后的皮肤窗口。脸底的线与色若分层，应在需要时一起选入你定义的 Warp。将原部件 PNG 按 textureBounds 放回原画布，再用既定 box 裁出 source-face-reference.png，保持原始像素位置；这只是预览底图，不改变作者源或贴图。
2. 先独立辨认 left 帧中脸与遮挡物的形体归属，再描真实可见的脸外缘：两侧眼窝、颧颊、颌角至下巴能看到多少就描多少。脸的实体外缘即使邻接头发，实际显露的区间仍是 visible；不要把远侧眼窝至颊部整段一概写成 occluded。顺着发束切入脸内部的皮肤窗口才是遮挡边界，不把发丝凹口捏进脸肉。必要时回看相邻视频帧辨认被头发盖住的是哪一条线，本角色指定 left.png 仍是拟合目标。部分显露的段按显露范围拆分，分别标 visible/occluded；不确定的隐藏走势留补全阶段。
3. 复用 part-layering 的描边方法：保存 source-face.svg 与 target-face.svg，使用一种纯色、闭合 path、stroke="none"、透明背景，width/height 为 box.size，viewBox="0 0 box.size box.size"；填色边缘就是轮廓。先按可靠可见边缘起稿，在隐藏处临时闭合，不把临时补线当可见证据。source 用 preview_svg 的 reference=source-face-reference.png 核对完整原脸底；target 省略 reference，固定叠到 left.png。先整图 blend，再用重叠 crop、scale=4..8 分区，以 blend 与 edge 核对实际外缘的位置、切线、转折和尖端；细描线的中心、整图相似或拟合残差小均不能代替这次核对。
   远侧眼尾外侧到颊部是重点：按视频保留陡直程度、眼窝至颧颊的转向与笔锋；参考呈近竖向的区间不能被一条跨越眼窝/颊部的大圆弧磨圆，也不把整段硬拉成直线。转折处拆段，分别调整端点与控制柄，让可见范围贴住视频，而不是增加很多无意义的控制点。source 同样逐段贴住原 PNG 的真实外缘，不能靠 Warp 抵消 source 描错。修改后重看改动区及相邻区，已核对正确的近侧和下巴没有新证据就保留。source/target 小段的起终点为同一语义位置，方向一致；少量 landmarks 指定真实转折，鼻嘴等该移动的位置不能钉在正面。
4. 可见边缘核对后，才预测被遮挡的完整 left 脸底。以核对过的可见脸缘为硬证据，结合原画完整脸型与带图先验，向眼窝/颊部/太阳穴/额头补出连续、合理的整体外轮廓；近侧脸颊保留完整体量，远侧起伏和笔锋取本角色可见视频。先验不能磨圆或移动已贴住视频的可见段。选择适用脸型并说明选择理由，不平均多个不同脸型。更新闭合 SVG，再用 preview_svg 的 svg 独显看整体、blend/edge 复查可见范围。
   由这两份已检查的 SVG 同一组路径段生成 face-trace.json：version=1、space=view、completion={part,source,target}，source/target 是完整闭合 SVG path d；curves 为同一轮廓上的对应小段，分别标 visible/occluded。避免整脸、分段和预览画成三套不同轮廓。完整预测包含被挡区域，不沿发缘闭合皮肤窗口。
5. 调用 fit_nine_axis action=inspect，查看 source 描线、left 帧描线及无遮挡完整 target 脸底；另查看返回的 completionCheck 素脸双图。检查原画完整脸/预测 left 完整脸的体量与轮廓连续性，尤其近侧眼窝至颊部不能因头发被削成波浪。completionMismatch 必须为空；若出现偏差，回查把发缘当脸缘的段并修正。将真实输出保存 trace-check.png 和 face-completion-check.png，先完成此检查再拟合。
6. 由你建立合适的脸底 Warp，控制点多少按轮廓转折需要决定。用 fit_nine_axis action=fit，给 trace 路径和所选 Warp id，程序按对应曲线自动求 left 参数。visible 优先，occluded 只指导没有可见证据的结构。检查逐段误差；某段未贴住时，检查对应关系、拆段、增加合适的控制点或子 Warp 后重新求解。不要用一段下巴的误差代表整张脸。
7. 用 view_nine_axis 单独渲染变形后的脸底，保存 face-base-left-check.png，与完整预测核对，不能仅交付一张好看的预测图。再以 reference={path:left.png,bounds:[box.x,box.y,box.size,box.size]} 看完整同坐标叠加，放大两侧眼窝至颊部、颌角和下巴，检查位置、切线、笔锋与线条粗细。网格贴描线不等于描线贴视频，必须再看实际帧。
【五官：一轮批量液化，然后整体协调】
重新显示五官，对着 left 目标批量调整眉眼、鼻、嘴、腮红的形状和落点；分组由你选择，父级适合大形，局部与子级补不足。不要求每个五官都经过描线求解，也不要求所有五官共用同一个 Warp。
用一次 edit_nine_axis operations 批次完成你有把握的整体调整，再预览与微调。看两眼内外角、上眼睑峰值、虹膜与高光的相对关系、鼻尖、嘴角和口腔层是否贴合。远侧眼的宽度与眼尾走向必须照视频，不能只挪瞳孔来制造转头。五官之间的透视和表情取视频，保住原画细节。
最后完整显示脸、五官与固定脖子，回看两侧轮廓是否因后续编辑偏离描线；需要时重新拟合脸底或修局部。头部中心与下巴的移动量按参考，不把整张脸横移代替转面，也不强行锁住鼻嘴。脖子保持原形，接触问题记录给 step07，不能通过扭脖子或改错脸型填缝。
耳朵如有：保持整体形状，近侧根部贴脸，远侧排在脸后，由脸遮挡，不用透明度隐藏。源 KRA 没有独立耳层就说明，不伪造。

【端点与过渡】
查看 {left_angle}、中间负角度、0、对应正角度与 {right_angle} 的完整效果。允许按实际轨迹选 ellipse 或补中间关键形。确认眼睛、嘴、脸底在过渡中不突然收缩、融化或分离，固定脖子没有动。几何检查通过只证明网格有效，不能代替视觉拟合验收。
