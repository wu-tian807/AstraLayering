【任务】
像 Live2D 画师做俯仰那样，做脸部＋双耳的上下形变：沿用 step03 的脸部图层与 warp 网格，摆两个关键形，ParamAngleY = {up_angle} 是抬头（约 {up_degrees}°，对照 up.png），ParamAngleY = {down_angle} 是低头（约 {down_degrees}°，对照 down.png），单位为度。上下不对称，两个方向各做各的，不镜像。
只做形变本身：抬头、低头时轮廓线的出现与消失（如下颌线、下巴下缘）留给后续步骤；不补绘、不改图层像素、不用透明度。

【输入】（只读）
- step03 的变形器："{uri:nine-axis/step03_angle-x/deformers.json}"。每个部件的 bbox、cols、rows、keyforms["0"]（静止网格）与绘制顺序就是本步的网格，不改；贴图在同目录 layers/ 下。
- 正面头部特写："{uri:nine-axis/step01_video/upper-body.png}"；抬头视角："{uri:nine-axis/step04_views-y/up.png}"；低头视角："{uri:nine-axis/step04_views-y/down.png}"。三张都是 box.size 见方，与画布 1:1，像素 (u,v) 对应画布 (box.x+u, box.y+v)；box 见 "{uri:nine-axis/step01_video/crop.json}"。
- up.png、down.png 是镜头上下移动的视频中的一帧，是参考，不是描摹对象：镜头移动会让帧里的头整体变大变小、上下挪位，这不是俯仰，看的是脸型和五官之间的关系；画法细节与原图层不同，不拿它们的像素替换图层；被头发挡住的地方照教程纯脸走。
- 教程纯脸模版（Live2D 教程里同一张不带头发的脸，带变形网格；不是本角色）：正面网格 "{reference:step05_angle-y/references/tutorial/front-grid.png}"，低头网格 "{reference:step05_angle-y/references/tutorial/down-grid.png}"，抬头网格 "{reference:step05_angle-y/references/tutorial/up-grid.png}"；正面带五官 "{reference:step05_angle-y/references/tutorial/front.png}"，低头带五官 "{reference:step05_angle-y/references/tutorial/down-face.png}"；教程对照的 3D 模型（左抬头、中正面、右低头，红线标出眉眼距离）"{reference:step05_angle-y/references/tutorial/model-3d.png}"。

【怎么做】
- 直接改变形器：face-y.json 里的控制点就是关键形，像在 Cubism 里拖变形器的手柄一样，从静止网格出发，看着参考一处一处地挪，先把整个头俯仰过去（网格像贴在球上，横线随俯仰弯曲），再调五官的距离和形状。形状由你亲手定；可以用小脚本帮你成片挪点、让一片点挪得顺滑，但不拿参考图去自动拟合。
- 每改一次就用 view_nine_axis 预览：它按程序的方式组装你的交付并用工作台的渲染画出来，与工作台效果一致。看 {up_angle}、{down_angle}，也看 0 到它们之间的几个角度，放大看脸缘、下巴、五官和刘海、侧发下的接缝；看出不对就回去挪那里的手柄，再看。只有在 view_nine_axis 里看起来对了才算做好，自己脚本里的预览不算。
- 要挪手柄时，用 view_nine_axis 的 grid 叠出那个部件的网格和控制点：图上看清哪几个点该往哪挪，按它返回的行列找到交付里对应的点去改。
- 和参考对照时，把 view_nine_axis 保存的图与 up.png、down.png、教程图并排或半透明叠在一起看。

【俯仰的样子】（教程纯脸示范的，画的时候眼睛要看的地方；Y 轴的重点不在透视，而在距离关系）
- 头的大小不变：俯仰后的头和正面一样宽，头顶仍是圆的；脸只是纵向变扁一些，轮廓不整体缩放，可以随俯仰微微上下平移。
- 低头：横向网格线中间往下弯，像从上往下看一个球；额头和头顶一圈变宽、显得饱满，下半张脸收窄，下巴变尖。眉眼距离缩小，眼到嘴、嘴到下巴变短；嘴变扁；鼻子更靠近嘴。
- 抬头：横向网格线中间往上拱，像从下往上看一个球；下半张脸变宽、脸颊和下颌更饱满，下巴变圆润。眉眼距离增大，额头变矮；嘴变高；鼻子跟着嘴一起移动。
- 轮廓是一整条干净顺滑的外凸线，不在上面推出起伏、凹口或直边；中线仍竖直，左右对称地变。
- 耳朵（没有耳朵图层时跳过）：不做细节调整，贴着脸缘随动、不变形；它在脸后面，抬头时相对五官下移，低头时上移。
- 有脖子部件（neck）时，它所有关键形都与静止相同：脸在脖子上面移动。
- 大造型小细节：脸底决定位置和造型，五官只补脸底做不到的；做一个五官时看它与其他五官和脸型的关系。

【保护】
- 俯仰后的脸型看起来就是 up.png、down.png 里那张脸的脸型；被头发挡住的部分像教程纯脸一样干净。
- 正面里伸在刘海、侧发下面的脸边，俯仰后仍伸在头发下面，不露缝；参考里脸在头发下露得更多的地方，脸边顺着头型外扩到头发下面。
- 从 0 拖到上下两端的每个中间角度都成立，没有折线、缺口或网格折叠。

- up-check.png、down-check.png：view_nine_axis 画出的抬头、低头脸部，分别与 up.png、down.png 并排。
