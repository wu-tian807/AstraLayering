【任务】
做脸部＋双耳的上下形变：沿用 step03 的脸部图层与 warp 网格，再拟合两个关键形，ParamAngleY = {up_angle} 对齐抬头视角 up.png（抬头约 {up_degrees}°），ParamAngleY = {down_angle} 对齐低头视角 down.png（低头约 {down_degrees}°），单位为度。上下不对称，两个方向分别拟合，不镜像。
只做形变本身：抬头、低头时轮廓线的出现与消失（如下颌线、下巴下缘、被头发遮住或露出的线）本步不处理，留给后续步骤统一调整；不补绘、不改图层像素、不用透明度。

【输入】（只读）
- step03 的变形器："{uri:nine-axis/step03_angle-x/deformers.json}"。每个部件的 bbox、cols、rows、keyforms["0"]（静止网格）与绘制顺序就是本步的网格，不改；贴图在同目录 layers/ 下（按 textureBounds 裁出的透明 PNG）。step03 的拟合脚本在 workspace 里，可以复用。
- 正面头部特写："{uri:nine-axis/step01_video/upper-body.png}"；抬头视角："{uri:nine-axis/step04_views-y/up.png}"；低头视角："{uri:nine-axis/step04_views-y/down.png}"。三张都是 box.size 见方，与画布 1:1，像素 (u,v) 对应画布 (box.x+u, box.y+v)；box 见 "{uri:nine-axis/step01_video/crop.json}"。
- up.png、down.png 是镜头上下移动的视频中的一帧（up 镜头在下方仰视，down 镜头在上方俯视），只作形状目标；画法细节与原图层不同，不拿它们的像素替换图层。镜头移动会让帧里的头整体变大变小、上下挪位，这部分不是俯仰：先把目标视角按头的整体大小对齐到正面，再取它的脸型和五官关系。
- 教程纯脸模版（Live2D 教程里同一张不带头发的脸，带变形网格；不是本角色）：正面网格 "{reference:step05_angle-y/references/tutorial/front-grid.png}"，低头网格 "{reference:step05_angle-y/references/tutorial/down-grid.png}"，抬头网格 "{reference:step05_angle-y/references/tutorial/up-grid.png}"；正面带五官 "{reference:step05_angle-y/references/tutorial/front.png}"，低头带五官 "{reference:step05_angle-y/references/tutorial/down-face.png}"；教程对照的 3D 模型（左抬头、中正面、右低头，红线标出眉眼距离）"{reference:step05_angle-y/references/tutorial/model-3d.png}"。它示范一张纯脸怎么俯仰：

- 低头：横向网格线中间往下弯，像从上往下看一个球；额头和头顶这一圈变宽、显得饱满，最宽处上移；下半张脸收窄，下颌两侧向下巴收成更尖的下巴。
- 抬头：横向网格线中间往上拱（底边中间往下鼓），像从下往上看一个球；下半张脸变宽、脸颊和下颌更饱满，最宽处下移；下巴变圆润，不再是尖的。
- 两个方向轮廓都是一整条干净顺滑的外凸线，不在上面推出起伏、凹口或直边；中线仍竖直，左右对称地变。
- 3D 模型里：低头时额头显得更高、眉眼距离缩小，眼到嘴、嘴到下巴变短；抬头时眉眼距离增大，额头变矮，下半张脸舒展；耳朵在脸后面，抬头时相对五官往下移，低头时往上移。
目标视角里被头发挡住的地方，就照这个模版的样子走。

【做法】
和 step03 一样像画师照着模版画：在 workspace 里自己写脚本做变形（Python 的 numpy、scipy、opencv、torch；缺的库用 uv 装在 workspace 内；step03 的脚本可以复用），脚本是画笔，好坏靠自己看。每改一次就渲染出图，用 view_bitmap 放大看，看出哪里不像目标视角就改哪里，再渲染再看，直到抬头、低头的脸看起来就是 up.png、down.png 里那张脸。
- 自己的渲染用来对照参考；用户在工作台里看到的是 view_nine_axis 画出的样子。写出交付文件后就用它看（默认与工作台初始视图相同，可选角度、层级、选框与放大），收尾前把各关键形和几个中间角度都用它放大看一遍，看到的问题以它为准去改。
- 不在脚本里写形状的判定或断言（眉眼距离、嘴高、鼻嘴距离是否变大变小等），也不以损失收敛、数值达标当作做好了；数值只用来找问题出在哪。
- 每轮都看这三张：目标视角与渲染结果的叠线稿（两种颜色，重合处一眼可见）；不叠头发的脸单独放大，与目标视角、教程模版并排，被头发遮住的部分要像教程那张纯脸一样干净；渲染结果半透明叠在目标视角上。

抬头、低头各做一遍：
1. 先看清图：放大 upper-body.png 和目标视角，看哪些脸缘真的露出来（下颌、脸颊），哪些是被头发截断的假边。抬头时下颌下方、低头时下巴下缘新出现或消失的线本步不处理，不当作要对齐的轮廓。
2. 先把整个头俯仰过去，解决看不见的地方：五官在目标视角中做模板匹配，得到各自的位置和纵向压缩；用“头是绕横轴转动的球”拟合俯仰（球心在脸后，横向网格线因此像模版那样弯，额头与下巴的宽窄随之变化），作为整体变形（后向场：目标→原图）。被头发遮住的额头、鬓角、脸颊由它带着走，顺着模版的头型，不另外推，轮廓对照教程模版是一条完整顺滑的线。看叠图：五官大致位置和上下间距要对上。
3. 再液化看得见的地方：在球的俯仰之上加一层平滑位移，把脸底轮廓推到目标视角真实露出的下颌、脸颊上；假边不推。推错了拉出凹口就剔掉那段，太软出现折叠、鼓包就调硬，看不见的地方被推出波浪、锯齿、直边、折角就回到球的俯仰带着走。
4. 五官（按教程结构）：在整体变形之上，眉眼（有腮红时并入）6×4、嘴 4×4、鼻 3×3，各自拟合到目标视角中的五官，看叠线稿让眼、眉、嘴、鼻的线重合，并对照【教程先验】
Y 轴的重点不在透视，而在距离关系。这些是画的时候眼睛要看的地方，不写成脚本里的判定；看出不对时回去改变形，不手填轮廓点或控制点。
- 脸的总体轮廓以正面的大小和形状为基准：俯仰主要在轮廓内重新分配宽窄、弯曲网格、挪动五官，轮廓不整体缩放、不大幅变形，可以随俯仰微微上下平移；五官因此始终装在脸里。轮廓不是钉死的：目标视角里脸在头发下露得更多的地方（如抬头时刘海缝间升高的额头），脸边就顺着头型外扩到头发下面。在贴近正面轮廓与盖住头发之间权衡，两者都看得过去。
- 正面里伸在刘海、侧发下面的脸边，俯仰后仍和正面一样伸在头发下面，脸边与头发之间不露缝；看叠图时专门看刘海缝间的额头、两侧脸颊、鬓角与侧发内缘的接缝。露出来的下颌、下巴照目标视角走。
- 俯仰后的脸型看起来就是 up.png、down.png 里那张脸的脸型。
- 脸型：低头变扁、头顶一圈饱满、下巴变尖；抬头变扁、下半张脸饱满、下巴变圆润；轮廓保持一整条干净顺滑的线，见教程模版。
- 低头时眉眼距离缩小，抬头时增大。
- 嘴低头变扁，抬头变高。
- 鼻子低头时更靠近嘴，抬头时跟着嘴一起移动。
- 耳朵不做细节调整，贴着脸缘随动、不变形；它在脸后面，抬头时相对五官下移，低头时上移。没有耳朵图层（如被头发完全遮住）时跳过耳朵，照常交付脸部。
- 有脖子部件（neck）时，它所有关键形都与静止相同：脖子不变形，转头、俯仰时是脸在它上面移动。
- 大造型小细节：整体变形决定位置和造型，五官只补整体做不到的细节。做一个五官时，注意它与其他五官和脸型的关系。
