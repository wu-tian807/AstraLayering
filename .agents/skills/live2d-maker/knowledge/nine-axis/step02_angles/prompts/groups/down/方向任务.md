【脸底：完整脸描边 → 遮挡补全 → 自动拟合 → 实际脸底检查】
1. 隐藏五官，单独看原画完整 face_base 与固定脖子，打开本步 layers/ 中的脸底 PNG。source 是该部件的原画完整 alpha 外缘，不是头发之间露出的皮肤窗口。按 textureBounds 将 PNG 放回画布，再以既定 box 裁出 source-face-reference.png；仅用作检查底图，不改贴图。
2. 先辨认目标帧中的脸、头发、睫毛、脖子和下颌阴影，对着带头发的 down.png 起稿整张 target 脸型：准确描真实可见的两侧太阳穴、颊颌、下巴尖端、下颌与固定脖子的交界，在未知处临时闭合，临时补线不当作已完成的隐藏预测。同一次描边中辨认刘海、鬓发遮挡和缝间实际露出的额头/额角，把上露尖角、分离窗口及发影下的暗肤色都包进脸内；它们从起稿时就是可见证据，不能拟合后才补洞。脸实体外缘实际显露的段标 visible，远侧显露的脸缘同样准确描出，不能因短小或暗色就整段归为隐藏；被遮住的小段稍后补全并标 occluded。内部阴影、鼻线、发影和耳轮不是外脸缘，顺着发束切入脸内部的皮肤窗口是遮挡边界，不能把发梢凹口压进脸肉。必要时看相邻视频帧辨认归属，指定 down.png 仍是拟合目标。
3. 复用 Part 的闭合色块描边：source-face.svg 和 target-face.svg 为 box.size 见方、viewBox="0 0 box.size box.size"、纯色闭合 path、stroke="none"、透明背景，填色边缘就是轮廓。source 用 preview_svg reference=source-face-reference.png；target 省略 reference，自动叠到本步 down.png。先整图 blend，再用重叠 crop、scale=4..8，反复看 blend/edge 的真实填色外缘。核对两侧颊颌、下巴、可见太阳穴与额头窗口的端点、切线、转折和笔锋；不能只看整图相似或细描线的中心。source 同样逐段贴住原 PNG 的真实外缘，不能靠 Warp 抵消 source 描错。修改后回看相邻区。
4. 在描准可见段之后，结合原画完整脸型和带图先验补出隐藏的额头、太阳穴、脸颊及下颌体量，替换临时闭合段。完整 target-face.svg 保留已描的额头窗口，再在发后保留有依据的连续体量与搭接余量，不能让低额顶截断已知尖角。俯仰时这些区域的显露比例可能改变，不能把完整脸底简单整体拉高/压扁或膨胀。具体下巴位置、下颌弧度、头宽、纵深取当前视频；教材的规律只帮助理解没有证据的区域，不决定本角色外观。先独显闭合 SVG 看完整素脸，保证连续、合理，随后再叠加复查可见段与额头窗口没有被补全拉走；预测过低先改完整预测，不能靠最后补洞迁就错误预测。
5. 用两份已核对 SVG 的同一组路径段生成 face-trace.json：version=1、space=view、completion={part,source,target} 是完整闭合路径；curves 是这两条轮廓上语义对应、方向一致的小段，标 visible/occluded。两侧颊颌、下巴及额顶分别拆段，别用一条跨越多个转折的大曲线猜对应关系；少量 landmarks 可稳定真实对应点。不要让整脸、分段、预览成为三套轮廓。
6. 调用 fit_nine_axis inspect，实际查看 traceCheck 和 completionCheck：原画描线、目标描线、无遮挡完整预测，以及完整 source/target 素脸双图。completionMismatch 必须为空；它只校 SVG 与 trace，不证明预测包含可见皮肤。确认隐藏额顶和脸颊保留体量、包含可见额头，可见颊颌/下巴贴住视频，然后保存 trace-check.png、face-completion-check.png。
7. 自己选择合适的脸底 Warp 或部件，用 fit_nine_axis fit 自动求本步 Y 端点参数。工具已经绑定 down 方向，不需要手填角度或大量网格坐标；visible 优先、occluded 弱约束。看每段误差，未贴住时回查对应关系、分段、Warp 范围/密度或局部子级后重新拟合。拟合失败不会保存。
8. 用 view_nine_axis 在 X=0,Y={down_angle} 以 only=["face/face_base"] 单独渲染真正形变后的脸底，保存 face-base-down-check.png，与完整预测核对：刘海缝等可见处不能露底。若预测漏了可见额头，先修完整预测并同步 trace 再 fit；预测合理而实际脸底不足时，由你选择现有或局部 Warp，以 fit/edit 修正。随后以 reference={path:down.png,bounds:[box.x,box.y,box.size,box.size]} 同坐标叠加，放大两侧颊颌、下巴、额顶/太阳穴可见范围。网格贴描线不等于描线贴视频，必须看实际渲染；不能只交一张好看的预测。

【隐藏额顶与额角：实际补全验收】
本步完成从额顶中心经两侧额角、太阳穴到上颊的完整脸底与有依据的发缘搭接，不能把脸底自身的缺顶、凹坑或露底留给 step04_jaw-line。隐藏部分按原脸体量与带图先验补全，不沿刘海下缘闭合，不按全部头发外轮廓扩大脸底，不规定统一头骨尺寸或固定扩张量。
completionCheck 是 SVG 预测，completionMismatch=[] 只校 SVG 与 trace；fit 残差衡量描线约束，不是实际 alpha 覆盖。读取 occludedWeightScale：为守可见边缘它可能被压得很低甚至归零，此时独显真实脸底检查额顶、双侧额角/太阳穴，按先验的方法对照 completion、原帧和发缘；可见残差小、网格不翻折都不能作为补全完成。
如果预测合理但实际隐藏上沿起伏或不足，用现有 view_nine_axis 的 only/grid/crop/scale 定位，由你选择脸底部件、现有 Warp 或必要的局部 Warp，复用 edit_nine_axis 局部修正。需要 fit 时用 features 选择相关隐藏段和真实可见连接处；不能把 occluded 改成 visible 绕过保护，没有适用可见段时使用局部编辑。每轮回查全部已对齐的可见脸缘和五官，不只检查被选 features，也不通过全脸膨胀填顶。若预测本身不足，修隐藏 SVG 并同步 trace，再重新检查。
