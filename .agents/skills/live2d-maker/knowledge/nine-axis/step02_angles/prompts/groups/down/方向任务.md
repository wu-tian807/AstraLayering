【down：独立低头】
目标：用原画加网格形变，复刻本角色视频里低头的脸型与五官，只制作 X=0、ParamAngleY = {down_angle}（{down_degrees}°）。本步目标 X={target_x}、Y={target_y}，作者文件 "{author_file}"。本步从 "{neutral}" 的原工程独立开始，与 left、up 并行制作，不继承或镜像其他方向。

【输入与坐标】
源 KRA："{document}"；同画布合成 PNG："{color}"；程序导出的 neutral："{neutral}"。
本步目标："{reference_frame}"；原视频："{reference_video}"；正面："{source_frame}"；裁框："{uri:nine-axis/step01_video/crop.json}"。
特写像素 (u,v) 对应原画布 (box.x+u,box.y+v)，参考、描边和渲染一直用同一裁框、尺度和位置。
本提示词后面有通用脸部轮廓先验和 down 方向先验，可以打开其中的圆脸关键帧、教程脸底和分类模型图。先看原画是什么脸型，再选接近的结构并说明理由；示例的角度、表情和脖子运动不搬给本角色。

【先看视频】
描线前用 ffmpeg 从原视频取开头、四分之一、中间、四分之三、末尾五帧，用 view_bitmap 看一遍，确认是正立的竖直俯仰，没有水平转身、滚转或推近。视频本身运动不对时返回 error 说明，不去旋转或缩放参考来迁就。

【建立工程】
程序已把 neutral 的图层、来源、中轴和静止网格复制到本步 layers/ 与 "{author_file}"。先调用 edit_nine_axis {} 读取作者文件，用 view_nine_axis 在 X=0,Y=0 核对与原画重合，再看端点初始效果。Warp 的分组、父子层级与密度按需要自定。
脖子从一开始就进入完整渲染作为参考，保持原形原位、parent 为空、不跟头部 Warp；顶部补足和最终消线在 step04_jaw-line。

【脸底：描边 → 补全 → 自动拟合 → 看实际脸底】
1. source：隐藏五官，打开 layers/ 中的脸底 PNG，按 textureBounds 放回画布，以 box 裁出 source-face-reference.png，沿完整脸底 alpha 描 source-face.svg。
2. target 起稿：在 down.png 里先分清脸、头发、发影、睫毛、脖子和下颌阴影，对着带头发的帧起稿整张 target-face.svg。清楚的真实脸缘（下巴、可见的颊颌、下颌与脖子交界等）描准；刘海缝里露出的额头、额角皮肤包进脸内；紧贴头发或鬓发、走势突然变直或内凹的边缘，很可能是头发切出来的，先当作不确定，未知处临时闭合。需要时看相邻帧辨认归属。
3. 描边格式沿用 Part 的闭合色块：box.size 见方、viewBox="0 0 box.size box.size"、纯色闭合 path、stroke="none"、透明背景。source 用 preview_svg reference=source-face-reference.png；target 省略 reference 时叠到 down.png。先整图 blend，再用重叠 crop、scale=4..8 的 blend/edge 看端点、切线、转折和笔锋。
4. 补全：用通用轮廓先验和 down 方向先验，把临时闭合段和不确定段补成一张连续、外凸、圆润的完整脸。X=0 时两侧颊部大体对称、都是饱满的外凸弧；一侧被头发切直或切凹时，参照另一侧和原画正面的脸型补圆。额顶与额角在刘海后保持头骨圆弧。下巴位置、下颌弧度、头宽取视频里可信的部分。用 preview_svg 独显完整素脸，看它是否像同一个角色低头的完整脸型；再叠回 down.png，确认清楚的脸缘和额头窗口没有被拉走。
5. 用两份 SVG 的同一组路径段生成 face-trace.json：version=1、space=view、completion={part,source,target} 是完整闭合路径；curves 是语义对应、方向一致的小段，清楚可信的脸缘标 visible，被遮挡或拿不准的段标 occluded。两侧颊颌、下巴、额顶分别拆段，少量 landmarks 可以稳定真实对应点。
6. fit_nine_axis inspect：看 traceCheck、completionCheck，确认 completionMismatch 为空、完整预测合理，保存 trace-check.png、face-completion-check.png。
7. 自选脸底 Warp 或部件，用 fit_nine_axis fit 自动求端点参数（工具已绑定 down 方向）。看逐段误差，没贴住时回查对应关系、分段、Warp 范围或子级再拟合。
8. 用 view_nine_axis 在 X=0,Y={down_angle} 以 only=["face/face_base"] 看实际变形后的脸底，保存 face-base-down-check.png，和完整预测对照。fit 为保住 visible 段可能把 occludedWeightScale 压得很低，所以两侧颊部是否圆润、额顶额角是否连续、露肤处是否有脸底，要看实际渲染。不足时选现有或局部 Warp，用 fit（features 选相关段）或 edit_nine_axis 局部修正；预测本身不对就先改 SVG 和 trace。再用 reference={path:down.png,bounds:[box.x,box.y,box.size,box.size]} 同坐标叠加，放大两侧颊颌、下巴和额顶。
已有头发层时显示它看覆盖；没有时只说明静态覆盖情况。原贴图缺像素时说明素材限制。

【五官与整体】
重新显示五官，用一次 edit_nine_axis operations 批量调整眼、眉、鼻、嘴的形状和落点，再渲染微调；整眼、口腔各层可以共用 Warp，局部不足再单独修。俯仰时留意眉眼、鼻嘴、嘴颏的纵向关系、眼睑弧度、眼白与虹膜/高光，以本角色视频为准，保持表情和原画笔触。
最后一起显示脸、五官和脖子，看形状、层次和接触；脖子接触的问题记录给 step04_jaw-line。原 KRA 没有独立耳朵就说明并跳过。
