【down：独立低头】
用原 KRA 的绘画加网格形变，做出本角色视频里 down 的样子：X=0、ParamAngleY = {down_angle}（{down_degrees}°），本步目标 X={target_x}、Y={target_y}，作者文件 "{author_file}"。从 neutral 独立制作，不继承或倒转其他方向。贴图保持原画。

【输入】
- 源 KRA "{document}"，合成图 "{color}"；初始工程 "{neutral}"（脸部组与脖子已导出，图层已复制到本步）。
- 正面特写 "{source_frame}"，down 目标帧 "{reference_frame}"，原视频 "{reference_video}"。特写是 box.size 见方，(u,v) 对应原画布 (box.x+u,box.y+v)，box 见 "{uri:nine-axis/step01_video/crop.json}"。
- 可见的脸缘以视频为准；后面的通用轮廓先验和 down 先验帮助分辨哪些边是真实脸缘、哪些是头发切出来的。

先用 ffmpeg 从原视频取几帧，用 view_bitmap 看一遍，确认是正立的竖直低头，没有水平转身、滚转或推近；运动不对时返回 error 说明。然后 edit_nine_axis {} 读作者文件，用 view_nine_axis 在 0 度确认与原画重合。

【1. 照着视频描边】这是整个方向最关键的一步，后面的补全和形变都照着它走，描不准后面就跟着错。
- source-face.svg：沿原画 face_base 的完整 alpha 描脸底，用 preview_svg 对 source-face-reference.png（face_base 放回原画布后按 box 裁出）核对。
- target-face.svg：对着 down.png 描整张脸，两侧都一样认真。凡是视频里看得见的皮肤，它的边就照视频描准，贴着皮肤与背景、头发、阴影的交界走。
  - 下巴和两侧颊颌连成的底缘：走向、转折和下巴的尖圆照视频描。
  - 两侧脸颊、太阳穴被鬓发和发束切开时，露出来的每一段皮肤边都照视频描，不要因为旁边有头发就整段交给补全。
  - 刘海、鬓发之间露出的每一块额头、额角、脸颊皮肤都包进脸内，不漏细尖角和暗处的皮肤。
- 只有真正被头发盖住、视频里看不见的地方才临时闭合，留给补全。
- SVG 是纯色闭合 path、透明背景、viewBox="0 0 box.size box.size"。

自检：用 preview_svg 把 target-face 叠在 down.png 上，blend 和 edge 都看，并沿两侧脸缘、额角和下巴逐段放大 crop（scale 4..8）。
- 每段看得见的皮肤边，描线都应贴在上面。
- 描线越过皮肤伸进头发或背景的地方，要能指出那里确实是被头发盖住的脸；指不出就是描错了，改到贴住为止。
- 写 trace 时也按这个来：贴着可见皮肤边的段标 visible，不能把看得见的段标成 occluded。

【2. 补全：给头发运动垫底】
被头发盖住、看不见的部分不追求某种脸型，判断标准是：
- 和第 1 步描准的可见线连续相接，整条外缘顺滑干净，没有尖角、折角或缺口；第 1 步的线原样保留，可见部分仍贴合视频。
- 补出来的部分顺着这张脸本来的弧度往外走，整张脸仍是正面原画那张脸的样子，不补成直边、方块或额外的棱角。
- 每一条盖住脸的头发边下面，脸底都延伸得足够深：头发晃动、飘起、发梢移开一段时，露出来的仍是皮肤，不露背景或缝隙。刚好盖住可见发缘是不够的，不要沿头发内侧的发缘收边；额角、刘海与鬓发交界这类发缘离脸缘很近的地方尤其要留足。
补全按"补一版、review、改进"来做：补出一版后用 preview_svg 叠在 down.png 上，沿每条头发边逐段放大看：头发往外动一些，下面还是不是皮肤；补出来的线和可见线接得顺不顺。有问题就改，改完再 review，直到都满足。
然后写 face-trace.json（version=1、space=view、completion={part,source,target} 是完整闭合 path，curves 是对应小段：看得清的标 visible，补出来的标 occluded），用 fit_nine_axis action=inspect 检查。

【3. 应用形变】
建脸底 Warp，用 fit_nine_axis action=fit 自动求形变。

【4. 微调形变】
用 view_nine_axis only=["face/face_base"] 看实际变形后的脸底，和补全的脸、down.png 对照。补出来的部分 fit 可能没拉到位，没贴住的地方、边缘有碎裂或抖动台阶的地方，用 fit（features 选相关段）或 edit_nine_axis 局部修。
脸型和五官一样是同一个人的：脸的宽高比例、两颊到下巴的弧线、下巴的尖圆，都只随透视变化，和正面原画、视频帧一致，不变宽变方，不出现原画没有的直边、折角或台阶。这是本步的验收标准，拿变形后的脸底和正面原画并排比、叠在视频帧上比，不一致就改。网格贴住自己的描线不代表脸对上了视频，判断以和视频帧、正面原画的对照为准。

【5. 对着视频调整五官】
显示五官，对着 down.png 用 edit_nine_axis 批量调眉眼、鼻、嘴、腮红的形状和位置，留意眉眼、鼻嘴、嘴到下巴的纵向关系，再预览微调。五官始终是同一个人的五官：每个部件自身的大小、形状、内部结构，以及部件之间的距离和相对位置，都只随转头的透视变化，和正面原画、视频帧一致，不因网格拉扯变大变小、走形或错位。这是本步的验收标准，逐个部件和正面原画、视频帧对照，发现不一致就改。最后看完整的脸、五官和脖子，以及 0 到 {down_angle} 的中间过渡。脖子保持不动，接触收尾在 step04。

【交付，"{output}"】
face-down.json、face-trace.json、source-face.svg、target-face.svg（fit-report.json 由工具写出），以及简短的 notes.md：哪些段是补的、头发下留的余量、剩余偏差。完成返回 {"error":null}，做不了时 error 写原因。
