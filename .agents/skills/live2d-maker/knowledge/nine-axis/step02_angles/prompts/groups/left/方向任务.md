【参考的职责】
本角色 left 视频帧是可见区域唯一的视觉目标。先描原 KRA 的完整 source 脸底，再对着带头发的 left 参考描整张 target 脸型：可见脸缘准确，刘海间露出的额头和额角一并包进脸内，未知处临时闭合。随后补全未知轮廓，以 fit_nine_axis 自动求 Warp，最后独显实际脸底，对照完整预测与视频检查。五官继续由你一轮批量液化到参考位置并微调。
教程只帮助补足视频中看不见的脸部结构。未知的完整脸外轮廓标 occluded，弱约束参与拟合；真正可见的脸实体外缘标 visible。视频中可见皮肤占据的范围是完整脸底必须包含的硬下限，不能随 occludedWeightScale 降权，不能为错误先验维持过低的额顶。皮肤窗口的头发遮挡边界不等于脸实体外缘，不能把发丝轮廓当作脸缘。

【脸底：完整脸描边 → 遮挡补全 → 自动拟合 → 实际脸底检查】
1. 先描完整 source 原脸。暂时隐藏五官，单独查看原画脸底与固定脖子；打开导出的 face_base PNG，将原部件按 textureBounds 放回原画布，用既定 box 裁出 source-face-reference.png，保持原始像素位置。保存 source-face.svg，轮廓来自本次原 KRA 导出的完整脸底 alpha，不取头发盖住后的皮肤窗口；用 preview_svg 的 reference=source-face-reference.png 核对完整原脸。脸底的线与色若分层，应在需要时一起选入你定义的 Warp；预览底图不改变作者源或贴图。
2. 对着带头发的指定 left.png，先保存整张 target 脸型轮廓起稿 target-face.svg：准确描真实可见的眼窝、颧颊、颌角至下巴，在未知处临时闭合，临时补线不当作已完成的隐藏预测。同一次描边中辨认刘海、鬓发遮挡和缝间实际露出的额头/额角，把上露尖角、分离窗口及发影下的暗肤色都包进脸内；它们从起稿时就是可见证据，不能先忽略，拟合后才补洞。脸的实体外缘即使邻接头发，实际显露的区间仍是 visible；不要把远侧眼窝至颊部整段一概写成 occluded。顺着发束切入脸内部的皮肤窗口是遮挡边界，不把发丝凹口捏进脸肉。必要时回看相邻视频帧辨认被头发盖住的是哪一条线，本角色指定 left.png 仍是拟合目标。部分显露的实体外缘按范围拆分，分别标 visible/occluded；未知走势留补全阶段。
3. 复用 part-layering 的描边方法核对完整 source/target 起稿：一种纯色、闭合 path、stroke="none"、透明背景，width/height 为 box.size，viewBox="0 0 box.size box.size"；填色边缘就是轮廓。source 用 preview_svg 的 reference=source-face-reference.png 核对完整原脸底；target 省略 reference，固定叠到 left.png。先整图 blend，再用重叠 crop、scale=4..8 分区，以 blend 与 edge 核对可见外缘的位置、切线、转折和尖端，并查看刘海间额头窗口的位置；细描线的中心、整图相似或拟合残差小均不能代替这次核对。
   远侧眼尾外侧到颊部是重点：按视频保留陡直程度、眼窝至颧颊的转向与笔锋；参考呈近竖向的区间不能被一条跨越眼窝/颊部的大圆弧磨圆，也不把整段硬拉成直线。转折处拆段，分别调整端点与控制柄，让可见范围贴住视频，而不是增加很多无意义的控制点。source 同样逐段贴住原 PNG 的真实外缘，不能靠 Warp 抵消 source 描错。修改后重看改动区及相邻区，已核对正确的近侧和下巴没有新证据就保留。source/target 小段的起终点为同一语义位置，方向一致；少量 landmarks 指定真实转折，鼻嘴等该移动的位置不能钉在正面。
4. 在完整脸起稿和可见证据核对后，补全被遮挡的未知轮廓，替换临时闭合段。已描准的脸缘与刘海缝真实可见的额头仍由视频决定，只有未知区域交给原 KRA 体量、真实遮挡和带图先验。完整 target-face.svg 保留已描的额头窗口，再在发后保留有依据的连续体量与搭接余量，不能让低额顶截断已知尖角。近侧脸颊保留完整体量，远侧起伏和笔锋取视频；先验不能磨圆或移动已贴住视频的可见段。选择适用脸型并说明理由，不平均不同脸型。用 preview_svg 的 svg 独显看整张补全脸，再以 blend/edge 复查可见范围和额头窗口；预测过低先改完整预测，不能靠最后补洞迁就错误预测。
   由这两份已检查的 SVG 同一组路径段生成 face-trace.json：version=1、space=view、completion={part,source,target}，source/target 是完整闭合 SVG path d；curves 为同一轮廓上的对应小段，分别标 visible/occluded。避免整脸、分段和预览画成三套不同轮廓。完整预测包含被挡区域，不沿发缘闭合皮肤窗口。
5. 调用 fit_nine_axis action=inspect，查看 source 描线、left 帧描线及无遮挡完整 target 脸底；另查看返回的 completionCheck 素脸双图。检查原画完整脸/预测 left 完整脸的体量、额顶/双额角、可见额头包含性与轮廓连续性，尤其近侧眼窝至颊部不能因头发被削成波浪。completionMismatch 必须为空；它只校 SVG 与 trace，不证明预测包含可见皮肤。将真实输出保存 trace-check.png 和 face-completion-check.png，先完成完整预测检查再拟合。
6. 由你建立合适的脸底 Warp，控制点多少按轮廓转折需要决定。用 fit_nine_axis action=fit，给 trace 路径和所选 Warp id，程序按对应曲线自动求 left 参数。visible 优先，occluded 只指导未知结构。检查逐段误差；某段未贴住时，检查对应关系、拆段、增加合适的控制点或子 Warp 后重新求解。不要用一段下巴的误差代表整张脸。
7. 用 view_nine_axis 的 only=["face/face_base"] 独显实际脸底，保存 face-base-left-check.png，并与完整预测核对：刘海缝等可见处不能露底。若预测漏了可见额头，先修完整预测并同步 trace 再 fit；预测合理而实际脸底不足时，由你选择现有或局部 Warp，以 fit/edit 修正。然后再以 reference={path:left.png,bounds:[box.x,box.y,box.size,box.size]} 看同坐标叠加，放大两侧眼窝至颊部、额头窗口、颌角和下巴，回查位置、切线、笔锋和线宽。网格贴描线不等于描线贴视频。

【隐藏额顶、额角与发缘覆盖：检查实际脸底】
完整补全包含额顶中心经两侧额角、太阳穴到上颊的连续体量，以及真实刘海/鬓发后有依据的搭接；不沿发束凹口闭合，不照全部头发外轮廓扩大脸底，也不规定统一头骨尺寸或固定扩张量。
completionCheck 是 SVG 预测，completionMismatch=[] 只校 SVG 与 trace，低可见残差和网格不翻折不能证明实际 alpha 完整。先看完整预测是否覆盖视频中可见额头皮肤；预测本身过低不能被先验或小残差接受。读取 fit 报告的 occludedWeightScale；它为守可见边缘可能被压低甚至归零，此时用 view_nine_axis 的 only/grid/crop/scale 独显真实脸底，同坐标对照 completion 和原帧，放大额顶、双侧额角/太阳穴，检查缺顶、凹坑、波纹、压薄、断续及需要皮肤覆盖处露背景。
若预测合理但实际隐藏上沿不足，由你选择脸底部件、现有 Warp 或必要的局部 Warp，复用 edit_nine_axis 局部修正；分组、父子关系、控制范围和密度由实际需求决定，不预定联合 Warp。需要 fit 时用 features 选择相关隐藏段与真实可见连接处；不能把 occluded 伪标 visible，没有适用可见约束时用局部编辑后渲染核对。每轮回查全部已对齐的可见脸缘、五官和原画正面，不通过全脸膨胀、移动下巴或扭动固定脖子填顶。若预测本身不足，修隐藏 SVG 并同步 trace，再重新检查。
发缘覆盖用原 KRA 与当前 left 帧核对；工程已有头发层时显示检查。没有头发层或未定义发摆范围，只说明静态遮挡和脸底完整性，不能宣称未来头发动也不会露底，也不新增头发动画。原贴图缺所需像素时说明素材限制。最后一次局部编辑及五官调整后重新渲染完整脸底和额顶/额角，保存 forehead-temple-check.png、hair-coverage-check.png；notes 记录作者、参考帧 SHA、图像路径、occludedWeightScale 和剩余差异。不能用 SVG 预测、旧 fit 报告或旧截图验收新工程。
