【left：水平转面】
用原 KRA 的绘画加网格形变，做出本角色视频里 left 的样子：ParamAngleX = {left_angle}（{left_degrees}°），本步目标 X={target_x}、Y={target_y}，作者文件 "{author_file}"。向右 {right_angle} 由程序镜像。贴图保持原画。

【输入】
- 源 KRA "{document}"，合成图 "{color}"；初始工程 "{neutral}"（脸部组与脖子已导出，图层已复制到本步）。
- 正面特写 "{source_frame}"，left 目标帧 "{reference_frame}"，原视频 "{reference_video}"。特写是 box.size 见方，(u,v) 对应原画布 (box.x+u,box.y+v)，box 见 "{uri:nine-axis/step01_video/crop.json}"。
- 参考头型：原画正面的脸型为主，后面的通用轮廓先验和 left 脸型先验。

先 edit_nine_axis {} 读作者文件，用 view_nine_axis 在 0 度确认与原画重合。

【1. 照着视频描边】这是整个方向最关键的一步，后面的补全和形变都照着它走，描不准后面就跟着错。
- source-face.svg：沿原画 face_base 的完整 alpha 描脸底，用 preview_svg 对 source-face-reference.png（face_base 放回原画布后按 box 裁出）核对。
- target-face.svg：对着 left.png 描整张脸，两侧都一样认真。凡是视频里看得见的皮肤，它的边就照视频描准，贴着皮肤与背景、头发、阴影的交界走。
  - 转向一侧（画面左侧）：从额角、太阳穴经眼窝外侧、颧骨到下颌那条带起伏的线，走向、转折和陡度照视频描。
  - 另一侧（画面右侧）：脸颊、眼角外侧、下颌被鬓发和发束切开，露出来的每一段皮肤边都照视频描，不要因为旁边有头发就整段交给补全。
  - 刘海、鬓发之间露出的每一块额头、额角、脸颊皮肤都包进脸内，不漏细尖角和暗处的皮肤。
- 只有真正被头发盖住、视频里看不见的地方才临时闭合，留给补全。
- SVG 是纯色闭合 path、透明背景、viewBox="0 0 box.size box.size"。

自检：用 preview_svg 把 target-face 叠在 left.png 上，blend 和 edge 都看，并沿两侧脸缘、额角和下颌逐段放大 crop（scale 4..8）。
- 每段看得见的皮肤边，描线都应贴在上面。
- 描线越过皮肤伸进头发或背景的地方，要能指出那里确实是被头发盖住的脸；指不出就是描错了，改到贴住为止。
- 写 trace 时也按这个来：贴着可见皮肤边的段标 visible，不能把看得见的段标成 occluded。

【2. 补全：给头发运动垫底】
补全是为了给头发运动垫底：被头发盖住的地方，脸底要一直延伸到头发后面足够深，头发晃动、飘起时下面不会露出空白或缝隙；不要沿头发内侧的发缘收边。同时补出来的部分要贴合已有的脸部轮廓：接着第 1 步描准的线和原画正面的脸型走，是同一张脸自然的延续（额顶、额角到太阳穴是头骨的圆弧，近侧脸颊饱满，转向一侧的起伏接着视频描出的线走），曲率顺滑，不鼓包、不折角。第 1 步描准的线原样保留。
补全按"补一版、review、改进"来做：先按正面脸型、通用先验和 left 先验补出一版；再 review：用 preview_svg 把它叠在 left.png 上，也独显完整的脸，看头发后面垫得够不够深、哪里头发一动就会露缝，看补出来的线和已有脸部轮廓贴不贴、接得顺不顺，像不像这个角色转过去的完整脑袋。有问题就改，改完再 review，直到这几点都满足。
然后写 face-trace.json（version=1、space=view、completion={part,source,target} 是完整闭合 path，curves 是对应小段：看得清的标 visible，补出来的标 occluded），用 fit_nine_axis action=inspect 检查。

【3. 应用形变】
建脸底 Warp，用 fit_nine_axis action=fit 自动求形变。

【4. 微调形变】
用 view_nine_axis only=["face/face_base"] 看实际变形后的脸底，和补全的脸、left.png 对照。补出来的部分 fit 可能没拉到位，没贴住的地方、边缘有碎裂或抖动台阶的地方，用 fit（features 选相关段）或 edit_nine_axis 局部修。

【5. 对着视频调整五官】
显示五官，对着 left.png 用 edit_nine_axis 批量调眉眼、鼻、嘴、腮红的形状和位置，再预览微调。最后看完整的脸、五官和脖子，以及 0 到 {left_angle} 的中间过渡。脖子保持不动，接触收尾在 step04。

【交付，"{output}"】
face-left.json、face-trace.json、source-face.svg、target-face.svg（fit-report.json 由工具写出），以及简短的 notes.md：选用的头型、哪些段是补的、剩余偏差。完成返回 {"error":null}，做不了时 error 写原因。
