【共享制作流程与变量接口】

本流程用于 left/up/down 的独立作者工程。initial 已注入的完整脸底覆盖共同规范规定同一覆盖合同；下面按实际操作顺序执行，方向稿只补本方向任务和重点，先验稿只补隐藏结构。使用 view_bitmap、view_nine_axis、edit_nine_axis、fit_nine_axis、preview_svg；原 KRA 已由程序在并发开始前导出一次，不需要 Krita，agent 只形变原 PNG。

必需变量由调用方提供，不从固定 step 路径猜测：
- "{output}"：本方向独立输出目录。
- "{neutral}"：只读的共享原工程目录，含原 KRA 导出的 layers/、中性 deformers.json 与 export-record.json；不是某方向的已变形端点。
- "{reference_frame}"：当前方向指定的视频目标 PNG；"{source_frame}"：同裁框、同尺度、同位置的正面 PNG。
- X={target_x}、Y={target_y}：当前单轴目标的数值参数标签，不是从视频测出的物理角度。
- "{author_file}"：本方向完整 version 2 作者文件的绝对路径，位于 output 内，由方向稿指定文件名。
- "{document}"：只读原 KRA 来源；"{color}"：原画布合成 PNG。用于来源和正面核对，不用于另画贴图。

路径型变量的值全部是绝对路径，target_x/target_y 是数值。可选路径 "{completion_prior}"、"{reference_video}"、"{reference_frames}"、"{continuity_reference}" 分别为本方向补全先验文档、原视频、已抽出的相邻视频帧目录、已提供的角色连续参考目录；调用方未提供时传空字符串。未展开的占位符不是可访问路径。

所有检查均取 neutral 文档的 canvas、axis、view 与原图 textureBounds。记 box.x=view.x、box.y=view.y、box.size=view.width；本接口要求方形 view，height=width。特写 (u,v) 对应原画布 (box.x+u,box.y+v)。source_frame/reference_frame、SVG 和 trace 使用同一特写坐标；view_nine_axis 的 crop、bounds 与网格点使用原画布坐标。不能按变形后的眼睛、下巴重新居中、旋转、平移或缩放参考。

【1. 核对输入，打开独立原工程】

先核对 neutral 的导出记录、原贴图、原画布、中轴、绘制顺序与 document/color 的来源。共享 neutral 不预建 Warp，部件静止形为原形；它和 layers/ 都只读。程序须已将本方向 edit/fit/view 绑定到 author_file，并从同一 neutral 建立独立作者。先调用 edit_nine_axis {} 读 revision 与节点索引；缺少本方向绑定、来源不符或工具打开了另一方向时返回 error，不能从旧方向或旧描线凑输入，也不自行重导 KRA。

用 view_bitmap 看 color、source_frame、reference_frame。用 view_nine_axis 在 X=0,Y=0 核对原画重合，图层没有漏掉、错位，脸底是原 PNG 的完整 face_base。保留线/色层、耳朵和全部已有五官。脖子从最初完整预览参与下巴位置和遮挡参考，parent=null，静止形和所有关键形保持原形原位置，不挂到头部 Warp、不倾斜、不拉长。没有独立耳层或脖子时如实记录，不伪造部件。

本方向 Warp 的分组、父子层级、作用范围、密度与局部微调自由；可以共同 Warp、增加子级或独立调整。续修只沿用本次方向、同一 neutral 来源的合法 author_file，保留已认可的区域、五官、层级与笔锋锚点；全新任务不复制旧 X/Y/组合轴作者、网格、参数或 trace。其他方向不会因为先完成而成为本方向上游。

【2. 确认目标与先验，主动逐窗观察】

实际打开随后补全先验稿指定的圆脸关键帧板、教程完整脸底及分类模型图，先识别原画脸型，再说明选择的隐藏结构依据。当前视频可见区域优先，先验补不可见，不能平均不同脸型或复制示例的角度、表情、脖子运动。

有 reference_frames 时实际查看开头、四分之一、中间、四分之三、末尾及目标邻近帧；只有 reference_video 时复用已有 ffmpeg 抽帧到 output 内供 view_bitmap 查看。核对运动方向、正立画面和同一裁框，up/down 尤其排除水平转身、滚转倒立、推近放大。错误视频返回具体 error，不旋转、缩放参考掩盖。没有视频/相邻帧时说明检查范围，不能声称已检查；指定 reference_frame 始终是拟合目标，不改选来躲避缺口。

先看原画和目标全图，再用重叠放大区从额顶、两侧额角扫到太阳穴，主动辨认所有刘海间皮肤窗口、上露细尖角、分离细窗、发束之间的皮肤条、发影下暗肤色与混色边界。头发、睫毛、耳轮、阴影、真实皮肤和脸实体外缘分别辨认。用户问题截图和历史反馈仅辅助定位，不能只检查被圈出的区域。

【3. 完整 source、整张 target 起稿与独立窗口标记】

隐藏五官，独显原画完整 face_base 与固定脖子。按 neutral 的 textureBounds 将原脸底 PNG 放回原画布，以原 view 裁出 output/source-face-reference.png，保留真实 alpha。source 取完整脸底外缘，不取 source_frame 里被头发切碎的露肤轮廓，也不取任何变形端点。

在 output 写 source-face.svg 与 target-face.svg。使用 box.size 见方、同 viewBox、透明底、不透明纯色闭合 path、stroke="none"，填色外缘即轮廓。source 逐段贴原 PNG；target 从整张脸起稿，可见实体脸缘准确，未知处先临时闭合再补全，不沿刘海窗口闭成一小块皮肤。

同一观察阶段在 output/face-coverage.svg 独立标记 reference_frame 中实际露出的全部额部皮肤窗口，包括额顶、两侧额角和相连太阳穴。mask 同尺寸、透明底、不透明纯色闭合填充；从视频直接描，不从 source/target/completion、当前网格、实际脸底或旧缺口探针反推。保留细尖角、分离细窗和暗肤色，头发不画；整张脸缘、眼窝/颊部/下颌外轮廓不充当这个额部 mask。

分别用 preview_svg 显式 reference=source-face-reference.png、reference_frame 核对 source 和 target；mask 也显式 reference=reference_frame，不能使用默认 left 参考。先整图 blend，再以特写 crop=[u,v,width,height]、scale=4..8 重叠分区查看 blend/edge，逐一核对端点、切线、转折、尖端、笔锋及每个皮肤窗口。修改后看改动区和相邻区。保存 source-trace-edge.png、target-trace-edge.png、face-coverage-mask-check.png，并记录目标帧和 mask SHA。

【4. 补全完整 source/target，建立一致 trace】

source 全脸轮廓以原完整 alpha 为准；target 未知段用原画体量、该方向先验、真实发束遮挡和已知边界补全，替换临时闭合。从额顶中心到两侧额角、太阳穴、上颊连续连接，预测包含核准 mask 的全部窗口，并留有依据的搭接余量。不截断已见尖角，不照整个头发外轮廓扩脸，不硬编码统一头骨尺寸/扩张量，不以整脸膨胀补洞。

output/face-trace.json 使用 version=1、space="view"、completion={part:"face/face_base",source,target}，source/target 为同一 SVG 的完整闭合 path d。curves 把眼窝、颧颊、颌角、下巴、额顶等转折拆成语义对应、方向相同的小段，起终点对应同一部位；必要时少量 landmarks 固定真实转折。真实显露的实体脸缘标 visible，部分显露就拆段；只有看不到的完整外缘标 occluded，刘海窗口遮挡边界不伪标脸外缘。

source-svg、target-svg、completion 与 curves 保持同一套路径，不能为降低残差造三套轮廓。调用 fit_nine_axis({action:"inspect",trace:"output 内 face-trace.json 的绝对路径"})，实际查看 traceCheck 与 completionCheck 的描线、无遮挡完整 source/target，确认 completionMismatch=[]，保存 trace-check.png、face-completion-check.png。检查整张预测含全部核准窗口；source 描错先修 source，不能让 Warp 抵消。

【5. fit_nine_axis 自动 Warp，复核逐段误差】

先用 edit_nine_axis 自由建立适用的 Warp/父子结构，选择包含脸底的节点 id。实际调用 fit_nine_axis 的 fit，提供 trace 绝对路径、所选 id、最新 revision；本方向作者与 X/Y 由调用方工具绑定，不向 fit 伪造不存在的路径或角度参数。必须自动拟合脸底，不能只手填大量网格点或写报告交付。

读取逐段拟合前后平均/最大残差、completionMismatch 和 occludedWeightScale，保存 fit-report.json。visible 优先，occluded 为弱约束，保护已贴准可见边缘时可能降为零；mask 硬覆盖不随其降权。残差偏大先查描边、语义对应、分段与作用范围，再按需要增加控制点/局部 Warp 并重拟合，不用单一下巴误差代表整脸，也不弱化真实 visible 来过检查。

低残差只说明网格贴住 trace，completionCheck 只是完整预测，网格无折叠只说明几何有效。用 view_nine_axis 在 X={target_x},Y={target_y}、reference={path:reference_frame,bounds:[box.x,box.y,box.size,box.size]} 同坐标比较真实 PNG；特别重看远侧眼窝到颊部、两侧脸缘、下巴和已确认笔锋锚点，确保后续编辑没有拉走它们。

【6. 实际完整 alpha 与逐窗覆盖】

用 view_nine_axis 在当前 X/Y、only=["face/face_base"] 真正独显形变后的完整脸底，对照整张预测，重叠放大额顶、两侧额角/太阳穴、与上颊的连接。不能缺顶、凹坑、波纹、压薄、断续或在需皮肤处露背景。保存 face-base-check.png、forehead-temple-check.png、hair-coverage-check.png。

按共同规范执行同一次真实 RGBA 覆盖检查：view_nine_axis 的 x={target_x}、y={target_y}、only=["face/face_base"]、crop=[box.x,box.y,box.size,box.size]、scale=1；reference.path=reference_frame，coverage.path=output/face-coverage.svg，两个 bounds 都为同一个完整 view。读取 satisfied=true、requiredPixels>0、uncoveredPixels=0，以及实际缺口面积/范围、maskSha256、alphaSha256、builtDocumentSha256；保存工具真实报告与 returned savedPath/alphaSavedPath 的原字节。

程序只按所给 mask 检查 alpha，不判定像素是否为皮肤，也不判断 mask 是否漏窗。agent 必须对原帧逐窗视觉核对。预测漏窗口时先修完整预测、同步 SVG/trace、inspect 再 fit；预测合理而实际 alpha 不足时，用 only/grid/crop/scale 查范围，局部 fit/edit 修隐藏上沿与真实可见连接处，再回查全部已贴准脸缘及正面。不能缩小 mask、漏暗皮肤、改阈值/bounds、扭脖子、移动下巴或整脸膨胀刷通过。

【7. 五官 batch、整体微调与连续帧】

重新显示五官。用一次 edit_nine_axis operations 批次完成有把握的整眼、眉、鼻、嘴、口腔各层和腮红的形状/落点调整，再渲染与局部微调。父级改大形，子级或独立部件补局部，分组自由，不要求五官全部描线求解或共用脸底 Warp。保留原画笔触、表情、眼睑峰值、虹膜/高光、鼻尖、嘴角和口腔层配合，不只移动瞳孔制造角度。

完整显示脸、五官、耳朵（若有）和固定脖子，核对透视、层次与接触，线/脸色层一起考虑。近侧耳根贴脸，远侧由脸遮挡，不改透明度隐藏错误。当前方向完成额顶、额角、太阳穴脸底；脖子顶部补足、下颌接触消线和阴影收尾记录为后续事项，不在此改错脸型或重画素材。

实际看 0、端点、沿本方向至少四分之一/二分之一/四分之三及所有已编辑中间关键形附近的连续渲染。按实际轨迹选现有 ellipse 或补中间形，不突然收缩、融化、分离，不新增额角塌陷，固定脖子不动。left 另看程序镜像右侧；up/down 不镜像、不继承另一俯仰方向。其他角色连续参考仅诊断隐藏体量，尚未制作/集成的方向或组合过渡不能宣称通过。

工程有头发层时显示核对；只在已知、获授权的动态边界内观察搭接，不新增发摆或头发动画。没有头发层或未知动态范围时，只报告静态窗口覆盖与脸底自身完整性，不能保证未来头发运动不露底。原贴图缺所需像素时如实说明素材限制，不换贴图、涂像素或改 alpha 掩盖。

【8. 最后编辑后重检与交付】

最后一次五官、父子层级、Warp、镜像或中间形编辑后，重新在最终 author_file 的当前 X/Y 查看整脸/五官与目标叠加、实际完整脸底与 completion 对照、额顶/额角、全部视频皮肤窗口，再用同一核准 mask 做 scale=1 的完整实际 alpha 覆盖重检，并回看正面和本工程连续帧。旧作者或编辑前的零缺口不能验收最后作者。

在 output 保留 author_file、source-face-reference.png、source-face.svg、target-face.svg、face-trace.json、source-trace-edge.png、target-trace-edge.png、trace-check.png、face-completion-check.png、fit-report.json、face-base-check.png、face-coverage.svg、face-coverage-mask-check.png、face-coverage-report.json、face-coverage-check.png、face-alpha-check.png、forehead-temple-check.png、hair-coverage-check.png、target-check.png、target-fit-check.png、features-check.png、neck-contact-check.png、intermediate-check.png 与 notes.md；left 另保存 far-side-check.png，up/down 另保存 jaw-chin-check.png。PNG/报告均取工具真实输出，不补画或涂改。程序生成本方向 deformers.json 与来源投影，不手写成第二作者。

notes 记录全部变量绑定、neutral/原 KRA/PNG 来源、目标帧及 mask/最终作者 SHA、工具 builtDocumentSha256/alphaSha256、所选先验和补全区域、分组理由、逐段残差与 occludedWeightScale、窗口核对/实际图路径、已保护笔锋锚点、五官 batch 与微调、连续帧范围、仍可见偏差和后续接触收尾位置。未得到最终作者绑定证据时如实说明并重新渲染，不冒充程序已证明截图来自最后作者。

完成前由程序对最终作者、当前 X/Y、当前目标帧和同一 mask 强制重渲染，记录真实 coverage report/check/alpha；agent 不自行标记完成或手写零报告。技术通过不判定皮肤语义，也不代替视觉验收；本轮为候选，只有用户明确视觉认可后才能称本方向流程稳定。实际无法贴合时说明未解决部位。完成返回 {"error":null}；无法完成时返回具体 error。
