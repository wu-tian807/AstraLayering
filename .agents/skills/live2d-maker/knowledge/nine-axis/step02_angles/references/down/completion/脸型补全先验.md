# down 完整脸型补全先验

用于 `step02_angles/down`：从原 KRA 导出的正面 neutral 独立制作下俯 −25，与 left、up 并行，不读取其他单轴的变形结果。**本角色 down 视频帧决定可见脸缘、五官、笔锋与位置；本页只帮助补全视频遮挡的额头、太阳穴、脸颊和下颌。** down 独立描线、补全与拟合，不能把 up 结果倒过来或镜像当目标。原模型参数与教程示例都不决定本角色的实际角度。

先按已由 initial 直接注入的[完整脸底覆盖共同规范]({shared_reference:nine-axis/完整脸底覆盖.md})描原 KRA 的完整 source、起稿整张 target，并从带头发的当前 down 帧主动逐窗观察；再用本页先验补全未知。原画提供源体量，视频提供可见皮肤与脸缘，先验不能削掉已知窗口或沿发缘闭合一小块脸。

## 下俯时怎样使用隐藏结构先验

| 区域 | 补全时观察什么 | 怎样限制补全 |
| --- | --- | --- |
| 额头与额顶 | 额部在下俯投影中的完整体量，额顶到两侧太阳穴的连续性 | 不把刘海下沿当额顶；不因视频露肤少就把额头压成薄片；也不任意扩大隐藏额部 |
| 太阳穴与上颊 | 额头、眼外侧与两侧脸颊的连接 | 保留原脸型；发束凹口、发影、耳饰和耳轮不能直接描进脸肉 |
| 脸颊、下颌与下巴 | 颊部体量如何接到下颌渐收段、下巴弧度与线条转折 | 教程示例的“低头变扁、下巴更尖”只是一种画法；自己的圆颏或小尖颏由视频决定，不能统一挤成尖三角 |
| 下巴与固定脖子 | 下俯投影下脸底覆盖脖子的范围与接触位置 | 从开始加入固定脖子同坐标预览；脖子不跟头部 Warp、不倾斜、不拉长；顶部补足与下颌消线留 `step04_jaw-line` |

完整预测应把可见线接进整张连续脸型：隐藏区域有原画体量约束，可见段准确贴合本角色视频。先显示无遮挡完整预测，再显示自动形变后真正渲染的完整脸底，核对两者差异。随后加五官与固定脖子看同坐标接触，不能用颈部形变补脸底的错误；同时回查已完成 up/X 的脸型与五官。

## 共同规范与 down 文件绑定

按[完整脸底覆盖共同规范]({shared_reference:nine-axis/完整脸底覆盖.md})的同一制作/实际 alpha 合同执行，方向先验只补未知结构。本步 X=0、Y={down_angle}，指定 down.png 为可见目标，作者 face-down.json；保留本步规定的上游姿态。

完整 source-face.svg、target-face.svg 与 face-trace.json 一致；辅助 mask 为 face-coverage.svg，逐窗核对图 face-coverage-mask-check.png；最终程序报告/高亮/真实 RGBA 为 face-coverage-report.json、face-coverage-check.png、face-alpha-check.png。实际完整脸底 face-base-down-check.png、额顶/双额角 forehead-temple-check.png、发缘覆盖 hair-coverage-check.png；最后五官与过渡编辑后按共同规范重检。

## 六模型：下俯与正面，明确脸型

![六模型下俯脸型参考]({reference:step02_angles/references/down/completion/model-face-priors.jpg})

每行从左到右：X=0/Y=0 的完整脸底、X=0/Y=−25 的完整脸底、基准脸＋五官、下俯脸＋五官。脸底栏按原生渲染 alpha 平涂，保留真实轮廓，五官栏保留原纹理。原 moc3 关键形与蒙版直接渲染，没有图像液化；关闭 motion/physics/pose/expression、自动眨眼与呼吸，视线、嘴开、身体及其他整体变换固定。每次渲染新建模型，检查实际参数值，原模型文件只读。

每个模型 Y=0/+25/−25 的脸底和五官六张图使用同一个 alpha 联合裁框，上下板共用裁框与比例；不为低头另居中或放大。这里 ±25 是原模型参数值，**不是实测物理角度，也不是本角色拟合目标**。基准关键形仍可能自带绘画倾斜。

| 模型与放大图 | 脸型 | 下俯补全适用观察 |
| --- | --- | --- |
| [Haru]({reference:step02_angles/references/down/completion/models/haru/reference.jpg}) | 稍长鹅蛋脸 | 较直颊部到下颌渐收段、圆钝尖颏的连接 |
| [Hiyori]({reference:step02_angles/references/down/completion/models/hiyori/reference.jpg}) | 圆润鹅蛋脸 | 饱满颊、小尖颏；低头仍保留圆收体量，不能照教程把全部圆脸挤尖 |
| [Miara]({reference:step02_angles/references/down/completion/models/miara/reference.jpg}) | 圆颊小尖颏 | 原画倾斜且脸组含装饰，只看局部颊颌连续性，不取整脸方向与装饰边界 |
| [Natori]({reference:step02_angles/references/down/completion/models/natori/reference.jpg}) | 长窄脸 | 颧颊偏直、下颌收束到小尖颏；耳轮不是脸颊外缘 |
| [Koharu]({reference:step02_angles/references/down/completion/models/koharu/reference.jpg}) | 短圆脸 | 额部、宽颊与短下脸的比例；保持圆弧下颌，不按发影改脸底形状 |
| [Haruto]({reference:step02_angles/references/down/completion/models/haruto/reference.jpg}) | 宽圆脸 | 宽颊、短下巴、扁圆底缘在下俯时的连续性 |

先按本角色原画轮廓选择相近脸型，说明只用于哪些隐藏区域；不要平均长脸与圆脸。Miara 脸组里的耳饰、Natori 耳轮和所有模型的发影/纹理装饰都不作为骨肉边界。模型参考也不决定本角色五官尺度、脖子运动或角度。

每个单模型目录有 `face_front.png`、`face_down.png`、`features_front.png`、`features_down.png` 原 RGBA 渲染；[来源与参数记录]({reference:step02_angles/references/down/completion/models/sources.json}) 保存原模型/贴图 SHA、六姿态参数检查、联合裁框和图像指纹。来源为仓库已有官方样例包；复用 render_faces.py 的 `--axis y` 和 build_reference_board.py 的 `--direction down`，默认 X 行为保留。

## 圆脸视频：Y 变化中的体量，含 X 与表情
