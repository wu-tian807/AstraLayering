# down 完整脸型补全先验

用于 `step02_angles` 的 down 组：从 neutral 独立制作低头端点。视频里清楚的脸缘、五官和笔锋来自本角色 down 帧；这一页帮助判断整张脸型，补全被刘海、鬓发遮挡的额顶、额角、太阳穴、颊部和下颌，也帮助分辨哪些看似可见的边缘其实是头发切出来的。原模型参数与教程示例不决定本角色的实际角度。

## 低头时脸型的一般变化

- 额顶与头顶在画面中占比变大，额部被刘海遮住更多，但完整脸底的额顶仍是饱满的圆弧，通常高于刘海下沿。
- 下脸变短，下巴收向脖子，下颌在画面中可能显得更尖或更窄；两侧颊部仍是向外鼓的圆弧，最宽处大约在颧骨到眼下的高度，宽度与正面接近。
- X=0 时脸底大体左右对称。低头时鬓发和侧发常常贴着颊部垂下，会把颊缘切成直线或内凹；这类边缘多半是头发边界，按另一侧和原画正面的脸型补成圆润外凸的颊弧。
- 颊到下颌是平滑的弧，中间一般没有台阶或内凹；被遮住的颊颌连接沿两端可见段的切线延续。
- 下巴与固定脖子之间的阴影线不是脸缘；脸底覆盖脖子的范围按视频判断。

| 区域 | 低头时观察什么 |
| --- | --- |
| 额头与额顶 | 额部在低头投影中的完整体量，额顶到两侧太阳穴的连续圆弧；刘海下沿不是额顶 |
| 太阳穴与上颊 | 额头、眼外侧与两侧脸颊的连接；发束凹口、发影、耳饰和耳轮不是脸肉 |
| 脸颊、下颌与下巴 | 颊部体量怎样圆润地接到下颌渐收段；教程"低头下巴更尖"是一种画法，本角色圆颏或小尖颏看视频 |
| 下巴与固定脖子 | 低头投影下脸底覆盖脖子的范围与接触位置；脖子顶部补足与消线在 `step04_jaw-line` |

## 检查补全是否落到实际脸底

`completionCheck` 和 `completionMismatch=[]` 说明的是 SVG 预测与 trace 一致；fit 的可见残差小也只说明 visible 段贴合。fit 可能把 `occludedWeightScale` 降得很低甚至到 0，这时隐藏段几乎不受约束。所以要用 `view_nine_axis` 独显实际脸底，用整脸 crop 和放大 crop 看额顶、额角、两侧颊部是否连续圆润，露肤处是否有脸底。实际不足时，在相关脸底部件或局部 Warp 上用 fit（features 选相关段）或 `edit_nine_axis` 局部修正，然后回看已对准的可见脸缘和五官；补顶时不移动鼻嘴、下巴或脖子，也不整脸膨胀。覆盖余量按真实刘海/鬓发遮挡判断；没有头发层时只说明静态覆盖情况。

## 六模型：下俯与正面，明确脸型

![六模型下俯脸型参考]({reference:step02_angles/references/down/completion/model-face-priors.jpg})

每行从左到右：X=0/Y=0 的完整脸底、X=0/Y=−25 的完整脸底、基准脸＋五官、下俯脸＋五官。脸底栏按原生渲染 alpha 平涂，保留真实轮廓，五官栏保留原纹理。原 moc3 关键形与蒙版直接渲染，没有图像液化；关闭 motion/physics/pose/expression、自动眨眼与呼吸，视线、嘴开、身体及其他整体变换固定。每次渲染新建模型，检查实际参数值，原模型文件只读。

每个模型 Y=0/+25/−25 的脸底和五官六张图使用同一个 alpha 联合裁框，上下板共用裁框与比例；不为低头另居中或放大。这里 ±25 是原模型参数值，**不是实测物理角度，也不是本角色拟合目标**。基准关键形仍可能自带绘画倾斜。

| 模型与放大图 | 脸型 | 下俯补全适用观察 |
| --- | --- | --- |
| [Haru]({reference:step02_angles/references/down/completion/models/haru/reference.jpg}) | 稍长鹅蛋脸 | 较直颊部到下颌渐收段、圆钝尖颏的连接 |
| [Hiyori]({reference:step02_angles/references/down/completion/models/hiyori/reference.jpg}) | 圆润鹅蛋脸 | 饱满颊、小尖颏；低头仍保留圆收体量，圆脸不必挤尖 |
| [Miara]({reference:step02_angles/references/down/completion/models/miara/reference.jpg}) | 圆颊小尖颏 | 原画倾斜且脸组含装饰，只看局部颊颌连续性，不取整脸方向与装饰边界 |
| [Natori]({reference:step02_angles/references/down/completion/models/natori/reference.jpg}) | 长窄脸 | 颧颊偏直、下颌收束到小尖颏；耳轮不是脸颊外缘 |
| [Koharu]({reference:step02_angles/references/down/completion/models/koharu/reference.jpg}) | 短圆脸 | 额部、宽颊与短下脸的比例；保持圆弧下颌，不按发影改脸底形状 |
| [Haruto]({reference:step02_angles/references/down/completion/models/haruto/reference.jpg}) | 宽圆脸 | 宽颊、短下巴、扁圆底缘在下俯时的连续性 |

按本角色原画轮廓选相近脸型，说明用于哪些区域；长脸和圆脸各有自己的结构，不取平均。Miara 的耳饰、Natori 的耳轮和各模型的发影、纹理装饰不是骨肉边界。模型参考不提供本角色的五官尺度、脖子运动或角度。注意各模型低头后两侧颊部仍是圆润的外凸弧。

每个单模型目录有 `face_front.png`、`face_down.png`、`features_front.png`、`features_down.png` 原 RGBA 渲染；[来源与参数记录]({reference:step02_angles/references/down/completion/models/sources.json}) 保存原模型/贴图 SHA、六姿态参数检查、联合裁框和图像指纹。来源为仓库已有官方样例包；复用 render_faces.py 的 `--axis y` 和 build_reference_board.py 的 `--direction down`，默认 X 行为保留。
