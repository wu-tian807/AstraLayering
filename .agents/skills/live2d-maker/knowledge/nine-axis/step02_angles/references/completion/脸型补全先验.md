# left 完整脸型补全先验

本角色 left 视频帧里清楚的脸缘、五官和笔锋来自视频；这一页帮助判断整张脸型，补全被刘海、鬓发遮挡的额顶、额角、太阳穴、颊部和下颌，也帮助分辨哪些看似可见的边缘其实是头发切出来的。先看原画整体脸型，从下面的模型里选接近的形状，可以组合局部结构知识；长脸和圆脸各有结构，不取平均。

## 向左转时脸型的一般变化

- 转向一侧（画面左侧，远侧）：脸缘向内收，形成一条带起伏的轮廓线，从额角经太阳穴、眼窝外侧到颧骨，再接到下颌；它是转头最有特征的线，看视频可见段，近竖向的段落保留陡度。被头发挡住的部分沿这条线的走势自然延续。
- 近侧（画面右侧）：脸颊是一段完整饱满的外凸弧，从太阳穴鼓到颧颊最宽处再圆润地收到下颌，一般没有凹口；颊缘被发束切直或切凹时，多半是头发边界，按饱满弧补全。
- 下巴随转向偏向画面左侧，下颌线从近侧颊部平滑地斜向下巴。
- 被头发盖住的太阳穴、额角到额顶按头骨补成连续外凸的弧，从可见脸缘上端顺势接到额顶，额顶通常高于刘海下沿；眼窝至颧颊的凹凸只出现在视频看得见的那一段。
- 下巴与固定脖子的接触按本角色参考判断，示例里的脖子运动不参考。

## 已有模型：6 张不同脸型参考

真实渲染仓库已有官方样例的 moc3，用原模型关键形 X=0 与 X=-30；旧模型对应 PARAM_ANGLE_X，其余是 ParamAngleX。Y/Z、body、视线和嘴开归零，关闭默认 motion/physics/pose/expression、自动眨眼/呼吸。每个模型两姿态采用同一 alpha 联合裁框和比例，没有为左转重新居中或图像液化。X=0 指原模型基准，不保证原绘画本身没有倾斜。

前两栏按实际脸底渲染 alpha 平涂以看完整外轮廓，后两栏是原始脸＋五官渲染。原脸上的发影、同组耳轮/耳饰不是脸外缘。Miara 基准绘画带倾斜、脸组含耳饰，只看局部颊颌连续性；Natori 脸组含耳轮，判断颊线时跳过突出的耳轮。模型图不提供本角色脖子运动。
