# left 完整脸型补全先验

当前角色 left 视频帧决定所有看得见的皮肤范围、脸缘、五官和笔锋。主流程是完整脸描边 → 遮挡补全 → 自动拟合 → 实际脸底检查：source 先描本次原 KRA 的完整脸底 alpha；target 对着带头发的 left 参考描整张脸轮廓，可见脸缘准确，刘海缝间实际露出的额头和两侧额角也在这一次描边里包进脸内，未知处临时闭合；之后仅用本页先验补全未知轮廓。近侧发束凹口不能捏进脸肉，已看见的额头尖角不能被低额顶截断。目标完整轮廓受视频可见证据和原画体量约束，不能照搬其它角色。

先看原画整体脸型，再从下表选择接近的形状，解释选择理由。可组合局部结构知识，不能平均圆脸与长脸的轮廓；先验与当前视频可见部分冲突时，保留当前视频。头部中心、下巴和固定脖子的接触仍按当前角色参考核对，不能从示例复制脖子的运动。

## 刘海间露出的额头属于描边证据

描 target 时，真实可见的脸实体外缘进入 trace 的 visible 曲线；头发间露出的额头/额角皮肤是完整脸型必须包住的可见证据，但这些窗口沿发束的边界是遮挡边界，不是脸外缘，不沿它闭合。只有视频确实看不见的轮廓才使用 occluded 与本页先验，补全时在发后保留有依据的连续体量与搭接，不能为错误先验维持低额顶，也不靠统一扩张量或全脸膨胀补洞。

## 被遮住的额角是正常头骨的外凸弧

两侧被头发盖住的太阳穴、额角到额顶，按正常人类头骨补成连续外凸的弧线：从视频可见脸缘的上端顺势向外、向上接到额顶，不在额角或太阳穴处向内凹进去。眼窝至颧颊的凹凸只保留在视频确实看得见的那一段，不延伸到被遮住的上方。

## 每次主动发现可见证据

没有用户问题截图或修订反馈时，也必须从原 KRA 和当前 left 帧独立检查全部刘海/鬓发窗口、细尖角、额角和暗肤色。描整张脸时逐窗确认它们都在完整脸型内，再补全未知结构；已有反馈不能代替这项检查。

## 管线必须显示完整预测与实际结果

`face-trace.json.completion.source/target` 是整张闭合脸型；visible/occluded 分段取自这两条完整路径。source 先取完整原脸，target 先描整张脸、核对真实可见脸缘与刘海间额头，未知处的临时闭合只用于起稿。补全阶段依据这些已知证据和原画体量完成未知轮廓，以 inspect 查看无遮挡素脸双图，保存 face-completion-check.png，确认额顶/双额角、近侧体量、轮廓连续性与可见目标后自动拟合。不能沿发缘闭合一块皮肤窗口就当完整脸，也不能把皮肤窗口的遮挡边界塞成脸实体外缘。

完整预测须包含额顶中心、两侧额角、太阳穴到上颊的连续体量与连接切线，补的是刘海/鬓发后的额部，不照整个头发外轮廓扩张脸底，也不设通用头骨尺寸或扩张像素。脸底自身缺顶、额角断续或露底在本步处理；step04_jaw-line 只接续脖子顶部补足、下颌接触与阴影收尾，脖子始终保持原形、不挂头部 Warp。

`preview_svg`/`completionCheck` 展示 SVG 预测，`completionMismatch=[]` 只说明闭合 SVG 与 trace 分段一致，没有检查预测对视频皮肤窗口的包含或实际贴图 alpha。`fit_nine_axis` 的可见残差小也不证明隐藏补全完成：求解器可能逐级压低 `occludedWeightScale` 甚至到 0。必须读取报告，另用 `view_nine_axis` 的 only/grid/crop/scale 独显真实脸底，保存 face-base-left-check.png；同坐标完整图和重叠放大局部对照完整预测和原帧，检查额顶、双侧额角/太阳穴的连贯性与刘海皮肤窗口覆盖。闭合、平滑或误差小都不能解释可见皮肤处没有脸底。

预测漏掉可见额头时，先修完整预测与同步 trace，再自动拟合；不能只让实际脸底更贴住这条错误低额顶。预测合理而实际上沿不足、可见处露底时，由 agent 选择原脸底部件、现有 Warp 或必要的局部 Warp，复用 `fit_nine_axis`/`edit_nine_axis` 修正；分组、父子关系、控制范围与密度按实际需求决定，不预定联合 Warp。要重新 fit 时用 features 选择相关隐藏段和真实可见连接处，不能把隐藏段或皮肤窗口遮挡边界伪标 visible；没有适用可见曲线约束时用局部编辑后检查。每轮回查已对齐的可见脸缘、五官与正面，不用全脸膨胀、移动下巴或扭脖子填顶。

已有头发层时显示它检查；没有头发层或未知发摆范围，只能确认静态遮挡和脸底完整性，不能宣称未来头发动也不会露底，不自定发摆或新增动画。原贴图若缺所需像素，明确素材限制。

五官仍对指定 left 帧用同一次 operations 批量调整，再微调；之后独显脸底、显示五官与固定脖子，同坐标复查额顶/额角，并看本次 X 端点、零点与中间值。

最后一次编辑和五官调整后重新渲染并查看完整脸底、completion 对照、forehead-temple-check.png、hair-coverage-check.png 和过渡检查；notes 记录作者与原帧 SHA、实际图像路径、occludedWeightScale、覆盖依据与剩余差异，区分原 fit 报告和后续局部修正。不能用旧图验收新工程。本轮输出为候选，用户明确说通过前不得称流程稳定。
