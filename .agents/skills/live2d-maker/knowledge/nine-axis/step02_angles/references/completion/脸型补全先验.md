# left 完整脸型补全先验

当前角色 left 视频帧决定可见皮肤、脸缘、五官和笔锋。本页仅提供隐藏结构先验，完整脸起稿、主动逐窗观察、独立视频 mask、完整预测包含与最终实际 alpha 重检统一执行已由 initial 直接注入的[完整脸底覆盖共同规范]({shared_reference:nine-axis/完整脸底覆盖.md})。source 取原 KRA 完整脸底，target 从整张脸起稿，已看见的额头尖角不能被未知补全截断；不沿发束窗口闭合脸型。

先看原画整体脸型，再从下表选择接近的形状，解释选择理由。可组合局部结构知识，不能平均圆脸与长脸的轮廓；先验与当前视频可见部分冲突时，保留当前视频。头部中心、下巴和固定脖子的接触仍按当前角色参考核对，不能从示例复制脖子的运动。

若本任务 [continuity-reference]({uri:nine-axis/continuity-reference}) 存在，实际查看连续帧、独显脸底和 up/down/左上/左下角色图及说明（如有）。这些图仅约束本角色隐藏额部体量，并帮助诊断 left 与斜角过渡的衔接；不能平均不同角度或代替指定 left 帧的可见脸缘、五官与笔锋。全新制作的 source 必须独立来自本次原 KRA 导出的完整脸底 alpha，不复制旧 X/Y/XY 网格、参数、描线或贴图。参考图存在不代表新工程已完成这些方向；缺图或尚未集成的过渡如实说明。

## 已有模型：6 张不同脸型参考

真实渲染仓库已有官方样例的 moc3，用原模型关键形 X=0 与 X=-30；旧模型对应 PARAM_ANGLE_X，其余是 ParamAngleX。Y/Z、body、视线和嘴开归零，关闭默认 motion/physics/pose/expression、自动眨眼/呼吸。每个模型两姿态采用同一 alpha 联合裁框和比例，没有为左转重新居中或图像液化。X=0 指原模型基准，不保证原绘画本身没有倾斜。

前两栏按实际脸底渲染 alpha 平涂以看完整外轮廓，后两栏是原始脸＋五官渲染。原脸上的发影、同组耳轮/耳饰仍可能存在，它们不能被当成脸外缘。Miara 基准绘画带倾斜、脸组含耳饰，只看局部颊颌连续性；Natori 脸组含耳轮，判断颊线时跳过突出的耳轮。都不用于本角色脖子运动参考。

## left 方向核对

视频中远侧眼尾外侧到颊部的陡直趋势、眼窝至颧颊转向和笔锋是可见目标，不能被先验统一磨成大圆弧；近侧隐藏体量不按发束凹口削薄。真实显露的实体脸缘按范围进入 visible，窗口头发遮挡边界不当作实体外缘。

五官对指定 left 帧同一批次调整后微调，回查本步 X 端点、正面与中间值。若有角色连续参考，仅诊断 left 与上下斜角衔接；不修改 Y/四角，也不把旧连续参考冒充新工程已集成的结果。主动发现窗口和最后作者覆盖重检遵循共同正文，不以旧用户截图作为前提。用户明确通过前不得称流程稳定。
