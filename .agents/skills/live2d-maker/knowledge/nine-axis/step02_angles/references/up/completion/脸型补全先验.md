# up 完整脸型补全先验

用于 `step02_angles` 的 up 组：从 neutral 独立制作上抬端点。**本角色 up 视频帧决定可见脸缘、五官、笔锋与位置；本页只帮助补全视频遮挡的额头、太阳穴、脸颊和下颌。** 原模型参数和教程示例都不决定本角色的实际角度，不把别人的脸变成目标脸。

先辨认皮肤的真实外缘、头发遮挡边界和阴影边界，再描可见部分。发束围出的皮肤窗口不是完整脸型；被发梢挡住的凹口不能直接捏进脸肉。原 KRA 的完整脸底和原画脸型提供源体量，up 视频提供可见目标，先验帮助连接两者之间不可见的结构。与视频可见证据冲突时，以本角色视频为准。

## 上抬时怎样使用隐藏结构先验

| 区域 | 补全时观察什么 | 怎样限制补全 |
| --- | --- | --- |
| 额头与额顶 | 遮挡后仍有连续的额部体量，额顶接到两侧太阳穴 | 不沿刘海下缘闭合；不把整个额头填成任意大圆；投影高度由原脸体量与本角色视频限制 |
| 太阳穴与上颊 | 侧缘从额头、眼外侧连到饱满脸颊 | 保留本角色轮廓切线；发束凹口、发影和耳饰不是颊线 |
| 脸颊与下颌 | 下颌弧线如何接到两侧脸颊，底缘怎样保持角色原有的小尖颏或圆颏 | 教程示例的“抬头下巴变圆”只是一种画法；看得见的下巴与颊线必须描视频，不能一律压扁或磨圆 |
| 下巴与固定脖子 | 上抬投影下的覆盖关系、下颌与脖子顶部接触 | 脖子从开始就参与同坐标预览，保持固定、不挂头部 Warp；不拉长、不倾斜，顶部补足与消线留 `step04_jaw-line` |

完整预测应同时包含可见段和隐藏段：可见段贴着自己的视频描，隐藏段保持原画脸型与连续体量。先看无遮挡的完整预测脸，再看自动形变后真正渲染的脸底；两者都要显示整张脸。加回五官和固定脖子，检查接触与体量，避免只有露出皮肤的一小块对齐。

## 隐藏额顶必须落实到实际脸底

完整补全包括额顶中心、两侧额角和太阳穴到上颊的连续体量。按原 KRA 完整脸底、原画脸型与适用的带图先验预测遮挡段，分别检查额角与太阳穴的连接切线；不能仅用一条平滑闭合圆弧证明补全完成。补的是刘海、鬓发后属于脸的额部与太阳穴，不照全部头发外轮廓扩张脸底，也不规定通用头骨尺寸、额顶高度或扩张像素。

现有工具的证据分三层，不能混用：

- `preview_svg`、`completionCheck` 显示 SVG 预测；`completionMismatch=[]` 只说明 SVG 完整路径与 trace 分段一致，没有检查实际贴图 alpha。
- `fit_nine_axis` 的逐段残差衡量原画描线经过 Warp 后与目标对应点的差异；为保护可见约束，求解器会把 `occludedWeightScale` 逐级降低，必要时降到 0。隐藏段的有效权重还要乘这个值，原始 weight 小或可见残差小都不能证明隐藏区域已实现。
- `view_nine_axis` 显示当前工程的真实贴图和组合 Warp。必须以它独显完整脸底，用覆盖整张脸的 crop 核对额顶与两侧额角，再用重叠局部 crop、scale=4..8 放大检查实际 alpha 外缘与目标 completion 的差异。网格不翻折也不代表上沿连续、体量足够或覆盖可靠。

当 occludedWeightScale 被大幅压低，必须回看实际隐藏段。若预测已经合理而实际上沿出现凹坑、凸点、起伏、压薄或额角断续，单独解决隐藏上脸的 Warp：用 `grid` 查实际作用范围，由 agent 选择脸底部件、现有节点或按需要定义局部 Warp，再用 `edit_nine_axis` 小范围修正。需要重新自动拟合时，可用 `features` 选择相关额部/太阳穴段与真实可见连接处；工具至少需要一段可见约束，不能把隐藏点伪标 visible，也不能伪造可见连接处。局部没有适用的可见段时，使用现有局部编辑后渲染核对。节点结构与控制密度由实际需求决定；缩小 bbox 不等于其它区域必然不动，不能只加密整脸或盲目提高隐藏权重。

每轮修正后同坐标回查全部已对准的可见脸缘和五官；只修隐藏区的续修任务中，保留原参考帧、可见描边、五官和其它受保护方向的已认可姿态，不借额顶修正移动鼻嘴、下巴或固定脖子。若完整预测自身覆盖不足，回查隐藏结构依据并只修隐藏段，随后同步 SVG 与 trace；不能为了缩小实际残差而削掉本来需要的额部体量。全脸膨胀不能作为补全办法。

覆盖余量按真实刘海/鬓发遮挡和已知运动范围判断：当前需要显露或可能显露的额部、额角应有连续脸底，发缘后保留有依据的搭接，避免两层刚好相切。可只读查看原 KRA/正面与所选视频帧的发缘；若工程已有头发层，显示它检查实际覆盖。没有头发层或尚无发摆范围时，明确只能核对静态遮挡与脸底自身完整性，不能宣称未来头发动也不会露底；不要自定发摆幅度、做头发动画或改素材。原贴图若确实缺所需像素，要说明素材限制，不能用改透明度或拉伸整脸掩盖。

在端点和中间值查看真实额顶、额角及太阳穴，检查从轴到角、角间的已制作过渡；尚无四角的阶段只检查已有单轴过渡。上沿不能出现新的坑、波纹、裂口或需要皮肤覆盖处露背景。保存完整实际脸底、额顶/额角局部、completion 对照和发缘覆盖检查；最后一次局部编辑后重新检查并记录对应作者文件 SHA，区分自动 fit 报告与后续修正的实际结果，不能用旧截图验收新工程。

脸底自身的额顶/太阳穴补全与覆盖缺陷在当前步骤处理，不延后到 step04_jaw-line。step04_jaw-line 保留固定脖子顶部补足、下颌接触消线与阴影收尾。数值检查通过不能代替用户视觉验收。

## 六模型：上抬与正面，明确脸型

![六模型上抬脸型参考]({reference:step02_angles/references/up/completion/model-face-priors.jpg})

每行从左到右：X=0/Y=0 的完整脸底、X=0/Y=+25 的完整脸底、基准脸＋五官、上抬脸＋五官。前两栏只给真实渲染 alpha 平涂，后两栏保留原纹理。六模型均由原 moc3 的关键形与蒙版原生渲染，未液化图片；关闭 motion/physics/pose/expression、自动眨眼与呼吸，视线、嘴开、身体与其他整体变换固定。每次渲染新建模型，检查实际参数值，原模型文件只读。

每个模型的 Y=0/+25/−25、脸底与五官六张渲染共用一个 alpha 联合裁框；up 和 down 板因此也用同一裁框与尺度，不重新居中某个姿态。这里 ±25 是原模型参数值，**不是物理角度测量，也不是本角色拟合标准**。基准关键形不保证原画本身没有倾斜。

| 模型与放大图 | 脸型 | 上抬补全适用观察 |
| --- | --- | --- |
| [Haru]({reference:step02_angles/references/up/completion/models/haru/reference.jpg}) | 稍长鹅蛋脸 | 颊部较直，下颌渐收；看额顶到太阳穴、下颌到圆钝尖颏的连续性 |
| [Hiyori]({reference:step02_angles/references/up/completion/models/hiyori/reference.jpg}) | 圆润鹅蛋脸 | 饱满颊、小尖颏；看上抬后侧颊体量与底缘圆收如何共存 |
| [Miara]({reference:step02_angles/references/up/completion/models/miara/reference.jpg}) | 圆颊小尖颏 | 基准自带倾斜、脸组有装饰，只参考局部颊颌连续性，不抄倾斜与装饰外缘 |
| [Natori]({reference:step02_angles/references/up/completion/models/natori/reference.jpg}) | 长窄脸 | 颧颊偏直，渐收至小尖颏；脸组含耳轮，耳轮突出不等于脸颊变宽 |
| [Koharu]({reference:step02_angles/references/up/completion/models/koharu/reference.jpg}) | 短圆脸 | 宽颊、短下脸、圆弧下颌；看短下脸怎样保持连续底缘 |
| [Haruto]({reference:step02_angles/references/up/completion/models/haruto/reference.jpg}) | 宽圆脸 | 颊宽、下巴短、底缘扁圆；不把扁圆底缘强行改成小尖颏 |

按本角色原画轮廓选择接近的脸型，并说明用于哪个隐藏区域。不同脸型不能平均成一种脸；同属圆脸也不代表五官与头骨比例相同。原脸上的发影、纹理装饰、Miara 耳饰和 Natori 耳轮不能当骨肉外缘。模型图未提供本角色脖子运动依据。

每个单模型目录保留 `face_front.png`、`face_up.png`、`features_front.png`、`features_up.png` 原 RGBA 渲染；[来源与参数记录]({reference:step02_angles/references/up/completion/models/sources.json}) 包含原模型/纹理 SHA、六姿态参数检查、联合裁框与图像指纹。来源为仓库已有官方样例包；脚本复用 render_faces.py 的 `--axis y` 和 build_reference_board.py 的 `--direction up`，默认 X 行为保留。
