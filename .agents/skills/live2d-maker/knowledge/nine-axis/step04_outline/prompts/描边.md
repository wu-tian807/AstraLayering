【输入】
- 源 KRA "{document}"，合成图 "{color}"；初始工程 "{neutral}"（face_base 等脸部图层已导出）。
- 正面特写 "{source_frame}"，目标帧 "{reference_frame}"，原视频 "{reference_video}"。特写是 box.size 见方，(u,v) 对应原画布 (box.x+u,box.y+v)，box 见 "{uri:nine-axis/step02_video/crop.json}"。
- 后面的通用轮廓先验帮助分辨哪些边是真实脸缘、哪些是头发切出来的；本角色视频里清楚的证据优先。

【目标】
- source-face.svg：沿原画 face_base 的完整 alpha 描脸底，用 preview_svg 对 source-face-reference.png（face_base 放回原画布后按 box 裁出）核对。
- target-face.svg：对着目标帧描整张脸，两侧一样认真。视频里看得见的皮肤，它的边就贴着皮肤与背景、头发、阴影的交界走，走向、转折和陡度照视频；被鬓发、发束切开后露出的每一段皮肤边都照视频描；刘海、鬓发之间露出的额头、额角、脸颊皮肤都包进脸内，不漏细尖角和暗处的皮肤。
- 只有真正被头发盖住、视频里看不见的地方才临时闭合，不补形。
- SVG 是纯色闭合 path、透明背景、viewBox="0 0 box.size box.size"。

【要保护的】
看得见和被盖住要分清。描线越过皮肤伸进头发或背景的地方，要能指出那里确实是被头发盖住的脸；指不出就是描错了。
用 preview_svg 把 target-face 叠在目标帧上，blend 和 edge 都看，沿两侧脸缘、额角和下颌逐段放大 crop（scale 4..8），每段看得见的皮肤边都贴住为止。
