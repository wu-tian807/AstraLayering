
# 左上／左下完整脸型补全先验

用于 `step03_angle-xy`。目标帧由 agent 从左上、左下各自的视频中选择，选中帧里清楚的脸缘、五官和笔锋来自本角色；这一页帮助预测视频看不到的额头、太阳穴、脸颊和下颌，也帮助分辨哪些边缘是头发切出来的。

已认可的本角色 left、up、down 提供脸型、体量和过渡的参照，并且轴端点保持不变；斜向的目标仍来自斜向视频，两个角各自描边、补全和拟合，left 与 up/down 直接相加通常不等于斜向成品。模型参数 X=-30/Y=±25 只标记原模型关键形，不是物理角度，也不指定取帧时间。

## 斜向时脸型的一般变化

- 斜向是水平转面和上下俯仰的结合：远侧（画面左侧）出现眼窝到颧骨的起伏并向内收，近侧（画面右侧）是完整饱满的颊弧，下巴偏向画面左侧。
- 左上：下巴上移，下颌底缘偏平宽，近侧颊弧较完整地转到底缘；额部透视变短。左下：额顶占比变大，下巴收向脖子，近侧颊部仍是饱满外凸的弧，再渐收至下巴。
- 被头发盖住的太阳穴、额角到额顶按头骨补成连续外凸的弧，从可见脸缘上端顺势接到额顶；眼窝至颧颊的凹凸只出现在视频看得见的那一段。
- 紧贴头发、走势突然变化的颊缘多半是头发边界，可标 occluded，按相邻可信段的弧度补圆。

| 区域 | 左上观察 | 左下观察 |
| --- | --- | --- |
| 额头、额顶、太阳穴 | 额部到侧颊在上抬时的连续体量 | 遮挡增加时额部仍连到两侧太阳穴；刘海下沿不是额顶 |
| 远侧眼外侧到颊部 | 侧面转折怎样接到上抬的下颌 | 侧面转折怎样接到下俯的渐收段；视频里的竖向段、转折和笔锋保留 |
| 近侧脸颊与下颌 | 饱满颊连到投影后的底缘 | 颊部渐收至下巴，保留原脸型；头发挡住处仍有脸肉体量 |
| 下巴与固定脖子 | 下颌覆盖脖子顶部的范围 | 下俯脸底遮盖与接触位置；延长和消线在 `step04_jaw-line` |

五官目标同样取选中帧。先完成整张脸底的闭合预测，再自动拟合；五官可按整眼、整嘴等语义组批量形变后微调，分组和父子关系按本角色需要定。其它模型的五官位置帮助理解结构，"抬头更圆、低头更尖"之类是倾向而非规则。

## 检查补全是否落到实际脸底

`completionCheck` 和 `completionMismatch=[]` 说明的是 SVG 预测与 trace 一致；fit 的可见残差小也只说明 visible 段贴合。fit 可能把 `occludedWeightScale` 降得很低甚至到 0，这时隐藏段几乎不受约束。所以要用 `view_nine_axis` 独显实际脸底，用整脸 crop 和放大 crop 看额顶、额角、两侧颊部是否连续圆润，露肤处是否有脸底。实际不足时，在相关脸底部件或局部 Warp 上用 fit（features 选相关段）或 `edit_nine_axis` 局部修正，然后回看已对准的可见脸缘和五官；补顶时不移动鼻嘴、下巴或脖子，也不整脸膨胀。覆盖余量按真实刘海/鬓发遮挡判断；没有头发层时只说明静态覆盖情况。

## 描边、拟合后怎样核对

用现有 `preview_svg` 看选中视频帧的局部叠加，检查远侧眼外侧到颊部的切线和笔锋。将已核对 SVG 形成完整闭合 source/target 及 visible/occluded 分段：清楚的皮肤外缘标 visible，头发边界和拿不准的段标 occluded。先查看无遮挡完整预测，再调用现有 `fit_nine_axis` 自动求 Warp；拟合后用 `view_nine_axis` 单独看真正变形后的完整脸底，并加回五官和固定脖子同坐标对照。

两角分别核对可见轮廓与五官，再回查已认可 left/up/down 和轴到四角的过渡。数值拟合误差只说明约束贴合程度，不能代替脸型、体量和笔锋的视觉检查。结果是候选，等用户验收。
