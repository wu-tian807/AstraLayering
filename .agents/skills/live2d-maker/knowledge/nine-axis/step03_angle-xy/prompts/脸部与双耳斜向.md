【本角脸底：完整脸描边 → 遮挡补全 → 自动拟合 → 实际脸底检查】
1. 隐藏五官，打开原 KRA 导出的完整 face_base PNG。source 是原画完整 alpha 外缘，不是已变形的 left/up/down 轮廓，也不是头发围出的露肤窗口。按 textureBounds 放回原画布、再按既定 box 裁出 source-face-reference.png；仅作检查底图，不替换贴图。
2. 在所选 {corner}.png 中分清真实皮肤外缘、头发、睫毛、耳部、脖子和阴影，起稿整张 target 脸型：可见脸缘准确，刘海缝间实际露出的额头/额角（含细尖角、分离窗口和发影下的皮肤）一并包进脸内，未知处临时闭合。实际显露的脸缘标 visible，遮挡段标 occluded。重点看远侧眼尾外侧到颊部的竖向转面轮廓、近侧颊颌、下巴和下颌接触；远侧近竖向区间不能被一条跨越眼窝/颊部的大圆弧磨圆，也不整段硬拉成直线，转折处拆段分别调整端点与控制柄。发梢凹口、发影和内部线不是脸外轮廓。相邻帧只辅助辨认，目标仍是已选 PNG。
3. 复用 Part 的闭合纯色色块描边。source-face.svg 与 {corner}-target-face.svg 使用 box.size 见方、同一 viewBox、透明背景、纯色闭合 path、stroke="none"。source 用 preview_svg 的 reference=source-face-reference.png；target 每次显式 reference={corner}.png。先全图 blend，再用重叠局部 crop、scale=4..8 的 blend/edge 核对填色外缘、切线、转折和笔锋；单看细线中心、整图相似或小残差不够。
4. 描准可见段后，结合原画完整脸型、已认可 X/Y 的体量与本页先验补全隐藏额顶、太阳穴、颊部和下颌，替换临时闭合段；完整 target 保留已描的额头窗口并在发后保留有依据的搭接余量。不要把线性叠加当作正确补全，也不把发束凹口压入脸肉；按本角视频补全，不拿另一俯仰方向倒转。先独显完整闭合素脸，看远近侧体量与轮廓连续，再叠回所选帧，保证补全没有拉走可见边缘。具体脸宽、侧转起伏、额顶高度、下巴位置和尖圆按本角色视频。
5. 从两份实际核对的 SVG 的同一组路径段生成 {corner}-face-trace.json：version=1、space=view、completion={part,source,target} 为完整闭合轮廓，curves 为语义对应、方向一致的小段，标 visible/occluded。远侧眼窝到颊部、近侧颊颌、下巴、额顶分别拆段，可加少量真实对应 landmarks；不要另造与 SVG 不一致的描线。
6. 用 fit_nine_axis {action:"inspect",corner:"{corner}",trace:本角描线}，实际查看 traceCheck、completionCheck，确认 completionMismatch=[]；源与目标完整素脸、可见描线、补全段及可见额头包含性都要看。保存本角 trace-check 和 face-completion-check。
7. 自选脸底 Warp 或部件，以 action:"fit"、同一 corner/trace、id 和最新 revision 自动求当前组合关键形。工具绑定本角已选 PNG 和 X/Y，visible 优先、occluded 弱约束；不必手填大批网格坐标。看逐段残差；不准时先核对描边、对应关系和分段，再调整 Warp 范围/密度或局部子级重拟合。失败不保存。

【隐藏额顶与额角：实际补全验收】
本步完成本角从额顶中心经两侧额角、太阳穴到上颊的完整脸底与有依据的发缘搭接，不能把脸底自身的缺顶、凹坑或露底留给 step04_jaw-line。隐藏部分按原脸体量与带图先验补全，不沿刘海下缘闭合，不按全部头发外轮廓扩大脸底，不规定统一头骨尺寸或固定扩张量。
completionCheck 是 SVG 预测，completionMismatch=[] 只校 SVG 与 trace；fit 残差衡量描线约束，不是实际贴图结果。读取 occludedWeightScale：为守可见边缘它可能被压得很低甚至归零，此时独显真实脸底检查额顶、双侧额角/太阳穴，按先验页的方法对照 completion、所选帧和发缘；可见残差小、网格不翻折都不能作为补全完成。

原 KRA 或视频发缘只作遮挡依据，固定脖子始终不动。没有头发层或未定义发摆范围时，说明静态覆盖与未来动态覆盖的验证边界，不制作额外头发动画。用 {corner} 前缀保存 forehead-temple-check.png 与 hair-coverage-check.png，notes 记录对应作者 SHA、occludedWeightScale 和剩余差异；不能拿编辑前 fit 报告或旧图验收新工程。
