【{corner}：斜向】
用原 KRA 的绘画加网格形变，做出本角色视频里 {corner} 的样子：(X,Y)=({target_x},{target_y})，关键形键 "{corner_key}"，作者文件 "{author_file}"。本会话只做这一角，另一角由独立会话并行制作；程序合并两角，右侧由程序镜像。贴图保持原画。

【输入】
- 上游工程与贴图 "{uri:nine-axis/step02_angles/deformers.json}" 及 layers/，已完成并认可的 left、up、down 保持不动。起始形 "{linear}" 是三个单轴的组合，只是起点，不是目标。
- 原正面 "{uri:nine-axis/step01_video/upper-body.png}"，单轴参考 "{uri:nine-axis/step01_video/left.png}"、"{uri:nine-axis/step01_video/up.png}"、"{uri:nine-axis/step01_video/down.png}"；box 见 "{uri:nine-axis/step01_video/crop.json}"，特写 (u,v) 对应原画布 (box.x+u,box.y+v)。
- 本角原视频 "{reference_video}"（来源见本目录 videos.json）。
- 参考头型：原画正面的脸型为主，后面的通用轮廓先验和斜向脸型先验。

【0. 选帧】
用 ffmpeg 从原视频取多帧，用 view_bitmap 看完整运动，在合适处加密比较。选一张侧转幅度接近 left、俯仰接近对应 up/down、五官清楚的帧，按画面判断，不按固定时间。视频不是向画面左侧转面、或有滚转、推近、叠影而没有合适帧时返回 error 说明。
- 原帧保存为 frames/{corner}.png；等比规范化到 box.size 见方（可用 nine-axis/turn.ts 的 normalizeView）保存为 {corner}.png，不另裁切、旋转或平移。
- selected-frames.json：version:1，frames 对象只有键 {corner}，记录 video、path、frameIndex（从0起）和/或 timeSeconds、videoSha256、sha256、reason。

然后 edit_nine_axis {} 建立本角的 face-xy.json，用 view_nine_axis 看本角起始形。只编辑本角关键形，新建的 Warp 只在本角形变；axisSources 不改写。自定义左右配对用 mirror_pair 或完整 left/right 命名。

【1. 照着视频描边】这是整个方向最关键的一步，后面的补全和形变都照着它走，描不准后面就跟着错。
- source-face.svg：沿原 KRA face_base 的完整 alpha 描脸底（不是已变形的单轴结果），用 preview_svg 对 source-face-reference.png（face_base 放回原画布后按 box 裁出）核对。
- {corner}-target-face.svg：对着 {corner}.png 描整张脸，两侧都一样认真。凡是视频里看得见的皮肤，它的边就照视频描准，贴着皮肤与背景、头发、阴影的交界走。
  - 转向一侧（画面左侧）：从额角、太阳穴经眼窝外侧、颧骨到下颌那条带起伏的线，走向、转折和陡度照视频描。
  - 另一侧（画面右侧）：脸颊、眼角外侧、下颌被鬓发和发束切开，露出来的每一段皮肤边都照视频描，不要因为旁边有头发就整段交给补全。
  - 下巴和下颌底缘照视频描，带出本角的抬头或低头。
  - 刘海、鬓发之间露出的每一块额头、额角、脸颊皮肤都包进脸内，不漏细尖角和暗处的皮肤。
- 只有真正被头发盖住、视频里看不见的地方才临时闭合，留给补全。
- SVG 是纯色闭合 path、透明背景、viewBox="0 0 box.size box.size"。preview_svg 检查 target 时显式给 reference={corner}.png。

自检：用 preview_svg 把 target-face 叠在 {corner}.png 上，blend 和 edge 都看，并沿两侧脸缘、额角和下巴逐段放大 crop（scale 4..8）。
- 每段看得见的皮肤边，描线都应贴在上面。
- 描线越过皮肤伸进头发或背景的地方，要能指出那里确实是被头发盖住的脸；指不出就是描错了，改到贴住为止。
- 写 trace 时也按这个来：贴着可见皮肤边的段标 visible，不能把看得见的段标成 occluded。

【2. 补全：给头发运动垫底】
补全是为了给头发运动垫底：被头发盖住的地方，脸底要一直延伸到头发后面足够深，头发晃动、飘起时下面不会露出空白或缝隙；不要沿头发内侧的发缘收边。同时补出来的部分要贴合已有的脸部轮廓：接着第 1 步描准的线和原画正面的脸型走，是同一张脸自然的延续（额顶、额角到太阳穴是头骨的圆弧，近侧脸颊饱满，转向一侧的起伏接着视频描出的线走，脸型体量与已认可的 left、up/down 一致），曲率顺滑，不鼓包、不折角。第 1 步描准的线原样保留。
补全按"补一版、review、改进"来做：先按正面脸型、通用先验和斜向先验，并对照已认可的 left、up/down 补出一版；再 review：用 preview_svg 把它叠在 {corner}.png 上，也独显完整的脸，看头发后面垫得够不够深、哪里头发一动就会露缝，看补出来的线和已有脸部轮廓贴不贴、接得顺不顺，像不像这个角色转到这一角的完整脑袋。有问题就改，改完再 review，直到这几点都满足。
然后写 {corner}-face-trace.json（version=1、space=view、completion={part,source,target} 是完整闭合 path，curves 是对应小段：看得清的标 visible，补出来的标 occluded），用 fit_nine_axis action=inspect、corner:"{corner}" 检查。

【3. 应用形变】
建脸底 Warp，用 fit_nine_axis action=fit、corner:"{corner}" 自动求形变。

【4. 微调形变】
用 view_nine_axis 在本角 X/Y、only=["face/face_base"] 看实际变形后的脸底，和补全的脸、{corner}.png 对照。补出来的部分 fit 可能没拉到位，没贴住的地方、边缘有碎裂或抖动台阶的地方，用 fit（features 选相关段）或 edit_nine_axis 局部修。

【5. 对着视频调整五官】
显示五官，对着 {corner}.png 用 edit_nine_axis 批量调眉眼、鼻、嘴、腮红的形状和位置，再预览微调。最后看完整的脸、五官和脖子，从 left、对应 up/down 到本角的过渡，以及程序镜像后的右侧对应角；单轴端点保持不变。脖子保持不动，接触收尾在 step04。

【交付，"{output}"】
face-xy.json、selected-frames.json、{corner}.png、frames/{corner}.png、source-face.svg、{corner}-target-face.svg、{corner}-face-trace.json（{corner}-fit-report.json 由工具写出），以及简短的 notes.md：选帧依据、选用的头型、哪些段是补的、剩余偏差。完成返回 {"error":null}，做不了时 error 写原因。
