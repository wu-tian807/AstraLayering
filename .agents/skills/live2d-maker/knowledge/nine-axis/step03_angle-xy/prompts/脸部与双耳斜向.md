【left-up 与 left-down：斜向】
用原 KRA 的绘画加网格形变，做出本角色视频里两个左侧斜角的样子：left-up (X,Y)=({left_angle},{up_angle})，关键形键 "{left_up}"；left-down ({left_angle},{down_angle})，关键形键 "{left_down}"。两角在同一份作者文件 face-xy.json 里，先完整做完 left-up，再做 left-down；做第二角时保住已完成的第一角。右侧由程序镜像。贴图保持原画。下文的 <corner> 指当前正在做的那一角（left-up 或 left-down），文件名照此替换。

【输入】
- 上游工程与贴图 "{uri:nine-axis/step02_angles/deformers.json}" 及 layers/，已完成并认可的 left、up、down 保持不动。起始形 "{uri:nine-axis/step03_angle-xy/linear.json}" 是三个单轴的组合，只是起点，不是目标。
- 原正面 "{uri:nine-axis/step01_video/upper-body.png}"，单轴参考 "{uri:nine-axis/step01_video/left.png}"、"{uri:nine-axis/step01_video/up.png}"、"{uri:nine-axis/step01_video/down.png}"；box 见 "{uri:nine-axis/step01_video/crop.json}"，特写 (u,v) 对应原画布 (box.x+u,box.y+v)。
- 两角原视频 "{uri:nine-axis/step03_angle-xy/left-up.mp4}"、"{uri:nine-axis/step03_angle-xy/left-down.mp4}"（来源见本目录 videos.json）。
- 可见的脸缘以视频为准；后面的通用轮廓先验和斜向先验帮助分辨哪些边是真实脸缘、哪些是头发切出来的。

【0. 选帧】
每角各自从对应视频选帧。用 ffmpeg 从原视频取多帧，用 view_bitmap 看完整运动，在合适处加密比较。选一张侧转幅度接近 left、俯仰接近对应 up/down、五官清楚的帧，按画面判断，不按固定时间。视频不是向画面左侧转面、或有滚转、推近、叠影而没有合适帧时返回 error 说明。
- 原帧保存为 frames/<corner>.png；等比规范化到 box.size 见方（可用 nine-axis/turn.ts 的 normalizeView）保存为 <corner>.png，不另裁切、旋转或平移。
- selected-frames.json：version:1，frames 对象有 left-up、left-down 两个键，每项记录 video、path（指向规范化后的 <corner>.png，不是 frames/ 下的原帧）、frameIndex（从0起）和/或 timeSeconds、reason。

然后 edit_nine_axis {} 建立 face-xy.json，用 view_nine_axis 看两角起始形。只编辑两个左侧斜角的关键形，axisSources 不改写。自定义左右配对用 mirror_pair 或完整 left/right 命名。

【1. 照着视频描边】这是整个方向最关键的一步，后面的补全和形变都照着它走，描不准后面就跟着错。
- source-face.svg（两角共用，做一次）：沿原 KRA face_base 的完整 alpha 描脸底（不是已变形的单轴结果），用 preview_svg 对 source-face-reference.png（face_base 放回原画布后按 box 裁出）核对。
- <corner>-target-face.svg：对着 <corner>.png 描整张脸，两侧都一样认真。凡是视频里看得见的皮肤，它的边就照视频描准，贴着皮肤与背景、头发、阴影的交界走。
  - 转向一侧（画面左侧）：从额角、太阳穴经眼窝外侧、颧骨到下颌那条带起伏的线，走向、转折和陡度照视频描。
  - 另一侧（画面右侧）：脸颊、眼角外侧、下颌被鬓发和发束切开，露出来的每一段皮肤边都照视频描，不要因为旁边有头发就整段交给补全。
  - 下巴和下颌底缘照视频描，带出本角的抬头或低头。
  - 刘海、鬓发之间露出的每一块额头、额角、脸颊皮肤都包进脸内，不漏细尖角和暗处的皮肤。
- 只有真正被头发盖住、视频里看不见的地方才临时闭合，留给补全。
- SVG 是纯色闭合 path、透明背景、viewBox="0 0 box.size box.size"。preview_svg 检查 target 时显式给 reference=<corner>.png。

自检：用 preview_svg 把 target-face 叠在 <corner>.png 上，blend 和 edge 都看，并沿两侧脸缘、额角和下巴逐段放大 crop（scale 4..8）。
- 每段看得见的皮肤边，描线都应贴在上面。
- 描线越过皮肤伸进头发或背景的地方，要能指出那里确实是被头发盖住的脸；指不出就是描错了，改到贴住为止。
- 写 trace 时也按这个来：贴着可见皮肤边的段标 visible，不能把看得见的段标成 occluded。

【2. 补全：给头发运动垫底】
被头发盖住、看不见的部分不追求某种脸型，判断标准是：
- 和第 1 步描准的可见线连续相接，整条外缘顺滑干净，没有尖角、折角或缺口；第 1 步的线原样保留，可见部分仍贴合视频。
- 每一条盖住脸的头发边下面，脸底都延伸得足够深：头发晃动、飘起、发梢移开一段时，露出来的仍是皮肤，不露背景或缝隙。刚好盖住可见发缘是不够的，不要沿头发内侧的发缘收边；额角、刘海与鬓发交界这类发缘离脸缘很近的地方尤其要留足。
补全按"补一版、review、改进"来做：补出一版后用 preview_svg 叠在 <corner>.png 上，沿每条头发边逐段放大看：头发往外动一些，下面还是不是皮肤；补出来的线和可见线接得顺不顺。有问题就改，改完再 review，直到都满足。
然后写 <corner>-face-trace.json（version=1、space=view、completion={part,source,target} 是完整闭合 path，curves 是对应小段：看得清的标 visible，补出来的标 occluded），用 fit_nine_axis action=inspect、corner:"<corner>" 检查。

【3. 应用形变】
建脸底 Warp，用 fit_nine_axis action=fit、corner:"<corner>" 自动求形变。

【4. 微调形变】
用 view_nine_axis 在本角 X/Y、only=["face/face_base"] 看实际变形后的脸底，和补全的脸、<corner>.png 对照。补出来的部分 fit 可能没拉到位，没贴住的地方、边缘有碎裂或抖动台阶的地方，用 fit（features 选相关段）或 edit_nine_axis 局部修。

【5. 对着视频调整五官】
显示五官，对着 <corner>.png 用 edit_nine_axis 批量调眉眼、鼻、嘴、腮红的形状和位置，再预览微调。五官始终是同一个人的五官：每个部件自身的大小、形状、内部结构，以及部件之间的距离和相对位置，都只随转头的透视变化，和正面原画、视频帧一致，不因网格拉扯变大变小、走形或错位。这是本步的验收标准，逐个部件和正面原画、视频帧对照，发现不一致就改。最后看完整的脸、五官和脖子，从 left、对应 up/down 到本角的过渡，以及程序镜像后的右侧对应角；单轴端点保持不变。做完 left-down 后再回看 left-up 和两角之间的中间值，确认第一角没被带偏。脖子保持不动，接触收尾在 step04。

【交付，"{uri:nine-axis/step03_angle-xy}"】
face-xy.json、selected-frames.json、source-face.svg，以及每角的 <corner>.png、frames/<corner>.png、<corner>-target-face.svg、<corner>-face-trace.json（<corner>-fit-report.json 由工具写出），以及简短的 notes.md：每角的选帧依据、哪些段是补的、头发下留的余量、剩余偏差。完成返回 {"error":null}，做不了时 error 写原因。
