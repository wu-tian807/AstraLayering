【任务】
做 left 方向的脸部＋双耳透视形变：把角色的脸（脸部组下的脸底、五官与双耳图层，不含头发、头饰）做成向左转头的 warp 变形器，关键形为 ParamAngleX = −30，形状对齐 step01 画出的向左视角 left.png（头部向画面左侧转约 45°；−30 是参数值，不是度数）。向右（+30）由程序镜像得到，不用做。只做变形，不补绘、不改图层像素。

【输入】（只读）
- 源 KRA："{document}"；同画布合成 PNG："{color}"。
- 正面头部特写："{uri:nine-axis/step01_views/upper-body.png}"；向左视角："{uri:nine-axis/step01_views/left.png}"。两张都是 box.size 见方，与画布 1:1，像素 (u,v) 对应画布 (box.x+u, box.y+v)；box 见 "{uri:nine-axis/step01_views/crop.json}"。
- left.png 是生图结果，只作形状目标；其画法细节与原图层不同，不拿它的像素替换图层。

【做法】
沿用 pink-doll 的拟合方法，在本步 workspace 里自己写脚本完成（Python 的 numpy、scipy、opencv、torch；缺的库用 uv 装在 workspace 内）。下面给出流程与参考参数；肤色与头发蒙版、可见轮廓段、轴线、权重、ROI、远近侧耳与耳根点都要看本角色的图来定。每一步的中间结果都渲染成图看过再往下走，不合适就调参或改代码，不能跑通即交付。
1. 导出图层：用 krita 工具从 KRA 导出脸部组下每个图层的可见效果（含所在组的透明度蒙版）为同画布透明 PNG。部件 id 取图层名中的部件路径，如 face/face_base、face/eye_left/iris。
2. 五官定位：左右眼、左右眉、嘴、鼻各取正面合成上的范围作模板，在 left.png 中做多尺度模板匹配（横向 0.6–1.15、纵向 0.95–1.05，TM_CCOEFF_NORMED），得到各五官在目标图中的位置与横向缩放。匹配分数低或位置明显不对的五官降权或剔除，不硬套。
3. 父级（整体转向与脸型），后向场（目标→原图）= 圆柱转向 + 平滑残差：
   - 圆柱：x' = C + tx + R·sin(asin((x−C)/R) − θ)，C 为脸部中轴列。用 least_squares 拟合 R、θ、tx，使五官 x 位置吻合，并以权重 40 约束左右眼的横向缩放（cos(φ−θ)/cos φ）。纵向偏移取五官位移的平均。
   - 残差：脸部框上的 10×10 双三次网格（torch grid_sample），Adam lr 0.3，迭代 400 次。损失项：
     - left.png 中脸部可见的真实外轮廓（下颌、脸颊）内侧 3px 采到的脸底 alpha 为 1、外侧 3px 为 0。轮廓由肤色区域的外轮廓求得，先扣除线稿与头发，与头发相接处两端各裁掉约 20 个轮廓点。
     - 目标肤色区域内，脸底 alpha 覆盖（权重 0.3）。
     - 网格平滑 5e-3。
     - 被头发遮住的轮廓（额头、鬓角）不约束，由圆柱与平滑延续；不要让覆盖损失把额头拉高、拉成尖楔，也不要把下巴收窄。
   - 渲染只用父级变形的脸底与五官，叠在 left.png 上看：脸型轮廓是否贴合可见的脸颊与下颌，五官大致位置是否对上。
4. 子级（按教程结构）：在父级之上，眉眼（有腮红时并入）一个 6×4 网格、嘴 4×4、鼻 3×3。
   - 各组在本组 ROI 内拟合，ROI 为本组范围外扩 15% 再加 10px，并扣除头发。
   - 损失为多尺度（4、2、1）L1 颜色差，加 2 倍的边缘（横纵梯度）差；网格平滑 2e-3。Adam lr 0.4，300 次。
   - 脸底只用父级（含残差）；五官用父级加本组子级。
   - 子级只补细节：拟合后对照【教程先验】检查，子级把五官拉出父级形状太多时加大平滑或缩小 ROI。
5. 耳朵：没有耳朵图层（如被头发完全遮住）时跳过本项，照常交付。不拟合 left.png 中的耳朵像素，不进残差、覆盖和颜色损失；每只耳朵整体刚性移动，只做平移和横向缩放，形状不扭曲。−30 时：
   - 近侧耳（画面右侧，朝向观众）：取耳朵贴脸一侧、与脸底轮廓相接处的耳根点，按父级在该点的位移平移，横向缩放取父级在该点的横向缩放。耳根始终贴在变形后的脸缘上，不留缝，也不插进脸里。不要按头侧角度单独转近侧耳：脸缘在正面时并不在头侧 90°，转向时它比头侧移得多，单独转耳朵会让耳朵离开脸。
   - 远侧耳（画面左侧，转离观众）：耳朵长在头侧，按圆柱上头侧的角度（约 −90°）转过 θ，整体移到脑后，不压扁、不扭曲；在部件顺序中排在脸底之下，由脸遮挡，不用透明度隐藏。露出多少看渲染与 left.png 对照。
   - 渲染耳朵与脸底放大看：近侧耳根与脸缘相接，远侧耳被脸挡住。
6. 导出：每个图层一个 16×16 warp。
   - 控制网格是该层不透明像素外扩 8px 的范围（bbox）上的规则网格；keyform "0" 即此规则网格。
   - "-30" 是每个控制点经前向变形后的位置，用牛顿法反解后向场（父级＋本组子级）求得；反解不收敛或网格折叠时要查出原因，不交付折叠的网格。
   - 坐标均为原画布像素。
   - 用交付的关键形重新渲染（不是用拟合时的场），确认与拟合结果一致。

【教程先验】
拟合后逐项对照检查，不合适时调整拟合（加权、ROI、约束），不手填轮廓点或控制点。
- 转面一侧的脸型有三凹三凸：眉毛和腮红处在凸上，眼睛处在凹里。它应从可见轮廓的拟合中自然得到。
- 眉毛、腮红外凸，眼睛内凹，但不能把眼睛形状凹没；瞳孔的分割点保持横平竖直。
- 透视不可无，也绝不能过。眉眼的上半部分透视明显，下半部分几乎没有；嘴相反，下半部分透视较明显。
- 鼻子在 X 方向主要是位置偏移；鼻子、嘴、下巴连成一条线。
- 耳朵不做细节调整：近侧耳贴着脸缘随动、不变形，远侧耳转到脑后被脸遮住。
- 大造型小细节：父级决定位置、造型和透视，子级只补父级做不到的细节。做一个五官时，注意它与其他五官和脸型的关系。
