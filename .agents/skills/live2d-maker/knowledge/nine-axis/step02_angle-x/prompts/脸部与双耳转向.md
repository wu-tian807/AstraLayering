【任务】
做 left 方向的脸部＋双耳透视形变：把角色的脸（脸部组下的脸底、五官与双耳图层，不含头发、头饰）做成向左转头的 warp 变形器，关键形为 ParamAngleX = −30，形状对齐 step01 画出的向左视角 left.png（头部向画面左侧转约 45°；−30 是参数值，不是度数）。向右（+30）由程序镜像得到，不用做。只做变形，不补绘、不改图层像素。

【输入】（只读）
- 源 KRA："{document}"；同画布合成 PNG："{color}"。
- 正面头部特写："{uri:nine-axis/step01_views/upper-body.png}"；向左视角："{uri:nine-axis/step01_views/left.png}"。两张都是 box.size 见方，与画布 1:1，像素 (u,v) 对应画布 (box.x+u, box.y+v)；box 见 "{uri:nine-axis/step01_views/crop.json}"。
- left.png 是生图结果，只作形状目标；其画法细节与原图层不同，不拿它的像素替换图层。
- 教程纯脸模版（Live2D 教程里同一张不带头发的脸，向左转约 45° 前后，带变形网格；不是本角色）：正面 "{reference:step02_angle-x/references/tutorial/front.png}"，转向后的脸底 "{reference:step02_angle-x/references/tutorial/left-face-base.png}"，转向后带五官 "{reference:step02_angle-x/references/tutorial/left-face.png}"；脸底变形器的网格：正面 "{reference:step02_angle-x/references/tutorial/front-grid.png}"，转向后 "{reference:step02_angle-x/references/tutorial/left-grid.png}"。它示范一张纯脸怎么转：转面一侧（画面左）出三凹三凸；近侧（画面右）和头顶仍是一整条干净、顺滑外凸的轮廓，转向只是把它整体移过去、舒展开，不在上面推出起伏。看网格：头转过去，头的整体大小几乎不变——宽度、头顶的圆顶都还在；转向主要靠上下拉，不是左右推：以脸的上下中部为界，画面右边（近侧）上下两头都往外拉长——下半往下拉、额头那一角往上抬；左边（远侧）上下两头都往中间收短——下颌往上提、额角往下压。网格成了透视的梯形（近大远小），不是平行四边形：下半张脸的横线左高右低，额头的横线反过来左低右高，中间那条横线基本是平的；下巴和远侧下颌被提上去，近侧下颌落下来。整张脸不能像歪头（绕前后轴转）那样整体斜过去，竖着的中线仍大致是竖的；这股上下拉是越往网格外圈越明显，落在头本身上只是轻轻的：教程里网格外圈斜得厉害，头顶的圆顶却几乎还是平的、圆的，下巴还是原来那个尖，脸的轮廓是一条完整的线，没有被拉成斜坡、平台或缺口；中线和下巴随之移向画面左侧，近侧的弧往外舒展。把整张脸整体往左平移、压窄，就不是转头。脸是贴在头上的，转头不能把整个头压窄。left.png 里被头发挡住的地方，就照这个模版的样子走。

【做法】
像画师照着模版画转头：在本步 workspace 里自己写脚本做变形（Python 的 numpy、scipy、opencv、torch；缺的库用 uv 装在 workspace 内），脚本是画笔，好坏靠自己看。每改一次就渲染出图，用 view_bitmap 放大看，看出哪里不像 left.png 就改哪里，再渲染再看，直到转过去的脸看起来就是 left.png 那张脸。
- 不在脚本里写形状的判定或断言（宽度、距离、比例是否达标），也不以损失收敛、数值达标当作做好了；数值只用来找问题出在哪。
- 每轮都看这三张：
  - 叠线稿：left.png 的线稿用一种颜色、渲染结果的线稿用另一种颜色叠在一起，重合处一眼可见；
  - 不叠头发的脸单独放大，和 left.png、教程的 left-face.png 并排：它本身要是一张照模版转过去的人脸，被头发遮住的部分要像教程那张纯脸一样干净；
  - 渲染结果半透明叠在 left.png 上。

1. 导出图层：用 krita 工具从 KRA 导出脸部组下每个图层的可见效果（含所在组的透明度蒙版）为同画布透明 PNG。部件 id 取图层名中的部件路径，如 face/face_base、face/eye_left/iris。
2. 先看清两张图：放大 upper-body.png 和 left.png，看哪些脸缘真的露出来（紧挨背景、脖子或脸后面的头发），哪些是被刘海、垂在脸前的发束截断的假边。转面一侧从眉骨经眼角、颧骨到下巴的侧脸通常整段都露出来。
3. 先把整个头转过去，解决看不见的地方。照教程网格的做法：整体变形决定头型，头的整体大小基本保持，先做近侧上下拉长、远侧上下收短的纵向透视，再让中线和五官移过去；不要拿 left.png 里被头发截剩的那一窄条脸去定头的宽度。左右眼、眉、嘴、鼻在 left.png 中做模板匹配，得到各自的位置和横向压缩；用“头是一个转动的圆柱”拟合转角，作为整体变形（后向场：目标→原图）；圆柱只管横向，纵向那一下（近侧以脸的上下中部为界向两头拉长、远侧向中间收短）要一起放进整体变形里；不要写成右边整体往下、左边整体往上的斜切，那样上下都往同一方向倾斜，看起来是歪头。把自己的整张网格画出来，和 left-grid.png 并排看：是不是一个近大远小的梯形、额头和下巴的横线是不是往相反方向倾。再单看不叠头发的脸本身：圆顶、下巴尖和整条轮廓是不是还和原来一样好看，只是转了过去；如果头顶歪成一条斜线、下巴变成平台，就是拉过头了。被头发遮住的额头、鬓角、近侧脸颊就由它带着走，顺着模版的头型，不另外推；近侧轮廓对照教程 left-face-base.png，是一条完整顺滑的弧。看叠图：五官大致位置要对上；不叠头发的脸和教程 left-grid.png 并排，头型的大小、圆顶和透视要像模版，而不是变成一条窄蛋形。
4. 再液化看得见的地方：在圆柱之上加一层平滑位移，把转面一侧脸底的轮廓推到 left.png 真实露出的脸缘上，侧脸的三凹三凸由这段脸缘得来；假边不推。近侧轮廓不液化，保持原画那样干净的边。看叠线稿和单独的脸，常见的问题：
   - 把头发截断的边当成了脸缘，脸被拉出凹口：剔掉那一段；
   - 液化太软，网格折叠出钩形、鼓包或尖楔：调硬；
   - 近侧被推出波浪、锯齿、直边、折角，或超出模版的头部剪影：近侧不该被推，回到圆柱带着走，对照教程模版看它是不是一条顺滑的弧。
5. 五官（按教程结构）：在整体变形之上，眉眼（有腮红时并入）一个 6×4 网格、嘴 4×4、鼻 3×3，各自在本组周围拟合到 left.png 中的五官。睫毛、眼线、上眼睑和眉毛颜色深，别当成头发扣掉；只扣真正压在五官上的发丝。看叠线稿：眼、眉、嘴的线和 left.png 重合；脸底只用整体变形，五官用整体加本组。
6. 耳朵：没有耳朵图层（如被头发完全遮住）时跳过本项，照常交付。不拟合 left.png 中的耳朵像素；每只耳朵整体刚性移动，只做平移和横向缩放，形状不扭曲。−30 时：
   - 近侧耳（画面右侧，朝向观众）：取耳朵贴脸一侧、与脸底轮廓相接处的耳根点，按整体变形在该点的位移平移，横向缩放取该点的横向缩放。耳根始终贴在变形后的脸缘上，不留缝，也不插进脸里。不要按头侧角度单独转近侧耳：脸缘在正面时并不在头侧 90°，转向时它比头侧移得多，单独转耳朵会让耳朵离开脸。
   - 远侧耳（画面左侧，转离观众）：耳朵长在头侧，按圆柱上头侧的角度（约 −90°）转过同样的角度，整体移到脑后，不压扁、不扭曲；在部件顺序中排在脸底之下，由脸遮挡，不用透明度隐藏。露出多少看渲染与 left.png 对照。
   - 渲染耳朵与脸底放大看：近侧耳根与脸缘相接，远侧耳被脸挡住。
7. 导出：每个图层一个 16×16 warp。
   - 控制网格是该层不透明像素外扩 8px 的范围（bbox）上的规则网格；keyform "0" 即此规则网格。
   - "-30" 是每个控制点经前向变形后的位置，用牛顿法反解后向场（整体＋本组五官）求得；反解不收敛或网格折叠时要查出原因，不交付折叠的网格。
   - 坐标均为原画布像素。
   - 用交付的关键形重新渲染（不是用拟合时的场），看它与拟合时的渲染一致。

【教程先验】
这些是画的时候眼睛要看的地方，不写成脚本里的判定。看出不对时回去改变形，不手填轮廓点或控制点。
- 转向后的脸看起来就是 left.png 里那张脸。
- 转面一侧的脸型有三凹三凸：眉毛和腮红处在凸上，眼睛处在凹里。侧脸成了直线或一条光滑弧线，就是没推到那段真实脸缘。
- 近侧不出三凹三凸：45° 转向不破坏这一侧的边界，它仍是一条完整顺滑的外凸弧，见教程模版。
- 眉毛、腮红外凸，眼睛内凹，但不能把眼睛形状凹没；瞳孔的分割线保持横平竖直。
- 透视不可无，也绝不能过。眉眼的上半部分透视明显，下半部分几乎没有；嘴相反，下半部分透视较明显。
- 鼻子在 X 方向主要是位置偏移；鼻子、嘴、下巴连成一条线。
- 耳朵不做细节调整：近侧耳贴着脸缘随动、不变形，远侧耳转到脑后被脸遮住。
- 脸对头型的影响不能太大：转向时头型大小几乎不变，透视来自近侧上下拉长、远侧上下收短，以及中线、五官的移动；只把整个头往左平移或压窄、或者把整张脸斜切成歪头，都是做错了。近侧脸颊也不要额外鼓出包。这一阶段不用对脸做过多微调。
- 大造型小细节：整体变形决定位置、造型和透视，五官只补整体做不到的细节。做一个五官时，注意它与其他五官和脸型的关系。
