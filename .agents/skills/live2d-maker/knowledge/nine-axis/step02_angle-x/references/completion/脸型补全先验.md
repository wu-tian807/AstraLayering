# left 完整脸型补全先验

当前角色 left 视频帧决定所有看得见的脸缘、五官和笔锋。本页只帮助预测被头发挡住的脸底；先辨认真实脸外缘与皮肤/头发遮挡边界，再把遮挡区域补成完整连续的脸。近侧眼旁的发束凹口不能捏进脸肉。源轮廓取原 KRA 脸底，目标完整轮廓用可见证据和原画体量约束，不能照搬其它角色。

先看原画整体脸型，再从下表选择接近的形状，解释选择理由。可组合局部结构知识，不能平均圆脸与长脸的轮廓；先验与当前视频可见部分冲突时，保留当前视频。头部中心、下巴和固定脖子的接触仍按当前角色参考核对，不能从示例复制脖子的运动。

若本任务 [continuity-reference]({uri:nine-axis/continuity-reference}) 存在，实际查看连续帧、独显脸底和 up/down/左上/左下角色图及说明（如有）。这些图仅约束本角色隐藏额部体量，并帮助诊断 left 与斜角过渡的衔接；不能平均不同角度或代替指定 left 帧的可见脸缘、五官与笔锋。全新制作的 source 必须独立来自本次原 KRA 导出的完整脸底 alpha，不复制旧 X/Y/XY 网格、参数、描线或贴图。参考图存在不代表新工程已完成这些方向；缺图或尚未集成的过渡如实说明。

## 管线必须显示完整预测与实际结果

`face-trace.json.completion.source/target` 是整张闭合脸型；visible/occluded 分段取自这两条完整路径。先 inspect 并实际查看无遮挡素脸双图，保存 face-completion-check.png，确认近侧体量、轮廓连续性与可见目标再自动拟合。不能沿发缘闭合一块皮肤窗口就当完整脸。

完整预测须包含额顶中心、两侧额角、太阳穴到上颊的连续体量与连接切线，补的是刘海/鬓发后的额部，不照整个头发外轮廓扩张脸底，也不设通用头骨尺寸或扩张像素。脸底自身缺顶、额角断续或露底在本步处理；step07 只接续脖子顶部补足、下颌接触与阴影收尾，脖子始终保持原形、不挂头部 Warp。

`preview_svg`/`completionCheck` 展示 SVG 预测，`completionMismatch=[]` 只说明闭合 SVG 与 trace 分段一致，没有检查实际贴图 alpha。`fit_nine_axis` 的可见残差小也不证明隐藏补全完成：求解器可能逐级压低 `occludedWeightScale` 甚至到 0。必须读取报告并另用 `view_nine_axis` 的 only/grid/crop/scale 独显真实脸底，保存 face-base-left-check.png，以同坐标完整图和重叠放大局部对照 completion，检查额顶、双侧额角/太阳穴是否缺顶、凹陷、起伏、压薄、断续或露背景。

预测合理而实际隐藏上沿不足时，由 agent 选择原脸底部件、现有 Warp 或必要的局部 Warp，复用 `edit_nine_axis` 修正；分组、父子关系、控制范围与密度按实际需求决定，不预定联合 Warp。要重新 fit 时用 features 选择相关隐藏段和真实可见连接处，不能把隐藏段伪标 visible；没有适用可见约束时用局部编辑后检查。每轮回查全部已对齐的可见脸缘、五官与正面，不用全脸膨胀、移动下巴或扭脖子填顶；预测本身不足则修隐藏 SVG 并同步 trace。

覆盖余量按原 KRA、当前 left 帧及可选连续参考中真实刘海/鬓发遮挡判断：额部、额角应有连续脸底，发缘后保留有依据的搭接，避免刚好相切。已有头发层时显示它检查；没有头发层或未知发摆范围，只能确认静态遮挡和脸底完整性，不能宣称未来头发动也不会露底，不自定发摆或新增动画。原贴图若缺所需像素，明确素材限制。

五官仍对指定 left 帧用同一次 operations 批量调整，再微调；之后独显脸底、显示五官与固定脖子，同坐标复查额顶/额角及覆盖，并看本次 X 端点、零点与中间值。若有连续参考，重点诊断 X=left、Y 正值→0→负值在零点两侧的体量与线条；本步不修改 Y/四角，不把旧参考的连续图冒充新工程集成后的结果。

最后一次编辑后重新渲染并查看完整脸底、completion 对照、forehead-temple-check.png、hair-coverage-check.png 和过渡检查；notes 记录本次作者 SHA、实际图像路径、occludedWeightScale、覆盖依据与剩余差异，区分原 fit 报告和后续局部修正，不能用旧图验收新工程。本轮输出为候选，用户明确说通过前不得称流程稳定。
