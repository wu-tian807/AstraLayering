# left 完整脸型补全先验

当前角色 left 视频帧决定所有看得见的皮肤范围、脸缘、五官和笔锋。主流程是完整脸起稿/可见脸缘 → 遮挡补全 → 自动拟合 → 覆盖检查：source 先描本次原 KRA 的完整脸底 alpha；target 对着带头发的 left 参考先起稿整张脸轮廓，可见部分准确，未知处临时闭合。观察整脸时同时辨认刘海缝实际露出的额头、两侧额角和遮挡物，以 face-coverage.svg 辅助记录这些皮肤窗口；之后仅用本页先验补全未知轮廓。完整脸型描边始终是主流程，mask 只给补全下限和覆盖验收。近侧发束凹口不能捏进脸肉，已看见的额头尖角不能留到拟合后才发现或被低额顶截断。目标完整轮廓受视频可见证据和原画体量约束，不能照搬其它角色。

先看原画整体脸型，再从下表选择接近的形状，解释选择理由。可组合局部结构知识，不能平均圆脸与长脸的轮廓；先验与当前视频可见部分冲突时，保留当前视频。头部中心、下巴和固定脖子的接触仍按当前角色参考核对，不能从示例复制脖子的运动。

若本任务 [continuity-reference]({uri:nine-axis/continuity-reference}) 存在，实际查看连续帧、独显脸底和 up/down/左上/左下角色图及说明（如有）。这些图仅约束本角色隐藏额部体量，并帮助诊断 left 与斜角过渡的衔接；不能平均不同角度或代替指定 left 帧的可见脸缘、五官与笔锋。全新制作的 source 必须独立来自本次原 KRA 导出的完整脸底 alpha，不复制旧 X/Y/XY 网格、参数、描线或贴图。参考图存在不代表新工程已完成这些方向；缺图或尚未集成的过渡如实说明。

## 完整脸描边与补全中的额头窗口辅助检查

先完成完整 source 与整张 target 脸型起稿，再在同一带头发参考的观察阶段复用 part-layering 的描边与 `preview_svg`，记录本步辅助 `face-coverage.svg`：透明底、不透明纯色填充、无描边，保持 box.size 尺寸和 `0 0 box.size box.size` 的 viewBox。mask 范围只限刘海间、额头/两侧额角实际可见的皮肤窗口，细窄、分离窗口及上露尖角都保留。不要把整张脸的外缘边界或眼窝/颊部/下颌轮廓纳入该 mask；它们已由 trace 与视频核对，把边缘抗锯齿纳入 alpha>=250 检查会混淆外缘拟合与额头覆盖。头发不画进 mask，发影、暗部和渐变中的皮肤仍包含，不能按亮度阈值只描浅色部分，也不能为避开覆盖门槛裁掉已确认的额头尖角。用原帧为 reference 做整图与局部放大的 blend/edge 核对，分区辨认阴影皮肤与头发，保存 face-coverage-mask-check.png 与原帧/mask SHA；再据这些可见证据补全未知脸型。mask 直接来自视频，不能从完整脸起稿、completion、当前脸底或 source 反推，也不缩小它去适配低额顶。

三类信息分别使用：真实可见的脸实体外缘进入 trace 的 visible 曲线；头发间可见的皮肤窗口是“完整脸底至少必须包含这些像素”的独立硬下限，其遮挡边界不能一律当成脸外缘；只有视频确实看不见的完整轮廓才使用 occluded 与本页先验。硬覆盖不能随 `occludedWeightScale` 降权。完整 `target-face.svg` 必须包含核准 mask，再在未知区域按原画体量和真实遮挡保留有依据的搭接余量，不能为错误先验维持低额顶，也不靠统一扩张量或全脸膨胀补洞。

顺序是：原 KRA 完整 source → 整张 target 起稿/可见脸缘核对（同阶段记录额头窗口辅助 mask）→ 仅补全未知轮廓并包含已知额头窗口与合理余量 → `fit_nine_axis` → `view_nine_axis` 实际完整脸与覆盖检查 → 回查五官及可见边缘。不是先做 mask 的独立管线，也不能在末尾补洞掩盖错误完整预测。覆盖调用须 `only=["face/face_base"]`，`crop` 与 `coverage.bounds` 都是完整的 `[box.x,box.y,box.size,box.size]`，`coverage.path` 指向核准的本步额头/额角窗口 mask `face-coverage.svg`；可用 scale=1/2，不能通过局部 crop 裁掉缺口。mask alpha>=128 为 required，实际 face_base alpha>=250 才覆盖；参考、棋盘、五官和头发不参与测试，empty/allopaque mask 报错。

实际读取工具返回的 `coverage.satisfied`、`requiredPixels`、`uncoveredPixels`，要求 satisfied=true、requiredPixels>0、uncoveredPixels=0。`uncoveredAreaCanvasPixels`/`uncoveredBounds` 给出缺口面积与原画布位置，`savedPath` 是红色高亮图，`alphaSavedPath` 是实际渲染 RGBA；保留 `maskSha256`、`alphaSha256`、`builtDocumentSha256` 及原参考/作者 SHA。最终 finish 会强制重渲染，缺 mask 或有 uncovered 不生成 .completed，并生成 face-coverage-report.json、face-coverage-check.png、face-alpha-check.png；不能手写零报告或补画检查图。最后作者版本的独立复查也用同一核准 mask 和原帧取得 uncoveredPixels=0，不能以改 bounds、阈值、mask 或参考帧消除缺失。覆盖为零只对已核准 mask 有效，mask 与视频仍须准确，完整隐藏预测还要单独查看。

## 管线必须显示完整预测与实际结果

`face-trace.json.completion.source/target` 是整张闭合脸型；visible/occluded 分段取自这两条完整路径。source 先取完整原脸，target 先起稿整张脸、核对真实可见脸缘并同时记录额头窗口，未知处的临时闭合只用于起稿。补全阶段依据这些已知证据和原画体量完成未知轮廓，确认完整预测包含辅助 mask，以 inspect 查看无遮挡素脸双图，保存 face-completion-check.png，确认额顶/双额角、近侧体量、轮廓连续性与可见目标后自动拟合。不能沿发缘闭合一块皮肤窗口就当完整脸，也不能把辅助 mask 的遮挡边界塞成脸实体外缘。

完整预测须包含额顶中心、两侧额角、太阳穴到上颊的连续体量与连接切线，补的是刘海/鬓发后的额部，不照整个头发外轮廓扩张脸底，也不设通用头骨尺寸或扩张像素。脸底自身缺顶、额角断续或露底在本步处理；step07 只接续脖子顶部补足、下颌接触与阴影收尾，脖子始终保持原形、不挂头部 Warp。

`preview_svg`/`completionCheck` 展示 SVG 预测，`completionMismatch=[]` 只说明闭合 SVG 与 trace 分段一致，没有检查预测对视频皮肤窗口的包含或实际贴图 alpha。`fit_nine_axis` 的可见残差小也不证明隐藏补全完成：求解器可能逐级压低 `occludedWeightScale` 甚至到 0。必须读取报告，另用 `view_nine_axis` 的 only/grid/crop/scale 与 coverage 独显真实脸底，保存 face-base-left-check.png 和实际 coverage 报告/高亮；同坐标完整图和重叠放大局部对照完整预测、核准 mask 和原帧，检查额顶、双侧额角/太阳穴的连贯性与刘海皮肤窗口覆盖。闭合、平滑或误差小都不能解释可见皮肤处没有脸底。

预测漏掉核准 mask 时，先修完整预测与同步 trace，再自动拟合；不能只让实际脸底更贴住这条错误低额顶。预测已包含 mask 而实际上沿不足时，由 agent 选择原脸底部件、现有 Warp 或必要的局部 Warp，复用 `fit_nine_axis`/`edit_nine_axis` 修正到实际覆盖为零；分组、父子关系、控制范围与密度按实际需求决定，不预定联合 Warp。要重新 fit 时用 features 选择相关隐藏段和真实可见连接处，不能把隐藏段或皮肤窗口遮挡边界伪标 visible；没有适用可见曲线约束时用局部编辑后检查。每轮回查已对齐的可见脸缘、五官与正面，不用全脸膨胀、移动下巴或扭脖子填顶。

覆盖余量按原 KRA、当前 left 帧及可选连续参考中真实刘海/鬓发遮挡判断：额部、额角应有连续脸底，发缘后保留有依据的搭接，避免刚好相切。已有头发层时显示它检查；没有头发层或未知发摆范围，只能确认静态遮挡和脸底完整性，不能宣称未来头发动也不会露底，不自定发摆或新增动画。原贴图若缺所需像素，明确素材限制。

五官仍对指定 left 帧用同一次 operations 批量调整，再微调；之后独显脸底、显示五官与固定脖子，同坐标复查额顶/额角及覆盖，并看本次 X 端点、零点与中间值。若有连续参考，重点诊断 X=left、Y 正值→0→负值在零点两侧的体量与线条；本步不修改 Y/四角，不把旧参考的连续图冒充新工程集成后的结果。

最后一次编辑和五官调整后重新渲染并查看完整脸底、completion 对照、forehead-temple-check.png、hair-coverage-check.png 和过渡检查，重新取得同一核准 mask 对最终 face_base 的 coverage.satisfied=true、uncoveredPixels=0。保留 face-coverage.svg、face-coverage-mask-check.png，以及 finish 实际生成的 face-coverage-report.json、face-coverage-check.png、face-alpha-check.png；notes 记录作者、核准 mask 与原帧 SHA、工具 builtDocumentSha256/alphaSha256、实际图像路径、occludedWeightScale、覆盖依据与剩余差异，区分原 fit 报告和后续局部修正。不能手改最终报告/PNG，不能用旧图或从完整预测生成、缩小的 mask 验收新工程。本轮输出为候选，用户明确说通过前不得称流程稳定。
