# 九轴完整脸底与额头覆盖共同规范

本正文共同用于 step02_angles 的 left/up/down 三个组，以及 step03_angle-xy 的 left-up/left-down；由两个步骤的 agent.json 的 initial 直接注入。各方向稿只绑定当前角的 X/Y、视频目标帧、作者文件、SVG/trace 和检查文件名，并提供方向先验；这些绑定不同，以下制作与验收流程完全相同。

主流程始终是：**原画完整 source → 整张 target 起稿/可见脸缘（同阶段主动逐窗观察，记录独立视频 mask）→ 遮挡补全 → 自动拟合 → 实际完整脸底与覆盖检查 → 五官/过渡回查 → 最后编辑后重检**。mask 是可见额部皮肤的硬下限与辅助验收，不是替代整张脸描边的新管线，也不是末尾补洞的办法。

## 参考、坐标与作者边界

当前角指定或自主选定的视频帧决定可见皮肤、实体脸缘、五官、笔锋与位置。原 KRA 的完整脸底、原画体量、已认可姿态和方向先验只帮助补全视频看不到的结构，不能削掉已经可见的额头尖角或拉走已贴准的脸缘。模型参数只是关键形标签，不作为视频三维角度的物理测量。

按本步规定从原 KRA 静止导出开始，或继承受保护上游工程；source 始终来自原 KRA 导出的完整 face_base alpha，不取某个已变形端点或发间露肤轮廓。保留原贴图、来源、画布、绘制顺序及本步要求保护的姿态。明确 fresh 从 KRA 制作时，不导入旧网格、参数、描线或贴图；本次运行中的合法续修按本步来源检查继续，不能因存在诊断参考改成旧工程续修。

box 取任务的 nine-axis/step01_video/crop.json。特写 (u,v) 对应原画布 (box.x+u,box.y+v)，参考、SVG、trace 与实际渲染共用尺度和坐标。不按当前眼睛、下巴重对齐，不用裁切、旋转、平移或变焦消除误差。斜角初次选帧遵循本步视频流程；选定后所有描线、mask、拟合和检查绑定同一帧。若有真实理由改选，必须从新帧重新核对整脸、mask、trace 并拟合，不能改选来躲避覆盖缺口。

脖子从最初的完整预览参与下巴位置与遮挡参考，保持原形原位置，parent 为空，静止形与所有关键形不变；不跟头部 Warp、不倾斜、不拉长。脸底额顶、两侧额角和太阳穴的缺顶、凹坑、断续与露底在当前角处理；脖子顶部补足、下颌接触消线与阴影收尾留 step04 下颌步骤。

## 完整脸起稿与主动逐窗观察

1. 隐藏五官，查看原画完整 face_base 与固定脖子。将本次导出或合法继承的原脸底 PNG 按 textureBounds 放回原画布，再以 box 裁出 source-face-reference.png，仅作检查底图。先保存完整 source-face.svg，用 preview_svg 的 reference=source-face-reference.png 对照真实 alpha 外缘；线与色分层时按实际需要协调 Warp，不换贴图。
2. 对着带头发的当前视频帧起稿**整张** target 脸型：真实可见脸缘准确，未知处可以临时闭合，但不能沿刘海/发束围出的皮肤窗口闭合成一小块脸，临时闭合也不是已完成的预测。起稿时同时辨认刘海、鬓发、睫毛、耳轮、阴影、真实皮肤及实体外缘，不先忽略额头、拟合后才补洞。
3. 即使没有用户问题截图、反馈文件或缺口坐标，每次也必须自己检查原画与当前视频帧：先看全图，再以重叠放大区从额顶、两侧额角扫到太阳穴，逐窗核对上露细尖角、独立细窗、被发束分开的皮肤条、发影/阴影下的暗肤色与混色边界。必要时查看相邻视频帧辅助辨认，当前选定帧仍决定目标。旧用户问题截图仅是可选历史诊断，不能作为正确性的前提，不能只检查被圈出的地方。
4. 复用 part-layering 的闭合色块描边：source/target 用一种纯色、透明底、闭合 path、stroke="none"，width/height 为 box.size，viewBox="0 0 box.size box.size"；填色外缘就是轮廓。先 preview_svg 整图 blend，再用重叠 crop、scale=4..8 的 blend/edge 核对端点、切线、转折、尖端和笔锋。source 对原脸底检查图，target 对当前视频帧。修改后回看改动区和相邻区；细线中心、整图相似或低拟合残差不能替代真实边缘核对。

## 独立视频窗口 mask：核对完整性

在整张 target 已起稿的同一观察阶段，按本步文件名记录辅助 mask。**直接描当前视频帧**中刘海间、额头、两侧额角及相连太阳穴处实际露出的额部皮肤窗口；不能从 target/completion、source、当前网格或实际脸底反推，更不能从旧诊断探针生成。

mask 为 box.size 见方、相同 viewBox、透明底、不透明纯色填充、stroke="none"。只画这些皮肤窗口，头发不画；细尖角、分离细窗、发影和深色阴影中仍属皮肤的部分都保留，不能以亮度阈值只描浅色。不要把整张脸外缘或沿眼窝/颊部/下颌描成整脸 mask；外脸缘已由 trace 与视频核对，边界抗锯齿不应混入额头硬覆盖检查，也不能因此裁掉真正上露的额头尖角。

以 preview_svg 显式 reference=当前角视频帧，对 mask 做整图及重叠放大 blend/edge 检查并保存本角 mask 核对图。逐窗确认原帧证据都被包含，尤其分清暗皮肤与头发；发现漏窗先依据原帧修 mask 并重新核对，不能用已有预测限定它。**程序零缺口只证明实际脸底包含所给 mask，不能证明 mask 没有漏窗，视觉核对必须由 agent 主动完成。**记录本角参考帧与 mask SHA。

## 完整预测包含已知皮肤，SVG 与 trace 一致

原帧真实显露的脸实体外缘进入 visible 曲线；部分显露时拆分 visible/occluded，不能把远侧眼窝到颊部整段笼统标成隐藏。刘海窗口的遮挡边界不是脸实体外缘，不能把它伪标 visible 或将发梢凹口压进脸肉。只有看不见的完整轮廓使用 occluded 与方向先验。

据已核对的可见脸缘和视频窗口证据，补全整张 target 的未知段，替换临时闭合：完整预测必须包含核准 mask 全部皮肤窗口，再按原画体量、真实刘海/鬓发遮挡与已知边界保留有依据的连续体量和搭接余量。从额顶中心到两侧额角、太阳穴、上颊保持连续连接；不截断已知皮肤尖角，不沿头发窗口闭合，也不照全部头发外轮廓扩张脸底。不得硬编码统一头骨尺寸、固定扩张量或用全脸膨胀填顶。若预测本身过低，先修完整预测，不能最后补洞或缩小 mask 迁就它。

从实际核对的 source/target SVG 的同一组路径段生成本角 trace：version=1、space=view，completion={part,source,target} 保存这两条完整闭合路径；curves 是语义对应、方向一致的小段，按真实可见性标 visible/occluded，必要时加少量真实 landmarks。完整 SVG、trace completion、分段及预览不能成为三套不同轮廓。用 fit_nine_axis inspect 实际查看 traceCheck、completionCheck 的完整 source/target 素脸与可见描线，确认 completionMismatch=[]，保存本角检查图；另核对完整预测包含 mask。

## 自动拟合与实际完整脸底

Warp 分组、父子结构、作用范围与密度由 agent 按实际需求决定，可以共同 Warp、子 Warp 或部件独立微调，不预设所有五官与脸底共同变形。用现有 fit_nine_axis 对本角 trace 和所选 id 自动求解，检查各段误差；先核对描边、对应关系和分段，再按需要调整 Warp 后重拟合，不以一处下巴误差代替整脸核对。

visible 优先、occluded 弱约束；读取报告的 occludedWeightScale，它可能为了保护可见边缘降得很低甚至为 0。**mask 的硬覆盖不会随此降权。**completionMismatch=[] 只校 SVG 与 trace，completionCheck 是预测，低可见残差或网格不翻折都不能证明实际 alpha 完整。

用 view_nine_axis 在本角 X/Y、only=["face/face_base"] 独显真正形变后的完整脸底，对照完整预测，再重叠放大检查额顶、双侧额角/太阳穴：不能缺顶、凹坑、波纹、压薄、断续或在需要皮肤处露背景。保存本角实际完整脸底、额顶/额角及发缘覆盖图。

若预测漏 mask，先修完整预测并同步 trace、inspect，再 fit。预测合理而实际隐藏上沿或覆盖不足时，用现有 only/grid/crop/scale 查作用范围，由 agent 选择现有或必要的局部 Warp，复用 fit/edit 修正。重新 fit 可用 features 选择相关隐藏段和真实可见连接处；不能把 occluded 或窗口边界伪标 visible，没有适用可见约束时用局部编辑后检查。每轮回查全部已对准的脸缘、五官、原画正面及受保护姿态，不靠移动下巴、扭脖子或整脸膨胀填顶。

## 同一实际 alpha 覆盖合同

所有方向使用现有 view_nine_axis 的同一 coverage 接口，只有本角 X/Y、参考帧、mask 路径与作者文件不同：

```text
view_nine_axis({
  x: 本角X, y: 本角Y,
  only: ["face/face_base"],
  crop: [box.x,box.y,box.size,box.size], scale: 1,
  reference: {path: 本角视频帧, bounds: [box.x,box.y,box.size,box.size]},
  coverage: {path: 本角核准mask, bounds: [box.x,box.y,box.size,box.size]}
})
```

完整检查 crop 必须与 coverage.bounds 相同，不能局部裁掉窗口或缺口；可另用 scale=2 放大，最终重检用 scale=1。mask alpha>=128 为 required，实际 face_base RGBA alpha>=250 才覆盖。参考、棋盘、五官、头发不参与 alpha 测试；empty/allopaque mask 报错。必须实际读出 coverage.satisfied=true、requiredPixels>0、uncoveredPixels=0。

uncoveredAreaCanvasPixels/uncoveredBounds 是实际缺口面积与原画布位置；savedPath 是红色缺口图，alphaSavedPath 是真实 RGBA。保留工具报告的 maskSha256、alphaSha256、builtDocumentSha256，以及本角原帧/最终作者 SHA 与实际图路径。不能通过缩小 mask、漏暗皮肤、改变 bounds/坐标/阈值、改选帧或涂改报告/PNG 刷通过。

## 五官、动态遮挡、最后编辑后重检与完成门槛

五官仍按本角视频用一次 operations 批次完成有把握的整眼、眉、鼻、口腔等调整，再预览微调；分组由 agent 决定。显示脸、五官与固定脖子同坐标回查脸缘、笔锋和透视。只修隐藏区的授权续修保留原目标帧、已正确脸缘/五官和其它姿态，不借补顶重做这些区域。

发缘覆盖依据原 KRA、当前视频帧和已有明确的动态头发边界/运动范围。工程已有头发层时显示检查；只在已有、获授权的动态范围内核对皮肤搭接，不自定发摆、不新增头发动画。没有头发层或未知发摆范围时，只能说明静态窗口覆盖与脸底自身完整性，不能宣称未来头发动也不会露底。原贴图缺所需像素时说明素材限制，不换贴图、改透明度或拉伸整脸掩盖。

查看本步端点、正面、中间值及规定保护的姿态/已制作过渡，额顶和额角不出现新塌陷，五官不融化或分离，固定脖子不动。没有制作的角度不得用参考图冒充新工程过渡验收。

**最后一次编辑，包括五官、父子层级、局部 Warp、镜像或过渡修正后，重新检查完整实际脸底、completion 对照、额顶/额角、视频与 mask 的逐窗一致性，再用同一核准 mask 对最终作者重渲染取得零缺口。**斜角步骤必须在两角都完成后的同一个最终 face-xy.json 上分别重检 left-up 与 left-down；先完成角的旧报告不能验收被另一角编辑过的工程。

notes 按角记录目标帧/视频、mask、最终作者 SHA，工具 builtDocumentSha256/alphaSha256、occludedWeightScale、逐窗核对图、实际图和剩余差异。agent 检查图保留原字节；若工具没有返回作者 SHA，notes 声明不能冒充截图确实来自最后作者的程序证明，最终工程应重新渲染绑定。自动 fit 报告、旧截图或旧作者的零缺口不能验收新工程。

完成前程序必须对最终工程、当前角参数与参考帧强制重渲染，输出方向稿规定的 coverage report/check/alpha；缺 mask、空/全不透明 mask、非零缺口或未取得实际成功报告均不生成 .completed，斜角任一角不满足也不能完成。agent 不能手写零报告、补画检查图或自行标记完成。程序复检仍不证明 mask 无漏窗，原帧逐窗视觉核对与完整预测/实际脸底检查必须齐备；本轮结果为候选，用户明确通过前不得称流程稳定。
