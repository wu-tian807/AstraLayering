先保存对应 parts/<id>.svg，再提交结构。拆分、合并或修改终止部件 ID 时，在同一次调用中提供完整 layers 深度表，格式与 edit_occlusion 相同；仅改父组、归属、顺序或说明且终止 ID 不变时可省略 layers。工具校验重复／非法 ID、节点结构、全部终止部件的 SVG 和深度覆盖，全部通过才保存；失败返回具体错误，修正参数后再次调用，已有文件保持原样。
