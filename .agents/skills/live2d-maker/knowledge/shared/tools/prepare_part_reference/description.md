按 `part_id` 准备同一部件的灰底颜色参考和三色控制图。灰底图保留可见范围内的参考颜色。控制图红色是可见部分，黄色是待补全部分，绿色是生成时应透明的区域。

用 `output_dir` 指定绝对目录。两张图保存为 `reference.png` 和 `control.png`。画幅跟随部件比例，长边为 1024 像素，部件等比居中，最长边约占 85%。

调用生图时选择透明背景、自动画幅，先传 `referencePath`，再传 `controlPath`。保留部件在两张图里的位置、比例和笔触。`canvas` 为参考图宽高。`crop` 与 `placement` 分别是部件在原图和参考图上的 `[x, y, width, height]`，用于等比配准。
