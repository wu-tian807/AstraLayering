按本步当前交付构建头部九轴文档（与步骤完成时程序写出的相同），用工作台的同一渲染器在工作台深色棋盘底上画出并直接返回图片，即用户在工作台看到的样子。x、y 为角度 X、Y（默认 0，本步尚无的角度只能为 0）；level 为工作台层级 id（默认同工作台）；crop=[x,y,width,height] 为原画布像素选框（默认工作台初始视框）；scale 为每原画布像素对应的屏幕像素，默认 1，可取 0.25 至 8；masks 为要以青色显示的蒙版部件 id（同工作台勾选显示蒙版）。grid 为要叠出网格的部件 id 列表（同工作台选中部件并打开网格）：图上画出这些部件在该角度下的网格线与控制点，返回文本的 grid 里给出每个部件的 cols、rows 与 points，points 按行从上到下、每行从左到右排列，第 j 行第 i 列是 points[j×(cols+1)+i]，坐标为原画布像素；角度正好在某个关键形上时，这些就是交付里该关键形的控制点。交付有误时返回错误。预览会保存。
