把当前父组完成稿中一块边界明确的范围直接作为一个直属子节点的轮廓，不再重新描边。name 填将要在 submit_children 中提交的子节点名称，范围用 region 或 maskSvg 二选一给出。

适用范围：父组完成稿本身已经完整，子节点只是它的一部分，且与相邻部分之间的分界线明确，例如手臂完成稿中的上臂、前臂，或互不相连的左右眼、两侧发束。父组缺失、残缺或分界不清，需要新增或重画形状时不要用本工具，走常规描边与补全；子节点只是父组某个元素内部的一个封闭形状、需要自己勾勒时同样不适用。

- region：原画布坐标中的整数选框 {x,y,width,height}，用于子节点是父组中与其他形状不相连的独立一块。框线须全部落在空白处：框内形状整体复制，框外形状整体排除；框线切过形状、框内外形状相连、框内没有形状或包含父组全部形状时报错。
- maskSvg：用于分界线穿过相连形状的拆分。先自己写一个与父组完成稿同画布（width、height 与 viewBox 一致）的 SVG，里面只放封闭形状，一并表示子节点要的范围：把分界线画准，沿线一侧用足够大的形状盖住干净的一侧，不必贴着轮廓画，范围之外的部分留给另一个子节点。父组完成稿按这些形状裁剪，裁剪后的结果即子节点轮廓。maskSvg 只接受 path（每个子路径以 Z 闭合）、rect、circle、ellipse、polygon，形状上可带 transform。遮罩没有裁掉任何部分、或遮罩内没有父组形状时报错。

调用后返回复制结果的 SVG 路径：先用 preview_svg 的 edge 模式叠在参考图上查看分界线是否落在应有的位置、范围是否完整，不满意就改遮罩再调用。同名再次调用会替换上次结果。region 方式下不同子节点的选框不能复制同一形状；maskSvg 方式下相邻子节点各写自己一侧的遮罩即可。

提交同名子节点后，程序从父组完成稿按同一范围重建其轮廓，跳过描边与轮廓 review，父范围与结构校验照常执行；去重与补全照常进行。该子节点不能同时标记 hiddenInReference。以 maskSvg 复制出的轮廓带有裁剪，不能再作为 copy_parent_region 的父稿。
