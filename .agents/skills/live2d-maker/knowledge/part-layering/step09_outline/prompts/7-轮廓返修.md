先核对反馈涉及的部件归属和主要形状。归属、整体形状或位置比例错误时，可以重画当前组草稿，不限于微调控制点；修改后先看整体，再检查局部边缘。逐项对照原图核实反馈，按可见边缘和遮挡边界修改；例如 face 的上边界沿刘海与皮肤的可见分界描绘。

先核对反馈所说的部件是否真的漏画。group 本轮把所属各部分合在一起画成色块；饰件已经落在本组色块内时，不要求另画内部边界或单独 path。若反馈只是因为没有内边或 path 数量少就判定漏画，说明哪些色块已经画到了这些部件，保留正确轮廓，内部拆分留到下一层；仍须补上确实漏画的可见部分，不挖空底形来制造饰件分界。

有父组时，按 group.allowOutsideParent 处理范围：为 true 时，依据 note 确定部件归属，按参考修改本组可见部分，允许伸出父轮廓，并继续核对原图位置、画布坐标和归属；省略或为 false 时，在父范围内修正可修漏画，只有扩大父稿才能恢复的部分单列上游限制，写清位置与依据。父 SVG 始终保持原样；受父范围约束时保留该检查，如实说明尚未补齐的父外缺漏。

同组相邻、连续的可见部分画在一起，实际分开的部分保持分开。部件连接处按两侧可见边缘的位置和走向闭合，可以保留连接所需的少量重叠；例如耳朵沿清晰耳缘描绘，耳坠连接处按可见边缘衔接。被其他部件遮住的地方，沿原图中能看到的分界描绘，再放大叠加检查修改后的范围。
