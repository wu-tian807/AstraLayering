依据上述意见修正当前组的可见联合轮廓，按参考中的可见外缘、遮挡接缝和真实开口确定色块范围。当前组 note 和已有子树说明用于理解组件归属与连接关系；其中的完整形态描述落实为当前参考中可见的形状。保留可靠的可见边缘，清理噪音，微小缺口按相邻可见边缘的位置和走向连续描绘。

先重新核对反馈涉及区域的真实归属和主要形体。归属、整体形状或位置比例错误时，可以重画当前组草稿，不限于微调控制点；修正后先复查整体，再检查局部边缘。逐项以原参考核实反馈，修改后的色块沿可见外缘和遮挡接缝闭合；例如 face 上沿按刘海与皮肤的可见分界描绘。

先核对反馈所称的组件缺失是否确有未覆盖区域。group 此步是联合覆盖色块；完全位于本组另一实体色块内部的饰件不要求另画内部边界或单独 path。若反馈仅依据没有内边或 path 数量判断漏画，说明现有覆盖依据，保留正确的联合色块，内部结构留到直属拆分；仍须修正真实未覆盖的外露部分，不挖空底形来制造饰件分界。

有父组时，按 group.allowOutsideParent 处理范围：为 true 时，依据 note 确定实体归属，按参考修正本组可见形体，允许伸出父轮廓，并继续核对原图定位、画布坐标和归属；省略或为 false 时，在父范围内修正可修漏画，只有扩大父稿才能恢复的部分单列上游限制，写清位置与依据。父 SVG 始终保持原样；受父范围约束时保留该检查，如实说明尚未补齐的父外缺漏。

同组相邻、连续的可见形体合并覆盖，实际分离的区域保留。实体接合处按两侧可见边缘的接点和走向局部闭合，接合余量的范围由这些可见接点确定；例如耳朵沿清晰耳缘描绘，耳坠接点附近按可见边缘衔接。遮挡处沿本组与遮挡物的可见接缝收束，并在局部叠加中核对修改后的范围。

逐项核对反馈是否已修正，放大改动处及相邻区域，以原图叠加和边缘图确认边缘、接缝和形体连续性；再看整图确认未引入位置、比例或其他区域的变形。发现问题在本次返修内修正并复查，不把已发现的问题留到下次审查。
