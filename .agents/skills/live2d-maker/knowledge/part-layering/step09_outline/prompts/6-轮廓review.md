独立检查当前组的轮廓色块：本组可见部分是否画全，色块边缘是否贴合原图，开口和部件归属是否正确。读取组说明、参考图、候选 SVG；有父组时同时查看父组完成 SVG。当前组 note 和已有子组的说明用于理解部件归属和连接关系，色块范围以原图实际可见的边界为准。输入和候选只读。本轮由 part-layering 程序调度，只审当前组，不审整棵树，不进入其他技能或流水线。按需局部放大参考图。

先独立依据参考与本组职责确认可见区域的归属，候选中画了一块不等于原图存在该部件。先检查误认部件、误包相邻结构、可见组件遗漏，以及主要形体、位置和比例，再检查局部边缘精度。归属错误或主要形体错误须优先指出，明确是否需要重画当前组，不把它当作几个像素的边缘偏差修补。完全遮挡的已登记部件以绑定本组路径的空轮廓和遮挡依据验收；部分可见的组件按实际露出范围与接缝验收。

先查看整图与原图的叠加，定位本组各区域，并安排覆盖全部可见区域的选框；再裁剪放大，以原图叠加和边缘图逐块仔细对照参考，相邻选框适当重叠以核对接缝与连续性。发现问题后仍须继续检查其余区域，完成全组核对后一次汇总所有已发现、有明确图像依据的问题，不分批留到下一轮；不能仅凭整图缩览或少数局部下结论。

逐处核对本组的可见区域，包括与其他部件的接缝，以及外缘、孔洞、开口和尖端；覆盖须完整，边缘的位置、宽度、弧度与转向须精确对齐原图，内部明暗分界不作为轮廓。保留明显折线、折角和转折，不能磨成弧线；轮廓超出或缩入原图、接缝漏画或无依据留空均须返修，不能因整体大致相似或缺漏较小而放行。左右成对或相近的组件若由复制、镜像得到，同样逐件对照原图；transform 写法本身不是问题，但不能因两件彼此对称就放过与原图透视、遮挡或画风不符之处。

重点检查轮廓是否干净、形体归属是否清晰：来源不明的碎发丝、孤立像素点、碎片堆砌须清理，不能因为原图有一点痕迹就单独画一块。小缺口根据两侧可见边缘的位置和走向画连贯，例如眼角只露出一点时，须核对这一小段实际可见形状。结构明确的独立饰件和确有依据的分离区域应保留。逐段核对色块外缘是否贴合原图外缘、遮挡边界；部件连接处是否按两侧可见边缘闭合。范围不符时，指出具体位置和应采用的边界。

有父组时，结合 group.allowOutsideParent 检查范围：为 true 时，以 note 确定部件归属，按参考核对本组伸出父轮廓的可见部分；省略或为 false 时，候选须容纳在父完成轮廓内。两种情况都检查真实可见边缘、画布坐标和部件归属，父稿保持只读。相邻组连接处的少量重叠按原图中可见的连接位置核对，组内纹理、最终着色或显影顺序留给后续阶段。纯色色块只表达结构范围，返修须有具体轮廓或归属证据。

对于受父范围约束的节点，若参考中某段边缘位于父范围之外，须把父 SVG 与候选在同一局部叠加核对：候选尚未覆盖的父内区域仍属于可修问题；候选已贴合父边界、只有扩大父范围才能恢复的部分属于上游问题，不再要求当前子组越界返修。将上游问题的位置、参考依据和父范围冲突单独写入 feedback，不声称它已经补齐，不放宽父检查，也不修改父稿。仅存在这类已确认的上游限制、当前允许范围内其余检查均通过时，可以给本轮 pass；若仍有父内可修问题则继续 revise。

这里“不审组内细节”仅指纹理、普通明暗和最终画法，不豁免 group 所属独立组件的覆盖。参考中明确存在且属于本组的眼褶线、链饰、吊坠等，即使与主色块分离，也须核对有没有被整段漏掉；不能只检查已画出来的主体。眼褶线与睫毛间的真实肤色间隙应保留，弥散眼影不因此变成独立轮廓。报告须区分“组件缺失”与“最终着色未画”。

上述检查以本组色块是否画到相应部件的范围为准，不能要求 group 提前完成内部拆分。部件完全落在本组已有色块内时，其范围已经画到，不要求独立 path 或可见内部边界；不能仅因 edge 中没有内边、SVG 只有一个 path，就判定漏画。例如腿脚色块内的踝链与宝石留给下一层分析和绘制；只有它们露在本组色块之外、尚未画到的部分才算漏画。位于眼睛主色块之外的独立眼褶线则仍须覆盖。这不允许填平真正的孔洞，也不改变 part 的明确职责。

同组连续的可见部分应画在一起，实际分开的部分保持分开。部件连接处按两侧可见边缘的位置和走向闭合，并核对重叠范围；例如耳朵与耳坠连接处可有少量重叠，手臂与身体的重叠限于可见肩点附近。被其他部件遮住的地方，按原图中能看到的分界验收：例如 face 上沿应沿刘海与皮肤的可见分界描绘；如果候选用跨过刘海的整段额头弧线代替这条边界，应给 revise，并指出需要修改的位置。

完成分块放大核对后提交审查结论。本组可见部分画全、色块边缘贴合原图外缘和遮挡边界、轮廓干净、连接处符合两侧可见边缘，且满足本轮适用的父范围条件，给 pass；否则给 revise，在 feedback 中逐项指出位置、图像依据和修改要求，明确是否涉及噪音或形体混乱；仅输入或工具故障使检查无法执行时给 blocked。不自行修改候选，最终回复不作为审查结果。

只提交已经核对、确定需要修改的问题，写明位置、参考证据与具体要求。疑点先继续查看局部，不设“待确认”或等待标准维护方批准的中间态；无依据的猜测不列为缺陷。说明错误交给当前绘制 agent 修正 note。父范围限制按本阶段已有上游限制规则报告，后续绘画内容按阶段职责处理，不因此 blocked。blocked 仅用于必要输入缺失、损坏或工具故障导致无法实际检查，须给出具体路径或错误、受影响范围与恢复尝试。
