把父组完成稿中一块边界明确的范围直接复制为本组轮廓，写入本组轮廓草稿，不再重新描边。范围用 region 或 maskSvg 二选一给出。

适用范围：父组完成稿本身已经完整，本组只是它的一部分，且与相邻部分之间的分界线明确，例如手臂完成稿中的上臂、前臂，或互不相连的左右眼、两侧发束。父组缺失、残缺或分界不清，本组需要新增或重画形状时不要用本工具，按常规描边；本组只是父组某个元素内部的一个封闭形状、需要自己勾勒时同样不适用。

- region：原画布坐标中的整数选框 {x,y,width,height}，用于本组是父组中与其他形状不相连的独立一块。框线须全部落在空白处：框内形状整体复制，框外形状整体排除；框线切过形状、框内外形状相连、框内没有形状或包含父组全部形状时报错。
- maskSvg：用于分界线穿过相连形状的拆分。先自己写一个与父组完成稿同画布（width、height 与 viewBox 一致）的 SVG，里面只放封闭形状，一并表示本组要的范围：把分界线画准，沿线一侧用足够大的形状盖住干净的一侧，不必贴着轮廓画。父组完成稿按这些形状裁剪，裁剪后的结果即本组轮廓。maskSvg 只接受 path（每个子路径以 Z 闭合）、rect、circle、ellipse、polygon，形状上可带 transform。遮罩没有裁掉任何部分、或遮罩内没有父组形状时报错。

调用后复制结果写入本组轮廓草稿：用 preview_svg 的 edge 模式叠在参考图上查看分界线是否落在应有的位置、范围是否完整，不满意就改范围再调用，再次调用会替换草稿。

保持复制结果不改即完成本轮：父组完成稿已是完整形状，复制出的轮廓跳过轮廓 review 和补全，直接作为本组完成稿。之后若又用 write_outline_svg 改写草稿，它就是常规描边，照常 review 与补全。以 maskSvg 复制出的轮廓带有裁剪，不能再作为子组复制的父稿。
