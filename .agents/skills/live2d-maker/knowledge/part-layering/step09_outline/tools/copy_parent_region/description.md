把父组完成稿中的一部分直接复制为本组轮廓，写入本组轮廓草稿，不再重新描边。范围由你画的一张同画布遮罩 SVG 给出，先预览、确认后再裁剪。

适用范围：父组完成稿本身已经完整，本组只是它的一部分，且与相邻部分之间的分界线明确，例如手臂完成稿中的上臂、前臂，或互不相连的左右眼、两侧发束。父组缺失、残缺或分界不清，本组需要新增或重画形状时不要用本工具，按常规描边；本组只是父组某个元素内部的一个封闭形状、需要自己勾勒时同样不适用。

遮罩 SVG：width、height 与 viewBox 同父组完成稿，里面只放封闭形状，它们的并集就是本组要的范围。把分界线画准，沿线一侧用足够大的形状盖住干净的一侧，不必贴着轮廓画；互不相连的几块可以画成多个形状。只接受 path（每个子路径以 Z 闭合）、rect、circle、ellipse、polygon，形状上可带 transform。

两种 mode：
- preview（默认）：不写草稿。返回一张叠在原图上的预览：红色是遮罩选中的父稿部分，蓝色是被排除的部分，绿线是遮罩边界。分界线是否落在应有的位置、选中的范围是否完整，都看这张图；不满意就修改自己的遮罩 SVG 再预览，可用 crop、scale 放大局部。
- crop：按遮罩裁剪父组完成稿，结果写入本组轮廓草稿，再次调用会替换草稿。遮罩内没有父组形状、或遮罩没有裁掉任何部分时报错。

保持裁剪结果不改即完成本轮，裁出的轮廓跳过轮廓 review。补全由工具自动判别并返回 needsCompletion、reason：完整取出独立形体时跳过补全与检查，分界线切穿连续形体或几何不确定时进入后续补全与检查。仅提供遮罩，不提交补全开关。

判别记录由程序写入本组 outline 步骤的 copy-decision.json，只归属本组，不写进 SVG，也不随父稿继承；程序信任已保存的工具判定，不回查上游文件指纹。之后若又用 write_outline_svg 改写草稿（即使内容相同），它就是常规描边，照常 review 与补全；去重改稿也会进入补全与检查。带 clipPath 的裁剪完成稿可以继续作为下一层父稿。
