【任务流程】
在本次 agent 调用内完成两个小步骤：
1. 根据图1当前画幅判断是否需要换装。当前仅有脸、头发或颈部，角色已是素体，已有满足图2用途的简洁贴体连体服，或动物、器物等主体没有需要替换的衣装时，直接复用。仅有随人物保留的手套、袜类、鞋靴或自身装饰时也直接复用。画面内可见的上衣、裙裤、连衣裙、外套或盔甲等主体衣装需要替换时，选择换装；画外身体与衣装保持画外。
2. 无需换装时调用 reuse_reference，说明复用理由；需要换装时，将下面的绘制提示词原样交给本步骤配置的生图工具。只选择并执行一种交付方式。

【绘制提示词】
编辑图1现有画幅内的衣服，进行局部换装。图1决定最终画布、取景、人物坐标、人物大小和裁切；图2仅提供简化连体服的款式，按图1人物原有姿势和体型贴合。

保持图1相同画布宽高、透明边距和画面各边的截断位置。头顶、眉眼、鼻尖、嘴唇、下巴、颈根、肩点及已有肢体分别保持原来的画布坐标；脸、头发和身体保持原来的大小与比例。图1为全身、半身、头像或局部时，结果分别沿用同一种取景，画外身体继续留在画外；与画边相交的人物和衣服仍在原位置截断。

将画面内可见的上衣、裙裤等主体衣装替换为图2连体服对应的局部。头像或半身参考只呈现当前画幅覆盖的领口、肩带、胸部等衣服区域，其余部分自然延伸到画外。图2的衣服全貌用于理解款式，图1决定最终展示范围。手套、所有袜类（含丝袜、连裤袜）、鞋靴及它们自身的装饰保留原样，作为人物手、腿、脚的穿着外观，不随主体衣装去除。

保持图1的画风、脸、头发、表情、手势、身形比例和非服装配件；闭眼、闭嘴等原有表情保持原状。只在当前画幅内合理补出换装后露出的身体部分；戴手套的手和穿鞋袜的腿脚保持原有位置、轮廓、颜色、明暗及材质，不改成裸手或赤脚，不单独分离丝袜透明层。在原有取景内输出换装结果。
透明背景，角色外区域完全透明，不画辉光、光晕或雾气。

【执行规则】
本轮只使用提供的两张参考。reuse_reference 将图1复制到本步骤绑定的输出位置，输入与输出路径由程序确定。生图工具为 imagegen（Codex 为内置 image_gen.imagegen，其他模型为同名工具 imagegen）。生图时传入两张参考图，启用透明背景并输出 PNG。
选定的复制或生图工具只调用一次，完成后直接交付，不检查、不返修。工具使用范围为查看本次参考图、本次复制或已配置生图，图片和判断依据直接来自本次输入。复制或生成的图片由程序直接接收，不用回报路径。成功返回 JSON：{"error":null,"reason":"复用或换装的具体依据"}；失败时 error 和 reason 说明原因。
