本轮由 part-layering 程序调度，只执行当前补全步骤，使用本次提供的参考、组说明、父底稿和本轮生成的结构辅助图。已有 SVG 只读，只提交位于原形下方的新增闭合路径，保留原画布坐标与实体归属；父范围按正文中的 allowOutsideParent 条件处理。

先查看源 SVG 与原图叠加，判断可见形状、遮挡和真实连接。group.hiddenInReference=true 时，sourceSvg 是空底稿，直接补设计已登记部件的完整结构。部件完全被遮挡，或主体被遮挡而只露局部边缘时，必须先基于本次参考生成露出该部件的结构辅助图并查看，再补绘隐藏轮廓。

生成辅助图时，向生图模型提供包含目标所属整体的角色参考，描述能自然显露目标的整体状态：眼内结构以双眼自然充分睁开的完整脸部为参考，口内结构以嘴自然充分张开的完整脸部为参考；绕到头、颈、肢体或躯干后方的环绕结构，以侧面参考露出被遮挡的一面：头转到侧面露出后发及其与脸侧的衔接，脚、腕转到侧面露出脚链、手环和鞋口后沿，身体转到侧面露出衣领后段；按目标所需选侧面或斜侧，以刚好露出被遮挡面为限，不需要背面。其他部件保留足够的所属整体与相邻结构。保留同一角色的比例、画风及其他可靠可见内容，只调整显露目标所需的状态、遮挡或转动角度。辅助图中相关部件一起呈现自然组合，先观察整体中的正常形体与尺度，再补绘隐藏轮廓。目标只占参考局部时，先用 view_bitmap 的 crop 截取目标及足够的所属整体和相邻结构，以返回的 savedPath 作为 input_images，让生图集中在该局部，不把整张角色图交给生图只为转动一只脚或一侧手腕；记下截取的 [x,y]，对照时据此换算回原画布坐标。

补环绕结构的后段前，先在原图中找出前段在本体轮廓边缘消失的每一对端点，例如脚链上沿的翼尖与下沿的卷环各自绕到踝后，各对端点都需要对应的后段，不只补最明显的一圈；组说明只提供引导，后段的段数与范围以原图实际端点为准。

绘制后按以下方式自查：
- 同姿态生成图：朝向与姿态和原图相同，只睁开眼、张开嘴，或拨开、去掉遮挡。以 preview_svg 的 edge 模式整体对照形状：reference 指向生成图，referenceRegion 框选生成图中的对应部件；工具保持 SVG 原坐标，将生成裁片等比缩放并居中对齐。检查边缘、比例及结构一致性，眼角、眼睑、耳根等与原图共有的位置应当重合；referenceOffset 只在需要微调时填写，通常用默认值。
- 转面生成图：转头、转脚、转身得到的侧面或斜侧图，姿态与原图不同，整体边缘必然对不上。edge 对照时 referenceRegion 只框选与当前部件对应的那一段，例如被遮挡面所在的后环，只读取结构、宽度比例、走向和包裹关系；不要求边缘与当前姿态重合，不按它移动或拉伸新增形状。位置与端点以当前姿态的可见端点、本体轮廓和接缝为锚画回原坐标。后段两端须与前段端点衔接：宽度、走向与前段在本体边缘处的回绕边一致，端头伸入前段下方保留局部胶水余量，不留缝也不在前段外露出圆头；用 svg 独显和 blend 的局部放大逐个核对接口。
- 省略全部 reference 参数，用 blend 直接叠加到人物参考图，检查真实大小、位置、邻接和连接归属。crop 只裁剪最终查看窗口，可按局部检查需要填写。
- 用 svg 独显检查完整形体，局部放大核对补形、连接圆弧、接缝、开口和局部胶水余量。每次修改后重新完成适用的对照与独显，再提交结果。

原图负责可靠的可见轮廓、角色比例和位置，可见锚点用于定位；生成图中完整展开的结构提供不可见部分的形状依据。交付仍限当前部件的 SVG，最终跨部件的形状、颜色与细节协调由下游节点处理。

只补当前姿态下被遮挡的结构；真实连接的局部胶水余量由伸入侧承担，覆盖侧保持已有形状。交付仍为可编辑 SVG，在 note 中记录辅助图及其属于同姿态还是转面、自查依据和每处补全职责；无需新增时也须观察并说明。正式文件及其他组的合格形状保持原样。
