# 左侧内搭短袖补全

已补角色自身左侧、画面右侧的完整内搭衬衫短袖。源 SVG 与中断草稿均为空，新增一个可编辑闭合复合路径，以 evenodd 保留斜向椭圆袖口。画布仍为 1115×1410。

## 实体与依据

本片包含袖山、袖身、袖口近侧衣缘、袖内远侧回转衣料；不包含衬衫躯干、外套短袖、青色袖口、标识、人体或袖口封口面。纯衣服图中本袖整体被外套遮挡，不能据外套边界描成内搭袖。采用只读父稿中已登记的本袖完整路径，主要范围约 x742–866、y347–588；袖外边界与开口均直接沿用父稿，不扩张到父轮廓之外。

先查看完整纯衣服图、空源稿叠加及父稿独显，再通过内置 image_gen 生成并查看同姿态结构辅助图。第一张辅助图证明深色短袖及斜向袖口结构，但袖宽偏大，因此追加第二张，提供完整衣装参考和父稿袖片轮廓指引。第二张自然露出目标袖，保留整套衣装上下文与正面姿态，袖口确为真实开口。

第二张生成图的袖根仍被挪开的外套前片局部覆盖，外缘、袖口厚度及位置有少量生成漂移；因此这些像素不取代已确定的父稿袖根、实体外缘和开口。生成图只补充不可见结构理解，形状及坐标以已登记父稿为锚。



## 分界、搭接与运动

与 shirt_body 的分界沿约 (752,347) 至 (757,567) 的袖山至腋下接缝。袖根保留父稿已有的弧形伸入区，在衣身袖窿缝合边下形成保守搭接；中段搭接约数像素至十余像素，端部随接缝自然收束。衣身是覆盖侧，不改其形状，也不把本袖延伸成跨胸躯干衣料。没有为外套、标识或其他相邻物添加连接。

本袖全部位于外套左短袖及相邻外套前片之后。袖身近侧表面和袖口近侧衣缘位于左上臂之前；袖内远侧壁及后侧回转衣缘位于左上臂之后。近、远侧区域在开口两端约 (782,574)、(858,511) 连续回转，沿袖口内缘与两端转折划分深度区域。后侧衣料沿近侧衣料后自然延续，不填上臂、不封袖口。

整袖及前后回转衣料共同随左上臂旋转、弯曲、变形，袖根与 shirt_body 的左肩连接定位。作为一个逻辑 part 保留；后续深度规划使用多个区域，栅格 step01 再拆实际绘画层。本片不涉及领口、薄纱或独立袖口带。
