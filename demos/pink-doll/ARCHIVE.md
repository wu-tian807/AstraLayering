[清单](manifest.json)记录相对来源、大小与 SHA-256；复制文件已逐字节核对。文件名带 `-snapshot.png` 的两张预览直接提取自对应 KRA 的 `mergedimage.png`，清单注明出处。其余 PNG 与报告均保留源文件，没有重画或改写。

agent 日志、会话、逐次操作记录、提示词副本、脚本、缓存、运行标记、工作 KRA 与备份不收录。历史报告和 JSON 中的机器路径及未收录操作图引用按原文保留用于追溯；本目录是成果快照，不是会话恢复包。源任务仍保留在被 Git 忽略的 `.run/pink-doll/`，运行数据的中间文件已整理到对应步骤的 `workspace/`。
