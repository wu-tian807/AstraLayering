# 穿衣角色组装报告

交付画布为 **1254 × 1254**。右图来自正式 KRA 重开后的透明合成。 [Krita 工程](character-assembled.kra) · [透明 PNG](character-assembled.png)



## 衣装配准与局部修画

以画布左上角为原点，11 张衣片统一应用 **53% 等比缩放**，再平移 **向右 296 px、向下 258.5 px**。对照参考确认肩口、领线、腰带和裙摆后，在各自的绘画层内局部调整。胸衣与肩饰在躯干前，四张裙片在髋部前、手臂和手指后，前发及外露发尾继续压在衣装前。

| 位置 | 局部修画及复看 |
| --- | --- |
| 双肩带、领口与肩荷叶 | 调整发束内侧露出的肩带宽度，重画内侧包边。修顺白色领褶顶缘和胸衣领口的粉色包边。重画双肩荷叶外缘、末端回折和右侧回折的短折线，独显检查各道布边和内侧布面连贯。 [上身与双肩回折](inspection/02-neck-and-sleeves.png) |
| 腋下、腰带与裙腰 | 校正胸衣下口和腰带高度，续齐腰带下缘，接顺第一层裙腰的收褶。把裙腰下方仍盖在裙片前的皮肤用 `25 body` 子层中的原生透明度遮罩收起，关掉遮罩即可检查这段躯干。 [腰线及遮罩开关](inspection/03-waist-mask.png) |
| 裙侧、肘部、腕部和发尾 | 在第一、二层裙片上补画伸入前臂下方的搭量与侧边线，消除前臂和裙侧之间的细缝。放大查看肘、腕、掌指的连接，以及两侧前发从裙面伸出的发尖。 [两侧搭接及独显](inspection/04-arms-and-hair.png) |
| 四层裙片、下摆与双腿 | 微调各层落点及末层两翼，重画末层各瓣的软描边和转折高光。按参考在双肩荷叶下和裙摆下的五个人体绘画层上补暖调投影，原皮肤像素的透明度和外轮廓均通过逐像素核对。 [裙摆、露肤及裙片独显](inspection/05-skirt-and-hem.png) |

## 保存重开自检

- 正式 KRA 重开后有 71 个绘画层、7 个组和 6 张原生透明度遮罩。原素体节点和 11 张衣片均保有源 UUID。两份输入 KRA 与参考图的文件哈希同开工记录一致。
- 核对重开前后的图层树、绘画层像素、遮罩和合成。一张新增遮罩的实际作用范围为画布 `x=552–701、y=503–545`，位于腰带下的躯干层。遮罩关闭和开启均看过独显与合成，交付工程保存为开启。
- 重开后重新导出并核对透明 PNG。整图并排、各接点放大和衣片独显均已复看，未发现错位、漏肤、布边断线或缺口。11 张衣片在 alpha 阈值 8、48、128 下各为一个连通片。
