# left 可见脸缘描边

本步已交付源脸底轮廓、目标帧可见肤区轮廓与原坐标脸底参考。没有制作补全轮廓、形变或 trace。

## 坐标与参考

- 两个 SVG 均为 774×774，`viewBox="0 0 774 774"`，纯色填充闭合 path，透明背景、`stroke="none"`。
- 下文坐标均为特写 `(u,v)`；原画坐标为 `(319+u, -21+v)`。左右均指**画面左右**。
- 裁框依据：`nine-axis/step02_video/crop.json`。
- 源贴图：`nine-axis/step01_preparation/layers/0039-face__face_base.png`。
- `textureBounds=[600,301,217,241]`，从原始 `deformers.json` 中的 `face/face_base` 读取。先原尺寸放回 1376×2048 原画布，再按裁框裁出；贴图在特写中的偏移为 `(281,322)`。没有重新居中、缩放或使用形变后的坐标。
- 交付参考：`nine-axis/step04_angles/model/left/outline/source-face-reference.png`。已逐像素确认等于上述放回、裁切结果。
- 目标参考：`nine-axis/step03_frames/left.png`。对应原视频第 50 帧，时间 2.083333 秒。相邻第 48、52 帧仅帮助辨认发束和露肤；最终坐标始终取目标 PNG，没有对齐相邻帧或改变目标位置。

`source-face.svg` 描独立脸底的完整轮廓，包含原合成图里被头发盖住的额顶、额角和两侧。轮廓沿原始 alpha 的抗锯齿半覆盖边平滑描出，不以合成图的刘海切口截断脸底，也不把低 alpha 的像素毛边变成几何毛刺。source 的 25 段三次曲线已对独立参考检查。



## target 路径如何读

`target-face.svg` 中一个填色 path 包含两个闭合子路径：

1. 主肤区，从 `M 288.7100 362.3000` 开始。
2. 画面右侧发束间的独立肤色小窗，从 `M 443.4000 514.6500` 开始。它与主肤区之间仍保留头发，未桥接成一块。

下面的段号按各子路径的 `C`、`L` 命令从 1 开始计数，`M`、`Z` 不计。端点直接对应交付 SVG。`visible` 表示此处确有可见肤区交界；其中既有下颌边，也有头发切出的边，下一步还要分别判断，不能把所有 visible 都当成脸自身的外轮廓。`occluded` 仅用于三处发线汇合尖端的短闭合，不能作为隐藏脸形的依据。
