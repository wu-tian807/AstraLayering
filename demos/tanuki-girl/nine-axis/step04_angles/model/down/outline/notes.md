# down 脸缘描边

本步交付原画完整脸底轮廓和目标帧露肤区域的闭合描边。目标的刘海凹口、露肤尖角、两侧发尖下的短边均按画面保留；未补额顶、太阳穴或头发下的脸颊，未做形变或写 trace。

## 坐标与原画参考

两份 SVG 均为 774×774、`viewBox="0 0 774 774"`，透明背景、一个纯色闭合 path、`stroke="none"`。下表所有位置使用特写像素 `(u,v)`；左右均指画面左右。

裁框读取 `nine-axis/step02_video/crop.json`：`box={x:319,y:-21,size:774}`。特写点对应原画布 `(319+u,-21+v)`，没有重新居中、缩放或对齐。

原画脸底读取 `nine-axis/step01_preparation/layers/0039-face__face_base.png`。按 `nine-axis/step01_preparation/head_parts_manifest.json` 的 `textureBounds=[600,301,217,241]` 原尺寸放回 1376×2048 透明画布，再按上述 box 裁出 `source-face-reference.png`，完整保留原 RGBA。脸底的特写放置位置为 `(281,322)`。

`source-face.svg` 沿该完整脸底的 alpha 轮廓取边，包括原来被头发挡住的额顶和两侧；抗锯齿过渡按 alpha 127.5 的中线取边，极淡晕边仍保存在参考 PNG 中。已用该参考 PNG 做全图 blend 和 4 倍 edge 核对，未使用合成图的头发切口代替脸底。

目标参照 `nine-axis/step03_frames/down.png`，与本方向选定的第 50 帧对应。目标 SVG 的内部包含五官和腮红；这些内部颜色变化不作轮廓孔洞。

## 下一步使用

V5–V7 是本帧连续可见的下颌、下巴边界，应作为补全和形变的直接约束。其余 visible 段主要是皮肤与头发的实际遮挡交界；保留这些露肤位置、陡度、尖端和短回折，但补全脸底时不能把刘海凹口、鬓发尖回折当成真实脸底凹陷。

O1–O3 不提供额顶形状、脸宽或曲率证据。下一步可以在确实被头发盖住的区域补全，再写 trace；完整脸底的隐藏外缘应结合原画脸底与本帧可见证据决定。遮挡边外侧可扩展的依据分别是刘海、鬓发和中央发束的覆盖。下颌可见皮肤外侧的颈部、耳机、背景不属于这些可扩展区域。
