# up 可见脸缘描边记录

本步交付原画脸底完整轮廓和目标帧皮肤边界的闭合记录。目标中的刘海、鬓发接触边按可见交界描出；这些发束切出的凹口记录的是遮挡边界。头发下的额顶、太阳穴及完整颊形由下一步补全。

## 输入与坐标

- 源工程：`nine-axis/step01_preparation/character-nine-axis.kra`
- 源脸底：`nine-axis/step01_preparation/layers/0039-face__face_base.png`
- 图层位置依据：`nine-axis/step01_preparation/head_parts_manifest.json`
- 裁框依据：`nine-axis/step02_video/crop.json`
- 目标帧：`nine-axis/step03_frames/up.png`
- 视频：`nine-axis/step02_video/up.mp4`；目标为第 51 帧、2.125 秒。另查看第 49–53 帧确认窄口和发束遮挡关系，描边坐标始终以目标 PNG 为准。

两份 SVG 均为 774×774、`viewBox="0 0 774 774"`，透明背景、单个纯色闭合 path、`stroke="none"`。下文所有坐标都是特写坐标 `(u,v)`，对应原画布 `(319+u, -21+v)`；左右指画面左右。

`source-face-reference.png` 的制作：在 1376×2048 透明画布上，将 217×241 原脸底贴图按 `textureBounds=[600,301,217,241]` 原样放回，再裁出 `[319,-21,774,774]`。贴图左上角因此位于特写 `(281,322)`。没有重新居中、缩放或对齐。

`source-face.svg` 沿脸底完整 alpha 外缘，包括被刘海盖住的原画额顶。抗锯齿过渡以 alpha 中线定位，使用连续三次曲线；与提取边界的拟合 RMS 约 0.26 个特写像素。已用该参考图核对额顶、两侧及下巴。

## target-face.svg 逐段说明

从 `M (333.8,321.2)` 开始，按 SVG 的书写顺序遍历。`C1` 是第一条 `C`，依次到 `C33`；`Z` 回到同一个起点，没有额外长闭合线。曲线的控制点以 SVG 为准，表中的位置为端点和辨认标记。

`visible` 表示目标帧可见交界，其中“发接触边”是皮肤被头发切开的可见边，“脸外缘”是露出的下颊、下颌与下巴轮廓。`occluded` 仅用于三处刘海夹缝顶端的短帽状闭合：它们位于合拢发束的深色区域，不能当作已知额顶或脸形证据。
