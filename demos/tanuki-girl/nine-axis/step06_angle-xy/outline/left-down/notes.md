# left-down 可见脸缘描边

本步交付原画完整脸底轮廓与目标帧可见皮肤边界。目标上方及两侧的发束切口保留视频中的尖端、陡边和转折；只有三个约 1 像素的发根连接标为 `occluded`，未补额顶或头发下面的完整脸形。

## 坐标与参考

- 所有 SVG 均为透明背景、一个纯色闭合 path、`stroke="none"`，尺寸与 `viewBox` 均为 `774 × 774`。
- 裁框来自 `nine-axis/step02_video/crop.json`：`box = {x:319, y:-21, size:774}`。下表 `(u,v)` 均为特写坐标，原画布坐标为 `(319+u,-21+v)`。画面左、右均按观看方向称呼。
- 原画脸底读取 `nine-axis/step01_preparation/layers/0039-face__face_base.png`，对应 UUID `b59364ca-e52c-46dd-a5b9-c24f09b553ce`。按 `nine-axis/step01_preparation/head_parts_manifest.json` 的 `textureBounds=[600,301,217,241]` 原尺寸放回 `1376×2048` 透明画布，再按上述 box 裁出 reference；没有移动、缩放或重新居中。
- 目标直接对照 `nine-axis/step05_frames/left-down.png`。上游选帧记录为视频第 40 帧、`1.6666667 s`；本步沿所交付目标 PNG 描边。
- Source 沿完整导出脸底 alpha 的抗锯齿过渡中线（`127.5/255`）描出，保留原额顶、两颊、下颌和下巴；该 alpha 主体只有一个连通区域。27 段 cubic 对原 alpha 等值线的采样 RMS 偏差约 `0.106 px`，已用 reference 的 blend 和 4 倍 edge 核对。

## 供下一步补全与 trace 使用

22–24 是可见的脸自身下缘，应照此保留。其余 `visible` 段主要是头发切出来的皮肤交界；这些段的凹口和发尖是本步需要保留的图像证据，下一步再判断怎样在头发下面接成完整脸底。三个 `occluded` 连接仅是色块闭合位置，不应当作完整额缘的目标，也不能替代附近真实可见的皮肤段。眉、眼睫、腮红、内部发影线和颈部下方阴影均没有成为额外外轮廓。
