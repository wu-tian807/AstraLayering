# 可复用的角色绘画任务模板

以下是根据 suzuran.svg 分析整理的执行模板，不是作者原始提示词。适用于模型使用 SVG、画布或绘图工具进行多轮角色临摹；笔触尺度与颜色应随参考图和输出尺寸调整。

---

请根据提供的参考图绘制角色。目标是在保留造型与画风的同时，让形体、光照、材质和细节有明确层次。按以下过程实际制作并渲染检查；不要仅输出计划。

**开始前明确这些内容**

- 记录构图、头部及主要部件边界、眼位等关键点、主发束流向、遮挡顺序。
- 从参考图确定主要光源、焦点，以及肤色、头发、服饰和背景的颜色关系；不要给所有材质使用同一种渐变。
- 为部件使用稳定 ID，记录哪一层被哪一层遮挡。
- 识别哪些部位需要清楚的硬边，哪些适合软边或消失边。
- 以最终观看尺寸为判断标准。先区分必须保留的造型特征与可以概括的微纹理。

**分阶段推进**

1. 建立比例、轮廓和结构草图。此阶段不要用纹理遮掩形体错误。
2. 建立完整底色和主要亮暗面。关闭辅助草图与微细节时，主形体仍应可读。
3. 按材质增加有明确形状的色面与反射。头发先总量、主发束和流向，再加宽亮带、转折暗面及有限环境反射；布料用折面；毛绒先毛簇，再少量散毛。
4. 整理最终线条与边缘。接触、遮挡和重要转折可加强；受光侧及同色衔接可以减淡、断开或消失。线色与局部材质协调。若采用先线稿后上色的风格，上色后仍需进行这一轮整理。
5. 最后补焦点细节，如睫毛、虹膜高光、少量发丝、局部纹理。让细节跟随结构；不要把等距、等宽、等深的线均匀铺满所有区域。
6. 进行统一与减法：合并冲突色斑，减少重复暗边，清除多套轮廓、补丁接缝和没有结构作用的纹理。

**笔触规则**

- 每一笔应能说明职责：铺色、塑形、接触阴影、结构强调、材质或点睛。
- 不仅改变笔宽，也控制收尖、透明度、线色、边缘软硬与方向。
- 粗笔用于概括有意义的面；细笔用于选择性强调，不能代替主色面。
- 头发的主要光泽使用连续、随曲面转向和收窄的亮带；少量细亮线作为补充。颜色、透光和光泽强度以参考图为准。
- 保留宽阔、安静的区域，让复杂细节在焦点附近形成组织；不要求所有区域细节一样多。
- 使用 SVG 时：可变宽笔触用收尖的闭合路径，恒宽细线才使用普通 stroke；渐变、裁切和遮罩各自承担明确的局部作用。

**迭代与验收**

- 每一轮只解决一个主要问题，明确修改部件、预期效果与检查尺度。
- 已经确认的构图、眼位和主轮廓应保留；确有结构错误时明确修正并重新检查依赖部分。
- 每个主要阶段保存实际图像预览。看缩略图检查构图和大明暗，看目标尺寸检查表情与材质，放大检查边缘与接缝。
- 体积扁时先改大明暗；拥挤时先减少相互竞争的线和色块；造型不准时返回结构阶段。不要自动把“更好”解释为“添加更多细节”。
- 每次只列最影响画面的少量问题，并按视觉影响排序；解决后再决定是否需要更多细节。
- 输出成图、可编辑文件与简短阶段记录。只有检查过的项目才声称通过；看不到原始参考或缺少渲染能力时，明确说明对应限制。

**需要独立分层或后续动画时追加**

- 从开始就使用语义部件与完整遮挡补全，不先做扁平整图再拆可见区域。
- 如任务要求严格 bottom-up：先完成全局规划，再从后到前制作完整部件；每个部件内部按“结构、底色、大明暗、材质、最终线与细节”的顺序推进。
- 本部件的色面、线条和材质细节归属于本部件，随之一起显隐与移动。
- 跨部件接触阴影等效果单独记录依赖关系；隐藏相关部件时，避免留下不成立的投影或残片，并遵循指定图层契约。
- 在检查整图之外检查单层独显、隐藏前景后的补全、跨层效果与缩放结果。

---

建议把上述模板与实际参考图一起使用。需要继续精修时，用具体局部指令，例如：

> 保留已确认的轮廓和眼位。本轮只整理刘海的三个主要发束：让每束的亮面连续，明确卷曲处的窄暗面，弱化同一边缘上的重复描边。渲染后对照目标显示尺寸和缩略图，确认发束没有被细丝切碎，再决定是否补发丝。
