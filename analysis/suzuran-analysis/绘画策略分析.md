# 从 suzuran.svg 提取的绘画策略

分析对象：[suzuran.svg](./source.svg)。本文依据实际图像、SVG 元素和浏览器中的描边对照实验；没有作者对话、历史版本或原始临摹参考图。

能提取的是成品中的组织方法，不能据此还原原始提示词、真实画笔设置、创作时间顺序或临摹准确度。文件标题中的“手工”和版本号是文件自述，不是独立验证过的制作记录。

## 1. 最关键的发现

这张图把任务分配给不同尺度的形状：大色面负责体积，发束和褶皱负责组织，局部强暗部负责遮挡，少量轻重不同的线负责强调。细节大多服从已有形体与色调，因此可以很多而不显得散乱。

“更换画笔粗细”只是其中一部分。更有用的控制变量是：笔触用途、覆盖宽度、沿程收尖、颜色、透明度、边缘软硬、方向、所在层和局部密度。

### 做过的显示对照

选取后发、刘海、两侧前发等七个头发组，找到 261 个自身或继承了描边的图元，进行以下比较：

1. 保留原图。
2. 仅把这些图元的 `stroke` 设为 `none`。
3. 保留相同几何，把这些描边统一设为宽度 3 的深褐色，保留图元原有透明度。

浏览器中可见：第二种状态仍保留了大量体积与光泽，但轮廓和分束的强调减弱；第三种状态中发线开始相互竞争，局部出现很重的平行线簇。

边界：第二种状态仍保留用填充画出的线状暗边，也保留其他部件；第三种同时改变颜色、粗细以及渐变描边自身的颜色/透明度变化。因此，它是展示表达差异的定性对照，不是“全部去线稿”，也不是仅检验线宽的单变量实验。

## 2. 这张图为什么成立

### 2.1 先组织发束，再解释发丝

[刘海主体](./source.svg#L2758) 有 foundation、plates、volume、curved planes、light volume 等层次。主发束是完整的曲面形状，很多高光也是沿发束延伸的闭合色带。

可迁移的顺序是：头发总轮廓 → 主发束的流向和前后关系 → 每束的受光面与暗面 → 局部纤维。细丝依附发束，不负责拼出发束。

相邻发束应有长短、宽窄和间距变化，但共享合理的生长方向。随机性只在这个结构里面出现。规则等距会像梳齿，完全随机会像乱草。

### 2.2 光泽是带状反射与曲面转折的配合

[右侧卷发的局部表面](./source.svg#L3162) 在同一组里包含：连续底色、淡粉色覆盖、卷边暗面，以及宽 4.1、1.65、1.25 到 0.56 等不同尺度的亮边和细丝。

这个局部说明了光泽可以怎样构造：

- 用大面积、相互连贯的色面建立圆润的发束。
- 用顺着曲面变化的宽亮带建立主要反射。
- 用窄暗面解释卷起、转向和叠压。
- 用更窄、会消失的亮线补充表面反射。
- 在发梢和靠近脸部的位置引入浅粉、暖色与有限的透明变化。

最后两项是这幅金发、暖光、柔和画风的处理，不能推广为所有发色都应有粉色发梢。这里可确认的是艺术模拟，也不代表真实头发的光学仿真。

### 2.3 所谓粗笔，往往是一块被设计过的形状

毛绒耳部的楔形亮块、蕾丝折面、前发上的宽亮带，并不都由较大的 `stroke-width` 形成。很多直接使用闭合填充路径：中段宽，末端细，边缘局部凹凸，有时配合微小柔化。

因此，给 SVG 模型说“用粗笔刷”信息不足。应指定“沿这个发束画一条先宽后窄的亮面，保持一侧明确、另一侧柔和，在末端消失”。这同时说明了形状、方向、宽度变化与边缘。

粗笔的价值在于一笔概括一个有意义的面，而不是把细节线等比例放大。

### 2.4 轮廓的强弱服务于前后关系

[最后的卷发轮廓](./source.svg#L3162) 引用 `tipOutline48`，颜色和透明度沿路径变化，末端的 stop-opacity 为 0。它提供的是一段会消隐的边界，而非完整的封闭黑圈。

通用原则：

- 遮挡接触、关键转折和焦点附近，可以更清楚、更深。
- 受光边与相邻同色面，可以变浅、断开或消失。
- 内部纤维通常弱于承担结构的边界。
- 线色来自局部材质和环境色，不必统一纯黑。

“外轮廓永远最粗”也不是普遍规则：这幅图里眼睑与睫毛的局部深色，比许多受光头发外缘更强。

### 2.5 复杂度被分配，而不是平均铺开

脸部保留大面积平静的浅色，细小的鼻口不抢眼；眼睑、虹膜和刘海接触处集中更强的对比。毛绒与背景可以有很多笔触，但大多受相近色调、局部低对比或柔边控制。

可使用一个不作数值计算的诊断思路：当某个区域同时有很多边缘、很强对比、很多相反方向的线，它最容易抢走注意力。

需要保留的不是“全图细节越少越好”，而是“某些地方复杂，某些地方允许安静”。脸颊排线、局部平行发丝也是该图的风格特征，不应因为有重复就机械删除；应该检查它们是否压过表情。

### 2.6 软硬边按材质、景深和结构分工

文件中的 `soft` 是较宽的模糊，`silkEdge38` 的模糊标准差只有 0.42，`silkPigment38` 为 1.4；毛绒的 `furEdge31` 还使用小幅度位移与轻柔化。

含义不是“给所有东西套模糊”，而是：背景、浅薄色层、主要结构边缘，分别采用不同的处理。硬边保持造型，软边连接色面，消失边把物体融入光线。少了硬边会糊，全部硬边会碎。

## 3. 能反推到什么程度的作画流程

从组的用途和命名，可提出一个合理的重建流程：先确立构图与遮挡，建立后景、头发和脸部基础形体，再不断修订眼睛、刘海分束、发根投影、左右前发体积，最后加强透光、连续亮面和局部收尖轮廓。

这不是作者原始时间线。SVG 的 DOM 顺序表示叠放关系；较旧命名的组里也可能包含较新版本的路径和渐变，因此不能删除所有“v38 以后”的组并宣称还原了 v37。

真正值得复用的是以下分工：

| 阶段 | 当前要解决的问题 | 进入下一阶段的条件 |
|---|---|---|
| 观察与规划 | 构图、关键点、主光、材质、遮挡、焦点 | 眼位、头型、主发束和大色块关系清楚 |
| 结构草图 | 比例、轮廓、曲线流向 | 缩小后仍能读出姿态和角色特征 |
| 底色与大明暗 | 完整实体、主要亮暗块、前后分离 | 暂不依赖微小纹理，也能读出体积 |
| 材质色面 | 光泽带、毛簇、布料折面、反射色 | 不同材质的表达有差异，主光仍一致 |
| 最终边缘与线 | 遮挡、线宽、线色、软硬和消隐 | 没有多套相互冲突的轮廓或满图同强度线条 |
| 焦点细节 | 睫毛、瞳孔高光、局部发丝和纹理 | 细节支持焦点，没有把大形切碎 |
| 统一与减法 | 清除重复暗边、割裂色斑、过密纹理 | 整图、小图和局部都成立 |

“上色和线稿分阶段”应理解为分开解决问题，而不是唯一正确的固定顺序。结构草图通常在前；线稿型风格可以先完成大部分线稿再上色，厚涂型风格可以先色块后提线。无论哪一种，都应把结构探索、材质塑造和最终边缘整理区分开，并在上色后复核线条。

## 4. 让后续模型更稳定的任务设计

### 4.1 用可执行的约束替代审美形容词

“精细、油润、漂亮、不要乱”无法确定模型下一笔该做什么。更有效的指令示例是：

> 保留已经确定的刘海轮廓和眼位。本轮只整理三个主要发束的明暗面：每束建立连续亮带与相邻转折暗面，亮带随曲面收窄；发丝在亮带两端逐渐消失。渲染后先看缩略图，若主发束被细线切碎，先减少重复线再增加细节。

这是一段由分析提炼的示例指令，不是作者原话。

### 4.2 为每种笔触指定职责

| 笔触职责 | 几何与边缘 | 适用位置 |
|---|---|---|
| 铺色 | 完整闭合形状，清晰大轮廓 | 肤色、头发主体、衣物主体 |
| 塑形 | 宽窄变化的色带或折面，一侧可软一侧可硬 | 发束转折、鼻部、衣褶 |
| 接触与投影 | 面积受控，靠接触点更实，远离后可软 | 发根、刘海投到脸上的阴影、层间叠压 |
| 结构强调 | 选择性深色线或收尖暗形 | 眼睑、发束边界、重要转折 |
| 材质与空气感 | 弱对比、间断、逐渐消失 | 少量发丝、毛绒、反光 |
| 焦点点睛 | 少量较强、位置明确的笔触 | 睫毛、虹膜高光、局部亮点 |

对 SVG：恒宽细线可用 stroke；粗细变化的笔触优先用收尖闭合形；渐变控制色面与沿程衰减；clip 保证颜色属于自身部件；mask 处理有限透明度。若主要体积还没建立，不应依赖密集纹理和复杂滤镜来掩盖它。

### 4.3 每轮只推进一个视觉目标

给模型稳定的部件 ID、共享颜色角色和主发束曲线，让修改发生在已有结构内。每轮明确：修改范围、当前问题、预期画面变化、复核尺度。保存可回退版本，对照实际渲染，不靠阅读代码想象画面。

如果眼位或轮廓错了，退回结构阶段；如果体积扁，先修大明暗；如果拥挤，先降低重复边缘和局部对比；如果像塑料，检查光泽形状、软硬边和粗细变化。不要对所有失败都用“继续加细节”处理。

### 4.4 采用多尺度验收

- 缩略图：检查轮廓、构图、大明暗和焦点。此时不应主要被纹理吸引。
- 目标显示尺寸：检查表情、材质和线条轻重。这个尺度决定实际观看体验。
- 放大局部：检查路径毛刺、接缝、重叠和遮挡。不要为了放大效果而破坏正常尺寸。
- 单层与去细节视图：前者检查部件归属，后者检查大形是否独立成立。隐藏微细节不能移除不可替代的结构信息。

允许用模糊/灰度辅助检查大关系，但不应把“所有区域灰度必须分离”等规则强加给高调、低对比的风格。

### 4.5 把阶段交付作为稳定性机制

模型在每次调用中同时解决构图、准确轮廓、完整遮挡补全、全部纹理和最终文件结构，容易顾此失彼。分阶段的价值在于降低每轮需要共同维持的变量数。

比较可靠的交付单位是：“规划记录 + 当前 SVG + 本轮渲染 + 少量下一轮问题”。这比依赖一次超长提示词更容易定位失败，但不能保证任何模型一次就达到该成图水平。

## 5. 对 AstraLayering 分层任务的额外启示

项目当前提示词对语义分层和遮挡完整性要求很充分，但对色面组织、边缘层级、材质笔触和阶段验收的描述较少。可以追加本文的视觉方法；无需把源文件的 112 个组原样当作通用模板。

这里要区分三种次序：

1. 叠放次序：哪一个部件挡住哪一个部件。
2. 部件制作次序：严格 bottom-up 时，从后到前完整制作每个部件。
3. 部件内部的绘画次序：结构 → 底色 → 大明暗 → 材质 → 最终线与细节。

如果要求“本层完整制作后才开始上一层”，可以先建立全局比例、光照、配色和遮挡规划，再让每个部件内部都走一遍上述绘画阶段。规划不等于先画完整成图再拆层。也不应把“分阶段”误解成把所有物体的底色和所有物体的线稿永久分成两张大图层。

跨部件投影需显式管理。例如刘海投在脸上的阴影同时依赖刘海和脸：可作为独立接触效果，记录投影者与承受者，二者任一关闭时效果一起关闭；具体存放方式还需符合目标图层契约。否则静态画面漂亮，关闭刘海后却在脸上留下阴影残片。

这份 SVG 的整体绘画效果可以作为研究样本，但文件分组本身不能证明隐藏部件后的完整性，也不能直接证明适合动画。
