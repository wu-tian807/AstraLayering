# 角色工作台检查

自动检查位于 `web/tests/`，在仓库根目录执行：

```sh
pnpm check:web
pnpm test:web
```

## 覆盖内容

| 功能 | 检查内容 |
| --- | --- |
| 项目加载 | 最新 KRA、法线／深度、阴影与累计九轴模型，文件更新和缺失状态 |
| 图层编辑 | 分组、显隐、不透明度、混合方式、剪贴链、蒙版与撤销／还原 |
| 头部九轴 | 三种预览组合、独立方向范围、关键形、父级变形、裁切及纹理刷新 |
| 光照与物理 | 原画／贴图对照、光源参数、物理绑定、扰动与复位 |
| 保存与会话 | revision 冲突、文件边界、临时文档关闭与源文件保持 |

## 实际画稿检查

使用现有项目打开角色工作台，核对整图、图层和各组合的方向。脸＋五官应支持已完成的九轴；头发、头饰按实际制作范围显示，当前流程只制作左右。来回切换组合，再保存上游 KRA 并更新项目，确认纹理与角度范围一起刷新。

图层与蒙版涉及原生像素时，使用已配置的 Krita 合成服务；检查独立实例关闭、源 KRA 保持和还原像素。浏览器检查同时记录页面及 WebGL 错误。软件 GPU 的检查用于核对渲染结果，设备性能另行测量。

当前操作见[工作台说明](../README.md)，原生合成配置见[Linux 配置](../README.md#原生合成服务配置linux)。
