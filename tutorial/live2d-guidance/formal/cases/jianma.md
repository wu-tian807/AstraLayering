# Jianma：从光影到嘴部的实战记录

记录日期 2026-10-20。皮套来源为本仓库 `demos/jianma-assembled`，初始导入版本 `99f47f813eb48920cbf5c2a7f1430190346c22fc`；工作台实现快照与原研究入口见[来源](../sources/README.md)。

这是一次正面二维制作试验。下面分开记录用户认可的方法、已完成的功能和仍未通过的美术，避免把可运行样片直接当成成品规范。

## 1. 实践中留下的主要取舍

| 阶段 | 发现与用户反馈 | 最终保留的经验 |
| --- | --- | --- |
| 法线打光起步 | 光过强，脸发白，有立体布偶感 | 降低重复提亮，保护原画浅色，控制法线起伏与光比 |
| 光源方向与风格 | 用户纠正为右中光；一度偏好连续柔光，后来希望二分更可读 | 方向、明暗差、边缘宽度分开调，保留柔光与二分预设 |
| 深度投影 | 开始检验刘海／脸、身体与衣料的层间阴影 | 单独查看投影遮罩；只减主光，保留环境光与单视角限制 |
| 摆动物理 | 前侧发整片晃动不自然，贴头处应固定 | 固定区、平滑过渡、自由端弯曲与分组重新细化 |
| 预览交互 | 用户要同一页面；选中扰动后悬停施力；默认进入移动 | 控制页签独立，人物预览和物理系统共用；工具门槛作用于输入 |
| 画质 | 一开扰动画质明显降低，不接受皮套降清晰度 | 恢复所有缓冲原尺寸，通过缓存、图集和批量绘制减少工作 |
| 初版果冻 | 像固定弹簧，需要更慢、更多次回弹 | 主位移与形变分级，平滑限幅保留动量 |
| 眼部 | 先不明显，后来只有跟随仍不够 | 眼眶先稳定，虹膜、瞳孔、高光和睫毛独立形变与相位 |
| 胸部 | 视频启发两侧挤压、上缘固定、聚拢与延迟 | 优化后用户反馈基本可以；作为正面局部方法保留 |
| 嘴部 | 需要清晰的必做／选做清单；猫嘴等未必需要重绘 | 稳定 S/P/F 编号，依据原图与角色用途选项，先试形变 |
| 嘴部近看 | 白牙和红唇关系异常；隐藏上牙后白块仍在 | 用户判定原图裸露牙齿被错误归入上唇，素材语义检查先于网格绑定 |

## 2. 光影沿革与可复现参数

首次深度投影提交 `db8f7c0cc222bf5f1b81550c63a5a8d10844c3ae` 只增加投影控制与查询，保留之前的右中连续柔光基础。柔化与亮部保护早于该提交；之后又有合成精度、闭眼数据归属与二分可读性的独立修正。不能把整个视觉变化归因于“加深度图就换了一套光照”。

当前样例默认参数：

| 参数 | 值 | 含义 |
| --- | --- | --- |
| 方位 / 仰角 | 52° / 0° | 本坐标约定的画面右中光 |
| 主光 / 环境光 | 0.35 / 0.65 | 保守提亮与暗部基线 |
| 二分阈值 / 过渡 | 0.46 / 0.045 | 当前“清晰二分”分区 |
| 阴影深浅 / 总影响量 | 0.72 / 0.72 | 提高可读性同时保留原画 |
| 法线幅度 / 平滑 | 0.85 / 2 | 平滑以原图像素为尺度 |
| 亮部保护 | 0.9 | 抑制浅色再次过曝 |
| 投影强度 / 深度尺度 / 柔和度 | 0.65 / 0.35 / 3 | 与基础二分控制分离 |
| 主光色 / 暗部色 | `#fff8f0` / `#c1bdd0` | 当前角色调色样例 |

这些是该皮套与该实现的预设，不是所有人物的通用答案。原图中的明暗仍存在，当前不是纯反照率素材。

## 3. 嘴部选择与素材

基础七项全部属于制作范围。首批选项固定为 S01 小圆口、S02 轻嘟嘴、S03 猫嘴、F03 短直吐舌、P03 收拢／展宽、P04 特色强度、P05 轻微不对称。F01 虎牙明确不启用：原图没有明确虎牙，不能因为技术能做就添加身份特征。

| 条件项 | 本角色判断 |
| --- | --- |
| S01 圆口 | 小到中等 O 口，适合疑惑与惊讶；现有圆润张口适合先变形 |
| S02 嘟嘴 | 轻微前噘，适合不满、逗趣；保留薄唇画法 |
| S03 猫嘴 | 弱到中等 ω，服务得意与调侃；默认仍回原画 |
| S04 波浪嘴 | 后续候选，柔和线条与委屈表现相容，未列首批 |
| S05–S08 | 暂不推荐；强折线、三角、方口、叉号与当前唇部画法差异较大且无明确需求 |
| F02 扩展 | 现有牙齿基础遮挡必做；咬紧牙齿另列候选 |
| F03 扩展 | 侧摆、卷舌、舔唇未选择；不能用口内舌层代替这些能力 |
| F04 / F05 | 无新装饰或口中物品需求；保留原有颜色的正确归属与随动 |
| F06 / P06 / P07 | 基础口周衔接必做；独立鼓腮、大下颌、嘴整体偏移暂缓 |

角色设定与用户取舍决定这些选择；不以成年或柔和画风为由禁止所有大表情，也不把“暂不推荐”写成“技术上不可行”。

当前原始裁片：

| ID | 当前层名 | 尺寸 | 检查结论 |
| --- | --- | --- | --- |
| body-66 | 口腔 | 19×14 | 口内层 |
| body-67 | 舌头 | 16×9 | 有口内素材，不证明外伸完整性 |
| body-68 | 下牙 | 14×3 | 小尺寸，藏露和形体需检查 |
| body-69 | 上牙 | 17×6 | 独立层存在，但不代表上牙像素已分干净 |
| body-70 | 下唇 | 20×10 | 与上唇闭合关系需检查 |
| body-71 | 上唇 | 19×10 | 含用户指出应属上牙的亮白像素；不能全层当唇 |
| body-49 | 脸底 | 102×138 | 嘴下方淡线在源图中存在，需检查覆盖与残影 |

整图为 1024×1536。这些是原始裁片尺寸，不是本轮预览压缩。24 种嘴型的原尺寸对照揭示了闭嘴／猫嘴唇线偏厚、吐舌边缘模糊和上牙归属问题；没有通过放大伪造高精度细节。

用户最后要求嘴部先保留现状，转入教程整理。因此本次不移动牙像素、不调嘴型，也不把以前“白块可能是高光”的假设继续作为结论。修复前，嘴部状态是**试演功能已实现，牙唇语义和美术待修**。

## 5. 专业工作台的摆动物理更新（2026-10-24）

独立 `all` 工作流已完成三步并生成正式 `physics.json`：40 个启用组件覆盖衣料、六组自由头发、冠带及耳／腰／踝挂件，贴头和真实支撑区保持固定，最大形变约束落盘。新配置已经导入原 Jianma 项目，物理、光照、法线、深度和 6 组贴图投影在同一画布工作。选中组件只决定编辑对象；默认移动不会悬停施力，选择扰动后无需点击即可影响范围内其他组件。

九组各 960 步的数值和 1,101 张当前版本选帧通过正式复核；同名同目录恢复跳过已完成步骤并正常退出。原纹理 1024×1536 保留，原衣物参考和此前失败证据留档。部分袖片轻扫响应很细微，内裙的六次孤立回退及右袖筒的约束介入均如实保留；人工自然度确认仍待实际连续体验。配方与证据入口见 [13 的正式交付记录](../13-secondary-physics-solver.md#revision07-正式工作流与同页交付)。
