## 制作与观察

先从本角色视频选择关键帧，确定可见轮廓和五官位置，再根据结构延续被遮挡部分。教程和其他模型用于理解隐藏形态；当前角色的可见画面决定目标。

前发、侧发和后发共同构成头部体积。后发常以小幅运动和露出隐藏发面承担转头；发根保留完整覆盖，连接处藏入相邻发面。带头饰的角色结合最终组合判断头顶与遮挡，连续检查中间姿态。

转头先制作部件的基准位置、朝向与透视，保留固有形状。后续摆动物理在此基础上增加响应，挂点随承载部件运动；方法见[组件物理](../10-component-physics-authoring.md)和[摆动物理工作流](../11-secondary-physics-workflow.md)。
