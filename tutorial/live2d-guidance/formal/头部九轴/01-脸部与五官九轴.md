# 脸部与五官九轴

来源：B 站铁锭 Ferrum《Live2D Cubism Tutorial No.004 ④ 五官九轴》，用户 2026-10-30 提供，见 [sources/face-nine-axis.mp4](sources/face-nine-axis.mp4)。讲解约 13.5 分钟，之后是无讲解的头发、发饰制作。本页只整理脸和五官（不含头发）。live2d-maker 的 `nine-axis` 的 `step04_angles`（left 方向的脸部＋双耳透视形变，[提示词](../../../../.agents/skills/live2d-maker/knowledge/head-nine-axis/step04_angles/prompts/groups/left/方向任务.md)）按本页做角度 X。

## 制作顺序

1. 用脸底和线稿建脸部 XY 变形器；五官是否挂在它下面需看实际层级，教程面板中眉眼、嘴、鼻的 XY 与 FaceXY 并列。
2. 做脸的 X：注意转面一侧的形状（三峰三谷）。做完一侧再反转。
3. 先做眉、眼、腮红一组。关掉鼻子和嘴，给这三类部件建一个变形器。
4. 做嘴。
5. 做鼻子。嘴定好后，鼻子就容易定位。
6. 除耳朵外，对五官和脸型整体微调。

总原则是**大造型小细节**：父变形器决定位置、造型和透视，子变形器只补父级做不到的细节。做一个五官时，要同时看它和其他五官、脸型的关系，不对就回头调整别的。

其他要点：

- **只看五官**：做嘴时，可以关掉除眉眼腮和嘴之外的头部图层，单独对比两者的关系。脸型可能还不对，会干扰透视判断 [10:39]。
- **Y 轴**：重点不在透视，而在距离关系。低头时眉眼距离缩小，抬头时增大 [07:12]。嘴低头变扁，抬头变高 [10:34]。鼻子低头更靠近嘴，抬头时跟着嘴一起动 [11:39]。
- **斜切（四角合成）**：建议手动做，不用自带斜切。不碰中间手柄，留作中轴参考。斜切后整体上下微移，过渡会更圆滑。静态轴始终以画面中心为准保持透视 [08:02–09:37]。
- **检查**：反转后反复拖动参数，看过渡是否流畅、是否沿一条好看的弧线 [04:45、06:59]。

## 变形器层级（看教程变形器面板，2026-11-03）

讲解里说把其他部件“放进脸 XY”，但面板显示（03:35、06:12、08:00、10:10、11:30、14:00、17:00）五官组并不在 FaceXY 里，而是与它**并列**：

- 根部有四个并列的 XY 变形器：FaceXY（脸）、BEC_XY（眉眼腮）、NoseXY（鼻）、MouthXY（嘴）。
- FaceXY 里有 FaceLine、FaceMask，还有 FaceShadowXY 和 FaceLineMaskXY 两个子变形器。FaceShadowXY 里是 FaceBaseColor，以及装着 FaceShadow 的 ShadowXY；FaceLineMaskXY 里是 FaceLine_Mask。
- BEC_XY 直接装眉、泪、睫毛、眼白、眼珠、高光的图形网格。
- 头发同理，如 FrontHair2XY 下有 XL、XR。

[眼睛拆分指南](../../../live2d-tutorial-text/3.眼睛拆分和制作指南.txt)第 83 行补充：眼珠 X/Y 视情况可以把所有眼内部件放进同一个变形器。开眼闭眼由轮廓部件做，眼白作蒙版。

本项目的 version 2 把无贴图的 `deformers` 与 `parts` 分开，`parent` 决定实际形变层级，`group` 仍只是名称。层级由 agent 根据角色与预览结果建立，不预设解剖分组；部件保留局部网格，父级不足时可微调、增加子 Warp 或改挂。脖子从首次导入就进入完整预览，保持固定，不挂入头部 Warp。接缝先检查脖子顶端补足、脸底遮盖与下颌线的分层／裁切，不能用拉长脖子修复。

## 耳朵的随动与遮挡

教程的微调明确跳过耳朵。耳朵整体跟随父级，只做平移和横向透视缩放，不扭曲形状。近侧耳保持原形，按父级在贴脸耳根处的位移跟随，始终贴着脸缘；不按头侧角度单独旋转，否则脸缘比耳朵移得多，耳朵会离开脸。远侧耳（转离观众的一侧）随头部整体转到脑后，绘制顺序在脸底之下，由脸遮挡，模拟真实的遮挡关系；不压扁、不扭曲，也不用透明度隐藏。角度制作保持原有不透明度，用形变和绘画顺序表达耳部露出。
