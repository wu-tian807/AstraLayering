## 本目录采用的原则

1. **先确认像素的语义，再决定它随谁运动。** 图层叫“上唇”不证明其中所有像素都是唇。白牙、眼白、皮肤、高光、阴影必须对照原图确认。
2. **物理输出只是驱动力，作者形变决定好不好看。** 根部、支撑区、局部压缩与遮挡不由一个弹簧参数自动解决。
3. **颜色、法线、深度、遮罩与选取共享最终形变。** 方向数据额外做正确变换；隐藏表面和跨层前后关系另有边界。
4. **先保证原画身份与闭合边界，再做夸张和余弹。** 特色选项按角色需要启用；没有虎牙的角色不强加虎牙。
5. **看极值，也看全过程。** 原图、微张、闭合、反转、回弹尾段和真实组合都有不同失败方式。
6. **保持原图精度。** 增加顶点不能补出原图不存在的绘画细节；运行中降采样也不能用作正式画质的默认补偿。

## 如何读取结论的状态

| 状态 | 含义 |
| --- | --- |
| 正式方法 | 本轮采用的制作原则或明确的角色判断规则，可进入工作流 |
| 实战验证 | 已在所记版本、姿态与参数范围检查；不能外推为所有角色或全部九轴保证 |
| 条件目录 | 定义与选择方法已经明确，具体角色仍需制作和验收；如叉号嘴、舔唇 |
| 推导／待验证 | 技术上有依据，尚未在本轮完整制作；如完整九轴地图插值、多层几何投影 |
| 已知反例 | 已发现的问题，不能因为功能可运行而登记美术验收通过 |

本目录是正式方法的维护入口。外层资料继续作为原始研究参考，不因被链接就自动升格。后续更新要说明适用角色、实际检查范围和被替代的判断；保留来源，不把后来的结论倒写成“视频已完整证明”。
